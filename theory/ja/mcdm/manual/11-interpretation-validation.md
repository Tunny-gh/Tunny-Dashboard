# 第11章 個体選択結果の解釈と検証

## ランキング結果の読み方

MCDMのランキングは、評価基準、重み、正規化方式、計算手法に基づいて得られる相対的な順位です。ランキングは意思決定を支援する情報であり、単独で最終結論を保証するものではありません。

ランキングを見るときは、まず次の点を確認します。

| 確認項目 | 内容 |
| --- | --- |
| 順位 | どの代替案が上位・下位にあるか。 |
| スコア差 | 上位案同士の差が十分に大きいか。 |
| 寄与基準 | どの評価基準が順位に影響しているか。 |
| 前提条件 | 使用した重み、正規化方式、評価方向は何か。 |
| 制約条件 | 上位案が実務上の必須条件を満たしているか。 |

例えば、1位と2位のスコア差が非常に小さい場合、順位だけを強調するのは適切ではありません。この場合は、同等の候補として扱う、追加評価を行う、または感度分析で順位の安定性を確認します。

また、スコアが高い理由を評価基準ごとに分解して確認することも重要です。総合スコアだけを見ると、ある代替案がどの観点で優れているのか、どの観点で弱いのかが分かりません。

## 1位をそのまま選ばない場合

多目的最適化結果の個体選択では、MCDMランキングの1位を機械的に採用しない方がよい場合があります。MCDMは価値判断を反映したランキングを作りますが、最終採用では制約余裕、実装可能性、再現性、関係者の受容性も確認する必要があります。

1位をそのまま選ばない代表的な状況は次のとおりです。

| 状況 | 対応 |
| --- | --- |
| 1位と2位のスコア差が小さい | 同等候補として扱い、追加比較する |
| 1位が制約ギリギリ | 制約余裕の大きい上位候補も確認する |
| 1位が極端解 | バランス解や膝点も候補に残す |
| 重み変更で順位が大きく変わる | 複数シナリオで安定する個体を確認する |
| 未評価の実務リスクがある | 最終判断前に追加評価する |

このような場合、MCDMランキングは「採用個体を一つに決める結果」ではなく、「詳細確認すべき候補を絞る結果」として扱います。

## 感度分析

感度分析は、重みや評価値を変化させたときに、ランキング結果がどの程度変わるかを確認する分析です。MCDMでは重みや正規化方式が結果に影響するため、感度分析は結果の信頼性を確認する重要な工程です。

代表的な感度分析は次のとおりです。

| 方法 | 説明 |
| --- | --- |
| 重み変更 | 特定の評価基準の重みを上下させて順位変化を見る。 |
| 等重み比較 | 等重みの結果と比較し、重み設定の影響を見る。 |
| 手法比較 | TOPSIS、VIKOR、WSMなど複数手法で順位を比較する。 |
| 正規化方式比較 | Min-Max正規化とベクトル正規化などを比較する。 |
| 評価基準除外 | 特定の基準を除外した場合の順位変化を見る。 |

感度分析で確認すべき主な観点は、上位候補の安定性です。重みを少し変えただけで1位が頻繁に変わる場合、そのランキングは不安定です。一方で、重みや手法を変えても同じ候補が上位に残る場合、その候補は比較的安定した選択肢と考えられます。

## 重み変更による影響確認

重みは意思決定者の価値判断を表すため、MCDMの結果に大きな影響を与えます。重み変更による影響確認では、重みを意図的に変化させ、ランキングがどのように変わるかを調べます。

確認例は次のとおりです。

- 最重要基準の重みを10%増減させる
- コスト重視、性能重視、リスク重視の3パターンを比較する
- 専門家判断の重みとエントロピー重みを比較する
- 上位2案の順位が入れ替わる重みの範囲を確認する
- 特定の基準の重みを0にして影響を確認する

重み変更の結果は、次のように整理すると説明しやすくなります。

| シナリオ | 重みの特徴 | 1位 | 備考 |
| --- | --- | --- | --- |
| 基準設定 | 通常の重み | A | 総合バランスが良い |
| コスト重視 | コスト重みを増加 | C | 低コスト案が上位 |
| 性能重視 | 性能重みを増加 | B | 高性能案が上位 |
| リスク重視 | リスク重みを増加 | A | 低リスク案が維持 |

このように、重み変更による順位変化を示すことで、最終判断がどの価値判断に依存しているかを説明できます。

## 外れ値・バイアスの確認

MCDMの結果は、入力データの品質に依存します。外れ値、欠損値、評価基準の偏り、主観評価のばらつきがあると、ランキング結果が歪む可能性があります。

確認すべき代表的な問題は次のとおりです。

| 問題 | 影響 | 対応 |
| --- | --- | --- |
| 外れ値 | 正規化結果や距離計算に強く影響する | 外れ値の理由を確認し、除外・補正・別分析を検討する |
| 欠損値 | 比較対象が不完全になる | 補完、除外、または評価不能として扱う |
| 評価基準の重複 | 特定の観点を二重に評価する | 基準を統合または重みを調整する |
| 主観評価のばらつき | 評価者により結果が変わる | 評価尺度を定義し、複数評価者で確認する |
| データ取得時点の違い | 同じ条件で比較できない | 取得期間や前提条件をそろえる |

特にMin-Max正規化は外れ値に敏感です。極端に大きい値や小さい値がある場合、他の代替案の差が小さく見えることがあります。外れ値が妥当な実測値なのか、入力ミスや特殊条件による値なのかを確認する必要があります。

## 検証結果の記録

MCDMの結果を実務で使う場合は、ランキングだけでなく、検証結果も記録します。後から判断を再確認できるようにするためです。

記録すべき情報は次のとおりです。

- 使用した評価行列
- 評価基準と評価方向
- 重みと重み設定方法
- 正規化方式
- 使用したMCDM手法
- ランキング結果
- 感度分析の結果
- 外れ値や欠損値への対応
- 最終判断とその理由

この情報を残すことで、ランキング結果の再現性と説明可能性が高まります。MCDMは計算結果を出すだけでなく、判断の前提を明確にするための技術として運用することが重要です。
