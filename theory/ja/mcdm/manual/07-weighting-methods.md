# 第7章 個体選択における重み付け手法

## 重み付けの役割

重み付けは、評価基準ごとの相対的重要度を数値として表す工程です。MCDMでは、同じ評価行列を使っても、重みが変わると総合スコアやランキングが変わることがあります。そのため、重みは単なる計算パラメータではなく、意思決定者の価値判断を表す重要な前提です。

例えば、多目的最適化結果から個体を選ぶとき、「性能」を重視する場合と「コスト」や「リスク」を重視する場合では、同じパレートフロントを評価しても結論が異なる可能性があります。MCDMでは、このような重視する観点の違いを重みとして明示します。

重みの基本形は次のようなベクトルです。

| 評価基準 | 重み |
| --- | ---: |
| コスト | 0.30 |
| 性能 | 0.40 |
| リスク | 0.20 |
| 納期 | 0.10 |

多くのMCDM手法では、重みの合計が1になるように正規化して扱います。

$$
\sum_{j=1}^{n} w_j = 1
$$

ここで $w_j$ は評価基準 $j$ の重み、$n$ は評価基準の数です。合計が1であれば、各重みは総合評価に対する寄与割合として解釈しやすくなります。

## シナリオ別重み

個体選択では、単一の重みだけで結論を出すよりも、複数の重みシナリオを比較する方が有効です。多目的最適化結果はトレードオフを含むため、どの価値判断を採用するかによって上位個体が変わることがあります。

代表的な重みシナリオは次のとおりです。

| シナリオ | 重み付けの考え方 | 適した確認 |
| --- | --- | --- |
| 等重み | すべての目的を同程度に扱う | 基準線としての順位 |
| 性能重視 | 性能や品質の重みを大きくする | 高性能個体の確認 |
| コスト重視 | コスト、時間、資源消費の重みを大きくする | 実装しやすい個体の確認 |
| リスク重視 | リスク、制約余裕、安定性を重視する | 採用しやすい安全側候補の確認 |
| バランス重視 | 最悪基準を避けるように重みを調整する | 極端な弱点が少ない個体の確認 |

複数シナリオで同じ個体が上位に残る場合、その個体は比較的安定した候補と考えられます。逆に、重みを少し変えるだけで1位が入れ替わる場合は、順位だけでなくスコア差やトレードオフ内容を確認する必要があります。

## 等重み

等重みは、すべての評価基準を同じ重要度として扱う方法です。評価基準が $n$ 個ある場合、各基準の重みは次のようになります。

$$
w_j = \frac{1}{n}
$$

例えば、4つの評価基準がある場合、各基準の重みは0.25です。

| 評価基準 | 重み |
| --- | ---: |
| コスト | 0.25 |
| 性能 | 0.25 |
| リスク | 0.25 |
| 納期 | 0.25 |

等重みは、重み付けの根拠をまだ決められない場合や、初期分析として中立的な評価を行いたい場合に有効です。また、他の重み付け方法と比較するための基準線としても使えます。

ただし、等重みは「すべての評価基準が同じ重要度である」という明確な仮定を置いています。これは中立的に見えますが、実務上は必ずしも妥当とは限りません。例えば、コストと安全性を同じ重要度として扱うことが適切かどうかは、意思決定の目的によって変わります。

等重みを使う場合は、次の点を確認します。

- 評価基準間に明確な優先度差がないか
- 初期分析として使うのか、最終判断として使うのか
- 等重みの結果と他の重み設定の結果が大きく異ならないか
- すべての評価基準を同じ重要度と説明できるか

## 専門家判断による重み付け

専門家判断による重み付けは、意思決定者、業務担当者、技術者、専門家が評価基準の重要度を直接設定する方法です。実務の目的や制約を反映しやすく、最も直感的に使える方法です。

例えば、次のように重要度を直接設定します。

| 評価基準 | 重要度の考え方 | 重み |
| --- | --- | ---: |
| コスト | 予算制約が強いため重視する | 0.35 |
| 性能 | 最終品質に直結するため最も重視する | 0.40 |
| リスク | 問題発生時の影響を考慮する | 0.15 |
| 納期 | 重要だが他基準より優先度は低い | 0.10 |

専門家判断は、業務上の価値判断を反映しやすい一方で、主観性が入りやすいという特徴があります。特定の担当者の経験や関心に強く依存すると、重みが偏る可能性があります。

専門家判断を使う場合は、次のような工夫が有効です。

- 複数の関係者で重みを確認する
- 重みの根拠を文章として記録する
- 極端な重みになっていないか確認する
- 重みを変えた場合のランキング変化を確認する
- 等重みやエントロピー法など、別の重みと比較する

専門家判断は、意思決定者の価値観を反映する方法として有効です。ただし、重みの根拠を説明できない場合、ランキング結果の説明可能性も低くなります。

## AHPによる重み付け

AHP（Analytic Hierarchy Process: 階層分析法）は、評価基準同士を一対比較し、その比較結果から重みを求める方法です。直接重みを入力する代わりに、「コストは性能と比べてどの程度重要か」「リスクは納期と比べてどの程度重要か」のように、基準間の相対的重要度を比較します。

AHPでは、Saatyの1-9スケールを使って重要度を表すことが一般的です。

| 値 | 意味 |
| ---: | --- |
| 1 | 同等に重要 |
| 3 | 少し重要 |
| 5 | かなり重要 |
| 7 | 非常に重要 |
| 9 | 極めて重要 |
| 2, 4, 6, 8 | 中間的な重要度 |

一対比較の結果は、次のような行列として表されます。

|  | コスト | 性能 | リスク |
| --- | ---: | ---: | ---: |
| コスト | 1 | 1/3 | 2 |
| 性能 | 3 | 1 | 4 |
| リスク | 1/2 | 1/4 | 1 |

この行列から、各評価基準の優先度ベクトル、つまり重みを計算します。AHPの利点は、重みを直接決めるよりも、基準間の比較として判断しやすいことです。また、比較結果に矛盾がないかを整合性比（CR: Consistency Ratio）で確認できます。

一般的には、CRが0.10以下であれば一対比較の整合性があるとみなします。CRが高い場合は、比較判断に矛盾が含まれている可能性があるため、入力を見直します。

AHPが適している場面は次のとおりです。

- 評価基準の数が少数から中程度である
- 重要度を直接数値で決めるのが難しい
- 関係者に重みの根拠を説明したい
- 判断の整合性を確認したい

一方で、評価基準が多くなると一対比較の回数が増えます。評価基準が $n$ 個ある場合、比較回数は次のとおりです。

$$
\frac{n(n-1)}{2}
$$

基準数が増えるほど入力負荷が大きくなり、整合性を保つことも難しくなります。そのため、AHPを使う場合は、評価基準を必要十分な数に絞ることが重要です。

## エントロピー法

エントロピー法は、評価データのばらつきに基づいて重みを客観的に求める方法です。意思決定者が重みを直接設定するのではなく、評価基準ごとの情報量や識別力を使って重みを計算します。

基本的な考え方は、代替案間で値の差が大きい評価基準ほど、代替案を区別する情報を多く持つというものです。逆に、すべての代替案でほぼ同じ値になる評価基準は、代替案の違いを説明しにくいため、重みが小さくなります。

エントロピー法の流れは次のとおりです。

```text
1. 評価値を非負値に変換する
2. 各評価基準の値を比例正規化する
3. 評価基準ごとのエントロピーを計算する
4. 多様度を計算する
5. 多様度を正規化して重みを求める
```

評価基準 $j$ のエントロピーを $e_j$ とすると、多様度 $d_j$ は次のように表されます。

まず、評価基準 $j$ について代替案 $i$ の比例正規化値 $p_{ij}$ を計算します。

$$
p_{ij} = \frac{x_{ij}}{\sum_{i=1}^{m} x_{ij}}
$$

$p_{ij} = 0$ の場合は $p_{ij} \ln p_{ij} = 0$ と定義します。評価基準 $j$ のエントロピー $e_j$ は次のように計算します。

$$
e_j = -\frac{1}{\ln m} \sum_{i=1}^{m} p_{ij} \ln p_{ij}
$$

$e_j$ は $0$ から $1$ の範囲に収まります。多様度 $d_j$ は次のように表されます。

$$
d_j = 1 - e_j
$$

多様度を正規化することで重み $w_j$ を求めます。

$$
w_j = \frac{d_j}{\sum_{k=1}^{n} d_k}
$$

多様度が大きい基準ほど、代替案を区別する力が大きいとみなし、重みも大きくなります。

エントロピー法の利点は、主観的な重み設定を避けられることです。大量の評価データがあり、データのばらつきから機械的に重みを決めたい場合に有効です。

一方で、エントロピー法には「ばらつきが大きい基準ほど重要である」という仮定があります。これは常に正しいとは限りません。例えば、業務上は非常に重要な安全性指標であっても、全代替案でほぼ同じ値ならエントロピー法では重みが小さくなります。

エントロピー法が適している場面は次のとおりです。

- 主観的な重み設定を避けたい
- 評価データが十分にある
- 評価基準ごとの識別力を重みに反映したい
- 初期分析や比較用の重みとして使いたい

エントロピー法を使う場合でも、算出された重みが意思決定の目的と合っているかを確認する必要があります。

## 重みの妥当性確認

重みを設定した後は、その妥当性を確認します。MCDMのランキング結果は重みに強く依存するため、重みを決めた時点で終わりにせず、結果への影響を確認することが重要です。

重みの妥当性確認では、次の観点を確認します。

| 観点 | 確認内容 |
| --- | --- |
| 合計 | 重みの合計が1になっているか。 |
| 非負性 | 負の重みが含まれていないか。 |
| 根拠 | 各重みを設定した理由を説明できるか。 |
| 極端さ | 特定の基準だけが過度に大きくないか。 |
| 安定性 | 重みを少し変えてもランキングが大きく崩れないか。 |
| 合意 | 関係者が重みの考え方を理解・合意できるか。 |

特に重要なのは感度分析です。感度分析では、重みを少し変化させたときにランキングがどの程度変わるかを確認します。ランキングが小さな重み変更で大きく変わる場合、その結論は不安定です。

例えば、次のような確認を行います。

- 最重要基準の重みを上下に変更する
- 等重みと比較する
- 専門家判断の重みとエントロピー重みを比較する
- 上位候補の順位が入れ替わる重みの範囲を確認する
- 特定の基準を除外した場合のランキングを確認する

重みの妥当性を説明する際は、最終的な重みだけでなく、重みの設定方法、設定理由、感度分析の結果をあわせて示します。これにより、ランキング結果がどの前提に基づいているのかを説明しやすくなります。

## 手法選択の目安

重み付け手法は、意思決定の目的や利用できる情報に応じて選択します。

| 手法 | 適している場面 | 主な注意点 |
| --- | --- | --- |
| 等重み | 初期分析、基準線、明確な優先度差がない場合 | すべて同じ重要度という仮定が妥当か確認する |
| 専門家判断 | 業務上の価値判断を直接反映したい場合 | 主観性と説明責任に注意する |
| AHP | 一対比較で重要度を整理したい場合 | 基準数が多いと入力負荷が大きい |
| エントロピー法 | データから客観的に重みを求めたい場合 | ばらつきと重要度を同一視する仮定に注意する |

実務では、1つの重み付け手法だけに依存するのではなく、複数の重み設定を比較することが有効です。例えば、等重み、専門家判断、エントロピー法の3つでランキングを比較し、結論が安定しているかを確認します。

重み付けの目的は、計算上もっとも精密な数値を作ることではありません。意思決定の価値判断を明示し、ランキング結果を説明可能にすることです。そのため、どの重み付け手法を使う場合でも、重みの意味と根拠を記録することが重要です。
