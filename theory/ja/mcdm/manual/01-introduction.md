# 第1章 はじめに

## 本書の目的

本書は、多目的最適化で得られた個体、トライアル、候補解の中から、どれを採用候補として選ぶべきかを判断するために、MCDM（Multi-Criteria Decision Making: 多基準意思決定）を活用する方法を説明する技術説明書です。

MCDMは、複数の評価基準を同時に考慮しながら、候補となる代替案を比較・評価・順位付けするための方法論です。単純に一つの数値だけで良し悪しを判断できない問題に対して、評価基準ごとの値、重要度、意思決定者の選好を整理し、説明可能な形で判断を支援します。

本書では、MCDMを単なる数式やアルゴリズムとして扱うだけでなく、多目的最適化の探索結果を意思決定に接続するための技術要素として説明します。具体的には、パレートフロントの扱い、目的関数と評価基準の対応、制約条件の処理、重み付け、正規化、代表的なMCDM手法、結果の解釈、システム実装時の設計ポイントを対象とします。

## MCDMの概要

MCDMは、複数の評価基準が存在する状況で、どの代替案が総合的に望ましいかを判断するための枠組みです。

例えば、多目的最適化で「精度を最大化し、処理時間とコストを最小化する」探索を行った場合、得られる結果は一つの最良個体ではなく、複数のトレードオフ候補になることがあります。精度が最も高い個体は処理時間やコストで不利かもしれません。一方で、コストが最も低い個体は精度が不足するかもしれません。

MCDMでは、このような複数の観点を評価基準として定義し、各個体を評価します。そのうえで、評価基準ごとの重要度を重みとして反映し、個体の総合評価やランキングを算出します。

MCDMで扱う典型的な要素は次のとおりです。

| 要素 | 説明 |
| --- | --- |
| 代替案 | 比較対象となる候補。多目的最適化では個体、トライアル、候補解、設計案など。 |
| 評価基準 | 代替案を評価する観点。目的関数、制約余裕、リスク、安定性など。 |
| 評価値 | 各個体が各評価基準に対して持つ値。 |
| 重み | 評価基準ごとの相対的重要度。 |
| 評価手法 | 評価値と重みから総合評価を計算する方法。 |
| ランキング | 総合評価に基づく代替案の順位。 |

MCDMの重要な点は、判断の過程を明示できることです。どの基準を使い、どの基準を重視し、どの計算手法で順位を出したのかを説明できるため、関係者間の合意形成や結果の検証に利用しやすくなります。

## 想定読者

本書は、次の読者を想定しています。

- 複数の評価基準を用いた意思決定手法を理解したい技術者
- MCDMをシステムや分析機能に実装する開発者
- 多目的最適化結果から採用候補となる個体を選びたい分析担当者
- AHP、TOPSIS、VIKOR、PROMETHEEなどの手法を比較したい設計者
- 評価基準や重み付けを含む意思決定プロセスを説明可能にしたい利用者

本書では、MCDMの数学的な背景にも触れますが、主な目的は実務で使える理解を得ることです。そのため、各章では数式だけでなく、入力データの意味、計算結果の解釈、実装時の注意点をあわせて説明します。

## 用語定義

本書で使用する主な用語を以下に示します。

| 用語 | 説明 |
| --- | --- |
| MCDM | Multi-Criteria Decision Makingの略。複数の評価基準に基づいて代替案を比較・評価する意思決定手法の総称。 |
| 代替案 | 評価対象となる候補。最適化ではトライアルや解に相当する。 |
| 評価基準 | 代替案を評価するための観点。目的関数、指標、属性とも呼ばれる。 |
| 個体 | 最適化アルゴリズムが生成した一つの候補解。トライアル、解、設計案と同じ意味で使う場合がある。 |
| パレートフロント | 他の個体に支配されない非劣解の集合。多目的最適化結果の主要な選択候補になる。 |
| パレート支配 | ある個体が別の個体に対して、すべての目的で同等以上かつ少なくとも一つの目的で優れる関係。 |
| 評価行列 | 代替案と評価基準の組み合わせに対する評価値を並べた行列。 |
| 重み | 評価基準の相対的重要度を表す値。通常は合計が1になるように扱う。 |
| ベネフィット型基準 | 値が大きいほど望ましい評価基準。性能、品質、利益など。 |
| コスト型基準 | 値が小さいほど望ましい評価基準。価格、時間、リスク、損失など。 |
| 正規化 | 単位やスケールが異なる評価値を比較可能な形に変換する処理。 |
| 総合スコア | 複数の評価基準を統合して得られる代替案ごとの評価値。 |
| 感度分析 | 重みや評価値の変化がランキング結果に与える影響を確認する分析。 |

## 本書の読み方

MCDMの全体像を把握したい場合は、第2章から第4章を先に読むと、基本概念、多目的最適化との関係、パレートフロントから候補を作る考え方を理解できます。

実際に計算を実装したい場合は、第5章から第10章を中心に読むことで、評価基準の設計、重み付け、MCDM手法、正規化、評価計算の流れを確認できます。

実務での導入や運用上の注意点を知りたい場合は、第11章から第14章を参照してください。ランキング結果の解釈、感度分析、説明可能性、システム実装時の設計ポイントを扱います。

本書では、MCDMを「唯一の正解を自動的に決める仕組み」としてではなく、「複数の判断材料を整理し、意思決定を説明可能にするための技術」として扱います。最終的な意思決定では、計算結果だけでなく、前提条件、評価基準の妥当性、利害関係者の合意もあわせて確認する必要があります。
