# エントロピー重み法（Entropy Weight Method）

## 概要

エントロピー重み法は、情報理論のシャノンエントロピー（Shannon Entropy）を用いて、**データの分散度合いから各目的関数の重みを客観的に算出**する手法である。評価基準間のばらつきが大きいほど重要度が高いという前提のもと、意思決定者の主観に依らない重みを導出する。

Tunny Dashboard では、TOPSIS / VIKOR といった MCDM 手法の重みとして使用できる。エントロピー重みモードを選択すると、手動スライダーによる設定を置き換え、データ自体が重みを決定する。

| 返り値              | 説明                                               |
| ------------------- | -------------------------------------------------- |
| `weights[j]`        | 目的関数 j の重み（0〜1、合計が 1）                |
| `entropies[j]`      | 目的関数 j の情報エントロピー $e_j$（0〜1）        |
| `diversities[j]`    | 目的関数 j の多様度 $d_j = 1 - e_j$（0〜1）        |
| `normalized_matrix` | 比例正規化後の行列（行: トライアル、列: 目的関数） |

---

## 理論背景

### 直感

情報理論において、エントロピーは「不確かさ」または「情報量」を表す。均一に分布している変数はエントロピーが高く（識別力が低い）、偏りがある変数はエントロピーが低い（識別力が高い）。

- **全トライアルで同じ値** → エントロピー = 1.0 → 多様度 = 0 → 重み = 0
  （この目的関数はトライアル間の差異を生まないので情報がない）
- **トライアル間で大きくばらつく** → エントロピー < 1 → 多様度 > 0 → 重みが大きい

### アルゴリズムの概要

```
Step 1: 負値処理（必要な場合のみ Min-Max 正規化）
Step 2: 比例正規化（列和が 1 になるよう正規化）
Step 3: 情報エントロピーの計算
Step 4: 多様度の計算
Step 5: 重みの正規化
```

---

### Step 1: 負値の前処理

エントロピー計算では対数を用いるため、全値が非負である必要がある。負値を含む目的関数列には Min-Max 正規化を適用する。

列 $j$ に負値が含まれる場合:

$$
x_{ij}' = \frac{x_{ij} - \min_i(x_{ij})}{\max_i(x_{ij}) - \min_i(x_{ij})}
$$

負値を含まない列はそのままの値 $x_{ij}' = x_{ij}$ を使用する。

**ゼロ除算ガード（定数列）**: 列内の全値が同一（$\max = \min$、range = 0）の場合、$x_{ij}' = 1.0$ とする（0.0 ではない）。0.0 にすると Step 2 の比例正規化で全行が $p_{ij} = 0$ となり、Step 3 で $e_j = 0$（多様度 $d_j = 1$）と計算されてしまい、情報量ゼロのはずの定数列が最大重みを獲得するという逆転が起きる。全行を 1.0 とすれば比例正規化で $p_{ij} = 1/m$（一様分布）となり、$e_j = 1.0$・$d_j = 0$・$w_j = 0$ という正しい結果になる（正の定数列を Min-Max 正規化しない場合と同じ挙動）。

---

### Step 2: 比例正規化

各列を列和で割ることで、確率的解釈が可能な行列 $P$ を構築する。

$$
p_{ij} = \frac{x_{ij}'}{\sum_{i=1}^{m} x_{ij}'}
$$

各列の和は 1 になる（$\sum_i p_{ij} = 1$）。

**ゼロ除算ガード**: 列和が 0 の場合（全値が 0）、$p_{ij} = 0$ とする。この場合、後続のエントロピー計算でも $p \ln p$ の項は 0 として扱われる（$\lim_{p \to 0} p \ln p = 0$）。

---

### Step 3: 情報エントロピーの計算

目的関数 $j$ のシャノンエントロピー:

$$
e_j = -\frac{1}{\ln m} \sum_{i=1}^{m} p_{ij} \ln(p_{ij})
$$

$\frac{1}{\ln m}$ で除算することで $e_j \in [0, 1]$ に正規化する。

**特殊ケース**:

- $p_{ij} = 0$ の項は $p_{ij} \ln(p_{ij}) = 0$ として扱う（情報論的に標準的な定義）
- $m = 1$（単一トライアル）の場合、$\ln m = 0$ なので $e_j = 0$ とする

---

### Step 4: 多様度の計算

$$
d_j = 1 - e_j
$$

エントロピーが高い（= 情報が少ない）目的関数ほど多様度が低くなる。

---

### Step 5: 重みの正規化

$$
w_j = \frac{d_j}{\sum_{k=1}^{n} d_k}
$$

**均一フォールバック**: $\sum_k d_k = 0$（全目的関数が定数）の場合、全目的関数に均等重み $w_j = 1/n$ を割り当てる。

## 実装の詳細

### NaN トライアルの扱い（`entropy.rs`）

いずれかの目的関数値が `NaN` のトライアルは有効トライアルから除外される。全トライアルが `NaN` の場合はエラーを返す。

```rust
let valid_indices: Vec<usize> = super::filter_valid_indices(values, n_trials, n_objectives);
if valid_indices.is_empty() {
    return Err("No valid trials for entropy computation (all NaN)".to_string());
}
```

### 負値処理の設計

負値チェックと処理は列（目的関数）ごとに独立して行われる。一部の列のみ負値を含む場合、その列だけ Min-Max 正規化が適用され、他の列は元の値を維持する。

これにより、正値の目的関数の絶対的なスケール情報（どのトライアルが大きく違うか）を保持したまま、負値列のみを補正できる。

### エントロピー重みと MCDM の統合

MCDM チャートウィジェットでは `WeightMode::Entropy` を選択すると以下のフローが動作する:

```
1. pending_entropy = true にセット
2. chart_registry がバックグラウンドで compute_entropy_weights() を実行
3. EntropyResult を message_handler 経由で受け取り widget_state に保存
4. entropy_result.weights を TOPSIS / VIKOR の重みとして使用
```

`pending_entropy` フラグと `computing` フラグにより、重複実行を防ぐ。

### 計算量

| ステップ           | 計算量       |
| ------------------ | ------------ |
| 負値チェック・処理 | O(m × n)     |
| 比例正規化         | O(m × n)     |
| エントロピー計算   | O(m × n)     |
| 重み正規化         | O(n)         |
| **合計**           | **O(m × n)** |

50,000 トライアル × 4 目的関数で 100ms 未満（実測）。

## 数値例

### 問題設定

3 トライアル × 2 目的関数（両方非負）

| トライアル | 目的1 | 目的2 |
| ---------- | ----- | ----- |
| 0          | 5     | 1     |
| 1          | 5     | 2     |
| 2          | 5     | 3     |

目的1は全トライアルで同値（= 5）、目的2はばらつきがある。

### Step 1: 負値なし → 処理なし

### Step 2: 比例正規化

列和: 目的1 = 15, 目的2 = 6

$$
P = \begin{pmatrix} 5/15 & 1/6 \\ 5/15 & 2/6 \\ 5/15 & 3/6 \end{pmatrix}
= \begin{pmatrix} 1/3 & 1/6 \\ 1/3 & 1/3 \\ 1/3 & 1/2 \end{pmatrix}
$$

### Step 3: エントロピー（m = 3, ln 3 ≈ 1.0986）

目的1（全均等）:

$$
e_1 = -\frac{1}{\ln 3} \left( 3 \times \frac{1}{3} \ln \frac{1}{3} \right)
    = -\frac{1}{\ln 3} \cdot \ln \frac{1}{3} = 1.0
$$

目的2（不均等）:

$$
e_2 = -\frac{1}{\ln 3} \left( \frac{1}{6} \ln \frac{1}{6} + \frac{1}{3} \ln \frac{1}{3} + \frac{1}{2} \ln \frac{1}{2} \right)
    \approx 0.982
$$

### Step 4: 多様度

$$
d_1 = 1 - 1.0 = 0.0, \quad d_2 = 1 - 0.982 = 0.018
$$

### Step 5: 重み

$$
w_1 = \frac{0.0}{0.018} = 0.0, \quad w_2 = \frac{0.018}{0.018} = 1.0
$$

目的1は識別力ゼロのため重みが 0 となり、目的2が全重みを持つ。これがエントロピー重み法の本質である。

## 特性・限界

**強み:**

- 主観的な重み設定が不要で、データから自動的に重みを決定する
- 分析者の偏りを排除した客観的な多基準評価が可能
- 計算量が O(m × n) と軽量で大規模データにも対応

**弱み:**

- データのばらつきが「重要度」と等価であるという仮定が前提（常に正しいとは限らない）
- 全目的関数がほぼ均一なデータでは、微小なノイズが重みを支配する可能性がある
- ドメイン知識（「この目的関数を重視したい」）を反映できない

**手動重みとの使い分け:**

```
各目的関数の重要度に関するドメイン知識がある
  → 手動スライダーで重みを設定

データが語る重要度を客観的に反映したい
  → エントロピー重みモードを使用

両者を比較して感度を確認する
  → 手動 ↔ エントロピーをモード切替で比較
```
