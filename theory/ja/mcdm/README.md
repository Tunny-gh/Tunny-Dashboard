# MCDM（多基準意思決定手法）

多目的最適化の結果から「総合的に優れたトライアル」を選ぶためのランキング手法群。Tunny Dashboard では以下の 3 手法と、重みを客観的に決定するエントロピー重み法を提供する。

## 手法一覧

| 手法                                | 特徴                               | スコア範囲     | 計算量    |
| ----------------------------------- | ---------------------------------- | -------------- | --------- |
| [TOPSIS](topsis.md)                 | 理想解との距離比によるランキング   | [0, 1]         | O(m × n)  |
| [VIKOR](vikor.md)                   | 効用と後悔のバランスによる妥協解   | [0, 1]         | O(m × n)  |
| [PROMETHEE](promethee.md)           | ペアワイズ選好比較によるランキング | Φnet ∈ [-1, 1] | O(m² × n) |
| [Entropy Weight](entropy-weight.md) | データの分散から重みを客観的に算出 | —              | O(m × n)  |

---

## 各手法の概要

### TOPSIS

各トライアルと「理想的な解（正理想解）」の近さをスコア化する。正規化 → 重み付け → 理想解/反理想解とのユークリッド距離 → 相対近接度を計算し、スコアが 1 に近いほど理想解に近い。直感的で計算が速い。

### VIKOR

各トライアルの「理想からのギャップ」を L1（マンハッタン）と L∞（チェビシェフ）の2つの距離で測り、パラメータ v でバランスを調整して妥協解を求める。v > 0.5 で全体的な効用重視、v < 0.5 で最悪ケースの後悔最小化。

### PROMETHEE I / II

すべてのトライアルペアについて「a は b よりどの程度好ましいか」を選好関数で評価し、フロー（Φ+/Φ-/Φnet）に集約する。PROMETHEE I は理論上は部分ランキング（比較不能なペアを許容）であり、本実装では Φ+ 降順（タイは Φ- 昇順）の全順序で表示しつつ、トライアルごとの比較不能件数（チャートでは ⇹N 表示）も報告する。PROMETHEE II は完全ランキングを提供。ペアワイズ比較に基づくため直感的だが、O(m²) の計算量に注意。

### エントロピー重み法

データ自体の分散から各目的関数の重みを自動算出する。ばらつきが大きい目的関数ほど「識別力が高い」とみなし、大きな重みを割り当てる。上記 3 手法の重み入力として利用可能。

## 選び方

```
まず重みをどう決めるか？
├─ 客観的に決めたい → エントロピー重み法で重みを自動算出
└─ 自分で調整したい → 手動スライダーで重みを設定

ランキング手法は？
├─ 速くて直感的なスコアが欲しい
│   └─ → TOPSIS（理想解との距離、[0,1] スコア）
│
├─ 全体バランスと最悪ケースの両方を考慮したい
│   └─ → VIKOR（v パラメータで効用/後悔のバランス調整）
│
└─ ペアワイズの優劣関係を詳細に知りたい
    ├─ トライアル数が少ない（<1万） → PROMETHEE I/II
    └─ トライアル数が多い（>1万） → 計算時間に注意
```

### 組み合わせの推奨

| シーン                           | 推奨                            |
| -------------------------------- | ------------------------------- |
| まず試す                         | TOPSIS + 均等重み               |
| 目的関数間のスケール差が大きい   | TOPSIS/VIKOR + エントロピー重み |
| 特定の目的の最悪ケースを抑えたい | VIKOR（v < 0.5）                |
| トライアル間の優劣を詳細比較     | PROMETHEE I + PROMETHEE II      |
| 重みの客観的な根拠が欲しい       | エントロピー重み法 + 任意の手法 |
