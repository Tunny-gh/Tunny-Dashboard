# VIKOR 法（VIseKriterijumska Optimizacija I Kompromisno Resenje）

## 概要

VIKOR 法は、1998年に Serafim Opricovic と Gwang-Huyng Tzeng によって提案された多基準意思決定（MCDM: Multi-Criteria Decision Making）手法である。セルビア語で「複数基準最適化と妥協解」を意味する名称であり、複数の評価基準（目的関数）が競合する問題において、理想解に最も近い妥協解（compromise solution）を選択する。

Tunny Dashboard では以下の値を返す:

| 返り値               | 説明                                                                    |
| -------------------- | ----------------------------------------------------------------------- |
| `s_values[i]`        | 効用指標（理想からの L1 ギャップ。小さいほど良い）                      |
| `r_values[i]`        | 後悔指標（最悪目的関数の L∞ ギャップ。小さいほど良い）                  |
| `q_values[i]`        | 妥協指標 Q（S と R の線形結合。NaN トライアルは 1.0）                   |
| `display_scores[i]`  | 表示用スコア = 1 − Q（高いほど良い。UI 表示で使用）                     |
| `ranked_indices`     | Q 昇順に並べたトライアルインデックス（Q が小さいほど妥協解に近い）      |
| `best_values[j]`     | 目的関数 j の有効トライアル中の最適値                                   |
| `worst_values[j]`    | 目的関数 j の有効トライアル中の最劣値                                   |
| `compromise_indices` | 妥協解集合（受容条件 C1/C2 による。Q 昇順の元トライアルインデックス）   |

## 基本思想

VIKOR は以下の2つの距離測度を用いて妥協解を求める。

- **S**: 重み付きマンハッタン距離（L1 ノルム）→ 全体的な効用性を評価
- **R**: 重み付きチェビシェフ距離（L∞ ノルム）→ 最悪の基準における後悔を評価

そして、パラメータ $v$（0〜1）でこれらを線形結合し、妥協指標 $Q$ を算出する。

## アルゴリズム

### 入力

| 変数     | 説明                                          |
| -------- | --------------------------------------------- |
| $f_{ij}$ | 試行 $i$ の目的 $j$ の値                      |
| $w_j$    | 目的 $j$ の重み（正規化済み、$\sum w_j = 1$） |
| $v$      | 戦略的重み（デフォルト 0.5）                  |

**重みの防御的正規化**: 合計が 1 でない重みが渡された場合、合計が正の有限値であれば合計で割って正規化する。合計が 0 以下・非有限（NaN 等）の場合は一様重みにフォールバックする。

### Step 1: 最適値・最劣値の決定

各目的 $j$ について、全試行中のベスト（最適値）とワースト（最劣値）を求める。

$$f_j^* = \text{best}_i(f_{ij}), \quad f_j^- = \text{worst}_i(f_{ij})$$

- 最小化目的: $\text{best} = \min$, $\text{worst} = \max$
- 最大化目的: $\text{best} = \max$, $\text{worst} = \min$

### Step 2: S 値と R 値の計算

各試行 $i$ について:

$$S_i = \sum_{j=1}^{n} w_j \cdot \frac{f_j^* - f_{ij}}{f_j^* - f_j^-}$$

$$R_i = \max_{j} \left( w_j \cdot \frac{f_j^* - f_{ij}}{f_j^* - f_j^-} \right)$$

- **$S_i$**（Utility measure）: 全目的の重み付きギャップの総和。小さいほど理想に近い。
- **$R_i$**（Regret measure）: 全目的中で最大のギャップ。小さいほど「最悪の基準」でも優れている。

**ゼロ除算ガード**: $f_j^* = f_j^-$ の場合、その目的の寄与は 0 とする（全試行が同一値なら差がないため）。

### Step 3: S*、S-、R*、R- の計算

$$S^* = \min_i(S_i), \quad S^- = \max_i(S_i)$$

$$R^* = \min_i(R_i), \quad R^- = \max_i(R_i)$$

### Step 4: Q 値の計算

各試行 $i$ について:

$$Q_i = v \cdot \frac{S_i - S^*}{S^- - S^*} + (1 - v) \cdot \frac{R_i - R^*}{R^- - R^*}$$

**パラメータ $v$ の意味**:

| $v$ の値  | 重み付け | 意味                                  |
| --------- | -------- | ------------------------------------- |
| $v > 0.5$ | $S$ 重視 | 全体的な効用性を優先（max-consensus） |
| $v = 0.5$ | 均等     | 効用と後悔のバランス                  |
| $v < 0.5$ | $R$ 重視 | 個別の最悪ケースを優先（min-regret）  |

**ゼロ除算ガード**: $S^- = S^*$ の場合、第1項は 0 とする。$R^- = R^*$ の場合、第2項は 0 とする。

### Step 5: Q 値によるランキング

$Q_i$ の昇順（小さい順）に試行を並べる。Q 値が小さいほど妥協解に近い（良い）。

### Step 6: 妥協解の受容条件（C1/C2）

$Q$ 値最小の解 $A^{(1)}$ が単独の妥協解として採用可能かを、Opricovic & Tzeng (2004) の2条件で判定する。

**C1（受容可能な優位性 / Acceptable advantage）**:

$$Q(A^{(2)}) - Q(A^{(1)}) \geq DQ, \qquad DQ = \frac{1}{J - 1}$$

ここで $J$ は有効（全目的が有限値の）試行数。1位と2位の Q の差が十分に大きいことを確認する。

**C2（意思決定の安定性 / Acceptable stability in decision making）**:

$A^{(1)}$ が $S$ または $R$ のランキングでも1位（同率を含む）であること。

**妥協解集合の決定**:

- C1・C2 とも成立 → $A^{(1)}$ が唯一の妥協解
- C2 のみ不成立 → $A^{(1)}$ と $A^{(2)}$ が妥協解
- C1 不成立 → $Q(A^{(k)}) - Q(A^{(1)}) < DQ$ を満たす $A^{(1)}, \dots, A^{(k)}$ すべてが妥協解

エッジケース: $J = 1$ の場合は唯一の有効試行が妥協解、$J = 0$ の場合は空集合。

**本実装では**: 妥協解集合は `compromise_indices`（Q 昇順の元トライアルインデックス）として返され、MCDM 散布図ウィジェットで ★ マーク付きで表示される（クリック詳細モーダルにも表示）。

## TOPSIS との比較

| 項目                 | TOPSIS                     | VIKOR                                  |
| -------------------- | -------------------------- | -------------------------------------- |
| 距離測度             | ユークリッド距離（L2）     | マンハッタン（L1）+ チェビシェフ（L∞） |
| 理想解へのアプローチ | 正・負の理想解との距離比   | 重み付きギャップの線形結合             |
| ランキング方向       | 降順（スコア高いほど良い） | 昇順（Q 小さいほど良い）               |
| 戦略パラメータ       | なし                       | $v$（効用 vs 後悔）                    |
| ゼロ除算処理         | スコア = 0.5               | 寄与 = 0                               |
| 適用場面             | 全体的な類似性を重視       | 妥協点・バランスを重視                 |

## 数値例

### 問題設定

3試行 × 2目的、両方最小化、重み $w = [0.5, 0.5]$、$v = 0.5$

| 試行 | 目的1 | 目的2 |
| ---- | ----- | ----- |
| 0    | 1     | 2     |
| 1    | 3     | 1     |
| 2    | 2     | 2     |

### Step 1: 最適値・最劣値

目的1: $f_1^* = 1$, $f_1^- = 3$, range = 2
目的2: $f_2^* = 1$, $f_2^- = 2$, range = 1

### Step 2: S と R の計算

| 試行 | contrib1                    | contrib2                   | S    | R   |
| ---- | --------------------------- | -------------------------- | ---- | --- |
| 0    | $0.5 \times (1-1)/2 = 0$    | $0.5 \times (1-2)/1 = 0.5$ | 0.5  | 0.5 |
| 1    | $0.5 \times (3-1)/2 = 0.5$  | $0.5 \times (1-1)/1 = 0$   | 0.5  | 0.5 |
| 2    | $0.5 \times (2-1)/2 = 0.25$ | $0.5 \times (1-2)/1 = 0.5$ | 0.75 | 0.5 |

### Step 3: S*, S-, R*, R-

$S^* = 0.5$, $S^- = 0.75$, $R^* = 0.5$, $R^- = 0.5$（同順）

### Step 4: Q 値

$R^* = R^-$ なので term2 = 0:

- $Q_0 = 0.5 \times (0.5 - 0.5)/0.25 + 0.5 \times 0 = 0$
- $Q_1 = 0.5 \times (0.5 - 0.5)/0.25 + 0.5 \times 0 = 0$
- $Q_2 = 0.5 \times (0.75 - 0.5)/0.25 + 0.5 \times 0 = 0.5$

### Step 5: ランキング

$Q = [0, 0, 0.5]$ → 試行 0 と 1 が同率1位、試行 2 が最下位。
