# クラスタリング手法の早見ガイド

Tunny Dashboard のクラスタリングウィジェット（`ClusterScatter`）で使用される手法の概要です。
詳細な理論・実装は各手法の個別ドキュメントを参照してください。

---

## クラスタリング手法

| 手法                            | 役割                            | 強み                              | 注意点                                 | 詳細                     |
| ------------------------------- | ------------------------------- | --------------------------------- | -------------------------------------- | ------------------------ |
| k-means（Lloyd's アルゴリズム） | データを $k$ 個のクラスタに分割 | 高速・直感的・WCSS で品質評価可能 | 球形クラスタを仮定・局所最適解のリスク | [kmeans.md](./kmeans.md) |

### k-means の初期化戦略（Init）

k-means の初期重心選択方法。どちらも**クラスタリング手法ではなく k-means の内部設定**であり、
Lloyd's アルゴリズム本体（割り当て・更新・収束）は共通。

| 初期化戦略    | 説明                                                         | 適した場面                   |
| ------------- | ------------------------------------------------------------ | ---------------------------- |
| k-means++     | D² 比例確率でサンプリング（xorshift64 固定シードで再現可能） | 局所最適を避けたい・品質優先 |
| Deterministic | 累積距離しきい値による確定的スプレッド                       | 完全な決定論的再現性が必要   |

## 分割数（k）の決め方

エルボー法は k-means を補助するための手法であり、クラスタリング手法そのものではありません。
k-means を実行する前に「いくつに分割するか」を決定するために使います。

| 手法       | 役割                                                      | 強み                    | 注意点                            | 詳細                   |
| ---------- | --------------------------------------------------------- | ----------------------- | --------------------------------- | ---------------------- |
| エルボー法 | クラスタ内二乗和（WCSS）の変化率から最適な $k$ を自動推定 | ユーザが $k$ を指定不要 | WCSS が滑らかだと推定精度が下がる | [elbow.md](./elbow.md) |

---

## ワークフロー

```
クラスタリング実行
  │
  ├── k 選択モード：Elbow (Auto)
  │    └── エルボー法で k=2〜max_k を総当たりし最適 k を自動推定
  │         └── 推定した k で k-means を実行（Init 戦略を適用）
  │
  └── k 選択モード：Manual
       └── ユーザ指定の k で k-means を直接実行（Init 戦略を適用）

Init 戦略（k-means の初期化のみ異なる）
  ├── k-means++    → D² 比例確率サンプリング
  └── Deterministic → 累積距離しきい値スプレッド
```

## 入力空間の選び方

| 設定            | 使うフィーチャー      | 向いている分析                   |
| --------------- | --------------------- | -------------------------------- |
| Objective Space | 目的関数値のみ        | 性能が似たトライアルを見つけたい |
| Variable Space  | パラメータ値のみ      | 設計変数のパターンを把握したい   |
| Combined        | 目的関数 + パラメータ | 両空間の関係を統合的に見たい     |
