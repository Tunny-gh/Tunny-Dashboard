# エルボー法（最適クラスタ数の自動推定）

## 概要

エルボー法は、k-means クラスタリングの**最適なクラスタ数 $k$** を自動推定する手法。
$k$ を変化させたときの WCSS（クラスタ内二乗和）の変化率が急激に鈍化する「肘（elbow）」の点を最適 $k$ とみなす。

Tunny Dashboard では「Elbow (Auto)」モードで自動推定を行い、ユーザが手動指定しなくても適切な $k$ を選択できる。

---

## 理論背景

### WCSS の挙動

$k$ を増やすにつれて WCSS は必ず単調減少する。
$k = N$（点と同数）にすれば WCSS は 0 になるが、それでは意味がない。

$$
k = 1 \Rightarrow \text{WCSS 最大}
\quad \xrightarrow{k\uparrow} \quad
k = N \Rightarrow \text{WCSS} = 0
$$

「十分な分割効果」が得られる点を超えると、WCSS の減少量は急速に小さくなる。この屈曲点がエルボーであり、過剰分割（過学習的クラスタリング）を避けた適切な $k$ とみなされる。

---

## アルゴリズム

### ステップ 1：WCSS の収集

$k = 2, 3, \ldots, k_{\max}$ のそれぞれで k-means を実行し、WCSS を記録する：

$$
W_k = \text{WCSS}(k) \quad (k = 2, \ldots, k_{\max})
$$

$k_{\max} = \min(N,\; 10)$。上限はハードコードされた 10 であり、ユーザが変更することはできない（$N$ はトライアル数）。

**注記。** ここで収集される各 $W_k$ の実体は linfa の `model.inertia()` であり、最近傍重心への二乗距離の**標本平均**（WCSS / N）であって WCSS の総和ではない（[kmeans.md](./kmeans.md) の該当注記を参照）。$N$ はどの $k$ を試しても共通なので、これは各 $W_k$ を共通の定数 $1/N$ 倍するだけであり、後述する二次差分の最大位置には影響しない。

### ステップ 2：二次差分の計算

WCSS 列の**二次有限差分**を計算する：

$$
\Delta^2 W_i = W_i - 2W_{i+1} + W_{i+2} \quad (i = 0, 1, \ldots)
$$

インデックス $i$ の $\Delta^2 W_i$ は、位置 $k = i + 3$ における曲線の「曲がり具合（凹性）」を表す。
直線では $\Delta^2 W = 0$、エルボー点では $\Delta^2 W$ が最大となる。

### ステップ 3：推奨 $k$ の決定

$$
\hat{k} = \operatorname*{arg\,max}_{i}\; \Delta^2 W_i \;+\; 3
$$

$+3$ のオフセットは、$k = 2$ から始まる WCSS インデックスと二次差分インデックスのずれによる：

| 変数           | $k$ との対応                                            |
| -------------- | ------------------------------------------------------- |
| $W_0$          | $k = 2$                                                 |
| $\Delta^2 W_0$ | $k = 2, 3, 4$ の 3 点を使用 → 肘は $k = 3$（$= 0 + 3$） |
| $\Delta^2 W_i$ | 肘は $k = i + 3$                                        |

推定 $k$ は $[2,\; k_{\max}]$ の範囲にクランプされる。

---

## 具体例

$k = 2, 3, 4, 5$ での WCSS が以下のとき：

| $k$ | WCSS |
| --- | ---- |
| 2   | 1000 |
| 3   | 400  |
| 4   | 350  |
| 5   | 340  |

二次差分：

$$
\Delta^2 W_0 = 1000 - 2 \times 400 + 350 = 150 \quad \text{(肘候補: } k=3\text{)}
$$

$$
\Delta^2 W_1 = 400 - 2 \times 350 + 340 = 40
$$

$\Delta^2 W_0$ が最大のため、推奨 $k = 0 + 3 = 3$。

---

## 特殊ケース

| ケース                                  | 動作                                                     |
| --------------------------------------- | -------------------------------------------------------- |
| $k_{\max} < 2$                          | WCSS を計算せず、$\hat{k} = 2$ を返す                    |
| 試行数が 2 以下（差分列が短い）         | 二次差分を計算せず、$\hat{k} = \text{試行数} + 1$ を返す |
| 全点が 1 点に重なる（距離 $\approx 0$） | 重複回避フォールバックで後続の点を重心として使用         |

---

## 強みと限界

### 強み

- ユーザが $k$ を指定しなくてよい
- 計算コストが低い（$k_{\max}$ 回の k-means 実行で完了）
- 二次差分は線形トレンドをキャンセルし、曲率だけを評価するため頑健

### 限界

- WCSS が滑らかに減少しエルボーが不明瞭なデータでは推定精度が下がる
- クラスタが自然に存在しないデータ（一様分布など）では過剰な $k$ を推奨する場合がある
- $k_{\max}$ は 10 に固定（ユーザ変更不可）されているため、本来 10 を超えるクラスタ数を必要とするデータでは真のエルボーが探索範囲外になる

### 推定結果が不自然なとき

エルボー法の推定が直感と合わない場合は「Manual」モードに切り替えてユーザが $k$ を指定する。
その際は以下を参考にする：

```
WCSS が急激に下がる k の直後を手動で選ぶ
クラスタ数を増やしても解釈性が下がる場合は小さい k を優先する
```
