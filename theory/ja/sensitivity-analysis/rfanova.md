# RF-ANOVA（パーミュテーション重要度）

## 概要

RF-ANOVA（Random Forest ANOVA）は、学習済みランダムフォレストを使い、**特定パラメータの値をランダムに並び替えたときに予測精度がどれだけ低下するか**でパラメータ重要度を定量化する手法。「パーミュテーション重要度（Permutation Importance）」とも呼ばれる。

MDI と異なり学習後のホールドアウトデータ上で評価するため、**高カーディナリティバイアスが少なく**、実際の予測貢献に近い重要度が得られる。

---

## 理論背景

### 基本原理

あるパラメータ $x_j$ の値をデータセット中でランダムに並び替えると、$x_j$ が目的変数と持っていた相関構造が破壊される。並び替え前後でモデルの予測誤差がどれだけ増加したかが、そのパラメータの重要度となる:

$$
I_j = \mathrm{MSE}_{\mathrm{permuted},j} - \mathrm{MSE}_{\mathrm{baseline}}
$$

- $\mathrm{MSE}_{\mathrm{baseline}}$：ホールドアウトデータ上のベースライン MSE
- $\mathrm{MSE}_{\mathrm{permuted},j}$：$x_j$ を並び替えた後の MSE

$I_j \approx 0$ であれば、$x_j$ を欠損させても精度が変わらない → 重要度が低い。

### 正規化

各パラメータの $I_j$ を合計が 1 になるよう正規化する:

$$
\widetilde{I}_j = \frac{I_j}{\sum_{j'} I_{j'}}, \quad I_j = \max(I_j, 0)
$$

負値は 0 にクリップする（並び替えで誤差が減少することはないが、有限サンプルの乱れによる数値誤差を防ぐため）。

---

## ホールドアウト評価の必要性

訓練データ上でパーミュテーションを実施すると、木が訓練データを記憶している（過学習）場合に $\mathrm{MSE}_{\mathrm{permuted}} \approx \mathrm{MSE}_{\mathrm{baseline}}$ となり、すべての重要度が 0 に近くなる。

これを避けるため、訓練データとは独立したホールドアウトデータ（評価データ）上でパーミュテーション評価を行う:

```
全データ → シャッフル → 80% 訓練 / 20% 評価
                            ↓
                  ランダムフォレスト学習
                            ↓
                 評価データ上でベースライン MSE を計算
                            ↓
             パラメータ j をパーミュテーション（評価データのみ）
                            ↓
              パーミュテーション後の MSE を計算
                            ↓
           I_j = max(permuted_mse - baseline_mse, 0)
```

## Tunny Dashboard の実装

### 全体フロー

```
実際のトライアルデータ
    ↓
Step 1: 前処理
  ├── NaN/Inf 行を除外
  └── N > 2000 の場合はランダムサンプリングで 2000 行に削減

Step 2: 80/20 ホールドアウト分割
  ├── シャッフル後 80% を訓練データ、20% を評価データとする
  └── N < 4 の場合は全データを訓練・評価両方に使う

Step 3: ランダムフォレスト学習
  └── 訓練データで 100 本の回帰木を構築

Step 4: ベースライン MSE・R² の計算
  ├── 評価データで MSE を計算
  └── R² = 1 - MSE_eval × N_eval / SS_total

Step 5: パーミュテーション重要度の計算
  ├── パラメータ j = 1, ..., P について:
  │     評価データの列 j をシャッフル
  │     permuted_mse を計算
  │     I_j = max(permuted_mse - baseline_mse, 0)
  └── I を合計=1 に正規化

出力: (importances[P], r_squared)
```

### ハイパーパラメータ

| パラメータ         | 値    | MDI との共通点 |
| ------------------ | ----- | -------------- |
| 木の本数           | 100   | ✓ 同じ         |
| 最大深さ           | 10    | ✓ 同じ         |
| 最小リーフサンプル | 2     | ✓ 同じ         |
| 乱数シード         | 42    | ✓ 同じ         |
| 最大行数           | 2,000 | ✓ 同じ         |

パーミュテーション時のシードは `42 + feature_idx` でパラメータごとに異なるシードを使い、独立したシャッフルを保証する。

## R² の解釈

RF-ANOVA の R² は **ホールドアウトデータ上のランダムフォレストの決定係数**を表す:

$$
R^2 = 1 - \frac{\mathrm{MSE}_{\mathrm{baseline}} \times N_{\mathrm{eval}}}{\sum_i (y_i - \bar{y})^2}
$$

- $R^2 \geq 0.8$（緑）: モデルの当てはまりが良好。重要度の信頼性が高い
- $0.5 \leq R^2 < 0.8$（黄）: やや低め。参考程度として扱う
- $R^2 < 0.5$（赤）: モデルが目的関数を説明できていない。重要度の信頼性が低い

## MDI との比較

| 比較軸         | RF-ANOVA                                 | MDI                                        |
| -------------- | ---------------------------------------- | ------------------------------------------ |
| 測定タイミング | **学習後**（ホールドアウト評価時）       | **学習中**（木構築時に記録）               |
| 計算コスト     | 木構築 + P 回のパーミュテーション評価    | 木 1 本あたり O(N·P·D)                     |
| バイアス       | 相関特徴量の影響が残る                   | 高カーディナリティ特徴量に過大評価傾向あり |
| 解釈           | "欠損させたときにどれだけ精度が落ちるか" | "学習時にどれだけ役立ったか"               |

---

## 計算コストの目安

| 試行数 N | RF-ANOVA 計算時間の目安                   |
| -------- | ----------------------------------------- |
| 50〜200  | < 200ms                                   |
| 1,000    | < 500ms                                   |
| 2,000+   | < 1,000ms（2,000 行にダウンサンプリング） |

MDI は木を 2 回構築するのに対し、RF-ANOVA は 1 回の木構築 + P 回のパーミュテーション評価のため、P が小さい場合は MDI と同程度の計算コスト。いずれもバックグラウンドスレッドで実行されるため UI はブロックされない。
