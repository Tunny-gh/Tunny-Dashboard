# MDI（Mean Decrease Impurity）によるパラメータ重要度

## 概要

MDI（Mean Decrease Impurity、不純度平均減少量）は、**Random Forest の学習過程で記録される分岐の品質**からパラメータ重要度を算出する手法。各パラメータが分岐に使われるたびに、そのノードでの不純度減少量（MSE 削減量）を加算し、全木にわたって平均する。

ImportanceChart では値を合計=1 に正規化して表示する。

### RF-ANOVA（パーミュテーション重要度）との違い

| 比較軸         | MDI                                        | RF-ANOVA                                 |
| -------------- | ------------------------------------------ | ---------------------------------------- |
| 測定タイミング | **学習中**（木構築時に記録）               | **学習後**（ホールドアウト評価時）       |
| 計算コスト     | 木 1 本あたり O(N·P·D)                     | 木構築 + P 回のパーミュテーション評価    |
| バイアス       | 高カーディナリティ特徴量に過大評価傾向あり | 相関特徴量の影響が残る                   |
| 解釈           | "学習時にどれだけ役立ったか"               | "欠損させたときにどれだけ精度が落ちるか" |

## 数式

### ノード不純度減少量

ノード $t$ での**不純度減少量** $\Delta I(t)$ を次で定義する:

$$
\Delta I(t) = \mathrm{MSE}(y_t) - \left[\frac{n_L}{n_t}\mathrm{MSE}(y_L) + \frac{n_R}{n_t}\mathrm{MSE}(y_R)\right]
$$

ここで:

- $y_t$：ノード $t$ のサンプルの目的値
- $y_L, y_R$：左・右の子ノードに分かれたサンプルの目的値
- $n_t, n_L, n_R$：それぞれのサンプル数（$n_t = n_L + n_R$）
- $\mathrm{MSE}(y) = \frac{1}{n}\sum_i (y_i - \bar{y})^2$

### 木あたりの MDI

木 $b$ におけるパラメータ $j$ の MDI は、そのパラメータを使ったすべての分岐ノードに対して、サンプル割合で重み付けした $\Delta I$ の総和:

$$
\mathrm{MDI}_b(j) = \sum_{\substack{t \in \text{木} b \\ \text{分岐特徴量}=j}} \frac{n_t}{n_{\mathrm{root}}} \cdot \Delta I(t)
$$

- $n_{\mathrm{root}}$：木 $b$ のルートノードのサンプル数（ブートストラップサンプルのサイズ）

### Random Forest での平均・正規化

全 $T$ 本の木にわたって平均し、合計が 1 になるよう正規化する:

$$
\mathrm{MDI}(j) = \frac{1}{T}\sum_{b=1}^{T} \mathrm{MDI}_b(j)
$$

$$
\widetilde{\mathrm{MDI}}(j) = \frac{\mathrm{MDI}(j)}{\sum_{j'} \mathrm{MDI}(j')}
$$

## アルゴリズムの手順

```
入力: X (N × P), y (N)

1. データ前処理
   ├── NaN/Inf 行を除外
   └── N > 2000 の場合はランダムサンプリングで 2000 行に削減

2. 80/20 ホールドアウト分割（R² 計算用）
   ├── シャッフル後 80% を訓練データ、20% を評価データとする
   └── N < 4 の場合は全データを訓練・評価両方に使う

3. MDI 集計（T=100 本の木）
   各木 b について:
     3a. 訓練データから N_train 点を復元抽出（ブートストラップ）
     3b. CART 回帰木を再帰的に構築
         - 最良分岐（j*, t*）= argmax Gain(j, t)
         - Gain を記録し、weighted_gain += (n_t / n_root) * Gain
         - 左右サブセットに対して再帰
     3c. 木構築後、全ノードの weighted_gain を特徴量別に集計

4. 正規化
   ├── 木間で平均: MDI(j) /= T
   └── 総和=1 になるよう正規化

5. R² の計算（標準 RandomForest を使用）
   ├── 同じ訓練データで RandomForest を学習
   ├── 評価データで MSE を計算
   └── R² = 1 - MSE_eval * N_eval / SS_total
```

### ハイパーパラメータ

| パラメータ         | 値    | RF-ANOVA との共通点 |
| ------------------ | ----- | ------------------- |
| 木の本数           | 100   | ✓ 同じ              |
| 最大深さ           | 10    | ✓ 同じ              |
| 最小リーフサンプル | 2     | ✓ 同じ              |
| 乱数シード         | 42    | ✓ 同じ              |
| 最大行数           | 2,000 | ✓ 同じ              |

## R² の解釈

MDI の R² は **ホールドアウトデータ上のランダムフォレストの決定係数**を表す:

$$
R^2 = 1 - \frac{\sum_i (y_i - \hat{y}_i)^2}{\sum_i (y_i - \bar{y})^2}
$$

- $R^2 \geq 0.8$（緑）: モデルの当てはまりが良好。重要度の信頼性が高い
- $0.5 \leq R^2 < 0.8$（黄）: やや低め。参考程度として扱う
- $R^2 < 0.5$（赤）: モデルが目的関数を説明できていない。重要度の信頼性が低い

## 注意事項・既知のバイアス

**高カーディナリティ特徴量への過大評価**

MDI は連続値パラメータや取りうる値が多いカテゴリ特徴量に対して、分岐候補が多いぶん重要度を過大評価する傾向がある（Breiman ら, 2001 が指摘）。取りうる値が少ないパラメータと比較するときは注意が必要。

**代替手法**

- 過大評価が懸念される場合は RF-ANOVA（パーミュテーション重要度）を使う。RF-ANOVA はホールドアウトデータ上の実際の予測精度への貢献を測定するため、カーディナリティバイアスが少ない。
- Sobol 指標は大域的感度を分散分解で定量化するが、計算コストが高い。

## 計算コストの目安

| 試行数 N | MDI 計算時間の目安                        |
| -------- | ----------------------------------------- |
| 50〜200  | < 200ms                                   |
| 1,000    | < 500ms                                   |
| 2,000+   | < 1,000ms（2,000 行にダウンサンプリング） |

MDI は木を 2 回構築する（MDI 用の MdiNode 木 + R² 用の RandomForest）ため、RF-ANOVA よりも計算量が約 2 倍になる。いずれもバックグラウンドスレッドで実行されるため UI はブロックされない。
