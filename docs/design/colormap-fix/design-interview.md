# カラーマップ色反映と拡張 設計ヒアリング記録

**作成日**: 2026-04-16
**ヒアリング実施**: step4 既存情報ベースの差分ヒアリング

## ヒアリング目的

egui-appのカラーマップ選択UIが色生成に接続されていない問題と、Jet等の一般的なカラーマップが未実装の問題について、設計方針を決定するためのヒアリングを実施しました。

## 質問と回答

### Q1: ColorModeとColormapNameの関係

**質問日時**: 2026-04-16
**カテゴリ**: アーキテクチャ
**背景**: ColorMode（何で色分けするか）とColormapName（どの配色を使うか）を独立させるか、ColorModeごとに固定カラーマップを割り当てるかで設計が大きく異なるため

**回答**: 独立選択（推奨） — ColorMode と ColormapName を別々に選択。ParetoRank+Viridis、TrialNumber+Jet など自由な組み合わせが可能

**信頼性への影響**:
- この回答により、`AppState` に `selected_colormap: ColormapName` フィールドを追加する設計が確定（信頼性: 🔵）
- UI に2つの独立した ComboBox を配置する設計が確定（信頼性: 🔵）

---

### Q2: 追加するカラーマップ

**質問日時**: 2026-04-16
**カテゴリ**: 技術選択
**背景**: 既存のViridis/Plasma/BlueYellowに加えてどのカラーマップを追加するかで、ColorMap構造体の拡張量が決まるため

**回答**: Jet, Turbo, Inferno, Coolwarm, Spectral, Plasma（既存）, Cividis を追加

**信頼性への影響**:
- ColormapName 列挙体のバリアントが確定（信頼性: 🔵）
- 各カラーマップの停止点定義が必要（5-7停止点近似）

---

### Q3: ClusterIdの離散色パレット

**質問日時**: 2026-04-16
**カテゴリ**: データモデル
**背景**: ClusterIdは離散値であり、連続カラーマップの補間では適切に表現できない。離散パレットを別途用意するかどうかで正規化ロジックが分岐するため

**回答**: 追加する — Tab10/Tableau10相当の10色離散パレット

**信頼性への影響**:
- `tab10_palette()` 関数の追加が確定（信頼性: 🔵）
- `normalize_trial()` 内で ClusterId の分岐処理が必要（信頼性: 🔵）

---

### Q4: PDPヒートマップの連動

**質問日時**: 2026-04-16
**カテゴリ**: アーキテクチャ
**背景**: PDP 2D ウィジェットは現在 viridis/plasma を直接使用している。AppState のカラーマップ選択に連動させるか独立させるかで、PDPウィジェットの変更範囲が決まるため

**回答**: 連動させる — 散布図とPDPヒートマップで同じカラーマップセレクタを共有

**信頼性への影響**:
- PDP 2D ウィジェットが `app_state.selected_colormap.to_colormap()` を使用する設計が確定（信頼性: 🔵）

---

### Q5: 色再計算の方式

**質問日時**: 2026-04-16
**カテゴリ**: パフォーマンス
**背景**: ColorMode/ColormapName変更時に5万点の色を再計算する方式（同期 vs 非同期）でUIの応答性が変わるため

**回答**: 即時同期（推奨） — ColorMode/ColormapName変更時に即座に全点の色を再計算

**信頼性への影響**:
- `update_chart_colors()` をUIスレッド内で同期的に呼び出す設計が確定（信頼性: 🔵）
- メッセージハンドラを経由しない（信頼性: 🔵）

---

### Q6: 実装範囲

**質問日時**: 2026-04-16
**カテゴリ**: 優先順位
**背景**: 現在4つのウィジェットがハードコード色を使用している。一斉に対応させるか段階的に進めるかでタスク分割が変わるため

**回答**: 全ウィジェット対応（推奨） — pareto_2d, scatter_matrix, cluster_scatter, pdp_2d の全てに対応

**信頼性への影響**:
- 4ウィジェットすべての変更がタスクに含まれる（信頼性: 🔵）
- 段階的リリースなし（信頼性: 🔵）

---

## ヒアリング結果サマリー

### 確認できた事項
- ColorMode と ColormapName は独立した選択肢
- 追加カラーマップ: Jet, Turbo, Inferno, Coolwarm, Spectral, Cividis
- ClusterId 用の離散パレット（Tab10相当10色）を追加
- PDP ヒートマップも AppState のカラーマップ選択に連動
- 色再計算は即時同期（メッセージ不要）
- 全4ウィジェットに一斉対応

### 設計方針の決定事項
- `ColormapName` 列挙体を新規追加（9バリアント）
- `AppState` に `selected_colormap` と `chart_colors` を追加
- `update_chart_colors()` メソッドで即時再計算
- 各ウィジェットは `chart_colors[i]` から色を取得
- PDP は `selected_colormap.to_colormap()` でヒートマップ色を生成

### 残課題
- なし（全項目についてユーザーの意思決定を確認済み）
