## 実装詳細

### 1. COLOR_INFEASIBLE 定数の追加 🔵
**信頼性**: 🔵 *要件定義書 REQ-CAV-011 + ユーザヒアリング 2026-06-03 より*

**実装ファイル**: `egui-app/src/theme/chart_colors.rs`

```rust
pub const COLOR_INFEASIBLE: Color32 = Color32::from_rgba_premultiplied(56, 56, 56, 80);
```

追加位置: ファイル末尾のコメントセクション

### 2. ウィジェット構造体へのフィールド追加 🔵
**信頼性**: 🔵 *要件定義書 REQ-CAV-014 + 設計文書 architecture.md より*

各ウィジェットファイル（`pareto_2d.rs`, `pareto_3d.rs`, `optimization_history.rs`, `parallel_coords.rs`, `scatter_matrix.rs`, `cluster_scatter.rs`）の構造体定義に `pub show_infeasible: bool` を追加し、`Default` impl で `true` を設定する。

```rust
// 各構造体に追加
pub show_infeasible: bool,

// Default impl に追加

```

### 3. message_handler.rs の StudySelected リセット 🔵
**信頼性**: 🔵 *要件定義書 REQ-CAV-014 + ユーザヒアリング 2026-06-03 より*

**実装ファイル**: `egui-app/src/state/message_handler.rs`

StudySelected ハンドラ（L49〜53付近）に以下を追加:
- `widget_states.pareto_2d.show_infeasible = true;`（または `widget_states.pareto_2d = Default::default();`）
- 同様に opt_history, parallel_coords, scatter_matrix のリセット
- `pareto_3d` は GPU リソースを保持するため `show_infeasible` のみリセット

注意: `pareto_2d` を `Default::default()` でリセットすると x_axis/y_axis も初期化されるため、`show_infeasible` フィールドのみ明示的にリセットする方が安全。

- `Color32::from_rgba_premultiplied` は premultiplied alpha であることに注意（egui の標準 Color32 API に従う）
