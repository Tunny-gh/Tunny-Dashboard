### 1. ScatterMatrix の変更 🔵
**信頼性**: 🔵 *要件定義書 REQ-CAV-070〜073 + 設計文書 architecture.md より*

**実装ファイル**: `egui-app/src/ui/widgets/scatter_matrix.rs`

全セル（散布図）の点描画ループに追加:

```rust
// ループ前（各セルの描画開始時）
let is_feasible_col = view.numeric_column("is_feasible");
let has_constraints = is_feasible_col.is_some();

// ループ内（trial ごと）
let feasible = is_feasible_col
    .and_then(|c| c.get(i))
    .map(|&v| v > 0.5)
    .unwrap_or(true);

let color = if !feasible {
    if !self.show_infeasible {
        continue; // スキップ
    }
    COLOR_INFEASIBLE // infeasible 点: 通常色より優先
} else {
    existing_color_for_trial(i) // feasible 点: 従来の色
};
```

"Show Infeasible" トグルをコントロール領域（グローバルコントロール行）に追加:

```rust
if has_constraints {
    ui.separator();
    ui.checkbox(&mut self.show_infeasible, "Show Infeasible");
}
```

注意: ScatterMatrix は複数セルに同一ループロジックが存在する場合があるため、共通化できるヘルパー関数（`feasibility_color()` 等）の導入を検討する。

## 注意事項
- TASK-2346 の完了（`show_infeasible` フィールド追加）が前提。必ず TASK-2346 完了後に着手すること
- ClusterScatter は Study 切替時に `message_handler.rs` L51 で `Default::default()` によるリセットが既実装済み。TASK-2346 で `show_infeasible` フィールドを追加すれば、`Default::default()` で `true` にリセットされるため追加対応不要
- ScatterMatrix は複数セル（N×N グリッド）に同一の feasibility ロジックが必要。セルごとにコピーするのではなく、共通ヘルパー関数（例: `point_color(feasible: bool, show_infeasible: bool, default_color: Color32) -> Option<Color32>`）を実装してコードの重複を避けること
- ClusterScatter の `COLOR_INFEASIBLE` はクラスタ色（各クラスタに割り当てられた色）より優先する。判定順序を `if !feasible { COLOR_INFEASIBLE }` → `else { cluster_color(...) }` とすること
