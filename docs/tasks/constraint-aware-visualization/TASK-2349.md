**信頼性**: 🔵 *要件定義書 REQ-CAV-080〜083 + 設計文書 architecture.md より*

**実装ファイル**: `egui-app/src/ui/widgets/parallel_coords.rs`

折れ線描画ループに追加:

```rust
// ループ前
let is_feasible_col = view.numeric_column("is_feasible");
let has_constraints = /* view から判断 */;

// ループ内（trial ごと）
let feasible = is_feasible_col
    .and_then(|c| c.get(trial_idx))
    .map(|&v| v > 0.5)
    .unwrap_or(true);

if !feasible {
    if !self.show_infeasible {
        continue; // スキップ
    }
    // infeasible 折れ線: COLOR_INFEASIBLE で描画
    draw_polyline(COLOR_INFEASIBLE, ...);
    continue;
}
// feasible 折れ線: 従来の色分けロジック（変更なし）
draw_polyline(existing_color(...), ...);
```

"Show Infeasible" トグルをコントロール領域に追加:

```rust
if has_constraints {
    ui.separator();
    ui.checkbox(&mut self.show_infeasible, "Show Infeasible");
}
```
