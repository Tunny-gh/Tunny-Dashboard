### 1. 入力検証ヘルパー（validate_inputs） 🔵

**信頼性**: 🔵 *既存topsis.rsのvalidate_inputs実装パターンより*

**実装ファイル**: `rust_core/src/mcdm/vikor.rs`

```rust
fn validate_inputs(
    values: &[f64],
    n_trials: usize,
    n_objectives: usize,
    weights: &[f64],
    is_minimize: &[bool],
) -> Result<(), String> {
    if n_trials == 0 { return Err("n_trials must be >= 1".to_string()); }
    if n_objectives == 0 { return Err("n_objectives must be >= 1".to_string()); }
    if values.len() != n_trials * n_objectives {
        return Err(format!("values length mismatch: expected {}, got {}",
            n_trials * n_objectives, values.len()));
    }
    if weights.len() != n_objectives {
        return Err(format!("weights length mismatch: expected {}, got {}", n_objectives, weights.len()));
    }
    if is_minimize.len() != n_objectives {
        return Err(format!("is_minimize length mismatch: expected {}, got {}", n_objectives, is_minimize.len()));
    }
    Ok(())
}
```

### 2. best/worst値の計算 🔵

**信頼性**: 🔵 *VIKORアルゴリズム仕様・dataflow.md計算ステップ3より*

各基準jの最良値f*_jと最悪値f-_jを決定する。

```rust
fn compute_best_worst(
    values: &[f64],
    n_objectives: usize,
    is_minimize: &[bool],
    valid_indices: &[usize],
) -> (Vec<f64>, Vec<f64>) {
    let mut col_min = vec![f64::INFINITY; n_objectives];
    let mut col_max = vec![f64::NEG_INFINITY; n_objectives];
    for &i in valid_indices {
        for j in 0..n_objectives {
            let v = values[i * n_objectives + j];
            if v < col_min[j] { col_min[j] = v; }
            if v > col_max[j] { col_max[j] = v; }
        }
    }
    let mut best = vec![0.0f64; n_objectives];
    let mut worst = vec![0.0f64; n_objectives];
    for j in 0..n_objectives {
        (best[j], worst[j]) = if is_minimize[j] {
            (col_min[j], col_max[j])
        } else {
            (col_max[j], col_min[j])
        };
    }
    (best, worst)
}
```

### 3. S値とR値の計算 🔵

**信頼性**: 🔵 *VIKORアルゴリズム仕様・dataflow.md計算ステップ4より*

S_i = Σ_j w_j * (f*_j - f_ij) / (f*_j - f-_j)
R_i = max_j { w_j * (f*_j - f_ij) / (f*_j - f-_j) }

ゼロ除算ガード: `range_j = |best_j - worst_j|`。`range_j < ε` の場合は寄与分 = 0。

### 4. Q値の計算 🔵

**信頼性**: 🔵 *VIKORアルゴリズム仕様・dataflow.md計算ステップ5より*

Q_i = v * (S_i - S*) / (S- - S*) + (1-v) * (R_i - R*) / (R- - R*)

ゼロ除算ガード:
- `S- - S* < ε` → 第1項 = 0
- `R- - R* < ε` → 第2項 = 0

### 5. NaN後処理・ranked_indices生成 🔵

**信頼性**: 🔵 *REQ-101・ユーザヒアリング（TOPSIS同方針）より*

NaN試行: s=0.0, r=0.0, q=1.0。display_scores[NaN試行] = 0.0（= 1.0 - 1.0）。
ranked_indices: valid試行をQ昇順ソート後、NaN試行を末尾に追加。

fn tc_vikor_perf01_50k_trials() {
    let n = 50_000;
    let m = 4;
    let values: Vec<f64> = (0..n*m).map(|i| (i % 100) as f64).collect();
    let weights = [0.25f64; 4];
    let is_minimize = [true; 4];
    let start = std::time::Instant::now();
    let _ = compute_vikor(&values, n, m, &weights, &is_minimize, 0.5).unwrap();
    assert!(start.elapsed().as_millis() < 100);
}
