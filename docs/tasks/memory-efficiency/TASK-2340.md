## タスク概要

ライブ更新を ArcSwap スナップショット差替え方式へ移行する。現行 `handle_live_update_done`（`message_handler.rs:209-268`）は `study.trial_rows` に追記し、Pareto ランクと `gpu_data` を再構築している。これを、ワーカー側で新試行を取り込んだ DataFrame を再構築 → `ArcSwap::store` で原子的差替え → UI 側で StudyView 並行配列（pareto_rank 等）を再算出、の流れに変更する。描画中の旧スナップショットが安全に生存することを保証する（EDGE-102）。

## 実装詳細

### 1. スナップショット再構築と差替え 🔵

**信頼性**: 🔵 *design-interview.md Q1・dataflow.md フロー3 より*

ワーカー（ポーラ）で新 batch を取り込んだ DataFrame を構築し `swap_snapshot(study_id, new_df)`。UI は次フレームで `snapshot` を取得し StudyView を更新。

**実装ファイル**: `egui-app/src/state/message_handler.rs`（handle_live_update_done）, ライブ更新ポーラ経路

### 2. 派生属性の再算出 🔵

**信頼性**: 🔵 *message_handler.rs:230-252（nd_sort/rank）より*

差替え後、`nd_sort` で Pareto ランクを再算出し `view.pareto_rank`/`pareto_indices` を更新。`gpu_data` 再構築（`build_gpu_data_from_rows`）は撤廃（TASK-2342 で gpu_data 削除のため）。

### 3. all_studies カウント更新 🔵

**信頼性**: 🔵 *message_handler.rs:257-266 より*

`updated_study_counts` による `completed_trials` 更新は現行どおり維持。
