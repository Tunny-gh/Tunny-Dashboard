## タスク概要

Parallel Coordinates（`col_data_cache: Option<Vec<Vec<f64>>>` + `col_ranges_cache`、`parallel_coords.rs:71-72`）と Scatter Matrix（`col_data_cache: Option<Vec<Vec<f64>>>`、`scatter_matrix.rs:31`）が同一 study データに対し独立に保持しているフルカラムキャッシュを、StudyView の共有列参照、または一元化された派生列キャッシュへ置換する。ウィジェット切り替えでメモリが可視化数に線形比例しないようにする（NFR-201）。

## 実装詳細

### 1. 派生列の一元化方針決定と実装 🔵

**信頼性**: 🔵 *REQ-007・architecture.md より*

可視化に必要な数値列は StudyView の `numeric_column` 借用で都度取得、または共有派生列ストア（AppState 側 or StudyView 内）に一度だけ構築して両ウィジェットで参照。正規化レンジ（col_ranges）も一元化。

**実装ファイル**: `egui-app/src/ui/widgets/parallel_coords.rs`, `egui-app/src/ui/widgets/scatter_matrix.rs`（必要に応じ `egui-app/src/state/`）

### 2. キャッシュ無効化ルール 🔵

**信頼性**: 🔵 *REQ-403・各 cache_key より*

`cache_key`（trial_count, n_params, n_objs）に基づく無効化を共有キャッシュ側に集約。
