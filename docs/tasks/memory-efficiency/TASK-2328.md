**実装ファイル**: `rust_core/Cargo.toml`

### 2. SharedStudyStore 骨格定義 🔵

**信頼性**: 🔵 *types.rs `SharedStudyStore` より*

`study_id → ArcSwap<DataFrame>` のマップと `active_study_id` を持つ構造体と、空の `store_all` / `snapshot` / `swap_snapshot` メソッドシグネチャを定義する（中身は TASK-2329）。

**実装ファイル**: `rust_core/src/data/dataframe/state.rs`

```rust
use arc_swap::ArcSwap;
use std::collections::HashMap;
use std::sync::Arc;

pub struct SharedStudyStore {
    slots: HashMap<u32, ArcSwap<DataFrame>>,
    active_study_id: Option<u32>,
}
```
