## タスク概要

`StudyContext`（`egui-app/src/state/types.rs:59`）から `trial_rows: Vec<TrialRow>` を撤廃し `view: StudyView` に置換する。`AppMessage::StudySelected` のペイロードを `trial_rows`/`gpu_data` 非搬送に変更し、`io/study.rs:46-94` の `extract_trial_rows` を撤廃して共有ストアの `snapshot` から StudyView を構築する。`message_handler.rs:25-43` の StudySelected ハンドラを新ペイロードへ対応させる。互換シム `row_at` により、本タスク時点で既存ウィジェットは未変更でもコンパイル可能に保つ。

## 実装詳細

### 1. StudyContext / StudySelected の再設計 🔵

**信頼性**: 🔵 *types.rs・message_handler.rs:25-43 より*

`trial_rows`/`gpu_data` を撤廃。`StudySelected` は `{ meta, study_id, pareto_rank, state, pareto_indices }` を運ぶ。

**実装ファイル**: `egui-app/src/state/types.rs`, `egui-app/src/state/messages.rs`, `egui-app/src/state/message_handler.rs`

### 2. study.rs の選択タスク刷新 🔵

**信頼性**: 🔵 *io/study.rs:46-144 より*

`extract_trial_rows` を撤廃。`select_study_task` は Pareto ランク算出後、派生属性（pareto_rank/state）と pareto_indices のみを `StudySelected` で返す。列データは共有ストア参照。

**実装ファイル**: `egui-app/src/io/study.rs`

### 3. StudyView 構築の配線 🔵

**信頼性**: 🔵 *dataflow.md フロー1（After）より*

`message_handler` の StudySelected 受信時に、`snapshot(study_id)` + 派生属性から StudyView を構築し StudyContext に格納。
