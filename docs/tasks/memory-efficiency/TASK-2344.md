## タスク概要

全 MEM 項目の実装完了後、改修後のメモリを TASK-2343 の基盤で測定し、PRD の削減目標（定常 -50% 以上等）を数値検証する。あわせて `cargo test --workspace` のグリーンを等価性の主証拠として確認する（REQ-404）。目標未達の項目があれば原因を特定し是正タスクを起票する。

## 実装詳細

### 1. 改修後メモリ測定 🔵

**信頼性**: 🔵 *NFR-004・TASK-2343 基盤より*

TASK-2343 の手順・データセットで定常／ロードピーク／分析ピークを測定し、ベースラインと比較。各 NFR の目標達成可否を判定。

**実装ファイル**: 測定結果記録（`docs/spec/memory-efficiency/` または検証レポート）

### 2. 等価性確認 🔵

**信頼性**: 🔵 *REQ-404・ヒアリングQ5 より*

`cargo test --workspace` 全パスを確認。チャート出力・分析結果の等価性をテストで担保。

### 3. 応答性確認 🟡

**信頼性**: 🟡 *NFR-005（妥当な推測）より*

study 選択・分析・描画の `[timing]` ログを改修前後で比較し悪化なしを確認。

### 4. 未達是正 🔵

**信頼性**: 🔵 *品質判定基準より*

目標未達の MEM 項目があれば原因分析し是正タスクを起票（例: ライブ更新の全列再ビルドコストが NFR-005 違反なら差分追記方式へ）。
