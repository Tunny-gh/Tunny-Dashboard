## タスク概要

メモリ削減効果を定量検証するためのベンチマーク基盤を整え、改修前（ベースライン）の定常・ピークメモリを測定・記録する。代表データセット（100k trials × 約22列、prep.md で用意）を用い、Windows 環境での測定手段（RSS / dhat 等）を確定する。本タスクは改修着手前のベースライン取得が目的のため、現行 `main` 相当に対して実施できるよう基盤を独立させる。
