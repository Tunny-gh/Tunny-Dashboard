## タスク概要

`Arc<DataFrame>` をラップし、アプリ層算出の行属性（`pareto_rank`/`cluster_id`/`state`/`trial_ids`）を並行配列で保持する UI 側軽量ビュー `StudyView` を新規実装する。ウィジェット段階移行を支えるため、一時的な互換ヘルパー `row_at(index) -> TrialRow`（永続保持しない）と列スライス借用 API（`numeric_column`）を提供する。
