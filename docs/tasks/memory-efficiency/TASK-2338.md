## タスク概要

PDP / Surface Plot / Sensitivity の入力行列構築を、行データからの `Vec<Vec<f64>>` 再構築から列スライス借用・フラットバッファへ置換する。現行 `poll_chart.rs:16-22` は `r.params.get(p)` の HashMap 参照で実行ごとに行列を再構築している。StudyView の列借用を使い、入力不変時の再生成を避ける（REQ-102）。
