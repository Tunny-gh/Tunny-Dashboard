## タスク概要

未使用のホスト側 `gpu_data` を `StudyContext` から撤廃し、全ウィジェット移行完了後に StudyView の互換ヘルパー `row_at` を除去する。コード調査では `StudyContext.gpu_data`（`types.rs:62`）は `message_handler.rs:254` で書き込まれるのみで、描画側（`render/gpu_buffer.rs` はレイアウト定数）からの `.gpu_data` 読み出しが存在しない。撤廃前に描画経路の最終確認を行う。

## 実装詳細

### 1. gpu_data 未使用の最終確認 🔵

**信頼性**: 🔵 *grep 結果（`.gpu_data` は書き込み message_handler.rs:254・テスト poller_integration.rs:147 のみ）より*

描画経路（`render/`, GPU 散布図ウィジェット）が `StudyContext.gpu_data` を読まないことを再確認。読まれている場合は撤廃を中止し設計へフィードバック。

### 2. gpu_data 経路の撤廃 🔵

**信頼性**: 🔵 *REQ-013・types.rs:62 より*

`StudyContext` から `gpu_data` を削除（TASK-2332 で未削除なら本タスクで）。`build_gpu_data_from_rows`（message_handler.rs:270）・ライブ更新での gpu_data 再構築・`build_gpu_buffer_data`（study.rs:13）の不要分を撤廃。

**実装ファイル**: `egui-app/src/state/types.rs`, `egui-app/src/state/message_handler.rs`, `egui-app/src/io/study.rs`

### 3. 互換シム row_at の除去 🔵

**信頼性**: 🔵 *types.rs（row_at は移行用）・ヒアリング（段階移行）より*

全ウィジェットが列アクセスへ移行済みであることを確認し、StudyView の `row_at`（および移行用 `TrialRow` 残骸）を除去。

**実装ファイル**: `egui-app/src/state/types.rs`（StudyView）
