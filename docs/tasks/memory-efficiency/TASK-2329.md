## タスク概要

`rust_core/src/data/dataframe/state.rs` の thread_local `GLOBAL_STATE`（`dataframes: Vec<DataFrame>` + `active_study_id`）を、`SharedStudyStore`（`study_id → ArcSwap<DataFrame>`）へ置き換える。`store_dataframes` / `select_study` / `with_active_df` / `with_df` の各公開関数を共有ストア版へ移行し、UI/ワーカー両スレッドから `Arc<DataFrame>` をクローン取得できるようにする。

## 実装詳細

### 1. 共有ストアのプロセスグローバル化 🔵

**信頼性**: 🔵 *architecture.md「thread_local 廃止」・state.rs:12-21 より*

thread_local をやめ、`OnceLock<RwLock<SharedStudyStore>>`（マップ構造の保護）または各スロット `ArcSwap` ＋ マップ自体は初期構築後不変、の方式でプロセス共有にする。読み取りはロックフリーな `ArcSwap::load_full()`。

**実装ファイル**: `rust_core/src/data/dataframe/state.rs`

### 2. 公開 API の移行 🔵

**信頼性**: 🔵 *state.rs:27-80 の既存 API より*

- `store_dataframes(dfs)` → `store_all`（study_id ごとに `ArcSwap` スロット構築）
- `select_study(study_id)` → active 設定＋`SelectStudyResult`（info/gpu_buffers）返却を維持
- `with_active_df(f)` / `with_df(id, f)` → スナップショット取得後にクロージャ適用（後方互換シグネチャを維持）

**実装ファイル**: `rust_core/src/data/dataframe/state.rs`, `rust_core/src/data/dataframe/mod.rs`（re-export）

### 3. スレッド間共有の担保 🔵

**信頼性**: 🔵 *dataflow.md フロー1 より*

ワーカースレッドで `store_all` した DataFrame を、UI スレッド相当から `snapshot` 取得できることを保証（thread_local の制約を解消）。

## 注意事項

- `select_study` の戻り値 `SelectStudyResult`（`data_frame_info` / `gpu_buffer_data`）は呼び出し側互換のため維持。
- マップ保護に `RwLock` を使う場合、読み取りは短時間で `Arc` を取り出し即解放しロック競合を避ける。
