## タスク概要

`pareto_rank`・`cluster_id`・`state` などアプリ層算出の行属性を、`StudyView` の並行配列に書き込む経路へ統一する。現行は `trial_rows` の各要素フィールドを直接ミューテートしている（例: クラスタリング結果反映、Pareto ランク設定）。これらを並行配列更新に置換し、`AppState::clear`（`app_state.rs:136`）の無効化ルールと整合させる。

## 実装詳細

### 1. クラスタ ID 反映の並行配列化 🔵

**信頼性**: 🔵 *message_handler.rs:320-347（handle_clustering_done）より*

`ClusteringDone` で `result.labels` を `view.cluster_id` に書き込む（現行は trial_rows.cluster_id 相当）。labels 長と row_count の整合チェックを維持。

**実装ファイル**: `egui-app/src/state/message_handler.rs`

### 2. Pareto ランク反映の並行配列化 🔵

**信頼性**: 🔵 *io/study.rs:124-128・message_handler.rs:244-252 より*

ランク算出結果を `view.pareto_rank` に格納。`pareto_indices` は StudyContext 側で保持。

### 3. 無効化ルールの整合 🔵

**信頼性**: 🔵 *app_state.rs:136-167（clear）・REQ-202 より*

study 切替（`clear`）で旧 StudyView と関連結果（cluster_result 等）を解放。
