## タスク概要

比較モードのメモリを軽量化する。現行 `comparison_studies: Vec<StudyContext>`（`app_state.rs:43`、フル保持）を、`study_id` 参照＋軽量メタ＋遅延 `StudyView`（`ComparisonStudy` 型）へ変更する。比較ロード `load_comparison_study_task`（`study_worker.rs:74-129`）のジャーナル全体再パースを廃止し、TASK-2330 で常駐化した共有ストアから `snapshot(study_id)` で参照する。

### 1. ComparisonStudy 型への置換 🔵

**信頼性**: 🔵 *types.rs `ComparisonStudy`・app_state.rs:43 より*

`comparison_studies: Vec<ComparisonStudy>` に変更。`study_id` 参照＋一覧用メタ、描画時に遅延 `StudyView` 構築（共有ストア snapshot）。

**実装ファイル**: `egui-app/src/state/app_state.rs`, `egui-app/src/state/message_handler.rs`（ComparisonStudyLoaded ハンドラ）

### 2. 比較ロードの再パース廃止 🔵

**信頼性**: 🔵 *study_worker.rs:74-129・design-interview.md Q2 より*

`load_comparison_study_task` の `parse_journal` 再実行を廃止し、共有ストアの `snapshot(study_id)` を使う。study 選択ロジック（`choose_comparison_study`）は維持。

**実装ファイル**: `egui-app/src/io/study_worker.rs`

### 3. 解放ルール 🔵

**信頼性**: 🔵 *app_state.rs:128-133（reset_comparison_session）・REQ-201 より*

比較削除・リセットで `ComparisonStudy`（遅延 view 含む）をドロップし Arc 参照を解放。
