Pareto 2D / 3D ウィジェットの `display_rows_cache: Option<Vec<TrialRow>>`（`pareto_2d.rs:38`, `pareto_3d.rs:99`）を撤廃し、描画に必要な最小データ（フィルタ済みインデックス・点座標・ランクスライス）のみをキャッシュする。データ供給は StudyView の列借用・並行配列へ移行する。

## 実装詳細

### 1. Pareto 2D の最小キャッシュ化 🔵

**信頼性**: 🔵 *pareto_2d.rs:38-85・REQ-005 より*

`display_rows_cache` を `point_cache: Option<Vec<[f32; 2]>>`（＋必要なランク/色スライス）に置換。`cache_key`（trial_count, downsample_count）は維持。データ供給は `view.numeric_column`/並行配列。

**実装ファイル**: `egui-app/src/ui/widgets/pareto_2d.rs`

### 2. Pareto 3D の最小キャッシュ化 🔵

**信頼性**: 🔵 *pareto_3d.rs:99-327 より*

同様に `display_rows_cache` を撤廃し点座標キャッシュへ。`range_cache`/`range_cache_key` は維持。

**実装ファイル**: `egui-app/src/ui/widgets/pareto_3d.rs`
