## タスク概要

初回ジャーナルパース時に、全 study の `DataFrame` を `study_id` キーで共有ストアに格納する経路を確立する。現行は `finalize_state`（`rust_core/src/io/journal/parser/finalize.rs:104-114`）が `Vec<DataFrame>` を返し、`store_dataframes` で Vec として格納している。これを `study_id → DataFrame` の `store_all` に接続し、後続の main/比較ロードが再パースなしで参照できる土台を作る。
