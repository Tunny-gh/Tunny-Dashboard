## タスク概要

Trial Table（`egui-app/src/ui/widgets/trial_table.rs`）の表示行取得を `StudyView` ベースへ移行する。現行は `get_display_rows_with_pins`（`trial_table.rs:121`）が `study_ctx.trial_rows` を参照して `&TrialRow` のリストを返す。StudyView の行インデックス＋列借用に置換し、選択・ピン留めフィルタ（`filter_rows_for_display`）の挙動を維持する。

## 実装詳細

### 1. 表示行取得の StudyView 化 🔵

**信頼性**: 🔵 *trial_table.rs:121-135・app_state.rs:190-201 より*

`get_display_rows_with_pins` を、`view` の行インデックス集合（selected ∪ pinned）を返す形に変更。各行のセル値は `view.numeric_column`/`row_at` で取得。

**実装ファイル**: `egui-app/src/ui/widgets/trial_table.rs`

### 2. 遅延描画の維持 🔵

**信頼性**: 🔵 *trial_table.rs:59-60（body.rows）より*

`TableBuilder` の行遅延描画でインデックス→列値参照に置換し、全行 TrialRow 化を避ける。
