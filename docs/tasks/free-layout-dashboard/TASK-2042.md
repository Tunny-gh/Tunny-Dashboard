## タスク概要
グリッドの各セルを右クリックすると `ui.context_menu()` でメニューを表示する。メニュー項目は「右に拡張」「下に拡張」「縮小（右）」「縮小（下）」「クリア」。各項目の有効/無効は境界条件や現在のspan状態で制御する。

## 実装詳細

### コンテキストメニューの実装 🔵
```rust
cell_response.context_menu(|ui| {
    let can_right = col + cell.col_span as usize < layout.grid.cols;
    if ui.add_enabled(can_right, egui::Button::new("右に拡張")).clicked() {
        layout.grid.expand_right(r, c);
        ui.close_menu();
    }
    let can_down = row + cell.row_span as usize < layout.grid.rows;
    if ui.add_enabled(can_down, egui::Button::new("下に拡張")).clicked() {
        layout.grid.expand_down(r, c);
        ui.close_menu();
    }
    if ui.add_enabled(cell.col_span > 1, egui::Button::new("縮小（右）")).clicked() {
        layout.grid.shrink_right(r, c);
        ui.close_menu();
    }
    if ui.add_enabled(cell.row_span > 1, egui::Button::new("縮小（下）")).clicked() {
        layout.grid.shrink_down(r, c);
        ui.close_menu();
    }
    ui.separator();
    if ui.add_enabled(cell.content.is_some(), egui::Button::new("クリア")).clicked() {
        layout.grid.cells[r][c].content = None;
        ui.close_menu();
    }
});
```
