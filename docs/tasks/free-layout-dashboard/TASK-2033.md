`GridCell` はグリッドの1セルの状態を表し、content / col_span / row_span / merged_into を持つ。

## 実装詳細

### 1. PanelItem enum の定義 🔵

**信頼性**: 🔵 *設計文書 interfaces.rs より*

**実装ファイル**: `egui-app/src/state/layout_state.rs`

```rust
#[derive(Debug, Clone, PartialEq, Eq, Hash)]
pub enum PanelItem {
    Chart(ChartId),
    TrialTable,
}

impl PanelItem {
    pub fn label(&self) -> &'static str {
        match self {
            PanelItem::Chart(id) => id.label(),
            PanelItem::TrialTable => "Trial Table",
        }
    }

    pub fn all() -> Vec<PanelItem> {
        let mut items: Vec<PanelItem> = ChartId::all()
            .iter()
            .map(|id| PanelItem::Chart(id.clone()))
            .collect();
        items.push(PanelItem::TrialTable);
        items
    }
}
```

### 2. GridCell 構造体の定義 🔵

**信頼性**: 🔵 *設計文書 interfaces.rs より*

**実装ファイル**: `egui-app/src/state/layout_state.rs`

```rust
#[derive(Debug, Clone, Default)]
pub struct GridCell {
    pub content: Option<PanelItem>,
    pub col_span: u8,
    pub row_span: u8,
    pub merged_into: Option<(usize, usize)>,
}

impl GridCell {
    pub fn new_empty() -> Self {
        Self { content: None, col_span: 1, row_span: 1, merged_into: None }
    }
    pub fn is_active(&self) -> bool {
        self.merged_into.is_none()
    }
}
```
