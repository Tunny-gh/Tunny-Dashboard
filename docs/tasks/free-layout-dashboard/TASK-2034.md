## 実装詳細

### 1. GridLayout 構造体の定義 🔵

**信頼性**: 🔵 *設計文書 interfaces.rs より*

**実装ファイル**: `egui-app/src/state/layout_state.rs`

```rust
#[derive(Debug, Clone)]
pub struct GridLayout {
    pub rows: usize,
    pub cols: usize,
    pub cells: Vec<Vec<GridCell>>,
}

impl Default for GridLayout {
    fn default() -> Self {
        let cells = vec![
            vec![GridCell::new_empty(), GridCell::new_empty()],
            vec![GridCell::new_empty(), GridCell::new_empty()],
        ];
        Self { rows: 2, cols: 2, cells }
    }
}
```

### 2. 各メソッドの実装 🔵

**信頼性**: 🔵 *設計文書 interfaces.rs より*

- `place(row, col, item)`: 既存配置を探してクリア後、対象セルに配置
- `placed_items()`: 全セルを走査し content のある参照を返す
- `add_row()` / `add_col()`: 行/列を末尾に追加
- `try_remove_last_row()` / `try_remove_last_col()`: 空チェック後に削除
- `expand_right(r, c)` / `expand_down(r, c)`: 隣接セルを merged_into に設定

## 単体テスト要件

### テストケース1: Default が2×2グリッド 🔵

**Given**: `GridLayout::default()`
**Then**: `rows=2, cols=2, cells.len()=2, cells[0].len()=2`

### テストケース2: place() がアイテムを配置 🔵

**Given**: 空の2×2グリッド
**When**: `place(0, 0, PanelItem::TrialTable)`
**Then**: `cells[0][0].content = Some(PanelItem::TrialTable)`

### テストケース3: place() が移動時に元セルをクリア 🔵

**Given**: `cells[0][0]` に `PanelItem::TrialTable` を配置済み
**When**: `place(1, 1, PanelItem::TrialTable)`
**Then**: `cells[0][0].content = None`, `cells[1][1].content = Some(PanelItem::TrialTable)`

### テストケース4: try_remove_last_row() でコンテンツありは削除不可 🔵

**Given**: 最終行の `cells[1][0]` にアイテムあり
**When**: `try_remove_last_row()`
**Then**: `false` を返し行数変わらず

### テストケース5: expand_right() が境界内でセル結合 🔵

**Given**: 2×2グリッド
**When**: `expand_right(0, 0)`
**Then**: `cells[0][0].col_span = 2`, `cells[0][1].merged_into = Some((0, 0))`
