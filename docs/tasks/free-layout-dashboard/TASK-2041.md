## タスク概要
右パネルの各アイテムを `ui.dnd_drag_source()` でドラッグ可能にし、グリッドの各セルを `ui.dnd_drop_zone()` でドロップゾーンとして機能させる。ドロップ時に `GridLayout::place()` を呼び出してセルにアイテムを配置する。ドロップゾーンにホバー中はセルのハイライト表示を行う。
