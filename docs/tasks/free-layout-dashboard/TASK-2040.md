## タスク概要
`egui-app/src/ui/grid_canvas.rs` を新規作成する。`GridLayout` の cells を2次元で走査し、各セルを `ui.allocate_exact_size()` または `ui.push_id()` + `ui.group()` で描画する。セルの幅は `available_width / cols * col_span`、高さは `available_height / rows * row_span` で計算する。`merged_into != None` のセルはスキップする。空セルにはプレースホルダーを表示する。

**実装ファイル**: `egui-app/src/ui/grid_canvas.rs`

```rust
pub fn show_grid_canvas(
    ui: &mut egui::Ui,
    app_state: &mut AppState,
    layout: &mut LayoutState,
    widgets: &mut WidgetStates,
) {
    let total_w = ui.available_width();
    let total_h = ui.available_height();
    let rows = layout.grid.rows;
    let cols = layout.grid.cols;
    let cell_w = total_w / cols as f32;
    let cell_h = total_h / rows as f32;

    for r in 0..rows {
        ui.horizontal(|ui| {
            for c in 0..cols {
                let cell = &layout.grid.cells[r][c];
                if cell.merged_into.is_some() { continue; }
                let w = cell_w * cell.col_span as f32;
                let h = cell_h * cell.row_span as f32;
                // セルを描画
                let (_, rect) = ui.allocate_space(egui::vec2(w, h));
                // コンテンツ描画
            }
        });
    }
}
```
