### 1. RightPanelState 定義 🔵

**実装ファイル**: `egui-app/src/state/layout_state.rs`

```rust
#[derive(Debug, Clone)]
pub struct RightPanelState {
    pub is_open: bool,
    pub width: f32,
}
impl Default for RightPanelState {
    fn default() -> Self {
        Self { is_open: true, width: 200.0 }
    }
}
```

### 2. LayoutState の変更 🔵

**実装ファイル**: `egui-app/src/state/layout_state.rs`

```rust
pub struct LayoutState {
    pub left_panel_width: f32,
    pub right_panel: RightPanelState,
    pub layout_mode: LayoutMode,
    pub grid: GridLayout,
    // 削除: pub visible_charts: HashSet<ChartId>,
}
impl Default for LayoutState {
    fn default() -> Self {
        Self {
            left_panel_width: 240.0,
            right_panel: RightPanelState::default(),
            layout_mode: LayoutMode::MultiObjective,
            grid: GridLayout::default(),
        }
    }
}
```
