## タスク概要
グリッドキャンバスの周囲（下端・右端）に「＋行」「－行」「＋列」「－列」ボタンを配置する。`GridLayout::add_row()` / `try_remove_last_row()` / `add_col()` / `try_remove_last_col()` を呼び出す。削除できない場合はボタンをグレーアウトする。

## 実装詳細

### ボタンの配置 🔵
```rust
// グリッド下部
ui.horizontal(|ui| {
    let can_remove = layout.grid.rows > 1 && layout.grid.try_can_remove_last_row();
    if ui.button("＋行").clicked() { layout.grid.add_row(); }
    if ui.add_enabled(can_remove, egui::Button::new("－行")).clicked() {
        layout.grid.try_remove_last_row();
    }
    if ui.button("＋列").clicked() { layout.grid.add_col(); }
    let can_remove_col = layout.grid.cols > 1 && layout.grid.try_can_remove_last_col();
    if ui.add_enabled(can_remove_col, egui::Button::new("－列")).clicked() {
        layout.grid.try_remove_last_col();
    }
});
```

GridLayout に `try_can_remove_last_row()` / `try_can_remove_last_col()` （削除可能か確認するだけのメソッド）を追加する（🟡）。
