faer の自己随伴固有値分解を用いて、共分散行列の固有値・固有ベクトルを計算する。

### 3. 固有値の降順ソート + 上位 n_components 射影 (🔵)

固有値を降順にソートし、上位 `n_components` 個の固有ベクトルでデータを射影する。
