## Summary

core/optimization/lbfgs.rs の手作り L-BFGS two-loop recursion を argmin の LBFGS solver に置き換える。argmin-math は vec バックエンドを使用（faer v0.24 と非互換のため）。line_search.rs は argmin 内蔵の line search に置き換えられ削除される。

## Implementation details

### 1. LbfgsOptimizer 構造体の argmin ベース再実装 (🔵 設計文書 architecture.md より)

```rust
use argmin::core::{Executor, State};
use argmin::solver::quasinewton::LBFGS;

pub struct LbfgsOptimizer {
    max_iter: u64,
    tolerance: f64,
}
```

**Files**: `rust_core/src/core/optimization/lbfgs.rs`

- mod.rs から参照を削除

**Files**: `rust_core/src/core/optimization/line_search.rs` (削除), `rust_core/src/core/optimization/mod.rs`
