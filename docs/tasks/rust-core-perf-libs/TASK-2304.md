## 実装内容

### 1. faer_to_ndarray: element-wise copy（column-major → row-major）

```rust
pub fn faer_to_ndarray(mat: &faer::Mat<f64>) -> ndarray::Array2<f64> {
    ndarray::Array2::from_shape_fn((mat.nrows(), mat.ncols()), |(i, j)| mat[(i, j)])
}
```

### 2. ndarray_to_faer: element-wise copy

```rust
pub fn ndarray_to_faer(arr: &ndarray::Array2<f64>) -> faer::Mat<f64> {
    faer::Mat::from_fn(arr.nrows(), arr.ncols(), |i, j| arr[[i, j]])
}
```
