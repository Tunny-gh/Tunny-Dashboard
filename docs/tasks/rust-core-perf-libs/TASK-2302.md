## Task summary

新しい SeededRng（ChaCha8Rng ラッパー）を実装し、sampling/common.rs の LCG を rand で置き換える。sensitivity/ 内の Lcg 利用箇所も SeededRng に移行する。clustering/kmeans.rs の xorshift64 移行は省略可（Phase 4 で linfa 化されるため）。

## Implementation details

### 1. core/math/rng.rs 新規作成 (🔵 設計文書 architecture.md より)

```rust
use rand::SeedableRng;
use rand_chacha::ChaCha8Rng;

pub struct SeededRng {
    rng: ChaCha8Rng,
}

impl SeededRng {
    pub fn from_seed(seed: u64) -> Self { ... }
    pub fn next_f64(&mut self) -> f64 { ... }  // rand::Rng::r#gen
    pub fn next_usize(&mut self, bound: usize) -> usize { ... }
}
```

**Files**: `rust_core/src/core/math/rng.rs`, `rust_core/src/core/math/mod.rs` (`pub mod rng;` 追加)

### 2. sampling/common.rs の LCG → SeededRng 移行 (🔵 要件定義 REQ-301-03 より)

**Files**: `rust_core/src/sampling/common.rs`

### 3. sensitivity/ 内の Lcg 利用箇所の SeededRng 移行 (🔵 コードベース調査より)

### 4. core/random_forest/rng.rs の Lcg 移行 (🟡 最小限)

- core/random_forest/rng.rs の Lcg は SeededRng に置き換え（一時的に core/math/rng.rs を参照）
- Phase 1 で random_forest が削除されるため、移行は最小限
