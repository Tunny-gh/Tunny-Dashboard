## 概要

core/kriging/sparse_fitc.rs の手作り `cholesky_flat`、`forward_sub_flat`、`backward_sub_flat` を faer の Cholesky 分解・三角 solve に置き換える。Woodbury 恒等式に基づく LML 計算と予測の数値結果が従来と同一であることを確認。

## 実装内容

### 1. cholesky_flat → faer::cholesky (🔵)

手作り Cholesky 分解を faer の Cholesky 分解に置き換える。

### 2. forward_sub_flat + backward_sub_flat → faer::solve_triangular (🔵)

手作り前進代入・後退代入を faer の三角 solve に置き換える。

### 3. フラット配列ベースの計算を faer::Mat ベースに変更 (🔵)

`Vec<f64>` フラット配列による行列表現を `faer::Mat<f64>` ベースに変更する。

### 4. FITC LML 計算が従来と同一結果であることを確認 (🔵)

Woodbury 恒等式に基づく Log Marginal Likelihood 計算が従来実装と同一の数値結果を返すことを確認する。

### 5. FITC 予測（predict_mean/predict_var）が従来と同一結果であることを確認 (🔵)

FITC 予測の平均・分散が従来実装と同一の数値結果を返すことを確認する。
