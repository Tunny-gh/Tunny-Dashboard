## 概要

pdp/ridge_core.rs と sensitivity/ 内の Ridge 回帰における手作りガウス消去を faer の Cholesky solve に置き換える。正則化項 αI > 0 により X'X + αI は常に SPD（対称正定値行列）であるため Cholesky が最適。

## 実装内容

### 1. X'X + α*I を faer::Mat で構築 (🔵)

Ridge 回帰の正規方程式における係数行列 X'X + αI を `faer::Mat<f64>` で構築する。

### 2. faer::cholesky で分解 (🔵)

構築した SPD 行列を faer の Cholesky 分解で処理する。X'X + αI は α > 0 の場合常に SPD であることが保証されるため、QR 分解ではなく Cholesky 分解を使用する。

### 3. solve_triangular で係数を求解 (🔵)

Cholesky 分解の結果を用いて、三角 solve で回帰係数を求解する。

### 4. R² 計算が従来と同一 (🔵)

決定係数 R² の計算が従来実装と同一の結果を返すことを確認する。
