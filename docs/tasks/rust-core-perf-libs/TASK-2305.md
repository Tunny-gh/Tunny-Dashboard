## 概要

rust_core 全モジュールの公開 API と内部インターフェースを Vec<Vec<f64>> から faer::Mat に移行する。data/dataframe、io/journal、mcdm、multi_objective、sensitivity、pdp の主要関数を更新。

## 実装内容

### 1. data/dataframe.rs: 行列データの保持型を faer::Mat 化 (🔵)

データフレーム内の行列データの保持型を `Vec<Vec<f64>>` から `faer::Mat<f64>` に変更する。

### 2. io/journal/parser: パース結果の行列データを faer::Mat で返す (🔵)

ジャーナルファイルのパース結果における行列データを `faer::Mat<f64>` で返すように変更する。

### 3. mcdm/*.rs: 内部計算の Vec<Vec<f64>> → faer::Mat (🔵)

MCDM（多基準意思決定）モジュール内の内部計算を `Vec<Vec<f64>>` から `faer::Mat<f64>` に移行する。

### 4. multi_objective/*.rs: Pareto/Hypervolume の入力型を faer::Mat 化 (🔵)

Pareto フロントおよび Hypervolume 計算の入力型を `faer::Mat<f64>` に変更する。

### 5. sensitivity/*.rs: 分析関数の入力型を faer::Mat 化 (🔵)

感度分析関数の入力型を `faer::Mat<f64>` に変更する。

### 6. pdp/*.rs: PDP API の入力型を faer::Mat 化 (🔵)

Partial Dependence Plot API の入力型を `faer::Mat<f64>` に変更する。
