### 1. 試行数カウンタ表示追加 🔵

**信頼性**: 🔵 *REQ-LU-009・既存toolbar.rs構造より*

**実装ファイル**: `egui-app/src/ui/toolbar.rs`

ツールバーに現在選択中のStudyのトライアル数を表示する:

```rust
// 試行数カウンタ表示
if let Some(study) = &app_state.current_study {
    ui.label(
        RichText::new(format!("Trials: {}", study.trial_rows.len()))
            .size(14.0)
    );
} else {
    ui.label(
        RichText::new("Trials: -")
            .size(14.0)
            .color(Color32::GRAY)
    );
}
```

`current_study.trial_rows.len()`から取得する。

### 2. ポーリング間隔調整スライダー追加 🔵

**信頼性**: 🔵 *REQ-LU-301・NFR-LU-201 より*

**実装ファイル**: `egui-app/src/ui/toolbar.rs`

egui::Slider を使用して1秒〜30秒の範囲でポーリング間隔を調整する:

```rust
// ポーリング間隔調整
let mut interval_sec = (app_state.live_update.interval_ms as f64) / 1000.0;
ui.add(
    egui::Slider::new(&mut interval_sec, 1.0..=30.0)
        .text("秒")
        .step_by(1.0)
);
let new_interval_ms = (interval_sec * 1000.0) as u64;
if new_interval_ms != app_state.live_update.interval_ms {
    actions.push(ToolbarAction::SetPollInterval(new_interval_ms));
}
```

### 3. ToolbarAction拡張 🔵

**信頼性**: 🔵 *既存ToolbarAction enum パターンより*

**実装ファイル**: `egui-app/src/ui/toolbar.rs`

`ToolbarAction`に新しいバリアントを追加:

```rust
pub enum ToolbarAction {
    // 既存
    ToggleLiveUpdate,
    // 新規追加
    SetPollInterval(u64),  // ミリ秒単位
}
```

### 4. app.rsでのSetPollInterval処理 🔵

**信頼性**: 🔵 *既存ToolbarAction処理パターンより*

**実装ファイル**: `egui-app/src/app.rs`

`SetPollInterval`受信時に`live_update.interval_ms`を更新する:

```rust
ToolbarAction::SetPollInterval(ms) => {
    state.live_update.interval_ms = ms;
    // 注: 実際のPollerへの反映はTASK-2223で実装
}
```

### 5. ファイル未開封時のトグル無効化 🔵

**信頼性**: 🔵 *REQ-LU-002 より*

**実装ファイル**: `egui-app/src/ui/toolbar.rs`

`journal_path.is_none()`時にLiveボタンを無効化する:

```rust
// トグルボタン
let can_toggle = app_state.journal_path.is_some();
if !can_toggle {
    ui.disable();
}
// ライブ更新状態に応じた表示
if app_state.live_update.enabled {
    let label = format!("Live: On ({}s)", app_state.live_update.interval_ms / 1000);
    if ui.button(label).clicked() {
        actions.push(ToolbarAction::ToggleLiveUpdate);
    }
} else {
    if ui.button("Live: Off").clicked() {
        actions.push(ToolbarAction::ToggleLiveUpdate);
    }
}
```

### 6. ライブ更新ON時の間隔表示 🔵

**信頼性**: 🔵 *REQ-LU-004・NFR-LU-202 より*

ライブ更新ON時は「Live: On (2s)」のようにポーリング間隔を表示する。OFF時は従来通り「Live: Off」とする。

## 注意事項

- eguiのUIテストは`egui::__run_test_ctx`または`Context::default()`を使用してレンダリング結果を検証する
- スライダーの値変更は即座に`ToolbarAction`として発行されるため、ドラッグ中の連続更新に注意する（debounceは不要、Poller側でinterval更新で対応）
- ファイル未開封時の無効化は`ui.disable()`スコープで実装し、視覚的にグレーアウトさせる
- 試行数カウンタは`LiveUpdateDone`受信後も自動的に最新値が表示される（`current_study.trial_rows.len()`を参照するため）
