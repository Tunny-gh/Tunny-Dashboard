### 2. ToggleLiveUpdate処理拡張 🔵

**信頼性**: 🔵 *REQ-LU-003・dataflow.md フロー1 より*

**実装ファイル**: `egui-app/src/app.rs`

`ToggleLiveUpdate`アクションの処理を拡張する:

```rust
ToolbarAction::ToggleLiveUpdate => {
    state.live_update.enabled = !state.live_update.enabled;

    if state.live_update.enabled {
        // ON: Poller起動
        if let Some(ref file_path) = state.journal_path {
            let byte_offset = std::fs::metadata(file_path)
                .map(|m| m.len())
                .unwrap_or(0);

            let ctx = LiveUpdateContext {
                file_path: file_path.clone(),
                byte_offset,
                interval_ms: state.live_update.interval_ms,
            };

            if let Ok(poller) = LiveUpdatePoller::start(ctx, sender.clone()) {
                self.poller = Some(poller);
            }
        }
    } else {
        // OFF: Poller停止
        if let Some(poller) = self.poller.take() {
            poller.stop();
        }
    }
}
```

### 3. OpenJournal処理拡張 🔵

**信頼性**: 🔵 *REQ-LU-005・REQ-LU-201 より*

**実装ファイル**: `egui-app/src/app.rs`

ファイルOPEN時の処理フロー:

1. 既存Pollerが起動中なら`stop()`して`poller = None`にする
2. `OpenJournal`メッセージで新ファイルをパース
3. `JournalParsed`完了後、`live_update.enabled`が`true`なら新ファイルでPollerを再起動

```rust
// OpenJournal受信時の処理冒頭に追加
if let Some(poller) = self.poller.take() {
    poller.stop();
}

// JournalParsed処理の末尾に追加
if state.live_update.enabled {
    // 新ファイルでPoller再開
    if let Some(ref file_path) = state.journal_path {
        let byte_offset = std::fs::metadata(file_path)
            .map(|m| m.len())
            .unwrap_or(0);
        let ctx = LiveUpdateContext {
            file_path: file_path.clone(),
            byte_offset,
            interval_ms: state.live_update.interval_ms,
        };
        if let Ok(poller) = LiveUpdatePoller::start(ctx, sender.clone()) {
            self.poller = Some(poller);
        }
    }
}
```

### 4. アプリ終了時のクリーンアップ 🔵

**信頼性**: 🔵 *REQ-LU-202・eframe::App トレイトより*

**実装ファイル**: `egui-app/src/app.rs`

`eframe::App`トレイトの`on_close`または`Drop`実装でPollerを停止:

```rust
impl Drop for App {
    fn drop(&mut self) {
        if let Some(poller) = self.poller.take() {
            poller.stop();
        }
    }
}
```

または`eframe::App::on_close`が利用可能であればそちらを使用:

```rust
fn on_close(&mut self) -> bool {
    if let Some(poller) = self.poller.take() {
        poller.stop();
    }
    true  // ウィンドウを閉じることを許可
}
```

### 5. SetPollInterval処理 🔵

**信頼性**: 🔵 *REQ-LU-203 より*

**実装ファイル**: `egui-app/src/app.rs`

`SetPollInterval`受信時にPollerへ間隔変更を反映:

```rust
ToolbarAction::SetPollInterval(ms) => {
    state.live_update.interval_ms = ms;
    if let Some(ref mut poller) = self.poller {
        poller.update_interval(ms);
    }
}
```

## 注意事項

- `LiveUpdatePoller::start`はスレッドを起動するため、テストではモックまたはテスト用の軽量実装を使用する
- `stop()`はスレッドの安全な終了を保証する必要がある（`JoinHandle::join`または`Sender::drop`によるスレッド終了待ち）
- ファイルOPEN時のPoller切替は、`OpenJournal`処理の冒頭で停止し、`JournalParsed`処理の末尾で再開する二段階フローとする
- `Drop`実装は`App`構造体に直接実装するか、`poller`フィールドをカスタム`Drop`実装のラッパー型で包む
- テストでのPoller検証は、`poller.is_some()`/`poller.is_none()`の状態確認と、メッセージ送信のモックで行う
