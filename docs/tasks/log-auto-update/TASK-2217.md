### 1. LiveUpdateContext 構造体追加 🔵

**信頼性**: 🔵 *設計文書interfaces.rs「LiveUpdateContext」セクション・アーキテクチャDD-02より*

`rust_core/src/io/journal/live_update.rs` に以下の構造体を追加する:

```rust
/// ポーリングスレッドに渡す初期化コンテキスト
/// 🔵 信頼性: 要件REQ-LU-103 + アーキテクチャ設計DD-02より
#[derive(Debug, Clone)]
pub struct LiveUpdateContext {
    /// 監視対象ファイルパス 🔵 *要件REQ-LU-005より*
    pub file_path: std::path::PathBuf,

    /// 現在のファイルサイズ（初期byte offset） 🔵 *要件REQ-LU-001より*
    pub initial_byte_offset: u64,

    /// 次のトライアルID（現在の完了トライアル数） 🔵 *既存 set_next_trial_id() より*
    pub next_trial_id: u32,

    /// 各Studyのdistribution情報 🟡 *インクリメンタルTrialRow構築に必要*
    pub study_distributions: Vec<StudyDistributionInfo>,
}

/// Study毎のdistribution情報
/// 🟡 信頼性: インクリメンタルパースの要件から妥当な推測
#[derive(Debug, Clone)]
pub struct StudyDistributionInfo {
    /// Study ID 🔵 *既存 StudyMeta.study_id より*
    pub study_id: u32,

    /// パラメータ名のリスト 🔵 *既存 StudyMeta.param_names より*
    pub param_names: Vec<String>,

    /// 目的関数名のリスト 🔵 *既存 StudyMeta.objective_names より*
    pub objective_names: Vec<String>,

    /// Distribution情報（パラメータ名 → distribution JSON）
    /// 🟡 *初期パース時に保持する必要がある*
    pub distributions: std::collections::HashMap<String, serde_json::Value>,
}
```

**実装ファイル**: `rust_core/src/io/journal/live_update.rs`

**注意**: `LiveUpdateContext` と `StudyDistributionInfo` には `#[derive(Debug, Clone)]` を付与する。`serde_json::Value` が `Clone` を実装済みのため派生可能。

### 2. LiveUpdateState 拡張フィールド追加 🔵

**信頼性**: 🔵 *設計文書interfaces.rs「LiveUpdateStateExtension」セクション・要件REQ-LU-010・REQ-LU-101より*

`egui-app/src/state/results.rs` の既存 `LiveUpdateState` に以下のフィールドを追加する:

```rust
use std::time::Instant;

#[derive(Debug, Clone)]
pub struct LiveUpdateState {
    // 既存フィールド
    pub enabled: bool,
    pub file_path: Option<String>,
    pub last_byte_offset: u64,
    pub interval_ms: u64,

    // 新規フィールド
    /// 連続エラーカウント 🔵 *要件REQ-LU-010（3回連続エラーで自動停止）より*
    pub consecutive_errors: u32,

    /// 最後にファイル変更があった時刻 🔵 *要件REQ-LU-101（60秒無変化で通知）より*
    pub last_change_time: Option<Instant>,

    /// ポーラースレッドがアクティブかどうか 🔵 *アーキテクチャ設計DD-01より*
    pub poller_active: bool,

    /// 最適化完了通知表示中かどうか 🔵 *要件REQ-LU-101より*
    pub showing_completion_hint: bool,
}
```

**実装ファイル**: `egui-app/src/state/results.rs`

**注意**: `Instant` は `Clone` を実装していないため、`Clone` derive がエラーになる場合は `last_change_time` フィールドを `Option<std::time::Instant>` のままとし、構造体の `Clone` 実装を手動で変更する必要がある。その場合は `Instant::now()` で再設定するか、`Clone` から外して個別にコピーする方針とする。
