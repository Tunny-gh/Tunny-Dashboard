### 抽出するヘルパー関数 🔵

**信頼性**: 🔵 *設計文書 architecture.md §2-C・設計ヒアリング Q3（指標計算まで並列化）より*

```rust
/// per-(pi, k) の Sobol 第一指数と全指数を計算する純粋関数。
/// 
/// # 引数
/// - `fa_k`: f_a の k 番目目的変数スライス（n_samples 個）
/// - `fb_k`: f_b の k 番目目的変数スライス（n_samples 個）
/// - `fab_k`: f_ab_pi の k 番目目的変数スライス（n_samples 個）
/// 
/// # 戻り値
/// `(first_order, total_effect)` — いずれも 0.0〜1.0 にクランプ済み。
/// 分散が極小の場合は `(0.0, 0.0)` を返す。
fn compute_sobol_index_pair(fa_k: &[f64], fb_k: &[f64], fab_k: &[f64]) -> (f64, f64) {
    let n_f = fa_k.len() as f64;
    let mean_fa = fa_k.iter().sum::<f64>() / n_f;
    let var_y = fa_k.iter().map(|&v| (v - mean_fa).powi(2)).sum::<f64>() / n_f;

    if var_y < f64::EPSILON {
        return (0.0, 0.0);
    }

    let s_i: f64 = fb_k
        .iter()
        .zip(fab_k.iter())
        .zip(fa_k.iter())
        .map(|((&fb_j, &fab_j), &fa_j)| fb_j * (fab_j - fa_j))
        .sum::<f64>()
        / (n_f * var_y);

    let st_i: f64 = fa_k
        .iter()
        .zip(fab_k.iter())
        .map(|(&fa_j, &fab_j)| (fa_j - fab_j).powi(2))
        .sum::<f64>()
        / (2.0 * n_f * var_y);

    (s_i.clamp(0.0, 1.0), st_i.clamp(0.0, 1.0))
}
```

### リファクタリング後のループ 🔵

```rust
// 変更前（インライン計算）
for pi in 0..n_params {
    // f_ab_pi 構築 ...
    for k in 0..n_objectives {
        let fa = &f_a[k];
        let fb = &f_b[k];
        let fab = &f_ab_pi[k];
        let n_f = n_samples as f64;
        let mean_fa = fa.iter().sum::<f64>() / n_f;
        let var_y = fa.iter().map(|&v| (v - mean_fa).powi(2)).sum::<f64>() / n_f;
        if var_y < f64::EPSILON {
            first_order[pi][k] = 0.0;
            total_effect[pi][k] = 0.0;
            continue;
        }
        // ... s_i, st_i 計算 ...
        first_order[pi][k] = s_i.clamp(0.0, 1.0);
        total_effect[pi][k] = st_i.clamp(0.0, 1.0);
    }
}

// 変更後（ヘルパー関数を呼ぶ形）
for pi in 0..n_params {
    // f_ab_pi 構築（変更なし）
    let ab_pi: Vec<Vec<f64>> = mat_a
        .iter()
        .zip(mat_b.iter())
        .map(|(a_row, b_row)| {
            let mut row = a_row.clone();
            row[pi] = b_row[pi];
            row
        })
        .collect();

    let f_ab_pi: Vec<Vec<f64>> = (0..n_objectives)
        .map(|k| ab_pi.iter().map(|row| surrogate_eval(&surrogate, row, k)).collect())
        .collect();

    for k in 0..n_objectives {
        let (fo, te) = compute_sobol_index_pair(&f_a[k], &f_b[k], &f_ab_pi[k]);
        first_order[pi][k] = fo;
        total_effect[pi][k] = te;
    }
}
```
