## タスク概要

TASK-2178 でヘルパー関数が抽出された `sobol.rs` に対して、
以下の 3 段階を `par_iter` / `into_par_iter` で並列化する:

1. `build_sobol_surrogate` 内の per-objective Ridge ループ  
2. `f_a` / `f_b` の per-objective 評価ループ  
3. `for pi in 0..n_params` の per-parameter Sobol 指標計算ループ

> `mat_a` / `mat_b` の LCG サンプリングは RNG 状態が順次依存のため **直列維持** する。

### 段階 1: build_sobol_surrogate per-objective Ridge 並列化 🔵

**信頼性**: 🔵 *設計文書 architecture.md §2-A より*

```rust
// 変更前
for y in y_matrix {
    let y_mean = y.iter().sum::<f64>() / n as f64;
    let y_centered: Vec<f64> = y.iter().map(|&v| v - y_mean).collect();
    let ridge_res = compute_ridge(&x_quad_std, &y_centered, alpha);
    r_squared.push(ridge_res.r_squared);
    betas.push(ridge_res.beta);
    intercepts.push(y_mean);
}

// 変更後（triplets を並列収集してから展開）
let triplets: Vec<(Vec<f64>, f64, f64)> = y_matrix
    .par_iter()
    .map(|y| {
        let y_mean = y.iter().sum::<f64>() / n as f64;
        let y_centered: Vec<f64> = y.iter().map(|&v| v - y_mean).collect();
        let ridge_res = compute_ridge(&x_quad_std, &y_centered, alpha);
        (ridge_res.beta, y_mean, ridge_res.r_squared)
    })
    .collect();

let mut betas = Vec::with_capacity(triplets.len());
let mut intercepts = Vec::with_capacity(triplets.len());
let mut r_squared_vec = Vec::with_capacity(triplets.len());
for (beta, intercept, r2) in triplets {
    betas.push(beta);
    intercepts.push(intercept);
    r_squared_vec.push(r2);
}
```

> `x_quad_std` は不変参照で全スレッドから安全にアクセス可能。
> `compute_ridge` は純粋関数（状態を持たない）。

### 段階 3: per-parameter Sobol 指標計算 並列化 🔵

**信頼性**: 🔵 *設計文書 architecture.md §2-C・TASK-2178 前提より*

```rust
// 変更前（TASK-2178 リファクタリング後の直列版）
for pi in 0..n_params {
    let ab_pi: Vec<Vec<f64>> = ...;
    let f_ab_pi: Vec<Vec<f64>> = ...;
    for k in 0..n_objectives {
        let (fo, te) = compute_sobol_index_pair(&f_a[k], &f_b[k], &f_ab_pi[k]);
        first_order[pi][k] = fo;
        total_effect[pi][k] = te;
    }
}

// 変更後（並列版）
let index_pairs: Vec<(Vec<f64>, Vec<f64>)> = (0..n_params)
    .into_par_iter()
    .map(|pi| {
        let ab_pi: Vec<Vec<f64>> = mat_a
            .iter()
            .zip(mat_b.iter())
            .map(|(a_row, b_row)| {
                let mut row = a_row.clone();
                row[pi] = b_row[pi];
                row
            })
            .collect();

        let f_ab_pi: Vec<Vec<f64>> = (0..n_objectives)
            .map(|k| ab_pi.iter().map(|row| surrogate_eval(&surrogate, row, k)).collect())
            .collect();

        let fo_vec: Vec<f64> = (0..n_objectives)
            .map(|k| {
                let (fo, _) = compute_sobol_index_pair(&f_a[k], &f_b[k], &f_ab_pi[k]);
                fo
            })
            .collect();

        let te_vec: Vec<f64> = (0..n_objectives)
            .map(|k| {
                let (_, te) = compute_sobol_index_pair(&f_a[k], &f_b[k], &f_ab_pi[k]);
                te
            })
            .collect();

        (fo_vec, te_vec)
    })
    .collect();

// index_pairs を first_order / total_effect に展開
let first_order: Vec<Vec<f64>> = index_pairs.iter().map(|(fo, _)| fo.clone()).collect();
let total_effect: Vec<Vec<f64>> = index_pairs.iter().map(|(_, te)| te.clone()).collect();
```

> `f_a`, `f_b` は並列ループ内で不変参照 (`&Vec<f64>`) のみ使用。`Arc` 不要。

### スレッドセーフ性確認事項 🔵

| リソース | アクセス方法 | スレッドセーフ性 |
|---------|------------|----------------|
| `surrogate: SobolSurrogate` | 不変参照 | `&Vec<f64>` フィールドのみ = `Sync` |
| `mat_a`, `mat_b` | 不変参照（並列ループ内） | `Sync` |
| `f_a`, `f_b` | 不変参照（並列ループ内） | `Sync` |
| `x_quad_std` | 不変参照 | `Sync` |
| `ab_pi`, `f_ab_pi` | スレッドローカル | 各スレッド独立 |

### LCG 直列維持の理由 🔵

```
// mat_a / mat_b サンプリングは直列維持
let mat_a: Vec<Vec<f64>> = (0..n_samples)
    .map(|_| param_ranges.iter().map(|(lo, hi)| lo + lcg_next(&mut rng_state) * (hi - lo)).collect())
    .collect();
```

`rng_state` は `&mut u64` で順次更新されるため並列化不可。
`n_samples` の LCG サンプリングは計算量が小さく並列化の恩恵も少ない。

## エラーハンドリング

- `n_params = 0` の場合: `(0..n_params).into_par_iter()` が空イテレータ → `index_pairs` が空 → `first_order`/`total_effect` が空のベクタ（既存動作を維持）
- `n_objectives = 0` の場合: 上位の `if n_objectives == 0 { return None; }` で弾かれるため到達しない
