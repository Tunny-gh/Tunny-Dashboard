## タスク概要

`rust_core/src/core/random_forest/forest.rs` の `RandomForest::train` において、
単一の `Lcg` RNG を共有するシーケンシャルな木構築ループを
`(0..n_trees).into_par_iter()` で並列化する。
各木は `Lcg::new(seed.wrapping_add(tree_idx as u64))` で独立した RNG を初期化し、
決定論的かつ並列安全にする。

```rust
// 変更前
use super::rng::Lcg;
use super::tree::{build_tree, predict_one};
use super::types::{DecisionTree, RandomForest};

impl RandomForest {
    pub fn train(
        x: &[Vec<f64>],
        y: &[f64],
        n_trees: usize,
        max_depth: usize,
        min_samples_leaf: usize,
        seed: u64,
    ) -> Self {
        let n = x.len();
        let p = x.first().map(|row| row.len()).unwrap_or(0);
        let feature_indices: Vec<usize> = (0..p).collect();

        let mut rng = Lcg::new(seed);
        let mut trees = Vec::with_capacity(n_trees);

        for _ in 0..n_trees {
            let mut x_boot: Vec<Vec<f64>> = Vec::with_capacity(n);
            let mut y_boot: Vec<f64> = Vec::with_capacity(n);

            for _ in 0..n {
                let idx = rng.next_usize(n);
                x_boot.push(x[idx].clone());
                y_boot.push(y[idx]);
            }

            let root = build_tree(
                &x_boot,
                &y_boot,
                &feature_indices,
                0,
                max_depth,
                min_samples_leaf,
            );
            trees.push(DecisionTree { root });
        }

        RandomForest { trees }
    }
}

// 変更後
use rayon::prelude::*;
use super::rng::Lcg;
use super::tree::{build_tree, predict_one};
use super::types::{DecisionTree, RandomForest};

impl RandomForest {
    pub fn train(
        x: &[Vec<f64>],
        y: &[f64],
        n_trees: usize,
        max_depth: usize,
        min_samples_leaf: usize,
        seed: u64,
    ) -> Self {
        let n = x.len();
        let p = x.first().map(|row| row.len()).unwrap_or(0);
        let feature_indices: Vec<usize> = (0..p).collect();

        let trees: Vec<DecisionTree> = (0..n_trees)
            .into_par_iter()
            .map(|tree_idx| {
                // 各スレッドが独立した RNG を持つ（seed + tree_idx で決定論的）
                let mut local_rng = Lcg::new(seed.wrapping_add(tree_idx as u64));

                let mut x_boot: Vec<Vec<f64>> = Vec::with_capacity(n);
                let mut y_boot: Vec<f64> = Vec::with_capacity(n);
                for _ in 0..n {
                    let idx = local_rng.next_usize(n);
                    x_boot.push(x[idx].clone());
                    y_boot.push(y[idx]);
                }

                let root = build_tree(
                    &x_boot,
                    &y_boot,
                    &feature_indices,
                    0,
                    max_depth,
                    min_samples_leaf,
                );
                DecisionTree { root }
            })
            .collect();

        RandomForest { trees }
    }
}
```

### シード設計 🔵

| 変更前 | 変更後 |
|-------|-------|
| 1 つの `Lcg` (`seed ^ 0xcafef00dd15ea5e5`) を順次更新 | 木ごとに `Lcg::new(seed.wrapping_add(tree_idx))` |
| シーケンシャル実行で再現可能 | 同じ `(seed, n_trees)` の組み合わせで各木が再現可能 |

> `wrapping_add` を使用するため u64 オーバーフローも安全に扱える。

### スレッドセーフ性確認事項 🔵

| リソース | アクセス方法 | スレッドセーフ性 |
|---------|------------|----------------|
| `x: &[Vec<f64>]` | 不変参照 | `Sync` |
| `y: &[f64]` | 不変参照 | `Sync` |
| `feature_indices: Vec<usize>` | 不変参照 | `Sync` |
| `Lcg` | スレッドローカル（`local_rng`） | 各スレッド独立 |
| `x_boot`, `y_boot` | スレッドローカル | 各スレッド独立 |

> **注意**: 並列化によりシード設計が変わるため、`seed=42, n_trees=10` で生成される木のセットは
> 直列版と異なる。これは REQ-102 の「決定論的シード」定義内で許容される変化である。

## エラーハンドリング

- `n = 0` の場合: `x.first()` が `None` → `p = 0` → `feature_indices` が空。`build_tree` は既存の空入力ハンドリングに委ねる（既存動作を維持）。
- `n_trees = 0` の場合: `into_par_iter` が空イテレータを返し `trees` が空の `RandomForest` になる（既存動作を維持）。
