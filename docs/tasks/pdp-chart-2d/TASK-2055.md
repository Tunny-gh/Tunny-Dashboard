## 実装詳細

### 1. rust_core PdpResult2d フィールド名変更 🔵

**信頼性**: 🔵 *設計文書 architecture.md より*

フィールド名を egui-app 側と統一する。

**実装ファイル**: `rust_core/src/pdp/types.rs`

変更前:
```rust
pub struct PdpResult2d {
    pub param1_name: String,
    pub param2_name: String,
    pub objective_name: String,
    pub grid1: Vec<f64>,
    pub grid2: Vec<f64>,
    pub values: Vec<Vec<f64>>,
    pub r_squared: f64,
}
```

変更後:
```rust
pub struct PdpResult2d {
    pub param1_name: String,
    pub param2_name: String,
    pub objective_name: String,
    pub x_values: Vec<f64>,                         // grid1 から改名
    pub y_values: Vec<f64>,                         // grid2 から改名
    pub z_values: Vec<Vec<f64>>,                    // values から改名
    pub r_squared: f64,
    pub uncertainties: Option<Vec<Vec<f64>>>,       // 追加: [x_grid][y_grid] 分散値
}
```

### 2. rust_core 内の参照箇所更新 🔵

**信頼性**: 🔵 *設計文書 architecture.md より*

以下のファイルで `PdpResult2d` を構築・参照している箇所のフィールド名をすべて更新する。

**実装ファイル**:
- `rust_core/src/pdp/kriging_core.rs` — `compute_pdp_2d_kriging_raw`, `compute_pdp_2d_sparse_kriging_raw` 等の `PdpResult2d` 構築部分
- `rust_core/src/pdp/api.rs` — `PdpResult2d` 参照箇所
- その他 rust_core 内の参照箇所すべて

### 3. egui-app PdpResult2d への uncertainties 追加 🔵

**信頼性**: 🔵 *設計文書 architecture.md より*

egui-app 側の `PdpResult2d` には `x_values`/`y_values`/`z_values` は既に存在するため、`uncertainties` フィールドのみ追加する。

**実装ファイル**: `egui-app/src/state/messages.rs`

```rust
pub uncertainties: Option<Vec<Vec<f64>>>,
```
