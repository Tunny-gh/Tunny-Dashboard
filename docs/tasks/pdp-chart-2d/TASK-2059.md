### 3. grid_canvas.rs: PdpChart2D ケース追加 🔵

**信頼性**: 🔵 *設計文書 architecture.md dataflow.md フロー7より*

**変更ファイル**: `egui-app/src/ui/grid_canvas.rs`

```rust
ChartId::PdpChart2D => {
    let param_names = app_state.param_names();
    let obj_names = app_state.obj_names();
    widgets.pdp_2d.show(ui, &param_names, &obj_names);
    if let Some(req) = widgets.pdp_2d.pending_compute.take() {
        widgets.pdp_2d.computing = true;
        let tx = tx.clone();
        spawn_task(tx, move || {
            match rust_core::pdp::api::compute_pdp_2d(
                &req.param1, &req.param2, &req.objective,
                req.n_grid, &req.model_type,
            ) {
                Some(r) => AppMessage::Pdp2dDone(r.into()),
                None => AppMessage::Error("PDP 2D computation failed".into()),
            }
        });
    }
}
```

既存の他 ChartId アームで `tx` を使わない場合も `_tx` で受け取りコンパイルを通す。

AppMessage::Pdp2dDone(result) => {
    self.widget_states.pdp_2d.result = Some(result);

## 注意事項
