## 実装詳細

### 1. Kriging の変更 🔵

**信頼性**: 🔵 *設計文書 architecture.md より*

**実装ファイル**: `rust_core/src/pdp/kriging_core.rs`

`compute_pdp_2d_kriging_raw` のグリッドループ内で `predict_mean` と同様に `predict_variance` を呼び出し、結果を `var_grid` に格納する。

```rust
// compute_pdp_2d_kriging_raw():
//   model = train_gp(...)  // GpModel に l・log_sn が保存済み（TASK-2053）
//   for each grid point (xi, xj):
//     mean_grid[i][j] = predict_mean(&model, &[xi, xj])
//     var_grid[i][j]  = predict_variance(&model, &[xi, xj])
//   PdpResult2d { z_values: mean_grid, uncertainties: Some(var_grid), ... }
```

### 2. Sparse Kriging の変更 🔵

**信頼性**: 🔵 *設計文書 architecture.md より*

**実装ファイル**: `rust_core/src/pdp/kriging_core.rs`

`compute_pdp_2d_sparse_kriging_raw` で FITC モデルを使い、各グリッド点の分散を計算する。

```rust
// compute_pdp_2d_sparse_kriging_raw():
//   z = select_inducing_points_kmeans(...)
//   params = optimize_fitc_hyperparams(...)
//   fitc_model = fitc_train(x, z, y, params, n, m)  // SparseFitcModel（TASK-2054）
//   for each grid point (xi, xj):
//     mean_grid[i][j] = fitc_predict_mean(&fitc_model, &[xi, xj])
//     var_grid[i][j]  = fitc_predict_variance(&fitc_model, &[xi, xj])
//   PdpResult2d { z_values: mean_grid, uncertainties: Some(var_grid), ... }
```

### 3. Ridge モデルの uncertainties: None 🔵

**信頼性**: 🔵 *設計文書 architecture.md より*

Ridge は確率モデルではないため `uncertainties: None` を返す。変更は `PdpResult2d` 構築時に `uncertainties: None` を明示するのみ。
