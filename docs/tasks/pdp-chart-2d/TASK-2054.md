```rust
pub(crate) struct SparseFitcModel {
    pub w: Vec<f64>,          // posterior weights: Σ^{-1} t
    pub l_sigma: Vec<f64>,    // chol(Σ) flat row-major M×M
    pub z: Vec<f64>,          // inducing points column-major M×n_dims

}
```

## 注意事項

- `fitc_predict_weights` の内部実装（`sparse_fitc.rs` 398〜442行目付近）を参照し、`l_sigma` 計算ロジックを `fitc_train` に抽出する。
- `forward_sub_flat` は `sparse_fitc.rs` に既に実装済みのため再利用可能。
- FITC予測分散は厳密には `k(x*,x*) - k(Z,x*)^T Σ^{-1} k(Z,x*)`。`Σ^{-1} = (L_sigma L_sigma^T)^{-1}` なので `||L_sigma^{-1} k(Z,x*)||²` を前進代入で計算する。
- 分散値のクランプ（`var.max(0.0)`）を忘れずに行い、数値誤差による負値を防ぐ。
