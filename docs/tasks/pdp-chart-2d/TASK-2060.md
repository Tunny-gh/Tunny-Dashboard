## 実装詳細

### 1. 描画ロジックの分岐 🔵

**信頼性**: 🔵 *設計文書 architecture.md（不確実性可視化セクション）より*

**実装ファイル**: `egui-app/src/ui/widgets/pdp_2d.rs`

```rust
// result.uncertainties の有無によって分岐
match &result.uncertainties {
    None => {
        // 従来どおり単一ヒートマップ
        let (rect, _) = ui.allocate_exact_size(plot_size, egui::Sense::hover());
        let painter = ui.painter_at(rect);
        draw_heatmap(&painter, rect, &result.z_values);
        // カラーバー + 軸ラベル
    }
    Some(var_grid) => {
        // デュアルヒートマップ
        let half_w = (available.width() - 48.0) / 2.0;
        let pane_size = egui::vec2(half_w, available.height().min(300.0));

        // 左ペイン: 平均
        ui.vertical(|ui| {
            ui.label("Mean");
            let (rect_left, _) = ui.allocate_exact_size(pane_size, egui::Sense::hover());
            draw_heatmap_with_cmap(&ui.painter_at(rect_left), rect_left, &result.z_values, &ColorMap::viridis());
            // カラーバー (viridis)
        });

        // 右ペイン: σ
        ui.vertical(|ui| {
            ui.label("σ (Std. Dev.)");
            let sigma_grid: Vec<Vec<f64>> = var_grid.iter()
                .map(|row| row.iter().map(|v| v.sqrt()).collect())
                .collect();
            let (rect_right, _) = ui.allocate_exact_size(pane_size, egui::Sense::hover());
            draw_heatmap_with_cmap(&ui.painter_at(rect_right), rect_right, &sigma_grid, &ColorMap::plasma());
            // カラーバー (plasma)
        });
    }
}
```

左右ペインを並べるためには `ui.horizontal(|ui| { ... })` の中で `ui.vertical` を2つ使う構成が egui パターン。

### 2. ColorMap::plasma() の追加 🔵

**信頼性**: 🔵 *設計文書 architecture.md（不確実性可視化セクション）より*

**実装ファイル**: `egui-app/src/render/colormap.rs`

`plasma()` が未実装の場合は viridis に準じた plasma カラーマップを追加する。plasma は黒→紫→赤→黄の色相グラデーション。matplotlib の plasma カラーマップの値を使用するか、黒→紫→赤→黄の補間で近似する（256サンプル）。

### 3. draw_heatmap の汎用化 🔵

**信頼性**: 🔵 *設計文書 architecture.md より*

**実装ファイル**: `egui-app/src/ui/widgets/pdp_2d.rs`（または描画ユーティリティ）

既存 `draw_heatmap` はカラーマップをハードコード（viridis）している可能性があるため、カラーマップを引数として受け取る `draw_heatmap_with_cmap` を追加するか、既存関数を汎用化する。
