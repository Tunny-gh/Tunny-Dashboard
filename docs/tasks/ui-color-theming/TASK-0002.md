## タスク概要

`app.rs` で起動時に `tunny_light_visuals()` を適用し、
`layout.rs` でツールバーパネルをダークネイビーの `egui::Frame` でラップする。
これによりグローバルなライトテーマ適用とツールバー固有の暗い背景が実現される。

## 実装詳細

### 1. app.rs への set_visuals() 追加 🔵

**信頼性**: 🔵 *設計文書 architecture.md「app.rs の変更」・eframe CreationContext API より*

**実装ファイル**: `egui-app/src/app.rs`

`TunnyApp::new()` の先頭に追加:

```rust
pub fn new(cc: &eframe::CreationContext<'_>) -> Self {
    cc.egui_ctx.set_visuals(crate::theme::tunny_light_visuals()); // ← 追加
    let (tx, rx) = mpsc::sync_channel(32);
    Self {
        // ...既存コード変更なし...
    }
}
```

### 2. layout.rs のツールバーFrame変更 🔵

**信頼性**: 🔵 *設計文書 architecture.md「layout.rs の変更」・egui TopBottomPanel Frame API より*

**実装ファイル**: `egui-app/src/ui/layout.rs`

変更前:
```rust
egui::TopBottomPanel::top("toolbar")
    .min_height(32.0)
    .show(ctx, |ui| {
        show_toolbar(...);
    });
```

変更後:
```rust
egui::TopBottomPanel::top("toolbar")
    .min_height(32.0)
    .frame(
        egui::Frame::default()
            .fill(crate::theme::TOOLBAR_BG)
            .inner_margin(egui::Margin::symmetric(8.0, 4.0)),
    )
    .show(ctx, |ui| {
        ui.visuals_mut().override_text_color = Some(crate::theme::TOOLBAR_TEXT);
        show_toolbar(...);
    });
```
