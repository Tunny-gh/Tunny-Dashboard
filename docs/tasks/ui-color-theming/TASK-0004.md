## 注意事項

- eguiのvisuals変更は実行時にしか確認できないため、目視確認が必須
- `cargo test` だけでは色の正確さは検証できないため、必ず実際に起動して確認する
- 微調整が必要な場合は `theme.rs` の定数値のみを変更すれば全体に反映される
