## タスク概要

`egui-app/src/ui/grid_canvas.rs` 内に散在するハードコードされたカラー値を
`crate::theme` モジュールの定数に置き換える。
具体的にはセル境界線・D&Dホバーハイライト・リサイズハンドルホバー・セルツールバー背景色を変更する。

### 2. D&Dホバーハイライトの置き換え 🔵

**信頼性**: 🔵 *設計文書 architecture.md「grid_canvas.rs の変更」・既存コード `grid_canvas.rs:122-125` より*

変更箇所（`show_grid_canvas()` 内 l.117-125）:

// 変更前

    cell_rect,
    0.0,
    egui::Color32::from_rgba_unmultiplied(100, 150, 255, 40),

## 注意事項

- `from_rgba_unmultiplied` の引数はpre-multiplied alphaではないため、ACCENT_BLUEの RGB値をそのまま使える
- ハンドルホバー（alpha=80）とD&Dホバー（alpha=40）で意図的にアルファ値を変えているため、誤って統一しないこと
- `show_cell_toolbar()` の `fill` と `stroke` は現在 `ui.visuals()` から取得しているが、
  グローバルVisuals適用後は `PANEL_BG` と `BORDER_COLOR` に近い値になる見込み。
  明示的に定数指定することで意図を明確化する。
