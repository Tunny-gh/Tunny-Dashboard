## タスク概要

`egui-app/src/state/app_state.rs` (648行) を3つのファイルに分割し、単一責任原則に従った構成にする:
- **types.rs**: データモデル型（StudyMeta, TrialRow, GpuBufferData, StudyContext, ColorMode）
- **filter.rs**: フィルタリングロジック（DownsampleCache, should_resample, impl AppState のフィルタメソッド）
- **results.rs**: 分析結果型（SensitivityResult, SobolResult, ClusterResult, TopsisResult, HvHistory, LiveUpdateState）

`app_state.rs` は `AppState` 構造体のみを残し、`pub use` で各モジュールを再エクスポートする。外部モジュールからの `use crate::state::app_state::*` パスは変更不要。

## 注意事項

- `impl AppState` を複数ファイル（app_state.rs, filter.rs）に分散定義することはRustの仕様上問題ない（同一クレート内のため）
- `use std::collections::HashMap` は types.rs, filter.rs, app_state.rs のそれぞれで必要
- `TrialRow` 型は filter.rs の `apply_live_update` で使用されるため、`super::types::TrialRow` をインポートする必要がある
- テストヘルパー `make_study_ctx_with_params()` は filter.rs のテストでも必要なため、適切な場所に配置する
