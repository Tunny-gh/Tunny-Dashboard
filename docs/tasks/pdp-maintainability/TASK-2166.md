### 2. R² ブロックの置き換え 🔵

**信頼性**: 🔵 *REQ-202 + 設計文書より*

sparse_kriging の R² は `fitc_predict_mean` を使うため、
y_pred を以下で構成:

```rust
let y_pred: Vec<f64> = x_norm
    .iter()
    .map(|xi| sparse_fitc::fitc_predict_mean(&fitc_model, xi) * y_std + y_mean)
    .collect();
let r_sq = r_squared(y, &y_pred);
```
