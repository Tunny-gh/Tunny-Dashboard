### 1. extract_xy の実装 🔵

**信頼性**: 🔵 *REQ-301 + 設計文書 dataflow.md + ユーザヒアリングより*

**実装ファイル**: `rust_core/src/pdp/utils.rs`

```rust
/// DataFrame から特徴量行列 x_matrix と目的変数 y を抽出する。
///
/// 欠損値（列未存在・インデックス外）は 0.0 でフォールバック。
pub(super) fn extract_xy(
    df: &crate::data::DataFrame,
    param_names: &[String],
    objective_name: &str,
) -> (Vec<Vec<f64>>, Vec<f64>) {
    let n = df.row_count();
    let x_matrix: Vec<Vec<f64>> = (0..n)
        .map(|i| {
            param_names
                .iter()
                .map(|p| {
                    df.get_numeric_column(p)
                        .and_then(|c| c.get(i))
                        .copied()
                        .unwrap_or(0.0)
                })
                .collect()
        })
        .collect();
    let y: Vec<f64> = (0..n)
        .map(|i| {
            df.get_numeric_column(objective_name)
                .and_then(|c| c.get(i))
                .copied()
                .unwrap_or(0.0)
        })
        .collect();
    (x_matrix, y)
}
```
