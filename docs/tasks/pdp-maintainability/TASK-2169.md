## タスク概要

`ridge_core.rs` の `compute_pdp_from_matrix` と `compute_pdp_2d_from_matrix` で使われている
fold クロージャ形式（`|a, b| a.min(b)`）を関数ポインタ形式（`f64::min`）に統一する。
`kriging_core.rs` では既に関数ポインタ形式が使われており、スタイルを揃える。

## 実装詳細

### 1. fold スタイル統一（6箇所） 🔵

**信頼性**: 🔵 *REQ-601 + コード直接分析より*

**実装ファイル**: `rust_core/src/pdp/ridge_core.rs`

```rust
// 変更前（クロージャ形式）
let min_j = param_col.iter().cloned().fold(f64::INFINITY, |a, b| a.min(b));
let max_j = param_col.iter().cloned().fold(f64::NEG_INFINITY, |a, b| a.max(b));

// 変更後（関数ポインタ形式）
let min_j = param_col.iter().cloned().fold(f64::INFINITY, f64::min);
let max_j = param_col.iter().cloned().fold(f64::NEG_INFINITY, f64::max);
```

変更箇所: `compute_pdp_from_matrix` で 2箇所、`compute_pdp_2d_from_matrix` で 4箇所。
