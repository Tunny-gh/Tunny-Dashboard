## 実装詳細

### 1. r_squared の実装 🔵

**信頼性**: 🔵 *REQ-201 + 設計文書 dataflow.md（既存3関数の同一パターン）より*

**実装ファイル**: `rust_core/src/pdp/utils.rs`

```rust
/// R² 決定係数を計算する。
///
/// ss_tot < EPSILON の場合（定数 y）: 1.0 を返す。
pub(super) fn r_squared(y_actual: &[f64], y_pred: &[f64]) -> f64 {
    let n = y_actual.len();
    if n == 0 {
        return 1.0;
    }
    let y_mean = y_actual.iter().sum::<f64>() / n as f64;
    let ss_tot: f64 = y_actual.iter().map(|&v| (v - y_mean).powi(2)).sum();
    if ss_tot < f64::EPSILON {
        return 1.0;
    }
    let ss_res: f64 = y_actual
        .iter()
        .zip(y_pred.iter())
        .map(|(&a, &p)| (a - p).powi(2))
        .sum();
    1.0 - ss_res / ss_tot
}
```
