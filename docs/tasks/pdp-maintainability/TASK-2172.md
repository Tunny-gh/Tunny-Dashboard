### 2. mean_avg 計算の par_iter() 化 🔵

**信頼性**: 🔵 *REQ-503 + ユーザヒアリング（meanループのみ）+ 設計文書 architecture.md より*

グリッドループ（`for &v in &grid`）内の mean_avg 計算のみを変更する:

```rust
// 変更前
let mean_avg: f64 = {
    let sum: f64 = x_norm
        .iter()
        .map(|row_norm| {
            let mut pt = row_norm.clone();
            pt[target_param_idx] = v_norm;
            gaussian_process::predict_mean(&model, &pt)
        })
        .sum();
    sum / n as f64
};

// 変更後
let mean_avg: f64 = x_norm
    .par_iter()
    .map(|row_norm| {
        let mut pt = row_norm.clone();
        pt[target_param_idx] = v_norm;
        gaussian_process::predict_mean(&model, &pt)
    })
    .sum::<f64>()
    / n as f64;
```

**Sync 確認**: `GpModel` は `Vec<f64>`, `Vec<Vec<f64>>`, `f64` のみ → 自動的に `Sync` → `&model` の共有は安全。

### 3. variance 計算は変更しない 🔵

**信頼性**: 🔵 *ユーザヒアリング（meanのみ）より*

centroid 単点の variance 計算（`predict_variance`）は変更しない。
compute が O(N²) なので並列化の効果が小さく、コードの複雑度を増やさない。
