## タスク概要

`kriging_core.rs` の `compute_pdp_1d_sparse_kriging_raw` 内のグリッドループ全体を
`grid.par_iter()` で並列化する。
各グリッド点の `mean_norm`・`var_avg` 計算は独立しているため並列化が安全。
結果はタプル `(pdp, upper, lower)` で収集し、順序を保持して Vec にアンパックする。

## 実装詳細

### 1. グリッドループの par_iter() 化 🔵

**信頼性**: 🔵 *REQ-502 + 設計文書 architecture.md + dataflow.md より*

**実装ファイル**: `rust_core/src/pdp/kriging_core.rs`

```rust
// 変更前（for &v in &grid { ... push ... }）

// 変更後
let results: Vec<(f64, f64, f64)> = grid
    .par_iter()
    .map(|&v| {
        let v_norm = (v - min_j) / range_j;

        // Mean: exact PDP marginalisation — O(N × M) per grid point
        let mean_norm: f64 = x_norm
            .iter()
            .map(|row| {
                let mut pt = row.clone();
                pt[target_param_idx] = v_norm;
                sparse_fitc::fitc_predict_mean(&fitc_model, &pt)
            })
            .sum::<f64>()
            / n as f64;

        // Variance: average over all rows — O(N × M²) per grid point
        let var_avg: f64 = x_norm
            .iter()
            .map(|row| {
                let mut pt = row.clone();
                pt[target_param_idx] = v_norm;
                sparse_fitc::fitc_predict_variance(&fitc_model, &pt).max(0.0)
            })
            .sum::<f64>()
            / n as f64;

        let pdp_orig = mean_norm * y_std + y_mean;
        let std_orig = var_avg.sqrt() * y_std;
        (pdp_orig, pdp_orig + 1.96 * std_orig, pdp_orig - 1.96 * std_orig)
    })
    .collect();
```

### 2. Vec のアンパック 🔵

**信頼性**: 🔵 *設計文書 architecture.md（順序保持の注意事項）より*

`par_iter().collect::<Vec<_>>()` は元の順序を保持するため、
`pdp_values[i]` が `grid[i]` に対応することが保証される。

```rust
let (pdp_values, y_upper_vec, y_lower_vec) =
    results.into_iter().fold(
        (
            Vec::with_capacity(n_grid),
            Vec::with_capacity(n_grid),
            Vec::with_capacity(n_grid),
        ),
        |(mut p, mut u, mut l), (pdp, upper, lower)| {
            p.push(pdp);
            u.push(upper);
            l.push(lower);
            (p, u, l)
        },
    );
```

### 3. Sync 確認 🔵

**信頼性**: 🔵 *Rust 型システム + 設計文書 architecture.md より*

`SparseFitcModel` は `Vec<f64>` のみで構成 → 自動的に `Sync`。
各スレッドが `row.clone()` で独自の `pt` を所有するため、
`pt[target_param_idx] = v_norm` の変更は他スレッドに影響しない。
