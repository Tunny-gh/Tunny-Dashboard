### 1. `lgbm_predict_contrib` の実装 🔵

**信頼性**: 🔵 *REQ-102 (SHAP完全置き換え) + lightgbm predict_contrib API + ユーザヒアリングより*

**実装ファイル**: `rust_core/src/core/lgbm.rs`

```rust
/// LightGBM モデルで SHAP (TreeSHAP) 値を計算する
///
/// # Returns
/// `Vec<Vec<f64>>` — shape: [n_samples][n_features + 1]
///   最後の列 (index n_features) はバイアス項（使用しない）
pub fn lgbm_predict_contrib(
    booster: &lightgbm::Booster,
    x: &[Vec<f64>],
) -> Vec<Vec<f64>> {
    booster.predict_contrib(x).unwrap_or_default()
}
```

注: `predict_contrib` のシグネチャは lightgbm-rs バージョンに依存する。`predict` と同様のインターフェースが多い。

### 2. `lgbm_feature_importance` の実装 🔵

**信頼性**: 🔵 *REQ-103 (MDI) + lightgbm feature_importance API より*

**実装ファイル**: `rust_core/src/core/lgbm.rs`

```rust
/// LightGBM モデルの Gain ベース特徴重要度を返す（正規化済み、合計=1）
///
/// # Returns
/// `Vec<f64>` — 長さ = n_features、合計 = 1.0（全ゼロの場合はゼロのまま）
pub fn lgbm_feature_importance(
    booster: &lightgbm::Booster,
    n_features: usize,
) -> Vec<f64> {
    let gains = booster.feature_importance(lightgbm::ImportanceType::Gain)
        .unwrap_or_else(|_| vec![0.0; n_features]);
    let total: f64 = gains.iter().sum();
    if total == 0.0 {
        return gains;
    }
    gains.iter().map(|g| g / total).collect()
}
```
