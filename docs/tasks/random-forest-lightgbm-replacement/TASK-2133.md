## 実装詳細

### 1. `sensitivity/rf_anova.rs` の更新 🔵

**信頼性**: 🔵 *REQ-104 + dataflow.md 6. RF-ANOVA データフローより*

**実装ファイル**: `rust_core/src/sensitivity/rf_anova.rs`

**変更点**:

use 文の更新:
```rust
// 削除
use crate::core::random_forest::{train_rf_on_columns, mse_on_dataset, extract_columns};
// 追加
use crate::core::lgbm::{LgbmRfConfig, train_lgbm_rf, lgbm_mse};
```

訓練部分の置き換え:
```rust
// 変更前
let model = train_rf_on_columns(&x_train, &y_train, RF_TREES, RF_MAX_DEPTH, RF_MIN_SAMPLES_LEAF, RF_SEED)?;
let baseline_mse = mse_on_dataset(&model, &x_eval, &y_eval);

// 変更後
let config = LgbmRfConfig {
    num_iterations: RF_TREES,   // 100
    max_depth: RF_MAX_DEPTH,    // 10
    min_data_in_leaf: RF_MIN_SAMPLES_LEAF as i32,  // 2
    seed: RF_SEED as i32,       // 42
    ..Default::default()
};
let booster = train_lgbm_rf(&x_train, &y_train, &config)?;
let baseline_mse = lgbm_mse(&booster, &x_eval, &y_eval)?;
```

順列重要度計算の mse_on_dataset 置き換え:
```rust
// 変更前
let permuted_mse = mse_on_dataset(&model, &x_permuted, &y_eval);

// 変更後
let permuted_mse = lgbm_mse(&booster, &x_permuted, &y_eval).unwrap_or(baseline_mse);
```

R² 計算（既存ロジック維持）:
```rust
// 既存の R² 計算式を維持
let r_squared = ...;  // 変更なし
```

### テストケース1: compute_rf_anova_importances 基本動作 🔵

**信頼性**: 🔵 *REQ-104 より*

**信頼性**: 🟡 *REQ-104 から妥当な推測（LightGBM の確率的性質から完全一致は保証しない）*

**When**: `compute_rf_anova_importances` を呼び出す
**Then**: `importances[0] > importances[1]` であることが多い
