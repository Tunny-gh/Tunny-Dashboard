### 2. `compute_shap_importances` の実装置き換え 🔵

**信頼性**: 🔵 *REQ-102 + dataflow.md 4. SHAP データフローより*

**実装ファイル**: `rust_core/src/sensitivity/shap.rs`

**新しい実装の流れ**（dataflow.md のフロー通り）:
```rust
pub fn compute_shap_importances(x_matrix: &[Vec<f64>], y: &[f64]) -> (Vec<f64>, f64) {
    let p = if x_matrix.is_empty() { 0 } else { x_matrix[0].len() };

    // ① データクリーニング（非有限値除去）— 既存ロジック流用
    // ② ダウンサンプリング（max 1,000 行）— 既存ロジック流用
    // ③ Lcg でシャッフル → 80/20 ホールドアウト分割 — 既存ロジック流用
    let (x_train, y_train, x_eval, y_eval) = split_holdout(...);

    // ④ LightGBM RF 訓練（64木, 深度10 — SHAP用設定）
    let config = LgbmRfConfig {
        num_iterations: RF_TREES,      // 64
        max_depth: RF_MAX_DEPTH,       // 10
        min_data_in_leaf: RF_MIN_SAMPLES_LEAF as i32,
        seed: RF_SEED as i32,
        ..Default::default()
    };
    let Some(booster) = train_lgbm_rf(&x_train, &y_train, &config) else {
        return (vec![0.0; p], 0.0);
    };

    // ⑤ lgbm_predict_contrib → phi: [n_train][p+1]
    //   最後の列（index p）はバイアス項 → 除外
    let phi = lgbm_predict_contrib(&booster, &x_train);
    let n_train = phi.len();
    if n_train == 0 {
        return (vec![0.0; p], 0.0);
    }

    // 各サンプルの |phi[i][j]| を j ごとに合計（バイアス列は除外）
    let mut phi_sum = vec![0.0f64; p];
    for sample_phi in &phi {
        for j in 0..p {
            phi_sum[j] += sample_phi[j].abs();
        }
    }
    let phi_avg: Vec<f64> = phi_sum.iter().map(|s| s / n_train as f64).collect();

    // 正規化
    let total: f64 = phi_avg.iter().sum();
    let importances = if total == 0.0 {
        vec![0.0; p]
    } else {
        phi_avg.iter().map(|v| v / total).collect()
    };

    // ⑥ lgbm_mse → R²
    let mse = lgbm_mse(&booster, &x_eval, &y_eval).unwrap_or(f64::INFINITY);
    let r_squared = mse_to_r_squared(mse, &y_eval);

    (importances, r_squared)
}
```

### 3. バイアス列の除外処理 🔵

**信頼性**: 🔵 *interfaces.rs lgbm_predict_contrib の仕様（最後の列はバイアス項、スキップで OK）より*

`phi[i]` の長さは `p + 1`。インデックス `p`（最後）がバイアス項のため、`for j in 0..p` でループし、`p` は含めない。
