## 実装詳細

### 1. normalize_values()関数 🔵

**信頼性**: 🔵 *architecture.md Section 5.1 Min-Max正規化より*

```rust
pub fn normalize_values(values: &[f64]) -> Vec<f64> {
    if values.is_empty() {
        return vec![];
    }

    let min = values.iter()
        .copied()
        .filter(|v| v.is_finite())
        .fold(f64::INFINITY, f64::min);
    
    let max = values.iter()
        .copied()
        .filter(|v| v.is_finite())
        .fold(f64::NEG_INFINITY, f64::max);

    let range = max - min;

    values.iter().map(|&v| {
        if !v.is_finite() {
            // NaN/Inf → skip (return NaN for filtering)
            f64::NAN
        } else if range == 0.0 {
            // All values equal → mid-point
            0.5
        } else {
            // Normal case: (v - min) / range
            (v - min) / range
        }
    }).collect()
}
```

### 2. エッジケース処理 🔵

**信頼性**: 🔵 *dataflow.md Section 5.2 エッジケース処理より*

| ケース | 処理 | 出力 |
|--------|------|------|
| 全値同一 | range = 0 | 0.5 (中央値) |
| 単一値 | range = 0 | 0.5 |
| NaN/Inf | is_finite() = false | NaN (フィルタ対象) |

## 単体テスト要件

### テストケース1: 基本正規化 🔵

**Given**: values = [100, 150, 200]  
**When**: normalize_values() 呼び出し  
**Then**: [0.0, 0.5, 1.0] が返される

```rust
#[test]
fn test_normalize_basic() {
    let values = vec![100.0, 150.0, 200.0];
    let normalized = normalize_values(&values);
    
    assert_eq!(normalized[0], 0.0);
    assert!((normalized[1] - 0.5).abs() < 1e-10);
    assert_eq!(normalized[2], 1.0);
}
```

### テストケース2: 全値同一 🔵

**Given**: values = [5.0, 5.0, 5.0]  
**When**: normalize_values() 呼び出し  
**Then**: [0.5, 0.5, 0.5] が返される

```rust
#[test]
fn test_normalize_all_equal() {
    let values = vec![5.0, 5.0, 5.0];
    let normalized = normalize_values(&values);
    
    assert!(normalized.iter().all(|&v| (v - 0.5).abs() < 1e-10));
}
```

### テストケース3: NaN/Inf フィルタリング 🔵

**Given**: values = [1.0, NaN, 3.0, Inf]  
**When**: normalize_values() 呼び出し  
**Then**: NaN/Inf は NaN のまま（caller側でフィルタ）

```rust
#[test]
fn test_normalize_with_nan_inf() {
    let values = vec![1.0, f64::NAN, 3.0, f64::INFINITY];
    let normalized = normalize_values(&values);
    
    assert_eq!(normalized[0], 0.0);
    assert!(normalized[1].is_nan());
    assert_eq!(normalized[2], 1.0);
    assert!(normalized[3].is_nan());
}
```
