## 実装詳細

### 1. downsample_points()関数 🔵

**信頼性**: 🔵 *architecture.md Section 7.1 アルゴリズムより*

```rust
pub fn downsample_points<T: Clone>(
    points: &[T],
    max_count: usize,
) -> Vec<T> {
    if points.len() <= max_count {
        return points.to_vec();
    }

    let step = (points.len() as f64 / max_count as f64).ceil() as usize;
    points.iter().step_by(step).cloned().collect()
}
```

### 2. ダウンサンプル率計算 🔵

**信頼性**: 🔵 *dataflow.md Section 6.1 Adaptive Downsampling より*

```rust
pub fn compute_downsample_factor(
    total_points: usize,
    max_points: usize,
) -> usize {
    if total_points <= max_points {
        1
    } else {
        (total_points as f64 / max_points as f64).ceil() as usize
    }
}
```

### 3. ステータスメッセージ生成 🔵

**信頼性**: 🔵 *dataflow.md Section 6.1 ステータスメッセージより*

```rust
pub fn compute_status_message(
    total: usize,
    rendered: usize,
) -> String {
    if total == rendered {
        format!("Rendering {} points", total)
    } else {
        format!(
            "Rendering {} points (downsampled from {} trials)",
            rendered, total
        )
    }
}
```

## 単体テスト要件

### テストケース1: 基本ダウンサンプリング 🔵

**Given**: points.len() = 600, max_count = 300  
**When**: downsample_points() 呼び出し  
**Then**: 約 300 個のポイントが返される

```rust
#[test]
fn test_downsample_basic() {
    let points: Vec<i32> = (0..600).collect();
    let downsampled = downsample_points(&points, 300);
    
    assert!(downsampled.len() >= 150);  // At least half
    assert!(downsampled.len() <= 300);
}
```

### テストケース2: ダウンサンプリング不要 🔵

**Given**: points.len() = 100, max_count = 300  
**When**: downsample_points() 呼び出し  
**Then**: 元のデータがそのまま返される

```rust
#[test]
fn test_downsample_no_need() {
    let points: Vec<i32> = (0..100).collect();
    let downsampled = downsample_points(&points, 300);
    
    assert_eq!(downsampled.len(), 100);
    assert_eq!(downsampled, points);
}
```

### テストケース3: 1000 trials → 300 points 🔵

**Given**: points.len() = 1000, max_count = 300  
**When**: downsample_points() 呼び出し  
**Then**: 約 300 個以下のポイント

```rust
#[test]
fn test_downsample_1000_to_300() {
    let points: Vec<i32> = (0..1000).collect();
    let downsampled = downsample_points(&points, 300);
    
    assert!(downsampled.len() <= 300);
    // step = ceil(1000 / 300) = 4
    // expected ≈ 250
}
```

### テストケース4: ダウンサンプル率計算 🔵

**Given**: total = 1000, max = 300  
**When**: compute_downsample_factor() 呼び出し  
**Then**: factor = 4

```rust
#[test]
fn test_compute_downsample_factor() {
    let factor = compute_downsample_factor(1000, 300);
    // ceil(1000 / 300) = 4
    assert_eq!(factor, 4);
}
```

### テストケース5: ステータスメッセージ 🔵
