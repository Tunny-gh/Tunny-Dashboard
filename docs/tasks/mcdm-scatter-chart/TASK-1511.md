## 実装詳細

### 1. 色分けマッピング 🔵

**信頼性**: 🔵 *architecture.md Section 4 色分けアルゴリズムより*

```rust
pub fn map_rank_to_color(rank: usize, threshold: TopN) -> Color32 {
    match rank {
        0..=4 if threshold >= TopN::Top5 => {
            Color32::from_rgb(255, 0, 0)  // Red
        }
        5..=9 if threshold >= TopN::Top10 => {
            Color32::from_rgb(255, 165, 0)  // Orange
        }
        10..=19 if threshold >= TopN::Top20 => {
            Color32::from_rgb(255, 255, 0)  // Yellow
        }
        _ => {
            Color32::from_rgb(200, 200, 200)  // Gray
        }
    }
}
```

### 2. ランキング逆変換 🔵

**信頼性**: 🔵 *dataflow.md Section 4.1 ランキング → 色変換より*

```rust
pub fn compute_rank_mapping(
    ranked_indices: &[usize],
) -> Vec<usize> {
    // ranked_indices = [5, 2, 8, 1, 3]
    // Output: [?, 3, 1, 4, ?, 0, ?, ?, 2, ?]
    // where [?] = trial index → rank position
    
    let mut rank_map = vec![usize::MAX; ranked_indices.len()];
    for (rank, &trial_idx) in ranked_indices.iter().enumerate() {
        if trial_idx < rank_map.len() {
            rank_map[trial_idx] = rank;
        }
    }
    rank_map
}
```

### 3. ポイント色生成 🔵

**信頼性**: 🔵 *design-interview.md 色分けルール選択より*

```rust
pub fn compute_point_colors(
    ranked_indices: &[usize],
    threshold: TopN,
) -> Vec<Color32> {
    let rank_map = compute_rank_mapping(ranked_indices);
    rank_map.iter()
        .map(|&rank| {
            if rank == usize::MAX {
                Color32::from_rgb(200, 200, 200)  // Gray
            } else {
                map_rank_to_color(rank, threshold)
            }
        })
        .collect()
}
```
