```
User: X軸を "Objective0" → "VIKOR_Q" に変更
  ↓
cache_key = hash(x_axis, y_axis) が変更を検知
  ↓
display_rows_cache = None に無効化
  ↓
pending_compute = Some(()) を設定
  ↓
Next frame: 背景タスク起動で再計算
```

## 実装詳細

### 1. cache_key 自動更新 🔵

**信頼性**: 🔵 *architecture.md Section 3 キャッシング戦略より*

`McdmScatterChart::show()` の各フレーム冒頭で：

```rust
pub fn show(&mut self, ui: &mut egui::Ui, app_state: &mut AppState) {
    // 1. キャッシュキー更新（Trial数変更検知）
    let trial_count = app_state.trials.len();
    let new_cache_key = (trial_count, Self::hash_axes(&self.x_axis, &self.y_axis));
    
    if new_cache_key != self.cache_key {
        // キャッシュキーが変更 → 軸変更 or Trial追加
        self.cache_key = new_cache_key;
        self.invalidate_cache();  // キャッシュ無効化
    }
    
    // 2. UI制御行
    self.render_controls(ui, app_state);
    
    // 3. プロット描画
    self.render_plot(ui, app_state);
    
    // 4. ステータスバー
    self.render_status(ui, app_state);
}
```

## 単体テスト要件

### テストケース1: 軸変更検知 🔵

**Given**: x_axis = "Objective0", cache_key = (100, hash1)  
**When**: x_axis を "VIKOR_Q" に変更して update_cache_key(100) 呼び出し  
**Then**: cache_key が (100, hash2) に更新、キャッシュが None

```rust
#[test]
fn test_axis_change_invalidates_cache() {
    let mut chart = McdmScatterChart::new();
    chart.display_rows_cache = Some(vec![(0.5, 0.5, Color32::RED)]);
    let old_cache_key = chart.cache_key;
    
    chart.x_axis = "VIKOR_Q".to_string();
    chart.update_cache_key(100);
    
    assert_ne!(chart.cache_key, old_cache_key);
    assert!(chart.display_rows_cache.is_none());
}
```

### テストケース2: Trial数増加検知 🔵

**Given**: cache_key = (100, hash)  
**When**: update_cache_key(150) 呼び出し  
**Then**: cache_key が (150, hash) に、キャッシュが None

```rust
#[test]
fn test_trial_increase_invalidates_cache() {
    let mut chart = McdmScatterChart::new();
    chart.display_rows_cache = Some(vec![(0.5, 0.5, Color32::RED)]);
    chart.cache_key = (100, 12345);
    
    chart.update_cache_key(150);  // Trial 100 → 150
    
    assert_eq!(chart.cache_key.0, 150);
    assert!(chart.display_rows_cache.is_none());
}
```

### テストケース3: Color Threshold はキャッシュ保持 🔵
