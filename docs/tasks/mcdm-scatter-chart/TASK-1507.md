### 1. get_axis_options()関数 🔵

**信頼性**: 🔵 *dataflow.md Section 3.1 軸選択メカニズムより*

`egui-app/src/ui/widgets/mcdm_scatter_chart.rs` または `compute module` に追加：

```rust
pub fn get_axis_options(
    mcdm_result: &McdmResult,
    trial_objectives: &[String],
) -> Vec<AxisOption> {
    let mut options = Vec::new();

    // 1. 目的関数オプション
    for (i, name) in trial_objectives.iter().enumerate() {
        options.push(AxisOption {
            id: format!("Objective{}", i),
            label: format!("Objective {} ({})", i, name),
            unit: None,
        });
    }

    // 2. MCDM方法別スコアオプション
    match mcdm_result {
        McdmResult::Vikor(_vikor) => {
            options.push(AxisOption {
                id: "VIKOR_Q".to_string(),
                label: "VIKOR Q Score".to_string(),
                unit: None,
            });
            options.push(AxisOption {
                id: "VIKOR_S".to_string(),
                label: "VIKOR S Value".to_string(),
                unit: None,
            });
            options.push(AxisOption {
                id: "VIKOR_R".to_string(),
                label: "VIKOR R Value".to_string(),
                unit: None,
            });
        }
        McdmResult::Topsis(_topsis) => {
            options.push(AxisOption {
                id: "TOPSIS_Score".to_string(),
                label: "TOPSIS Score".to_string(),
                unit: None,
            });
        }
        McdmResult::PrometheeI(_promethee) | McdmResult::PrometheeII(_promethee) => {
            options.push(AxisOption {
                id: "Phi+".to_string(),
                label: "Phi+ (Positive Flow)".to_string(),
                unit: None,
            });
            options.push(AxisOption {
                id: "Phi-".to_string(),
                label: "Phi- (Negative Flow)".to_string(),
                unit: None,
            });
        }
    }

    options
}
```

## 単体テスト要件

### テストケース1: VIKOR スコアオプション 🔵

**Given**: McdmResult::Vikor(...)  
**When**: get_axis_options() 呼び出し  
**Then**: VIKOR_Q, VIKOR_S, VIKOR_R オプションが含まれる

```rust
#[test]
fn test_get_axis_options_vikor() {
    let vikor_result = VikorResult {
        s_values: vec![0.5],
        r_values: vec![0.3],
        q_values: vec![0.2],
        display_scores: vec![0.8],
        ranked_indices: vec![0],
        best_values: vec![],
        worst_values: vec![],
        duration_ms: 100,
    };
    
    let trial_objectives = vec!["Height".to_string(), "Weight".to_string()];
    let options = get_axis_options(
        &McdmResult::Vikor(vikor_result),
        &trial_objectives
    );
    
    let has_vikor_q = options.iter().any(|o| o.id == "VIKOR_Q");
    let has_vikor_s = options.iter().any(|o| o.id == "VIKOR_S");
    let has_vikor_r = options.iter().any(|o| o.id == "VIKOR_R");
    
    assert!(has_vikor_q && has_vikor_s && has_vikor_r);
}
```
