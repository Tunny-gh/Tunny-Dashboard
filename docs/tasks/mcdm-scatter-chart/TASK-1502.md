## 実装詳細

### 1. ComboBox X軸選択 🔵

**信頼性**: 🔵 *ParetoScatter2D pareto_2d.rs より*

```rust
// X Axis ComboBox
egui::ComboBox::from_id_salt("x_axis_combo")
    .selected_text(&self.x_axis)
    .show_ui(ui, |ui| {
        for (axis_id, axis_label) in axis_options.iter() {
            if ui.selectable_value(&mut self.x_axis, axis_id.clone(), axis_label) {
                // Axis changed: invalidate cache
                self.invalidate_cache();
            }
        }
    });
```

**重要**:
- `axis_options` は TASK-1507 で実装する get_axis_options() から取得
- 軸変更時に `invalidate_cache()` を呼び出す
- x_axis の値変更を検知して cache_key を更新

### 3. ComboBox Color Threshold選択 🔵

**信頼性**: 🔵 *design-interview.md - 色分けルール選択より*

```rust
// Color Threshold ComboBox
egui::ComboBox::from_id_salt("color_threshold_combo")
    .selected_text(self.color_threshold.as_str())
    .show_ui(ui, |ui| {
        for threshold in TopN::all_options() {
            ui.selectable_value(&mut self.color_threshold, threshold, threshold.as_str());
        }
    });

// Note: TopN::all_options() は interfaces.rs で定義
impl TopN {
    pub fn as_str(&self) -> &str {
        match self {
            TopN::Top5 => "Top5",
            TopN::Top10 => "Top10",
            TopN::Top20 => "Top20",
        }
    }

    pub fn all_options() -> Vec<TopN> {
        vec![TopN::Top5, TopN::Top10, TopN::Top20]
    }
}
```

**注意**: Color Threshold 変更は色のみ再計算（座標キャッシュは再利用）

// Downsample Checkbox
let mut use_downsample = self.use_downsample;
if ui.checkbox(&mut use_downsample, "Enable Downsampling") {

    }
}

## 単体テスト要件

### テストケース1: X軸選択 🔵

**信頼性**: 🔵 *requirements.md REQ-003 より*

**Given**: McdmScatterChart の x_axis = "Objective0"  
**When**: x_axis を "VIKOR_Q" に変更  
**Then**: display_rows_cache が None になり、pending_compute が Some(()) になる

**テストコード**:
```rust
#[test]
fn test_x_axis_selection_invalidates_cache() {
    let mut chart = McdmScatterChart::new();
    chart.display_rows_cache = Some(vec![(0.5, 0.5, Color32::RED)]);
    
    chart.x_axis = "VIKOR_Q".to_string();
    chart.invalidate_cache();
    
    assert!(chart.display_rows_cache.is_none());
    assert!(chart.pending_compute.is_some());
}
```

### テストケース2: Color Threshold変更 🔵

**信頼性**: 🔵 *architecture.md 色分けアルゴリズムより*

**Given**: color_threshold = TopN::Top5  
**When**: color_threshold を TopN::Top20 に変更  
**Then**: color_threshold が更新される（キャッシュは保持）

**テストコード**:
```rust
#[test]
fn test_color_threshold_does_not_invalidate_cache() {
    let mut chart = McdmScatterChart::new();
    let cached = vec![(0.5, 0.5, Color32::RED)];
    chart.display_rows_cache = Some(cached.clone());
    
    // Note: UI では selectable_value で状態が更新される
    chart.color_threshold = TopN::Top20;
    
    assert!(chart.display_rows_cache.is_some());  // Cache retained
}
```

### テストケース3: ダウンサンプリング切り替え 🔵

**信頼性**: 🔵 *architecture.md ダウンサンプリング戦略より*

**Given**: use_downsample = true  
**When**: use_downsample を false に切り替え  
**Then**: キャッシュが無効化され、pending_compute が設定される

**テストコード**:
```rust
#[test]
fn test_downsample_toggle_invalidates_cache() {
    let mut chart = McdmScatterChart::new();
    chart.use_downsample = true;
    chart.display_rows_cache = Some(vec![(0.5, 0.5, Color32::RED)]);
    
    chart.use_downsample = false;
    chart.invalidate_cache();
    
    assert!(chart.display_rows_cache.is_none());
    assert!(chart.pending_compute.is_some());
}
```
