### 2. メッセージディスパッチ統合 🔵

**信頼性**: 🔵 *architecture.md Section 1.1 メッセージパッシング構造より*

既存メッセージハンドラー内に追加：

```rust
pub fn handle_message(
    message: AppMessage,
    app_state: &mut AppState,
) {
    match message {
        // ... existing match arms
        
        AppMessage::McdmScatterComputed { points, metadata } => {
            handle_mcdm_scatter_computed(
                &mut app_state.widget_states.scatter_chart,
                points,
                metadata,
            );
        }
        
        AppMessage::McdmScatterComputeFailed(reason) => {
            eprintln!("Scatter plot computation failed: {}", reason);
            app_state.widget_states.scatter_chart.error_message = Some(reason);
            app_state.widget_states.scatter_chart.computing = false;
        }
    }
}
```

## 単体テスト要件

### テストケース1: キャッシュ更新 🔵

**Given**: display_rows_cache = None, computing = false  
**When**: handle_mcdm_scatter_computed() 呼び出し  
**Then**: display_rows_cache が Some(points) に、computing が false のまま

```rust
#[test]
fn test_handle_mcdm_scatter_computed_updates_cache() {
    let mut widget = McdmScatterChart::new();
    let points = vec![(0.5, 0.5, Color32::RED)];
    let metadata = ScatterMetadata {
        total_trials: 100,
        rendered_points: 50,
        downsample_factor: 2,
        compute_time_ms: 100,
        x_axis_label: "X".to_string(),
        y_axis_label: "Y".to_string(),
    };
    
    handle_mcdm_scatter_computed(&mut widget, points.clone(), metadata);
    
    assert!(widget.display_rows_cache.is_some());
    assert_eq!(widget.display_rows_cache.unwrap().len(), 1);
    assert_eq!(widget.computing, false);
}
```

### テストケース2: エラーハンドリング 🔵

**Given**: McdmScatterComputeFailed メッセージ  
**When**: メッセージハンドラが処理  
**Then**: error_message が設定され、computing = false

```rust
#[test]
fn test_handle_mcdm_scatter_failed() {
    let mut widget = McdmScatterChart::new();
    widget.computing = true;
    
    let error_msg = "Computation timeout".to_string();
    widget.error_message = Some(error_msg.clone());
    widget.computing = false;
    
    assert_eq!(widget.error_message.unwrap(), error_msg);
    assert_eq!(widget.computing, false);
}
```
