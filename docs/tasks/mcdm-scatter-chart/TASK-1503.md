pub enum TabState {

### 3. show()メソッド拡張（タブUI） 🔵

**信頼性**: 🔵 *architecture.md Section 2.2 UI レイアウトより*

```rust
impl McdmRankChart {
    pub fn show(&mut self, ui: &mut egui::Ui, app_state: &mut AppState) {
        // Tab selector row
        ui.horizontal(|ui| {
            ui.selectable_value(
                &mut self.active_tab,
                TabState::Ranking,
                TabState::Ranking.as_str()
            );
            ui.selectable_value(
                &mut self.active_tab,
                TabState::ScatterPlot,
                TabState::ScatterPlot.as_str()
            );
        });
        
        // Tab content
        match self.active_tab {
            TabState::Ranking => {
                // 既存実装：バーチャート + テーブル
                self.show_ranking_tab(ui, app_state);
            }
            TabState::ScatterPlot => {
                // 新規実装：散布図（TASK-1502 で実装）
                self.scatter_chart.show(ui, app_state);
            }
        }
    }

    fn show_ranking_tab(&mut self, ui: &mut egui::Ui, app_state: &mut AppState) {
        // 既存の bar chart + table 表示ロジック（変更なし）
    }
}
```

### テストケース3: ScatterChart状態保持 🔵

**信頼性**: 🔵 *UI層独立管理設計より*

**Given**: TabState::ScatterPlot 表示中に軸選択を変更  
**When**: TabState を Ranking に戻してから ScatterPlot に戻す  
**Then**: ScatterChart の状態（軸選択等）が保持されている

**テストコード**:
```rust
#[test]
fn test_scatter_chart_state_retention() {
    let mut chart = McdmRankChart::new();
    
    chart.active_tab = TabState::ScatterPlot;
    chart.scatter_chart.x_axis = "VIKOR_Q".to_string();
    
    chart.active_tab = TabState::Ranking;
    chart.active_tab = TabState::ScatterPlot;
    
    assert_eq!(chart.scatter_chart.x_axis, "VIKOR_Q");
}
```
