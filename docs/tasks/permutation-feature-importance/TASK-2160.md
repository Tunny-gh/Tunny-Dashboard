## 実装詳細

### 1. ImportanceMetric → SensitivityMetric マッピング追加 🔵

**信頼性**: 🔵 *実装ガイド Step 7-A + 受け入れ基準 TC-PFI-INT-01 より*

**実装ファイル**: `egui-app/src/ui/chart_registry.rs`

既存の `ImportanceMetric::Shap =>` ケースの直後（またはマッピング match 文の末尾）に追加：

```rust
ImportanceMetric::Permutation => {
    tunny_core::sensitivity::SensitivityMetric::Permutation
}
```

### 2. SensitivityDone 変換に permutation フィールドを追加 🔵

**信頼性**: 🔵 *実装ガイド Step 7-B + 受け入れ基準 TC-PFI-INT-02 より*

`AppMessage::SensitivityDone` の `result` 構築部分（rust_core の `SensitivityResult` を
egui-app の `SensitivityResult` に変換するブロック）に追加：

```rust
permutation: r.permutation.map(|x| PermutationResult {
    importances: x.importances,
    r_squared:   x.r_squared,
}),
```

### 3. use 宣言に PermutationResult を追加 🔵

**信頼性**: 🔵 *実装ガイド Step 7 より*

既存の `use crate::state::results::{...}` の use 宣言に `PermutationResult` を追加：

```rust
use crate::state::results::{
    MdiResult, PermutationResult, RfAnovaResult, RidgeResult, SensitivityResult, ShapResult,
    SobolResult,
};
```

> **注意**: 既存の use 宣言の形式（複数行 or 一行）に合わせること。

### 4. unreachable!() の削除（必要な場合） 🟡

**信頼性**: 🟡 *実装ガイド注意事項より*

`chart_registry.rs` の match 文に `_ => unreachable!()` が残っている場合、
`ImportanceMetric::Permutation` バリアント追加後にコンパイルエラーになる。
その場合は `ImportanceMetric::Permutation` の明示ケースに変換すること。
