## タスク概要

egui-app 側のローカル結果型 `results.rs` に `PermutationResult` 構造体と
`SensitivityResult.permutation` フィールドを追加する。
rust_core の `PermutationResult` と 1:1 対応する mirror 型であり、
`chart_registry.rs` での変換コードが次タスクで追加される。

## 実装詳細

### 1. PermutationResult 構造体を追加 🔵

**信頼性**: 🔵 *実装ガイド Step 5-A + 既存 ShapResult パターンより*

**実装ファイル**: `egui-app/src/state/results.rs`

既存の `ShapResult` 構造体定義の直後に追加：

```rust
#[derive(Debug, Clone)]
pub struct PermutationResult {
    pub importances: Vec<Vec<f64>>,
    pub r_squared:   Vec<f64>,
}
```

### 2. SensitivityResult に permutation フィールドを追加 🔵

**信頼性**: 🔵 *実装ガイド Step 5-B より*

```rust
pub struct SensitivityResult {
    pub param_names:     Vec<String>,
    pub objective_names: Vec<String>,
    pub spearman:        Vec<Vec<f64>>,
    pub ridge:           Vec<RidgeResult>,
    pub rf_anova:        Option<RfAnovaResult>,
    pub mdi:             Option<MdiResult>,
    pub shap:            Option<ShapResult>,
    pub permutation:     Option<PermutationResult>,   // ← 追加
}
```

> **注意**: `SensitivityResult` のコンストラクタが他ファイルにある場合、
> `permutation: None` を追加する必要がある。コンパイルエラーを確認すること。
