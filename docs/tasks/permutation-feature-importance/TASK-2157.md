### 5. full.rs — Permutation ケースを match 文に追加 🔵

**信頼性**: 🔵 *実装ガイド Step 4 + 設計ヒアリング決定事項 3（transpose パターン）より*

**実装ファイル**: `rust_core/src/sensitivity/analysis/full.rs`

`SensitivityMetric::Shap =>` の直後（または `SensitivityMetric::RfAnova =>` の直後）に追加：

```rust
SensitivityMetric::Permutation => {
    let Some(ref x_mat) = x_matrix_opt else {
        return SensitivityResult {
            param_names: names,
            objective_names: vec![selected_obj],
            spearman: vec![],
            ridge: vec![],
            rf_anova: None,
            mdi: None,
            shap: None,
            permutation: None,
        };
    };
    let (imp, r2) = crate::sensitivity::compute_permutation_importances(x_mat, &y);
    let importances: Vec<Vec<f64>> = imp.into_iter().map(|v| vec![v]).collect();
    SensitivityResult {
        param_names:     names,
        objective_names: vec![selected_obj],
        spearman:        vec![],
        ridge:           vec![],
        rf_anova:        None,
        mdi:             None,
        shap:            None,
        permutation:     Some(crate::sensitivity::types::PermutationResult {
            importances,
            r_squared: vec![r2],
        }),
    }
}
```

> **注意**: `Default::default_empty()` が存在する場合はそれを使ってよいが、
> 存在しない場合は上記のように全フィールドを明示的に列挙する。
