### 1. ファイル新規作成 🔵

```rust
use super::data::sample_rows;
use crate::core::lgbm::{lgbm_mse, mse_to_r_squared, train_lgbm_rf, LgbmRfConfig};
use crate::core::random_forest::Lcg;

const N_REPEATS:         usize = 5;
const PFI_MAX_ROWS:      usize = 2_000;
const PFI_SEED_BASE:     u64   = 42;
const PFI_SPLIT_SEED:    u64   = 43;
const PFI_TREES:         usize = 100;
const PFI_MAX_DEPTH:     i32   = 10;
const PFI_MIN_DATA_LEAF: i32   = 2;
```

### 2. `compute_permutation_importances` 関数 🔵

**信頼性**: 🔵 *実装ガイド Step 2 + 設計ヒアリング決定事項（シード計算式）より*

1. NaN/Inf フィルタリング（`valid_indices`）
2. ダウンサンプリング（`PFI_MAX_ROWS=2,000`、`sample_rows`）
3. 80/20 holdout 分割（Fisher-Yates、`PFI_SPLIT_SEED=43`）
4. LightGBM RF 学習（`train_lgbm_rf`、`PFI_TREES=100`）
5. `baseline_mse` を `lgbm_mse` で計算
6. n_repeats=5 ループ:
   - `seed = PFI_SEED_BASE + feature_idx * N_REPEATS + repeat_idx`
   - `permute_single_column(x_eval, feature_idx, seed)`
   - `delta += max(permuted_mse - baseline_mse, 0.0)`
7. `importances[feat] /= N_REPEATS`
8. `normalize()` で sum=1.0 に正規化
9. `r_squared = mse_to_r_squared(baseline_mse, y_eval)` を返す

### 3. `permute_single_column` ヘルパー 🔵

**信頼性**: 🔵 *実装ガイド Step 2 より*

Fisher-Yates シャッフルで指定 feature_idx の列のみをシャッフルした `Vec<Vec<f64>>` を返す。

### 4. `normalize` ヘルパー 🔵

**信頼性**: 🔵 *既存 shap.rs / mdi.rs パターンより*

sum が `f64::EPSILON` 未満の場合は全要素を 0.0 にして早期リターン。それ以外は sum で除算。

## 単体テスト要件

### テストケース 1: 通常ケース（TC-PFI-001-01） 🔵

**信頼性**: 🔵 *受け入れ基準 TC-PFI-001-01 より*

**Given**: n=50, p=5 のランダム行列
**When**: `compute_permutation_importances` を呼び出す
**Then**: `imp.len() == 5` かつ `sum ≈ 1.0`（±0.001）

**テストファイル**: `rust_core/src/sensitivity/tests.rs`

```rust
#[test]
fn test_pfi_normal_case() {
    let n = 50;
    let p = 5;
    let x: Vec<Vec<f64>> = (0..n).map(|_| vec![1.0; p]).collect();
    let y: Vec<f64> = (0..n).map(|i| i as f64).collect();
    let (imp, _r2) = compute_permutation_importances(&x, &y);
    assert_eq!(imp.len(), p);
    let sum: f64 = imp.iter().sum();
    assert!((sum - 1.0).abs() < 1e-6 || sum < f64::EPSILON);
}
```
