## 実装詳細

### 1. 対象関数の特定 🔵

**信頼性**: 🔵 *build.rs 既存実装より*

**実装ファイル**: `egui-app/build.rs`

対象関数: `wrap_as_standalone_html()` 内の `<style>` タグ。

### 2. 変更後の CSS テンプレート 🔵

**信頼性**: 🔵 *TONMANUAL §2§3§6 準拠・implementation-guide.md §2 より*

`wrap_as_standalone_html()` 内の `<style>` タグを以下に変更する:

```css
/* === 変更後 CSS テンプレート (TONMANUAL §2§3§6 準拠) === */

body {
  font-family: -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, sans-serif;
  font-size: 14px;
  line-height: 1.6;
  color: #4B5563;            /* TONMANUAL gray-600 */
  background: #ffffff;
  max-width: 860px;
  margin: 0 auto;
  padding: 24px;
}

h1, h2, h3 {
  font-weight: 800;          /* TONMANUAL font-extrabold */
  margin-top: 1.5em;
  margin-bottom: 0.5em;
  color: #111827;            /* TONMANUAL gray-900 */
  letter-spacing: -0.025em;  /* TONMANUAL tracking-tight */
}

h1 {
  font-size: 1.8em;
  border-bottom: 1px solid #E5E7EB;  /* TONMANUAL gray-200 */
  padding-bottom: 0.3em;
}

h2 {
  font-size: 1.4em;
  border-bottom: 1px solid #E5E7EB;  /* TONMANUAL gray-200 */
  padding-bottom: 0.2em;
}

a {
  color: #2563EB;            /* TONMANUAL blue-600 */
  text-decoration: none;
}

a:hover {
  text-decoration: underline;
}

code {
  background: #F3F4F6;       /* TONMANUAL gray-100 */
  border-radius: 3px;
  padding: 0.1em 0.3em;
  font-size: 0.9em;
}

pre {
  background: #F3F4F6;       /* TONMANUAL gray-100 */
  border-radius: 6px;
  padding: 16px;
  overflow: auto;
}

pre code { background: none; padding: 0; }

table {
  border-collapse: collapse;
  width: 100%;
  margin: 1em 0;
}

th, td {
  border: 1px solid #E5E7EB; /* TONMANUAL gray-200 */
  padding: 8px 12px;
  text-align: left;
}

th {
  background: #F3F4F6;       /* TONMANUAL gray-100 */
  font-weight: 600;
  color: #111827;            /* TONMANUAL gray-900 */
}

{katex_css}
```

### 3. KaTeX CSS 配置に関する注意事項 🔵

**信頼性**: 🔵 *architecture.md HTML生成制約より*

- `{katex_css}` プレースホルダーは必ず `<style>` タグの**末尾**に配置する
- これにより KaTeX の CSS が brand CSS を上書きしないようにする
- 現在の `build.rs` で `{katex_css}` の位置を確認し、必要に応じて移動する

## 実装手順

### Step 1: 現在の build.rs を読み込む

`egui-app/build.rs` を Read ツールで読み込み、`wrap_as_standalone_html()` 内の CSS を確認する。

### Step 2: CSS を置き換える

Edit ツールを使用して、既存の CSS ブロックを上記の変更後 CSS に置き換える。

置き換える範囲: `<style>` タグの開始から `</style>` タグまでの内容（CSS 文字列全体）。

### Step 3: ビルド確認

```bash
rtk cargo build --workspace
```

`build.rs` が実行され、ヘルプ HTML ファイルが `OUT_DIR/help/` に再生成されることを確認する。

### Step 4: 生成 HTML の確認

生成された HTML ファイル（`OUT_DIR/help/ja/` または `OUT_DIR/help/en/` 配下）を確認し、CSS 値が正しく反映されているかチェックする。
