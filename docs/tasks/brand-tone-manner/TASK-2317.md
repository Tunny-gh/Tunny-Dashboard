**信頼性**: 🔵 *TONMANUAL §2§3 準拠・implementation-guide.md §3 より*

/* === 変更後 CSS (TONMANUAL §2§3 準拠) === */

### 3. SVG 散布図の色変更 🔵

**信頼性**: 🔵 *TONMANUAL §2 メインブルー blue-500 より*

```rust
// 変更前
let color = if row.pareto_rank == 0 { "#e74c3c" } else { "#3498db" };

// 変更後（TONMANUAL §2 blue-500）
let color = if row.pareto_rank == 0 { "#e74c3c" } else { "#3B82F6" };
```

- Pareto 最前沿点 (`pareto_rank == 0`) の赤 (#e74c3c) はセマンティックカラーのため**変更しない**
- Pareto 外点のみ `#3498db`（Google Blue）→ `#3B82F6`（TONMANUAL blue-500）に変更

### 4. スタンドアロン HTML 制約の維持 🔵

**信頼性**: 🔵 *html_report.rs 既存仕様・REQ-203 より*

- `<link>` タグや外部 `<script>` タグを追加しない
- フォントは `sans-serif`（システムフォント）のみ使用
- CSS はインライン `<style>` タグ内のみに記載
