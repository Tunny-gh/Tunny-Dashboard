## タスク概要

TASK-2269 で実装した `SamplingContext` を `egui-app` 側に統合する。
`AppState` に `sampling_ctx: Option<SamplingContext>` フィールドを追加し、
旧グローバル状態（`init_sampling()` 副作用版・`reset_sampling`・`set_cluster_labels`）の
全呼び出し箇所を新 API に置き換える。

## 実装詳細

### 1. AppState への sampling_ctx フィールド追加 🔵

**信頼性**: 🔵 *REQ-C08・interfaces.rs egui-app 変更より（ユーザー確認済み）*

`egui-app/src/state/app_state.rs` の `AppState` 構造体に新フィールドを追加する。

```rust
pub struct AppState {
    // ... 既存フィールド ...
    pub sampling_ctx: Option<SamplingContext>,
}
```

### 2. データロード完了時の初期化 🔵

**信頼性**: 🔵 *REQ-C08・dataflow.md セクション10 より（ユーザー確認済み）*

データロード完了時に `init_sampling` を呼び出し、返却値を `AppState` に保存する。

```rust
let ctx = init_sampling(is_minimize, pareto_indices, all_ranks);
self.sampling_ctx = Some(ctx);
```

### 3. クラスタリング完了時の cluster_labels 更新 🔵

**信頼性**: 🔵 *REQ-C08・dataflow.md セクション10 より（ユーザー確認済み）*

クラスタリング完了時に `SamplingContext` の `cluster_labels` を更新する。

```rust
self.sampling_ctx.as_mut().map(|c| c.cluster_labels = Some(labels));
```

### 4. ダウンサンプリング呼び出し箇所の更新 🔵

**信頼性**: 🔵 *REQ-C08・interfaces.rs egui-app 変更より（ユーザー確認済み）*

旧グローバル版の呼び出しを `&SamplingContext` を引数とする新 API に置き換える。

```rust
// 変更前: downsample_smart(max_points)
// 変更後:
if let Some(ctx) = &self.sampling_ctx {
    downsample_smart(ctx, max_points)
} else {
    // フォールバック
}
```

### 5. 新データロード時のリセット 🔵

**信頼性**: 🔵 *REQ-C08・dataflow.md セクション10 より*

新しいデータロード時に `sampling_ctx` を `None` にリセットし、旧コンテキストを破棄する。

### 6. 旧グローバル状態呼び出しの削除 🔵

**信頼性**: 🔵 *REQ-C08・interfaces.rs egui-app 変更より（ユーザー確認済み）*

以下の旧 API 呼び出しを全て削除する。
- `init_sampling()` の副作用版呼び出し
- `reset_sampling()`
- `set_cluster_labels()`
