## タスク概要

`rust_core/src/mcdm/topsis.rs` の `build_weighted_matrix` 関数を変更し、
行ごとの逐次 `push`/`extend` による複数アロケーションを廃止して単一アロケーションに統一する。
これにより O(n) 再アロケーションのリスクを排除し、メモリ効率を向上させる。

## 実装詳細

### 1. build_weighted_matrix の単一アロケーション化 🔵

**信頼性**: 🔵 *REQ-C03・architecture.md C-2・dataflow.md セクション8 より*

`rust_core/src/mcdm/topsis.rs` の `build_weighted_matrix` を以下のように書き換える。
事前に総要素数が確定しているため、単一の `vec!` でアロケートしてインデックス代入が最適。

```rust
// 変更前: 行ごとに Vec::push（O(n) 再アロケーションのリスク）
let mut result: Vec<f64> = vec![];
for row in valid_indices.iter() {
    let row_data: Vec<f64> = (0..n_objectives).map(|j| values[row][j] * weights[j]).collect();
    result.extend_from_slice(&row_data);
}

// 変更後: 単一アロケーション + インデックス代入
let mut result = vec![0.0_f64; n_valid * n_objectives];
for (idx, &original_row) in valid_indices.iter().enumerate() {
    for j in 0..n_objectives {
        result[idx * n_objectives + j] = values[original_row][j] * weights[j];
    }
}
```
