## タスク概要

TASK-2258 で定義した `SensitivityMetric` トレイトを、既存の Spearman 感度分析と Ridge 感度分析に対してそれぞれ実装する。既存の計算関数はラップするだけで内部ロジックの変更は行わず、後方互換性を維持する。`compute()` はデータ不足や計算失敗時に `None` を返しパニックしない設計を保証する。
