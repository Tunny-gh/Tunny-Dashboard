## 実装詳細

### 1. metric_trait.rs の新規作成 🔵

**信頼性**: 🔵 *REQ-A01〜A03・design-interview.md Q3 より（ユーザー確認済み）*

`rust_core/src/sensitivity/metric_trait.rs` を新規作成し、以下のトレイトを定義する:

```rust
pub trait SensitivityMetric: Send + Sync {
    fn compute(&self, df: &DataFrame, obj_idx: usize) -> Option<SensitivityResult>;
    fn name(&self) -> &'static str;
}
```

- `Send + Sync` スーパートレイトにより、マルチスレッド環境での安全な利用を保証する
- `compute()` は計算失敗時に `None` を返し、パニックしない設計とする
- `name()` は静的文字列を返し、ログや UI 表示での識別に使用する

### 2. enum SensitivityMetric → SensitivityKind リネーム 🔵

**信頼性**: 🔵 *REQ-A03・design-interview.md Q3 より*

`rust_core/src/sensitivity/types.rs` 内の `enum SensitivityMetric` を `enum SensitivityKind` にリネームする。これにより、トレイト `SensitivityMetric` との命名衝突を解消する。

対象箇所:
- `types.rs` の enum 定義
- `sensitivity/mod.rs` の再エクスポート（存在する場合）
- `egui-app` クレート内の `SensitivityMetric` 列挙型参照箇所すべて

### 3. mod.rs へのトレイト再エクスポート追加 🔵

**信頼性**: 🔵 *REQ-A01・architecture.md A-1 より*

`rust_core/src/sensitivity/mod.rs` に以下を追加する:

```rust
pub use metric_trait::SensitivityMetric;
```

これにより、外部クレートから `tunny_core::sensitivity::SensitivityMetric` でトレイトを参照できるようにする。
