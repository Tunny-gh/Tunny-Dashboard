## 実装詳細

### 1. `compute_xtx_matrix` の抽出 🔵

**信頼性**: 🔵 *REQ-B04・architecture.md B-3 より*

X'X 行列を計算する関数として抽出する。Ridge 正則化項の加算はオーケストレーター側で行う。

```rust
pub fn compute_xtx_matrix(
    x_cols: &[f64],
    p: usize,
    n: usize,
) -> Vec<Vec<f64>>
```

- `x_cols`: column-major 配列（長さ `n * p`）
- 返り値: `p × p` の X'X 行列

### 2. `compute_xty_vector` の抽出 🔵

**信頼性**: 🔵 *REQ-B04・architecture.md B-3 より*

X'y ベクトルを計算する関数として抽出する。

```rust
pub fn compute_xty_vector(
    x_cols: &[f64],
    y: &[f64],
    p: usize,
    n: usize,
) -> Vec<f64>
```

- 返り値: 長さ `p` の X'y ベクトル

### 3. `compute_r_squared` の抽出 🔵

**信頼性**: 🔵 *REQ-B04・dataflow.md セクション6 より*

決定係数 R² を計算する関数として抽出する。

```rust
pub fn compute_r_squared(
    y_actual: &[f64],
    y_predicted: &[f64],
) -> f64
```

- SS_tot ≈ 0 の場合は `0.0` を返す（ゼロ除算の回避）

### 4. オーケストレーターの簡略化 🔵

**信頼性**: 🔵 *REQ-B04・architecture.md B-3 より*

`compute_ridge_from_standardized_columns` は上記 3 関数を呼び出すのみとし、20 行以内に収める。
正則化項の加算（`X'X` 対角成分への `lambda` 加算）はこの関数内で行う。

### 5. 行列フォーマット変換の統一（REQ-C04）🔵

**信頼性**: 🔵 *REQ-C04・interfaces.rs より*

column-major → `Vec<Vec<f64>>` の変換が複数箇所で発生している問題を解消する。
`compute_xtx_matrix` および `compute_xty_vector` に渡す段階でフォーマットを確定し、
関数内部での重複変換をなくす。
