## タスク概要

`rust_core/src/clustering/kmeans.rs` 内の不要なクローン操作を削減し、メモリ効率を改善する。
重心初期化時の `to_vec()` による再アロケートを `Vec::with_capacity` + スライスコピーに置き換え、
フォールバック時の `centroids[c].clone()` を削除する。

## 実装詳細

### 1. 重心初期化時の再アロケート削減 🟡

**信頼性**: 🟡 *REQ-C01・architecture.md C-3 から妥当な推測*

`rust_core/src/clustering/kmeans.rs` の重心初期化処理で、`point.to_vec()` による再アロケートを
`Vec::with_capacity` + `extend_from_slice` に置き換える。

```rust
// 変更前
let centroid = point.to_vec();

// 変更後
let mut centroid = Vec::with_capacity(n_cols);
centroid.extend_from_slice(&flat_data[idx*n_cols..(idx+1)*n_cols]);
```

### 2. フォールバック時の不要クローン削除 🟡

**信頼性**: 🟡 *REQ-C02・architecture.md C-3 から妥当な推測*

フォールバック処理における `centroids[c].clone()` を参照ベースの代入または `swap` に変更し、
不要なメモリコピーを排除する。

```rust
// 変更前
centroids[c] = centroids[c].clone();

// 変更後: 不要なクローンを除去（参照を活用）
```
