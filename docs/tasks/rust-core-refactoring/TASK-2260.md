TASK-2258 で定義した `SensitivityMetric` トレイトを、ランダムフォレスト系の4つの感度指標（RfAnova, Mdi, Shap, Permutation）に対して実装する。いずれも既存の `TreeMetric` をラップする形で実装し、`tree_common.rs` の `prepare_training_data()` を経由して計算を再利用する。既存ロジックへの変更は行わない。

### 2. prepare_training_data() を介した既存計算の再利用 🔵

**信頼性**: 🔵 *architecture.md A-1 実装者表より*

各 `compute()` 実装は `tree_common.rs` の `prepare_training_data()` を呼び出してデータ前処理を行い、その結果を既存の `TreeMetric` に渡す。`prepare_training_data()` が `None` を返した場合（データ不足など）は、`compute()` もそのまま `None` を返す。
