## 実装詳細

### 1. `compute_sensitivity_single_obj` のシグネチャ変更 🔵

**信頼性**: 🔵 *REQ-B01・dataflow.md セクション1 より*

変更前は指標の種類を関数内部の `match` で判別していたが、変更後は呼び出し元が
`Vec<Box<dyn SensitivityMetric>>` を渡すことで、関数自体は指標の種類を知らなくて済む。

```rust
// 変更後のシグネチャ
pub fn compute_sensitivity_single_obj(
    df: &DataFrame,
    metrics: Vec<Box<dyn SensitivityMetric>>,
    obj_idx: usize,
) -> Vec<SensitivityResult> {
    metrics.iter()
        .filter_map(|m| m.compute(df, obj_idx))
        .collect()
}
```

### 2. match アームの削除 🔵

**信頼性**: 🔵 *REQ-B02・dataflow.md セクション2 より*

以下の 6 アームを削除し、各指標モジュール内の `SensitivityMetric` 実装に委譲する:
- Spearman アーム
- Ridge アーム
- RfAnova アーム
- Mdi アーム
- Shap アーム
- Permutation アーム

各指標の `SensitivityMetric::compute` メソッドが `Option<SensitivityResult>` を返し、
`filter_map` で `None`（計算失敗）を除外する。
