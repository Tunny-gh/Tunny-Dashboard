## タスク概要

`rust_core/src/core/kriging/gaussian_process/model.rs` の `GpModel` を
カーネルパラメータを表す `GpKernel` と学習済みモデルを表す `GpFittedModel` の 2 構造体に分割する。
これにより、最適化フェーズとフィッティングフェーズの責務が型レベルで明確に分離される。

## 実装詳細

### 1. `GpKernel` 構造体の定義 🟡

**信頼性**: 🟡 *REQ-B05・interfaces.rs より（既存コードは単純な単一構造体）*

カーネルのハイパーパラメータのみを保持する構造体を定義する。

```rust
#[derive(Debug, Clone)]
pub struct GpKernel {
    pub log_ls: Vec<f64>,  // 対数スケール長さ（次元ごと）
    pub log_sf: f64,        // 対数信号分散
    pub log_sn: f64,        // 対数ノイズ標準偏差
}
```

### 2. `GpFittedModel` 構造体の定義 🟡

**信頼性**: 🟡 *REQ-B05・design-interview.md Q5 より*

学習済みモデル全体を保持する構造体を定義する。

```rust
#[derive(Debug, Clone)]
pub struct GpFittedModel {
    pub kernel: GpKernel,       // 最適化済みカーネルパラメータ
    pub alpha: Vec<f64>,         // 訓練係数（Cholesky 解）
    pub x_train: Vec<Vec<f64>>, // 訓練入力データ
    pub l: Vec<Vec<f64>>,       // Cholesky 分解 L（下三角行列）
}
```

### 3. 関連関数のシグネチャ変更 🟡

**信頼性**: 🟡 *REQ-B05・interfaces.rs より*

既存 `GpModel` を参照している以下の関数を更新する:

- **最適化関数**: `GpModel` → `GpKernel` を返すよう変更
- **fit 関数**: `GpModel` → `GpFittedModel` を返すよう変更（`GpKernel` を受け取る）
- **predict 関数**: `&GpModel` → `&GpFittedModel` を受け取るよう変更

### 4. 既存 `GpModel` の扱い 🟡

**信頼性**: 🟡 *REQ-B05 より（後方互換性の考慮）*

既存コードへの影響を最小化するため、以下のいずれかを選択する:
- `GpModel` を削除し、全参照箇所を `GpFittedModel` に更新する
- `type GpModel = GpFittedModel;` として型エイリアスを維持する
