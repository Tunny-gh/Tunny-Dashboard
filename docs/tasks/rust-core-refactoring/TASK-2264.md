## 実装詳細

### 1. `compute_global_stats` の抽出 🔵

**信頼性**: 🔵 *REQ-B03・dataflow.md セクション5 より*

全体の列ごとの平均と標準偏差を計算する関数として抽出する。

```rust
pub fn compute_global_stats(
    flat_data: &[f64],
    n: usize,
    p: usize,
) -> (Vec<f64>, Vec<f64>)
```

- `flat_data`: column-major 配列（長さ `n * p`）
- 返り値: `(global_mean, global_std)` それぞれ長さ `p` のベクタ

### 2. `compute_cluster_centroid_std` の抽出 🔵

**信頼性**: 🔵 *REQ-B03・architecture.md B-2 より*

クラスタごとの重心と標準偏差を計算する関数として抽出する。

```rust
pub fn compute_cluster_centroid_std(
    flat_data: &[f64],
    labels: &[usize],
    n: usize,
    p: usize,
    k: usize,
) -> Vec<ClusterStat>
```

- 空クラスタの場合は全体平均を重心として使用する

### 3. `compute_significant_features` の抽出 🔵

**信頼性**: 🔵 *REQ-B03・dataflow.md セクション5 より*

t 統計量で有意特徴を判定する関数として抽出する。

```rust
pub fn compute_significant_features(
    cluster_stats: Vec<ClusterStat>,
    global_mean: &[f64],
    global_std: &[f64],
    n: usize,
) -> Vec<ClusterStat>
```

- t 統計量: `t = (centroid[j] - global_mean[j]) / SE`
- `SE = sqrt(var_c/nc + var_g/n)`
- `t > 3.0` のとき `significant_features = true` とする

### 4. オーケストレーターの簡略化 🔵

**信頼性**: 🔵 *REQ-B03・architecture.md B-2 より*

`compute_cluster_stats_on_data` は上記 3 関数を順に呼び出すのみとし、20 行以内に収める。
