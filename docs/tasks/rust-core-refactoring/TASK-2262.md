## 実装詳細

### 1. select_next_centroid 関数の追加 🔵

**信頼性**: 🔵 *REQ-A06・A07・interfaces.rs・dataflow.md セクション4 より*

`rust_core/src/clustering/kmeans.rs` に以下の関数を追加する:

```rust
/// k-means++ / 決定論的初期化の共通重心選択関数。
/// sampling_fn により確率的/決定論的を切り替え可能。
pub fn select_next_centroid<F>(
    flat_data: &[f64],
    n_cols: usize,
    existing: &[Vec<f64>],
    n: usize,
    sampling_fn: F,
) -> Vec<f64>
where
    F: Fn(&[f64]) -> usize,
{
    // 各点の既存重心からの最小距離² を計算
    // sampling_fn に渡して選択インデックスを取得
    // 選択された点のコピーを返す
}
```

**引数仕様**:
- `flat_data`: 行優先フラット配列（行数 = `n`、列数 = `n_cols`）
- `n_cols`: 特徴量次元数
- `existing`: 既に選択済みの重心ベクトルのスライス（空でも可）
- `n`: データ点の総数
- `sampling_fn`: 距離² スライスを受け取り、選択するデータ点のインデックスを返すクロージャ

**処理フロー**:
1. `existing` が空の場合、距離² は全点均一（= 1.0）として `sampling_fn` に渡す
2. `existing` が非空の場合、各データ点について既存重心との最小ユークリッド距離² を計算する
3. 距離² スライスを `sampling_fn` に渡し、選択インデックスを取得する
4. `flat_data[idx * n_cols .. (idx+1) * n_cols]` を `Vec<f64>` としてコピーして返す

### 2. init_kmeans_plusplus のリファクタリング 🔵

**信頼性**: 🔵 *REQ-A06 より*

`init_kmeans_plusplus` 内の重心選択ループを `select_next_centroid` 呼び出しに置き換える。確率的サンプリング（距離² 比例確率）を `sampling_fn` として渡す:

```rust
// Before: 重複コードで最小距離² 計算 + 確率的選択
// After:
let centroid = select_next_centroid(flat_data, n_cols, &centroids, n, |weights| {
    // 距離² に比例した確率分布からサンプリング
    weighted_random_choice(weights, &mut rng)
});
centroids.push(centroid);
```

### 3. init_deterministic のリファクタリング 🔵

**信頼性**: 🔵 *REQ-A07 より*

`init_deterministic` 内の重心選択ループを `select_next_centroid` 呼び出しに置き換える。決定論的選択（最大距離² の点を選ぶ）を `sampling_fn` として渡す:

```rust
// Before: 重複コードで最小距離² 計算 + 最大値選択
// After:
let centroid = select_next_centroid(flat_data, n_cols, &centroids, n, |weights| {
    // 最大距離² のインデックスを返す（決定論的）
    weights.iter().enumerate().max_by(|a, b| a.1.partial_cmp(b.1).unwrap()).map(|(i, _)| i).unwrap_or(0)
});
centroids.push(centroid);
```
