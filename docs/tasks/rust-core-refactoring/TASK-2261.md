## タスク概要

`spearman.rs` にローカル定義されている `pearson_correlation` 関数を、数学ユーティリティの共通モジュール `core/math/stats.rs` に移動する。これにより、他の感度分析モジュールや将来の機能拡張からも再利用可能な共通関数として提供する。spearman 感度計算の結果は移動前後で変わらないことをテストで保証する。

## 実装詳細

### 1. core/math/stats.rs への pearson_correlation 追加 🔵

**信頼性**: 🔵 *REQ-A04・A05・interfaces.rs より*

`rust_core/src/core/math/stats.rs` に以下の公開関数を追加する:

```rust
/// x と y のピアソン相関係数を計算する。
/// 分散が 0（全値同一）の場合は `f64::NAN` を返す。パニックしない。
pub fn pearson_correlation(x: &[f64], y: &[f64]) -> f64 {
    // スライス長が一致することを前提とする（呼び出し元が保証）
    // x の平均・y の平均を計算
    // 共分散・標準偏差を計算
    // 標準偏差が 0 の場合は f64::NAN を返す
    // 相関係数を返す
}
```

設計上の注意点:
- スライス長の不一致は呼び出し元の責任とし、パニックではなく `debug_assert!` でのみ検査する
- 空スライスに対しては `f64::NAN` を返す
- `f64::NAN` を返すケースは分散 0（全値同一）と空スライスのみとし、それ以外でパニックしない

### 2. spearman.rs のローカル定義削除と use 文変更 🔵

**信頼性**: 🔵 *REQ-A05 より*

`rust_core/src/sensitivity/spearman.rs` から:
- ローカルの `fn pearson_correlation(...)` 定義を削除する
- ファイル先頭の `use` 文に `use crate::core::math::stats::pearson_correlation;` を追加する

既存の呼び出し箇所はシグネチャが同一なので変更不要。

## 単体テスト要件

### テストケース: 完全正相関 🔵

**信頼性**: 🔵 *REQ-A04 より*

**Given**: `x = [1.0, 2.0, 3.0]`、`y = [1.0, 2.0, 3.0]`
**When**: `pearson_correlation(&x, &y)` を呼び出す
**Then**: `1.0` が返る（差 < 1e-10）

### テストケース: 比例スケール正相関 🔵

**信頼性**: 🔵 *REQ-A04 より*

**Given**: `x = [1.0, -1.0]`、`y = [2.0, -2.0]`
**When**: `pearson_correlation(&x, &y)` を呼び出す
**Then**: `1.0` が返る（差 < 1e-10）

### テストケース: 分散 0 エッジケース（NaN 返却） 🔵

**信頼性**: 🔵 *REQ-A04・A05 より*

**Given**: `x = [1.0, 1.0, 1.0]`（分散 0）、`y = [1.0, 2.0, 3.0]`
**When**: `pearson_correlation(&x, &y)` を呼び出す
**Then**: `f64::NAN` が返り、パニックが発生しない

### テストケース: spearman 計算結果の移動前後一致 🔵

**信頼性**: 🔵 *REQ-A05 より*

**Given**: 既存 spearman テストで使用しているサンプルデータセット
**When**: `SpearmanMetric`（または既存の spearman 計算関数）を実行する
**Then**: 移動前と同一の感度値が返る（差 < 1e-10）

### テストケース: 完全逆相関 🔵

**信頼性**: 🔵 *REQ-A04 より*

**Given**: `x = [1.0, 2.0, 3.0]`、`y = [3.0, 2.0, 1.0]`
**When**: `pearson_correlation(&x, &y)` を呼び出す
**Then**: `-1.0` が返る（差 < 1e-10）
