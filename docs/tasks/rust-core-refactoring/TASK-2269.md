## タスク概要

`rust_core` 側のサンプリング処理を `thread_local!` グローバル状態から値型 `SamplingContext` へ移行する。
`sampling/context.rs` を新規作成し、`init_sampling` が副作用なく `SamplingContext` を返すように API を変更する。
`downsample_*` 系関数は `&SamplingContext` を引数として受け取る形式に更新する。

## 実装詳細

### 1. SamplingContext 構造体の定義 🔵

**信頼性**: 🔵 *REQ-C05・interfaces.rs・dataflow.md セクション3 より*

`rust_core/src/sampling/context.rs` を新規作成する。

```rust
/// ダウンサンプリングに必要なコンテキスト情報。
/// 旧 thread_local グローバル STATE を値型に置き換える。
#[derive(Debug, Clone)]
pub struct SamplingContext {
    pub is_minimize: Vec<bool>,
    pub pareto_indices: Option<Vec<u32>>,
    pub all_ranks: Option<Vec<u32>>,
    pub cluster_labels: Option<Vec<i32>>,
}
```

### 2. sampling/mod.rs の API 変更 🔵

**信頼性**: 🔵 *REQ-C06・C07・dataflow.md セクション3・design-interview.md Q4 より（ユーザー確認済み）*

`rust_core/src/sampling/mod.rs` の公開 API を以下のように変更する。

- `init_sampling(is_minimize, pareto_indices, all_ranks) -> SamplingContext`
  - 値を返す・グローバル副作用なし
- `reset_sampling()` を削除（呼び出し側が `None` への代入で代替）
- `downsample_smart(ctx: &SamplingContext, max_points: usize) -> Vec<u32>`
- `downsample_stratified_by_rank(ctx: &SamplingContext, max_points: usize) -> Vec<u32>`
- `downsample_by_cluster(ctx: &SamplingContext, max_points: usize) -> Vec<u32>`

`pub use context::SamplingContext;` を `mod.rs` に追加する。

### 3. thread_local STATE の廃止 🔵

**信頼性**: 🔵 *REQ-C05・design-interview.md Q4 より（ユーザー確認済み）*

`rust_core/src/sampling/state.rs` の `thread_local! { static STATE: RefCell<SamplingState> }` を廃止し、
グローバル状態への依存を完全に除去する。

### テストケース: TC-C05-01 init_sampling のグローバル非汚染 🔵

**信頼性**: 🔵 *REQ-C05・dataflow.md セクション3 より（ユーザー確認済み）*

### テストケース: 独立した複数インスタンス 🔵

**信頼性**: 🔵 *REQ-C05・スレッドローカル廃止の検証*

**Then**: 互いに独立した結果が返され、一方の状態が他方に影響しない

**When**: `downsample_smart(&ctx, max_points)` を呼び出す
