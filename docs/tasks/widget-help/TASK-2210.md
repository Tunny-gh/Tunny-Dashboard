## タスク概要

`grid_canvas.rs` の `show_cell_toolbar` 関数に「?」ヘルプボタンを追加する。戻り値を `bool` から `CellToolbarAction` 列挙型に変更し、? クリック時に `Help(PanelItem)` を返すようにする。

## 実装詳細

### 1. show_cell_toolbar の戻り値変更 🔵

**信頼性**: 🔵 *設計文書 architecture.md・grid_canvas.rs 実装より*

**実装ファイル**: `egui-app/src/ui/grid_canvas.rs`

```rust
// 変更前: 戻り値 bool（close clicked）
// 変更後:
fn show_cell_toolbar(
    ui: &mut egui::Ui,
    row: usize,
    col: usize,
    item: PanelItem,
    title: &'static str,
) -> CellToolbarAction {
    // ... 既存の Move + Title + spacer ...

    // 追加: ? ボタン（閉じるボタンの直前）
    let help_resp = ui.add_sized(
        egui::vec2(16.0, 16.0),
        egui::Button::new(
            egui::RichText::new("?").small().color(CLOSE_BTN_TEXT)
        ).frame(false),
    );
    if help_resp.hovered() {
        help_resp.on_hover_cursor(egui::CursorIcon::PointingHand);
    }
    if help_resp.clicked() {
        return CellToolbarAction::Help(item);
    }
    ui.add_space(4.0);

    // 既存: x 閉じるボタン
    // ...
}
```

### 2. 呼び出し側の更新 🔵

**信頼性**: 🔵 *grid_canvas.rs の render_cell_content より*

`show_cell_toolbar` の呼び出し側で `CellToolbarAction` を処理:
- `CellToolbarAction::Close` → 既存の clear 処理
- `CellToolbarAction::Help(item)` → `widgets.help_modal.open = true; widgets.help_modal.item = Some(item);`
- `CellToolbarAction::None` → 何もしない
