## 実装詳細

### 1. 使い方ガイド標準フォーマット 🔵

**信頼性**: 🔵 *要件定義書 REQ-021（概要・操作方法・読み方）より*

各ウィジェットの md ファイルに以下の構造を使用:

```markdown
# {Widget Name}

## Overview
{チャートの概要・目的}

## Operations
- **Zoom**: {操作方法}
- **Pan**: {操作方法}
- **Select**: {操作方法}
{その他の操作}

## How to Read
{読み方の説明・解釈のポイント}
```

### 2. 作成対象ウィジェットと内容 🔵

**信頼性**: 🔵 *要件定義書 REQ-021 より*

| ウィジェット | ファイル | Overview | Operations | How to Read |
|-------------|---------|----------|------------|-------------|
| ParetoScatter2D | pareto-2d.md | パレートフロントとは | Zoom/Pan/Brush | 非劣解の解釈 |
| ParetoScatter3D | pareto-3d.md | 3Dパレートフロント | Arcball回転/Zoom | 3Dでの関係性 |
| ParallelCoordinates | parallel-coords.md | 多軸の関係可視化 | 軸ハイライト | パターンの読み方 |
| ScatterMatrix | scatter-matrix.md | ペアワイズ散布図 | Zoom/Select | 相関の読み方 |
| OptimizationHistory | optimization-history.md | 目的関数の推移 | Toggle表示 | 収束の判定 |
| HvHistory | hv-history.md | Hypervolume指標 | 表示切替 | 収束判定 |
| SliceChart | slice-chart.md | スライス可視化 | パラメータ選択 | 応答の読み方 |
| TrialTable | trial-table.md | トライアル一覧 | Sort/Select/Export | データの確認 |

### 3. help_content.rs 配線 🔵

**信頼性**: 🔵 *設計文書 architecture.md の対応表より*

各ウィジェットに単一タブの HelpContent を設定:
```rust
PanelItem::Chart(ChartId::ParetoScatter2D) => HelpContent {
    title: "Pareto Scatter 2D",
    tabs: &[
        HelpTabDef { label: "Usage Guide", markdown: include_str!("../../../../theory/en/widgets/pareto-2d.md") },
    ],
},
// ... 他7ウィジェットも同様
```
