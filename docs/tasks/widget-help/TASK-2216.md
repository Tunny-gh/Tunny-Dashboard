## 実装詳細

### 1. 手動テスト項目 🔵

**信頼性**: 🔵 *受け入れ基準 acceptance-criteria.md より*

**テスト対象**: PanelItem::all() の全18ウィジェット

各ウィジェットで以下を確認:
1. セルツールバーに「?」ボタンが表示される
2. 「?」クリックでモーダルが開く（ウィジェット名がヘッダーに表示）
3. タブバーが表示され、クリックでタブが切り替わる
4. 各タブのコンテンツが ScrollArea 内で表示される
5. Esc キーまたは閉じるボタンでモーダルが閉じる
6. 再度「?」クリックでモーダルが開く（状態リセット確認）

### 2. 自動テスト項目 🔵

**信頼性**: 🔵 *受け入れ基準 TC-001〜TC-020 より*

Rust 単体テストで確認:
- `get_help_content()` が全 PanelItem に対して HelpContent を返す
- 各 HelpContent の tabs が空でない
- 各 HelpTabDef の markdown が空でない（include_str! 成功確認）
- HelpModalState の Default が正しい

### 3. エッジケース確認 🟡

**信頼性**: 🟡 *要件定義 EDGE-001, EDGE-010 から妥当な推測*

- ウィンドウサイズが非常に小さい場合のモーダル表示
- モーダルのリサイズ動作
- 長いコンテンツのスクロール
- タブが多数ある場合（ImportanceChart: 8タブ）のタブバー表示
