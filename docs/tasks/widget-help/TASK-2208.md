### 1. help_types.rs の型定義 🔵

**信頼性**: 🔵 *設計文書 architecture.md の「新規 Rust 型定義」より*

```rust
// egui-app/src/ui/help/help_types.rs

/// ヘルプモーダルの状態
#[derive(Default)]
pub struct HelpModalState {
    pub open: bool,
    pub active_tab: usize,
    pub item: Option<crate::state::layout_state::PanelItem>,
}

/// ウィジェットごとのヘルプコンテンツ定義
pub struct HelpContent {
    pub title: &'static str,
    pub tabs: &'static [HelpTabDef],
}

/// ヘルプモーダルのタブ定義
pub struct HelpTabDef {
    pub label: &'static str,
    pub markdown: &'static str,
}
```
