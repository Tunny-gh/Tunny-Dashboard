## 実装詳細

### 1. 軸ブラッシュ状態管理 🔵

**信頼性**: 🔵 *設計文書より*

各軸のブラッシュ範囲を `HashMap<String, Option<(f32, f32)>>` で管理する。

```rust
pub struct ParallelCoordsChart {
    // ... 既存フィールド
    pub brush_ranges: HashMap<String, Option<(f32, f32)>>,  // normalized [0,1] range
    pub drag_start: Option<(String, f32)>,  // (axis_name, start_normalized_y)
}
```

### 2. マウスドラッグ検出 🔵

**信頼性**: 🔵 *設計文書より*

`Pointer::is_decidedly_dragging()` と軸エリア判定を組み合わせてドラッグを検出する。各軸の周辺 ±10px をヒットエリアとする。

```rust
let pointer_pos = ui.input(|i| i.pointer.hover_pos());
if let Some(pos) = pointer_pos {
    for (axis_idx, axis_name) in self.axis_order.iter().enumerate() {
        let axis_x = plot_left + axis_idx as f32 * axis_spacing;
        if (pos.x - axis_x).abs() < 10.0 {
            // この軸のドラッグ開始を記録
        }
    }
}
```

### 3. ドラッグ開始・更新・終了でブラッシュ矩形を更新 🔵

**信頼性**: 🔵 *設計文書より*

ドラッグの開始・更新・終了のそれぞれのイベントでブラッシュ範囲を更新する。

```rust
// ドラッグ開始
if response.drag_started() {
    self.drag_start = Some((axis_name.clone(), start_normalized_y));
}
// ドラッグ中
if response.dragged() {
    if let Some((ref axis, start_y)) = self.drag_start {
        let end_y = current_normalized_y;
        let range = (start_y.min(end_y), start_y.max(end_y));
        self.brush_ranges.insert(axis.clone(), Some(range));
    }
}
// ドラッグ終了
if response.drag_released() {
    self.drag_start = None;
}
```

### 4. ブラッシュ矩形を Painter::rect_filled でハイライト表示 🔵

**信頼性**: 🔵 *設計文書より*

ブラッシュ範囲を半透明の矩形でハイライト表示する。

```rust
if let Some(Some((y_min, y_max))) = self.brush_ranges.get(axis_name) {
    let screen_y_max = plot_bottom - y_min * plot_height;  // min値は画面下側
    let screen_y_min = plot_bottom - y_max * plot_height;  // max値は画面上側
    painter.rect_filled(
        Rect::from_x_y_ranges(
            axis_x - 8.0..=axis_x + 8.0,
            screen_y_min..=screen_y_max,
        ),
        0.0,
        Color32::from_rgba_unmultiplied(100, 150, 255, 80),
    );
}
```

### 5. ブラッシュ変更 → app_state.set_filter へ変換 🔵

**信頼性**: 🔵 *設計文書より*

ブラッシュ範囲をデータ値に逆変換して `app_state.set_filter()` に渡す。

```rust
let (raw_min, raw_max) = (
    y_min * (axis_max - axis_min) + axis_min,
    y_max * (axis_max - axis_min) + axis_min,
);
app_state.set_filter(axis_name, raw_min, raw_max);
```

### 6. 軸クリックでブラッシュリセット 🔵

**信頼性**: 🔵 *設計文書より*

軸エリアをシングルクリックした場合、その軸のブラッシュ範囲を解除する。

### 7. ブラッシュ解除ボタン 🔵

**信頼性**: 🔵 *設計文書より*

全軸のブラッシュをリセットする「フィルター解除」ボタンを追加する。

```rust
if ui.button("フィルター解除").clicked() {
    self.brush_ranges.clear();
    app_state.clear_all_filters();
}
```
