### 1. rust_core/src/lib.rs の WASM 関連コード整理 🔵

**信頼性**: 🔵 *設計文書より*

`#[cfg(feature = "wasm")]` ブロックの確認と整理を行う。

- WASM 専用の `#[wasm_bindgen]` アトリビュートが残っている関数を確認する
- `feature = "wasm"` が正しく設定されているか検証する
- パブリック関数のドキュメントコメントを Rust ネイティブ向けに更新する

```bash
grep -rn "wasm_bindgen\|web_sys\|js_sys" rust_core/src/ 
```

`wasm` feature ブロックのみに閉じ込められていない場合は `#[cfg(feature = "wasm")]` で囲む。

### 2. cargo clippy -p tunny-core で警告解消 🔵

**信頼性**: 🔵 *設計文書より*

```bash
cargo clippy -p tunny-core -- -D warnings
```

警告が出た場合はすべて修正する。よくある警告:
- 未使用インポート
- 不要な `mut`
- `unwrap()` の使用（`expect()` または `?` に置き換え）
- 公開関数のドキュメントコメント欠落

### 3. cargo clippy -p tunny-desktop で警告解消 🔵
