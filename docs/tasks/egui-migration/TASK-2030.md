### 2. 3D ViewProjection: アフィン変換行列 🔵

**信頼性**: 🔵 *設計文書より*

回転・スケール・視点を組み合わせた 4×4 ViewProjection 行列を計算し、Uniform Buffer に書き込む。

```rust
fn compute_view_projection(camera: &ArcballCamera, aspect: f32) -> glam::Mat4 {
    let projection = glam::Mat4::perspective_rh(
        std::f32::consts::FRAC_PI_4, aspect, 0.1, 100.0
    );
    let view = glam::Mat4::look_at_rh(
        glam::Vec3::new(0.0, 0.0, camera.zoom),
        glam::Vec3::ZERO,
        glam::Vec3::Y,
    );
    let rotation = glam::Mat4::from_quat(camera.rotation);
    projection * view * rotation
}
```

### 3. マウスドラッグ → 回転（arcball カメラ） 🔵

**信頼性**: 🔵 *設計文書より*

egui のポインタイベントを arcball カメラ回転に変換する。

```rust
if response.dragged_by(egui::PointerButton::Primary) {
    let delta = response.drag_delta();
    let angle_x = delta.y * 0.01;
    let angle_y = delta.x * 0.01;
    let rot_x = glam::Quat::from_rotation_x(angle_x);
    let rot_y = glam::Quat::from_rotation_y(angle_y);
    self.camera.rotation = (rot_y * rot_x * self.camera.rotation).normalize();
}
```

### 7. selected_indices 変更時: GPU バッファのアルファ値のみ更新 🔵

**信頼性**: 🔵 *設計文書より*

フィルター変更時には全データの再アップロードを避け、アルファ値のみを差分更新する。TASK-2029 の `GpuBuffer::update_alpha()` を使用する。

```rust
AppMessage::FilterChanged { selected_indices } => {
    // アルファ値のみを更新 (< 1ms 要件)
    let start = std::time::Instant::now();
    gpu_buffer.update_alpha(&queue, &selected_indices, 1.0);
    // 非選択は透明に
    let unselected: Vec<usize> = (0..total_count)
        .filter(|i| !selected_indices.contains(i))
        .collect();
    gpu_buffer.update_alpha(&queue, &unselected, 0.1);
    debug_assert!(start.elapsed().as_millis() < 1, "alpha update too slow");
}
```
