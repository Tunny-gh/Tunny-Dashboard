### 1. pdp_chart.rs に 2D 表示モードを追加 🔵

**信頼性**: 🔵 *設計文書より*

TASK-2016 で作成した `pdp_chart.rs` の `PdpMode::TwoDim` を実装する。2D モード選択時に専用の UI と描画ロジックに切り替える。

```rust
pub struct PdpChart2DState {

    pub selected_objective: usize,

    pub computing: bool,

```

### 2. egui Painter で手動ヒートマップ描画 🔵

**信頼性**: 🔵 *設計文書より*

グリッド全セルを矩形塗りつぶしで手動描画する。`compute_pdp_2d()` が返す n×n グリッドの各セルに対して `painter.rect_filled()` を呼び出す。

```rust
let cell_w = plot_width / n_grid as f32;
let cell_h = plot_height / n_grid as f32;
for row in 0..n_grid {
    for col in 0..n_grid {
        let value = result.grid[row][col];
        let color = colormap.interpolate(value, v_min, v_max);
        let rect = Rect::from_min_size(
            Pos2::new(plot_origin.x + col as f32 * cell_w,
                      plot_origin.y + row as f32 * cell_h),
            Vec2::new(cell_w, cell_h),
        );
        painter.rect_filled(rect, 0.0, color);
    }
}
```

### 3. 軸設定 🔵

**信頼性**: 🔵 *設計文書より*

x軸 = param1、y軸 = param2、色 = 目的関数値となるようにレイアウトする。軸ラベルと min/max 値のテキストを `painter.text()` で描画する。

### 4. カラーバー表示 🔵

**信頼性**: 🔵 *設計文書より*

右端に色グラデーションスケール（カラーバー）を表示する。カラーバーは縦方向のグラデーション矩形を細かく分割して描画し、上端・下端・中央に値テキストを表示する。

```rust
let bar_width = 16.0;
let n_steps = 64;
for i in 0..n_steps {
    let t = i as f32 / n_steps as f32;
    let color = colormap.interpolate_normalized(t);
    let rect = Rect::from_min_size(
        Pos2::new(bar_x, bar_y + t * bar_height),
        Vec2::new(bar_width, bar_height / n_steps as f32 + 1.0),
    );
    painter.rect_filled(rect, 0.0, color);
}
```

### 5. 2変数選択 UI (2つの ComboBox) 🔵

**信頼性**: 🔵 *設計文書より*

2つの ComboBox でそれぞれのパラメータを選択できるようにする。同一パラメータが選ばれた場合は警告表示する。変更時にバックグラウンド計算をトリガーする。
