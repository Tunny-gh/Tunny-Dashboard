### 2. AppState::set_filter() 実装 🔵

**信頼性**: 🔵 *設計文書より*

フィルター範囲を更新し、`tunny_core::data::filter::filter_by_ranges()` を直接呼び出して selected_indices を更新する。

```rust
pub fn set_filter(&mut self, axis: String, min: f64, max: f64) {
    self.filter_ranges.insert(axis, (min, max));
    self.apply_filters();
}

fn apply_filters(&mut self) {
    if let Some(ctx) = &self.current_study {
        // filter_ranges を JSON 形式に変換して rust_core に渡す
        let result = tunny_core::data::filter::filter_by_ranges(
            &ctx.trial_rows,
            &self.filter_ranges,
        );
        self.selected_indices = result;
    }
}
```

### 3. AppState::remove_filter() 実装 🔵

**信頼性**: 🔵 *設計文書より*

```rust
pub fn remove_filter(&mut self, axis: &str) {
    self.filter_ranges.remove(axis);
    self.apply_filters();
}
```

### 4. AppState::clear_filters() 実装 🔵

**信頼性**: 🔵 *設計文書より*

```rust
pub fn clear_filters(&mut self) {
    self.filter_ranges.clear();
    if let Some(ctx) = &self.current_study {
        self.selected_indices = ctx.trial_rows.iter()
            .map(|t| t.trial_id)
            .collect();
    }
}
```

### 5. AppState::brush_select() 実装 🔵

## テスト要件

### filter_by_ranges の結果確認 🔵

**信頼性**: 🔵 *設計より*

- `set_filter("x", 0.0, 0.5)` 後に x の値が 0.5 を超える Trial が selected_indices に含まれないことを確認する
- `remove_filter("x")` 後にフィルターが除去されることを確認する
- `clear_filters()` 後に全 trial_id が selected_indices に含まれることを確認する
- `brush_select([1, 3, 5])` 後に selected_indices が [1, 3, 5] になることを確認する
- 空の filter_ranges で apply_filters() を呼ぶと全 Trial が選択されることを確認する
