### 3. バックグラウンドで parse_journal 実行 🔵

**信頼性**: 🔵 *設計文書より*

```rust
fn load_journal(&mut self, path: PathBuf, ctx: &egui::Context) {
    self.app_state.is_loading = true;
    let tx = self.tx.clone();
    let ctx = ctx.clone();
    spawn_task(tx.clone(), move || {
        match read_journal_file(&path) {
            Ok(data) => {
                match tunny_core::io::journal::parse_journal(&data) {
                    Ok(studies) => {
                        ctx.request_repaint();
                        AppMessage::JournalParsed(studies)
                    }
                    Err(e) => AppMessage::Error(e.to_string()),
                }
            }
            Err(e) => AppMessage::Error(e),
        }
    });
}
```

### 4. JournalParsed 受信時の AppState 更新 🔵
