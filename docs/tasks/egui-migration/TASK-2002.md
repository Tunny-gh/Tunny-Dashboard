### 2. egui-app/src/main.rs 作成 🔵

**信頼性**: 🔵 *設計文書より*

`eframe::run_native()` を使って最小ウィンドウを表示する。

```rust
fn main() -> eframe::Result<()> {
    let options = eframe::NativeOptions::default();
    eframe::run_native(
        "Tunny Dashboard",
        options,
        Box::new(|cc| Box::new(app::TunnyApp::new(cc))),
    )
}
```

### 3. egui-app/src/app.rs 作成 🔵

**信頼性**: 🔵 *設計文書より*

`TunnyApp` struct と `eframe::App` trait の空実装を作成する。

```rust
pub struct TunnyApp {}

impl eframe::App for TunnyApp {
    fn update(&mut self, ctx: &egui::Context, _frame: &mut eframe::Frame) {
        egui::CentralPanel::default().show(ctx, |ui| {
            ui.heading("Tunny Dashboard");
        });
    }
}
```
