## タスク概要

UIレイアウト状態（LayoutState）と非同期メッセージ型（AppMessage）を実装する。LayoutState はパネルサイズや表示中のチャートIDを管理し、AppMessage はバックグラウンドスレッドから UI スレッドへの通知に使用する。

### 6. LayoutState::toggle_chart(id) メソッド 🔵

**信頼性**: 🔵 *設計文書より*

```rust
pub fn toggle_chart(&mut self, id: ChartId) {
    if self.visible_charts.contains(&id) {
        self.visible_charts.remove(&id);
    } else {
        self.visible_charts.insert(id);
    }
}
```
