## 実装詳細

### 1. frontend/ ディレクトリ全体を削除 🔵

**信頼性**: 🔵 *設計文書より*

`frontend/` ディレクトリを Git 管理対象から完全に削除する。削除前に以下を確認する。

- `frontend/` 配下に egui-app から参照されているファイルがないことを確認
- `frontend/` 配下の設計文書や仕様書で `docs/` に移動すべきものがないか確認

```bash
git rm -r frontend/
```

### 2. ルート package.json の削除 🔵

**信頼性**: 🔵 *設計文書より*

ルートに `package.json` が存在する場合は削除する。Node.js 関連の設定ファイル（`.npmrc`、`.nvmrc`、`yarn.lock`、`pnpm-lock.yaml` 等）も合わせて削除する。

### 3. CI ワークフローの更新 🔵

**信頼性**: 🔵 *設計文書より*

`.github/workflows/` 内の frontend ビルド関連 CI を削除または Rust ビルドに置き換える。

- Node.js セットアップステップを削除
- `npm run build` / `pnpm build` ステップを削除
- `cargo build --release -p tunny-desktop` ステップを追加（未存在の場合）
- `cargo test` ステップを追加（未存在の場合）

### 4. README.md のビルド手順を Cargo ベースに更新 🔵

**信頼性**: 🔵 *設計文書より*

README.md の「ビルド方法」セクションを Cargo コマンドに更新する。

```markdown
## ビルド方法

### 前提条件

- Rust 1.75 以上

### ビルド

```bash
cargo build --release -p tunny-desktop
```

### 実行

```bash
cargo run -p tunny-desktop
```

### テスト

```bash
cargo test
```
```

### 5. 最終ビルド確認 🔵

**信頼性**: 🔵 *設計文書より*

```

エラーが発生した場合は frontend/ 削除による依存切れを修正する。

### 6. テスト全通過確認 🔵

**信頼性**: 🔵 *設計文書より*

```bash
cargo test
```

全テストがパスすることを確認する。

### 7. 不要な依存関係の確認 🔵

使用されていない依存クレートが Cargo.toml に残っていないか確認し、必要に応じて削除する。
