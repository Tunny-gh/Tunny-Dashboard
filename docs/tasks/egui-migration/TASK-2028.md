## 実装詳細

### 1. export.rs 作成 🔵

**信頼性**: 🔵 *設計文書より*

`egui-app/src/io/export.rs` を作成する。

```rust
pub enum ExportTarget {
    AllData,
    SelectedOnly,
    ParetoOnly,
}

pub fn export_csv(
    trial_rows: &[TrialRow],
    selected_indices: &[usize],
    pareto_indices: &[usize],
    target: ExportTarget,
    output_path: &Path,
) -> Result<(), ExportError> {
    let rows = match target {
        ExportTarget::AllData => trial_rows.to_vec(),
        ExportTarget::SelectedOnly => selected_indices.iter()
            .map(|&i| trial_rows[i].clone()).collect(),
        ExportTarget::ParetoOnly => pareto_indices.iter()
            .map(|&i| trial_rows[i].clone()).collect(),
    };
    tunny_core::io::export::serialize_csv(&rows, output_path)
}
```

### 5. セッション保存: AppState のシリアライズ → JSON 🔵

**信頼性**: 🔵 *設計文書より*

AppState の filter_ranges・selected_indices・layout を JSON にシリアライズして保存する。

```rust
#[derive(serde::Serialize, serde::Deserialize)]
pub struct SessionSnapshot {
    pub filter_ranges: HashMap<String, (f64, f64)>,
    pub selected_indices: Vec<usize>,
    pub layout: LayoutState,
    pub study_name: String,
    pub saved_at: String,
}

pub fn save_session(snapshot: &SessionSnapshot, path: &Path) -> Result<(), io::Error> {
    let json = serde_json::to_string_pretty(snapshot)?;
    fs::write(path, json)
}
```

### 6. セッション復元: JSON 読み込み → AppState に適用 🔵

**信頼性**: 🔵 *設計文書より*

```rust
pub fn load_session(path: &Path) -> Result<SessionSnapshot, SessionError> {
    let json = fs::read_to_string(path)?;
    let snapshot: SessionSnapshot = serde_json::from_str(&json)?;
    Ok(snapshot)
}
```

セッション復元時は現在の Study が一致するか確認し、不一致の場合は警告を表示する。

**信頼性**: 🔵 *設計より*
