### 2. eframe::App::update() でのパネル配置 🔵

**信頼性**: 🔵 *設計文書より*

```rust
impl eframe::App for TunnyApp {
    fn update(&mut self, ctx: &egui::Context, _frame: &mut eframe::Frame) {
        self.poll_messages(ctx);

        egui::TopBottomPanel::top("toolbar")
            .show(ctx, |ui| {
                show_toolbar(ui, &mut self.app_state, &mut self.layout, &self.tx);
            });

        egui::SidePanel::left("left_panel")
            .resizable(true)
            .default_width(240.0)
            .width_range(120.0..=600.0)
            .show(ctx, |ui| {
                show_left_panel(ui, &mut self.app_state, &mut self.layout);
            });

        egui::TopBottomPanel::bottom("bottom_panel")
            .resizable(true)
            .default_height(200.0)
            .height_range(60.0..=600.0)
            .show(ctx, |ui| {
                show_bottom_panel(ui, &mut self.app_state);
            });

        egui::CentralPanel::default()
            .show(ctx, |ui| {
                show_main_canvas(ui, &mut self.app_state, &mut self.layout);
            });
    }
}
```

### 3. LayoutState へのパネルサイズ反映 🔵

**信頼性**: 🔵 *設計文書より*

egui の resizable パネルはユーザー操作でサイズが変化する。パネル描画後に `ui.available_width()` / `ui.available_height()` から現在のサイズを取得し、LayoutState に反映する。

```rust
egui::SidePanel::left("left_panel")
    .resizable(true)
    .default_width(self.layout.left_panel_width)
    .show(ctx, |ui| {
        self.layout.left_panel_width = ui.available_width();
        show_left_panel(ui, &mut self.app_state, &mut self.layout);
    });
```
