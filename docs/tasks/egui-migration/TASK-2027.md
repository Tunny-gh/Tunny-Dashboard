## 実装詳細

### 1. LiveUpdateState にポーリングスレッド JoinHandle を追加 🔵

**信頼性**: 🔵 *設計文書より*

```rust
pub struct LiveUpdateState {
    pub enabled: bool,
    pub poll_interval_secs: u64,
    pub stop_tx: Option<std::sync::mpsc::SyncSender<()>>,
    pub journal_path: Option<PathBuf>,
    pub last_size: u64,
}
```

### 2. ライブ更新 ON 時: ポーリングスレッド起動 🔵

**信頼性**: 🔵 *設計文書より*

```rust
std::thread::spawn(move || {
    loop {
        // 停止シグナルを確認
        if stop_rx.try_recv().is_ok() {
            break;
        }
        std::thread::sleep(Duration::from_secs(poll_interval));
        let current_size = match fs::metadata(&path) {
            Ok(m) => m.len(),
            Err(_) => continue,
        };
        if current_size > last_size {
            let data = match read_diff_bytes(&path, last_size) {
                Ok(d) => d,
                Err(_) => continue,
            };
            match tunny_core::io::journal::live_update::append_journal_diff(&data) {
                Ok(result) => {
                    let _ = tx.send(AppMessage::LiveUpdateDone {
                        new_trials: result.new_trials,
                        appended_count: result.appended_count,
                    });
                }
                Err(_) => {}
            }
            last_size = current_size;
        }
    }
});
```

### 3. LiveUpdateDone 受信: 新規 Trial を追記 🔵

**信頼性**: 🔵 *設計文書より*

LiveUpdateDone 受信時に既存の trial_rows に新規 Trial を追記する。GpuBuffer に追記する場合は TASK-2030 で実装する wgpu 版への差し替えを考慮して抽象化する。

```rust
AppMessage::LiveUpdateDone { new_trials, .. } => {
    self.app_state.trial_rows.extend(new_trials);
    // フィルタ・選択状態・カメラ位置を変更しない (REQ-134)
    ctx.request_repaint();
}
```

### 4. ブラッシング選択・フィルタ・カメラ位置を変更しない (REQ-134) 🔵

**信頼性**: 🔵 *設計文書より*

LiveUpdateDone メッセージ処理では `filter_ranges`、`selected_indices`、カメラ状態を一切変更しない。新規 Trial は現在のフィルター条件を自動適用して selected_indices に含まれるか判定のみ行う。

### 5. ライブ更新 OFF 時: スレッドを適切に停止 🔵

**信頼性**: 🔵 *設計文書より*

```rust
fn stop_live_update(&mut self) {
    if let Some(stop_tx) = self.live_update.stop_tx.take() {
        let _ = stop_tx.send(());
    }
    self.live_update.enabled = false;
}
```
