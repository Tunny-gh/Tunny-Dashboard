### 2. egui_plot::Plot + Points での散布図表示 🔵

**信頼性**: 🔵 *設計文書より*

TrialRow の目的値を散布図として表示する。

```rust
egui_plot::Plot::new("pareto_2d")
    .legend(egui_plot::Legend::default())
    .show(ui, |plot_ui| {
        let selected_points: Vec<[f64; 2]> = /* selected_indices の点 */;
        let unselected_points: Vec<[f64; 2]> = /* 非選択点 */;

        plot_ui.points(
            egui_plot::Points::new(unselected_points)
                .color(egui::Color32::from_rgba_unmultiplied(100, 100, 200, 50))
                .radius(3.0),
        );
        plot_ui.points(
            egui_plot::Points::new(selected_points)
                .color(egui::Color32::from_rgb(50, 100, 255))
                .radius(5.0),
        );
    });
```

### 3. selected_indices に基づくカラー計算 🔵

**信頼性**: 🔵 *設計文書より*

- 選択中の点: アルファ 255（不透明）
- 非選択の点: アルファ 50（ほぼ透明、0.2 相当）
- ハイライト点: 赤色 + 大きめのサイズ（radius 8.0）

## テスト要件

### カラー計算ロジックの単体テスト 🔵

**信頼性**: 🔵 *設計より*

- selected_indices が空でない場合に、含まれない trial_id の点がアルファ 50 になることを確認する
- selected_indices が空の場合に、全点が通常アルファで描画されることを確認する
- `highlighted_trial = Some(5)` の場合に trial_id=5 の点が赤色で描画されることを確認する

### ColorMap::interpolate() の単体テスト 🔵

**信頼性**: 🔵 *設計より*

- `interpolate(0.0)` が最初の停止点の色を返すことを確認する
- `interpolate(1.0)` が最後の停止点の色を返すことを確認する
- `interpolate(0.5)` が中間の色を返すことを確認する
- 範囲外の値（-0.1、1.1）がクランプされて正しく処理されることを確認する
