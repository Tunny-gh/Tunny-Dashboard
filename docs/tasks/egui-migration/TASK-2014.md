### 2. egui_plot::Plot + Line で最適化履歴描画 🔵

**信頼性**: 🔵 *設計文書より*

trial_id を X 軸、objective_value を Y 軸として `egui_plot::Line` を使って描画する。

```rust
let points: PlotPoints = trial_rows.iter().enumerate()
    .map(|(i, row)| [i as f64, row.objective_values[0]])
    .collect();
let line = Line::new(points).name("All Trials");
Plot::new("optimization_history").show(ui, |plot_ui| {
    plot_ui.line(line);
});
```

### 3. 表示モード切り替え 🔵

**信頼性**: 🔵 *設計文書より*

ベスト値推移モード・全試行値モード・移動平均モードを UI で切り替えられるようにする。

- **ベスト値推移**: `trial_id` ごとにそれまでの最小値（最大化問題では最大値）を累積で描画
- **全試行値**: 全 trial の生値を散布またはライン描画
- **移動平均**: 指定ウィンドウサイズでの移動平均ライン

### 5. tunny_core HV計算との連携 🔵

**信頼性**: 🔵 *設計文書より*

    let hv_history = tunny_core::multi_objective::pareto::compute_hypervolume_history(
