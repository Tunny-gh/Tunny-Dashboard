### 3. レイアウトモードボタン群 🔵

**信頼性**: 🔵 *設計文書より*

各 LayoutMode に対応するトグルボタンを実装する。現在選択中のモードはハイライト表示する。

```rust
for (mode, label) in [
    (LayoutMode::MultiObjective, "多目的"),
    (LayoutMode::VariableSpace, "変数空間"),
    (LayoutMode::ConvergenceAnalysis, "収束分析"),
    (LayoutMode::FreeLayout, "自由"),
] {
    let is_selected = layout.layout_mode == mode;
    if ui.selectable_label(is_selected, label).clicked() {
        layout.layout_mode = mode;
    }
}
```
