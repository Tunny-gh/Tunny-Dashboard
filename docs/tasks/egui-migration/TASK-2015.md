## 実装詳細

### 1. importance_chart.rs 作成 🔵

**信頼性**: 🔵 *設計文書より*

`egui-app/src/widgets/importance_chart.rs` を作成する。

```rust
pub struct ImportanceChart {
    pub metric: ImportanceMetric,
    pub computing: bool,
    pub results: Option<Vec<(String, f64)>>,  // (param_name, score) sorted desc
    pub objective_index: usize,
}

pub enum ImportanceMetric {
    Spearman,
    Ridge,
    Sobol,
}
```

### 2. egui_plot::BarChart で horizontal bar chart 描画 🔵

**信頼性**: 🔵 *設計文書より*

パラメータ名 vs 重要度スコアの水平バーチャートを描画する。

```rust
let bars: Vec<Bar> = results.iter().enumerate()
    .map(|(i, (name, score))| {
        Bar::new(i as f64, *score)
            .name(name)
            .horizontal()
    })
    .collect();
let chart = BarChart::new(bars).horizontal();
Plot::new("importance_chart").show(ui, |plot_ui| {
    plot_ui.bar_chart(chart);
});
```

### 3. メトリクス切り替えタブ 🔵

**信頼性**: 🔵 *設計文書より*

Spearman / Ridge(beta) / Sobol の3タブを実装する。タブ切り替え時に再計算をトリガーする。

```rust
ui.horizontal(|ui| {
    ui.selectable_value(&mut self.metric, ImportanceMetric::Spearman, "Spearman");
    ui.selectable_value(&mut self.metric, ImportanceMetric::Ridge, "Ridge (beta)");
    ui.selectable_value(&mut self.metric, ImportanceMetric::Sobol, "Sobol");
});
```
