```rust
pub fn show_bottom_panel(
    ui: &mut egui::Ui,
    app_state: &mut AppState,
) {
    if let Some(ctx) = &app_state.current_study {
        show_trial_table(ui, app_state, ctx);
    } else {
        ui.centered_and_justified(|ui| {
            ui.label("Journal ファイルを開いてください");
        });
    }
}
```

### 3. TableBuilder によるテーブル表示 🔵

**信頼性**: 🔵 *設計文書より*

trial_id・変数値・目的値・Paretoランクをカラムとして表示する。

```rust
fn show_trial_table(ui: &mut egui::Ui, app_state: &mut AppState, study_ctx: &StudyContext) {
    use egui_extras::{Column, TableBuilder};

    let display_rows = if app_state.selected_indices.is_empty() {
        study_ctx.trial_rows.as_slice()
    } else {
        // selected_indices でフィルタリングした行を使用
    };

    TableBuilder::new(ui)
        .striped(true)
        .resizable(true)
        .column(Column::auto().at_least(60.0))  // trial_id
        .column(Column::remainder())             // 変数値
        .column(Column::remainder())             // 目的値
        .column(Column::auto().at_least(80.0))  // Paretoランク
        .header(20.0, |mut header| {
            header.col(|ui| { ui.strong("Trial ID"); });
            // ...
        })
        .body(|body| {
            body.rows(18.0, display_rows.len(), |mut row| {
                let trial = &display_rows[row.index()];
                let is_highlighted = app_state.highlighted_trial == Some(trial.trial_id);
                // 行の描画と行クリック処理
            });
        });
}
```

### 4. 選択中 Trial のフィルタリング 🔵

**信頼性**: 🔵 *設計文書より*

`selected_indices` が空の場合は全 TrialRow を表示する。空でない場合は selected_indices に含まれる Trial のみを表示する。

### 5. 行クリックによるハイライト 🔵

**信頼性**: 🔵 *設計文書より*

テーブルの行クリックで `app_state.set_highlight(trial_id)` を呼び出す。ハイライト中の行は背景色を変える。

### 6. ソート機能 🔵

**信頼性**: 🔵 *設計文書より*

カラムヘッダーのクリックでソートを切り替える。trial_id / objective 値 / Pareto rank でのソートを実装する。ソート方向（昇順/降順）を保持する。
