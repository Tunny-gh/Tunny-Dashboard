### 3. 95%信頼区間: egui_plot::Polygon でバンド表示 🔵

**信頼性**: 🔵 *設計文書より*

上限・下限ラインを結合した `egui_plot::Polygon` で信頼区間バンドを半透明表示する。

```rust
let upper: Vec<[f64; 2]> = x_vals.iter().zip(y_upper.iter())
    .map(|(&x, &y)| [x, y]).collect();
let lower: Vec<[f64; 2]> = x_vals.iter().zip(y_lower.iter()).rev()
    .map(|(&x, &y)| [x, y]).collect();
let band_points: Vec<[f64; 2]> = upper.into_iter().chain(lower).collect();
let polygon = Polygon::new(band_points)
    .fill_color(Color32::from_rgba_unmultiplied(100, 100, 255, 40));
```
