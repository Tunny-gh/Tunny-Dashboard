## 実装詳細

### 1. ScatterMatrix struct 作成 🔵

**信頼性**: 🔵 *設計文書より*

グリッド全体の管理を担う `ScatterMatrix` struct を実装する。

```rust
pub struct ScatterMatrix {
    pub mode: MatrixMode,
    pub sort: AxisSort,
    pub selected_cell: Option<(usize, usize)>,
    pub n_params: usize,
    pub n_objectives: usize,
}

pub enum MatrixMode {
    ParamsVsParams,
    ParamsVsObjectives,
}

pub enum AxisSort {
    Alphabetical,
    Correlation,
    Importance,
}
```

### 2. egui::Grid でセルを配置 🔵

**信頼性**: 🔵 *設計文書より*

`egui::Grid` を使って 80px × 80px/セルのグリッドを描画する。各セルは TASK-2018 の `ScatterCell` を使用する。

```rust
egui::Grid::new("scatter_matrix")
    .spacing([2.0, 2.0])
    .show(ui, |ui| {
        for row in 0..n_rows {
            for col in 0..n_cols {
                let cell_response = ui.allocate_rect(
                    Rect::from_min_size(cursor, Vec2::splat(80.0)),
                    egui::Sense::click(),
                );
                // セル描画
                if col == n_cols - 1 { ui.end_row(); }
            }
        }
    });
```

### 3. 表示モード: Mode1(Params×Params) / Mode2(Params×Objectives) 🔵

**信頼性**: 🔵 *設計文書より*

Mode1 では n_params × n_params のグリッドを表示する。Mode2 では n_params × n_objectives のグリッドを表示する（全セルが散布図）。

```rust
ui.horizontal(|ui| {
    ui.selectable_value(&mut self.mode, MatrixMode::ParamsVsParams, "Params × Params");
    ui.selectable_value(&mut self.mode, MatrixMode::ParamsVsObjectives, "Params × Objectives");
});
```

### 4. セルクリックで modal ポップアップ拡大表示 🔵

**信頼性**: 🔵 *設計文書より*

セルクリック時に 300×300px のポップアップで拡大表示する。

```rust
if cell_response.clicked() {
    self.selected_cell = Some((row, col));
}
if let Some((sel_row, sel_col)) = self.selected_cell {
    egui::Window::new("Expanded Cell")
        .fixed_size([300.0, 300.0])
        .show(ctx, |ui| {
            // 拡大セル描画
            if ui.button("Close").clicked() {
                self.selected_cell = None;
            }
        });
}
```

### 5. 軸ソート選択 🔵

**信頼性**: 🔵 *設計文書より*

アルファベット順 / 相関係数順 / 重要度順の3種類のソートを実装する。ソート変更時にグリッドを再構築する。

### 6. DownsampleDone メッセージ受信後に再描画 🔵

**信頼性**: 🔵 *設計文書より*

Study切り替え時に DownsampleDone メッセージを受信したタイミングで散布図データを更新して再描画する。

### 7. スクロール対応 🔵

**信頼性**: 🔵 *設計文書より*

```rust

    // グリッド描画
});
```
