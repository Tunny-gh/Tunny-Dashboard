## 実装詳細

### 1. Study選択時に自動ダウンサンプリング開始 🔵

**信頼性**: 🔵 *設計文書より*

`StudySelected` メッセージ受信時に scatter/pcp/thumbnail の3種のダウンサンプリングをそれぞれバックグラウンドで開始する。

```rust
AppMessage::StudySelected { trial_rows, .. } => {
    // scatter ダウンサンプリング
    let rows_clone = trial_rows.clone();
    spawn_task(tx.clone(), move || {
        let scatter = tunny_core::sampling::smart::downsample_smart(5000, true, &rows_clone)?;
        AppMessage::DownsampleDone { key: DownsampleKey::Scatter, indices: scatter.indices }
    });
    // pcp ダウンサンプリング
    let rows_clone = trial_rows.clone();
    spawn_task(tx.clone(), move || {
        let pcp = tunny_core::sampling::smart::downsample_smart(2000, false, &rows_clone)?;
        AppMessage::DownsampleDone { key: DownsampleKey::Pcp, indices: pcp.indices }
    });
    // thumbnail ダウンサンプリング
    let rows_clone = trial_rows.clone();
    spawn_task(tx.clone(), move || {
        let thumb = tunny_core::sampling::smart::downsample_smart(500, false, &rows_clone)?;
        AppMessage::DownsampleDone { key: DownsampleKey::Thumbnail, indices: thumb.indices }
    });
}
```

### 3. DownsampleDone 受信時に DownsampleCache 更新 🔵

**信頼性**: 🔵 *設計文書より*

```rust
AppMessage::DownsampleDone { key, indices } => {
    match key {
        DownsampleKey::Scatter => self.app_state.downsample_cache.scatter = Some(indices),
        DownsampleKey::Pcp => self.app_state.downsample_cache.pcp = Some(indices),
        DownsampleKey::Thumbnail => self.app_state.downsample_cache.thumbnail = Some(indices),
    }
    ctx.request_repaint();
}
```

### 4. フィルター変更で選択率が 20% 以上変化した場合に再計算 🔵

**信頼性**: 🔵 *設計文書より*

フィルター変更後の選択率と前回ダウンサンプリング時の選択率を比較し、20%以上変化した場合に再計算を開始する。

```rust
fn check_resample_needed(&mut self) -> bool {
    let current_selection_rate = self.app_state.selected_indices.len() as f64
        / self.app_state.trial_rows.len() as f64;
    let delta = (current_selection_rate - self.last_sample_rate).abs();
    if delta > 0.20 {
        self.last_sample_rate = current_selection_rate;
        return true;
    }
    false
}
```
