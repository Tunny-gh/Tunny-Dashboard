### 2. キャッシュ: HashMap でパラメータ×目的関数の組み合わせをキャッシュ 🔵

**信頼性**: 🔵 *設計文書より*

`HashMap<String, PdpResult>` でキャッシュする。キャッシュキーはパラメータ名・目的関数インデックス・モデルタイプを組み合わせた文字列とする。

```rust
pub struct PdpChart {
    // ...
    pub cache: HashMap<String, PdpResult>,  // key: "param_name:obj_idx:model_type"
}

fn cache_key(param: &str, obj_idx: usize, model: &ModelType) -> String {
    format!("{}:{}:{}", param, obj_idx, model.to_str())
}
```

### 3. パラメータ/目的関数変更時にキャッシュを確認 🔵

**信頼性**: 🔵 *設計文書より*

パラメータまたは目的関数の変更時に、まずキャッシュを確認し、キャッシュヒットなら即座に表示、未キャッシュなら計算を開始する。

```rust
fn on_selection_changed(&mut self, tx: &SyncSender<AppMessage>) {
    let key = cache_key(&self.selected_param, self.selected_objective, &self.model_type);
    if self.cache.contains_key(&key) {
        self.result = self.cache.get(&key).cloned();
    } else {
        self.computing = true;
        // バックグラウンド計算開始
    }
}
```

### 4. PdpDone 受信時に app_state.pdp_cache を更新 🔵

**信頼性**: 🔵 *設計文書より*

```rust
AppMessage::PdpDone { param, objective, result } => {
    let key = cache_key(&param, objective, &current_model_type);
    self.pdp_chart.cache.insert(key.clone(), result.clone());
    // 現在選択中のパラメータ・目的関数と一致する場合のみ表示を更新
    if param == self.pdp_chart.selected_param
        && objective == self.pdp_chart.selected_objective
    {
        self.pdp_chart.result = Some(result);
        self.pdp_chart.computing = false;
    }
}
```

### 5. モデルタイプ切り替え: Ridge / Kriging / SparseKriging 🔵

**信頼性**: 🔵 *設計文書より*

モデルタイプ変更時はキャッシュを別キーとして扱い、既存キャッシュを上書きしない。

```rust
ui.horizontal(|ui| {
    ui.label("モデル:");
    let prev_model = self.model_type.clone();
    ui.selectable_value(&mut self.model_type, ModelType::Ridge, "Ridge");
    ui.selectable_value(&mut self.model_type, ModelType::Kriging, "Kriging");
    ui.selectable_value(&mut self.model_type, ModelType::SparseKriging, "Sparse Kriging");
    if self.model_type != prev_model {
        self.on_selection_changed(tx);
    }
});
```
