### 1. cluster_scatter.rs 作成 🔵

**信頼性**: 🔵 *設計文書より*

`egui-app/src/widgets/cluster_scatter.rs` を作成する。

```rust
pub struct ClusterScatter {
    pub k: usize,
    pub target_space: ClusterSpace,
    pub computing: bool,
    pub result: Option<ClusteringResult>,
    pub elbow_computing: bool,
    pub elbow_result: Option<Vec<f64>>,  // inertia per k
}

pub enum ClusterSpace {
    Objective,
    Variable,
    Combined,
}

pub struct ClusteringResult {
    pub labels: Vec<usize>,
    pub pca_components: Vec<[f64; 2]>,  // 2D PCA for scatter
    pub cluster_stats: Vec<ClusterStats>,
}

pub struct ClusterStats {
    pub cluster_id: usize,
    pub count: usize,
    pub centroid: Vec<f64>,
}
```

### 3. 「クラスタリング実行」ボタン → バックグラウンド計算 🔵

**信頼性**: 🔵 *設計文書より*

```rust
if ui.button("クラスタリング実行").clicked() && !self.computing {
    self.computing = true;
    let k = self.k;
    let space = self.target_space.clone();
    spawn_task(tx.clone(), move || {
        let pca = tunny_core::clustering::pca::run_pca(5, &space.to_str())?;
        let n_cols = pca.components[0].len();
        let kmeans = tunny_core::clustering::kmeans::run_kmeans(k, &pca.components, n_cols)?;
        AppMessage::ClusteringDone(ClusteringResult { labels: kmeans.labels, pca_components: pca.components_2d, cluster_stats: kmeans.stats })
    });
}
```

AppMessage::ClusteringDone(result) => {

### 5. PCA 2D/3D散布図 (egui_plot::Points でクラスタ色分け) 🔵

**信頼性**: 🔵 *設計文書より*

PCA の2次元主成分を egui_plot::Points でプロットし、クラスタラベルに応じた色分けを適用する。

```rust
for cluster_id in 0..k {
    let cluster_points: PlotPoints = pca_components.iter().zip(labels.iter())
        .filter(|(_, &l)| l == cluster_id)
        .map(|(pt, _)| [pt[0], pt[1]])
        .collect();
    plot_ui.points(Points::new(cluster_points)
        .color(CLUSTER_COLORS[cluster_id])
        .radius(3.0)
        .name(format!("Cluster {}", cluster_id)));
}
```
