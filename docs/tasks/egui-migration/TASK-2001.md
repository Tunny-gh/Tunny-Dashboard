## タスク概要

プロジェクトルートに Cargo.toml を追加してワークスペース化する。rust_core の default features から "wasm" を除外し、`#[wasm_bindgen]` 属性を `#[cfg(feature = "wasm")]` でラップすることで、WASMビルドをオプション化する。

## 実装詳細

### 1. ルート Cargo.toml 作成 🔵

**信頼性**: 🔵 *設計文書より*

プロジェクトルートに Cargo.toml を作成し、ワークスペースを構成する。

```toml
[workspace]
members = ["rust_core", "egui-app"]
resolver = "2"
```

### 2. rust_core/Cargo.toml の default features 変更 🔵

**信頼性**: 🔵 *設計文書より*

`rust_core/Cargo.toml` の `default = ["wasm"]` を `default = []` に変更する。wasm feature はオプションとして保持する。

```toml
[features]
default = []
wasm = ["wasm-bindgen", "js-sys", "web-sys"]
```

### 3. #[wasm_bindgen] 属性のフィーチャーゲート化 🔵

**信頼性**: 🔵 *設計文書より*

`rust_core/src/lib.rs` の全 `#[wasm_bindgen]` 関数を `#[cfg(feature = "wasm")]` でラップする。

```rust
#[cfg(feature = "wasm")]
#[wasm_bindgen]
pub fn some_function() { ... }
```

### 4. ビルド確認 🔵

**信頼性**: 🔵 *設計文書より*

`cargo build -p tunny-core` でビルドが通ることを確認する。
