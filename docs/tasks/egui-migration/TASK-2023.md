### 3. Study選択後に自動計算開始 🔵

**信頼性**: 🔵 *設計文書より*

`AppMessage::StudySelected` を受信した際に自動で感度分析バックグラウンド計算を開始する。

```rust
AppMessage::StudySelected { meta, trial_rows, .. } => {
    self.app_state.current_study = Some(/* ... */);
    // 感度分析を自動トリガー
    let tx = self.tx.clone();
    spawn_task(tx, move || {
        let result = tunny_core::sensitivity::compute_sensitivity(&trial_rows, ImportanceMetric::Spearman)?;
        AppMessage::SensitivityDone(result)
    });
}
```

### 5. ヒートマップ描画: egui Painter で行列セル 🔵

**信頼性**: 🔵 *設計文書より*

param × objective の行列をセル単位で描画する。

```rust
let cell_w = available_width / n_objectives as f32;
let cell_h = cell_height;
for (param_idx, param_name) in param_names.iter().enumerate() {
    for (obj_idx, _obj_name) in objective_names.iter().enumerate() {
        let score = scores[param_idx][obj_idx];
        let color = spearman_colormap(score);  // -1.0..1.0 -> Color32
        let rect = Rect::from_min_size(
            Pos2::new(header_width + obj_idx as f32 * cell_w,
                      header_height + param_idx as f32 * cell_h),
            Vec2::new(cell_w, cell_h),
        );
        painter.rect_filled(rect, 2.0, color);
        painter.text(rect.center(), Align2::CENTER_CENTER,
            format!("{:.2}", score), FontId::proportional(9.0), Color32::BLACK);
    }
}
```

### 6. 値に応じたカラーマップ（Spearman 係数: -1〜+1） 🔵

**信頼性**: 🔵 *設計文書より*

Spearman 係数 -1.0 を青、0.0 を白、+1.0 を赤とする発散型カラーマップを使用する。

### 7. Brushing後の再計算: 選択インデックスを compute_sensitivity_selected に渡す 🔵

**信頼性**: 🔵 *設計文書より*

フィルター変更後に選択中インデックスを使って再計算する。

```rust
fn recompute_sensitivity(&mut self, selected_indices: &[usize]) {
    let trial_rows: Vec<TrialRow> = selected_indices.iter()
        .map(|&i| self.app_state.trial_rows[i].clone())
        .collect();
    spawn_task(self.tx.clone(), move || {
        let result = tunny_core::sensitivity::compute_sensitivity(&trial_rows, metric_type)?;
        AppMessage::SensitivityDone(result)
    });
}
```
