### 3. 軸ラベル: 上端・下端に min/max 値テキスト + 軸名 🔵

**信頼性**: 🔵 *設計文書より*

各軸の上端に軸名、上端・下端に min/max 値テキストを表示する。

```rust
// 軸名（上端）
painter.text(
    Pos2::new(axis_x, plot_top - 20.0),
    Align2::CENTER_BOTTOM,
    &axis_name,
    FontId::proportional(10.0),
    Color32::WHITE,
);
// max 値（上端）
painter.text(
    Pos2::new(axis_x, plot_top),
    Align2::CENTER_TOP,
    format!("{:.2}", axis_max),
    FontId::proportional(8.0),
    Color32::LIGHT_GRAY,
);
// min 値（下端）
painter.text(
    Pos2::new(axis_x, plot_bottom),
    Align2::CENTER_BOTTOM,
    format!("{:.2}", axis_min),
    FontId::proportional(8.0),
    Color32::LIGHT_GRAY,
);
```

### 4. 各 Trial を折れ線で描画 🔵

**信頼性**: 🔵 *設計文書より*

各軸の値を [0, 1] に正規化し、画面座標に変換して `Painter::line_segment` で隣接軸間を接続する。

```rust
for trial in display_trials {
    let color = color_mode.get_color(trial);
    let mut prev_pos: Option<Pos2> = None;
    for (axis_idx, axis_name) in axis_order.iter().enumerate() {
        let raw_value = trial.get_value(axis_name);
        let normalized = (raw_value - axis_min[axis_idx]) / (axis_max[axis_idx] - axis_min[axis_idx]);
        let screen_x = plot_left + axis_idx as f32 * axis_spacing;
        let screen_y = plot_bottom - normalized as f32 * plot_height;
        let current_pos = Pos2::new(screen_x, screen_y);
        if let Some(prev) = prev_pos {
            painter.line_segment([prev, current_pos], Stroke::new(0.5, color));
        }
        prev_pos = Some(current_pos);
    }
}
```
