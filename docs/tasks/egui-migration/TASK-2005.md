## タスク概要

`TunnyApp` に `std::sync::mpsc::channel` を設置し、Journal解析・Study選択・感度分析等の重計算をバックグラウンドスレッドで実行する基盤を実装する。UI スレッドは poll_messages() で定期的にメッセージを受信し AppState を更新する。

### 1. TunnyApp に channel フィールドを追加 🔵

**信頼性**: 🔵 *設計文書より*

`egui-app/src/app.rs` の TunnyApp 構造体に tx/rx フィールドを追加する。

```rust
pub struct TunnyApp {
    pub app_state: AppState,
    pub layout: LayoutState,
    tx: std::sync::mpsc::SyncSender<AppMessage>,
    rx: std::sync::mpsc::Receiver<AppMessage>,
}
```

### 2. TunnyApp::new() で sync_channel 初期化 🔵

**信頼性**: 🔵 *設計文書より*

`sync_channel(32)` でバッファサイズ 32 の同期チャネルを初期化する。

```rust
impl TunnyApp {
    pub fn new(cc: &eframe::CreationContext<'_>) -> Self {
        let (tx, rx) = std::sync::mpsc::sync_channel(32);
        Self {
            app_state: AppState::new(),
            layout: LayoutState::default(),
            tx,
            rx,
        }
    }
}
```

### 3. poll_messages() メソッド実装 🔵

**信頼性**: 🔵 *設計文書より*

`rx.try_recv()` でノンブロッキングにメッセージを消費し AppState を更新する。

```rust
fn poll_messages(&mut self, ctx: &egui::Context) {
    while let Ok(msg) = self.rx.try_recv() {
        match msg {
            AppMessage::JournalParsed(studies) => {
                self.app_state.all_studies = studies;
            }
            AppMessage::StudySelected { meta, trial_rows, gpu_data, pareto_indices } => {
                // current_study を更新
            }
            AppMessage::Error(e) => {
                // エラー表示用フラグに記録
            }
            _ => {}
        }
        ctx.request_repaint();
    }
}
```

### 4. eframe::App::update() での poll_messages 呼び出し 🔵

**信頼性**: 🔵 *設計文書より*

`eframe::App::update()` の先頭で必ず `self.poll_messages(ctx)` を呼び出す。

### 5. spawn_task ヘルパー関数 🔵

**信頼性**: 🔵 *設計文書より*

バックグラウンドタスク起動の共通ヘルパーを実装する。

```rust
pub fn spawn_task<F>(tx: std::sync::mpsc::SyncSender<AppMessage>, f: F)
where
    F: FnOnce() -> AppMessage + Send + 'static,
{
    std::thread::spawn(move || {
        let msg = f();
        let _ = tx.send(msg);
    });
}
```
