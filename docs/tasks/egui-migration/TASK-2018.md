## 実装詳細

### 1. scatter_matrix.rs 作成 🔵

**信頼性**: 🔵 *設計文書より*

`egui-app/src/widgets/scatter_matrix.rs` を作成する。

```rust
pub struct ScatterCell {
    pub cell_type: CellType,
    pub x_data: Vec<f64>,
    pub y_data: Vec<f64>,
    pub color_data: Vec<Color32>,
    pub cell_rect: Rect,
}

pub enum CellType {
    Scatter,      // 下三角セル
    Correlation,  // 上三角セル
    Histogram,    // 対角セル
}
```

### 2. 下三角セル: 散布図描画 🔵

**信頼性**: 🔵 *設計文書より*

`painter.circle_filled()` でデータ点を描画する。ダウンサンプリングインデックスを使用して最大500点に制限する。

```rust
for (&x, (&y, &color)) in x_data.iter().zip(y_data.iter().zip(color_data.iter())) {
    let screen_pos = data_to_screen(x, y, &x_range, &y_range, cell_rect);
    painter.circle_filled(screen_pos, 2.0, color);
}
```

### 3. 上三角セル: 相関係数テキスト + 背景カラーヒートマップ 🔵

**信頼性**: 🔵 *設計文書より*

背景を相関係数の絶対値に応じた色で塗りつぶし、中央に相関係数テキストを表示する。

```rust
let bg_color = correlation_colormap(corr_value);  // -1.0..1.0 -> Color32
painter.rect_filled(cell_rect, 0.0, bg_color);
painter.text(
    cell_rect.center(),
    Align2::CENTER_CENTER,
    format!("{:.2}", corr_value),
    FontId::proportional(12.0),
    Color32::BLACK,
);
```

### 4. 対角セル: ヒストグラム描画 🔵

**信頼性**: 🔵 *設計文書より*

`painter.rect_filled()` でバー描画するヒストグラムを実装する。

```rust
let n_bins = 20;
let bins = compute_histogram(&x_data, n_bins);
let bar_width = cell_rect.width() / n_bins as f32;
for (i, &count) in bins.iter().enumerate() {
    let bar_height = (count as f32 / max_count as f32) * cell_rect.height();
    let bar_rect = Rect::from_min_size(
        Pos2::new(cell_rect.left() + i as f32 * bar_width,
                  cell_rect.bottom() - bar_height),
        Vec2::new(bar_width - 1.0, bar_height),
    );
    painter.rect_filled(bar_rect, 0.0, Color32::BLUE);
}
```

### 5. ダウンサンプリング: thumbnail インデックス使用 🔵

**信頼性**: 🔵 *設計文書より*

散布図セルの描画には DownsampleCache の thumbnail インデックスを使用して最大500点に制限する。インデックスが None の場合は全件使用する（データ件数が500以下の場合）。

### 6. カラーマップ適用 🔵

**信頼性**: 🔵 *設計文書より*

`render/colormap.rs` の `ColorMap::interpolate()` を使用してデータ値を Color32 に変換する。

## テスト要件

### 相関係数計算テスト 🔵

**信頼性**: 🔵 *設計より*

- rust_core の Spearman 相関係数関数を利用して計算の正確性を確認する
- 完全正相関データ（y = x）で相関係数が +1.0 に近いことを確認する
- 完全負相関データ（y = -x）で相関係数が -1.0 に近いことを確認する
- ランダムデータで相関係数が -1.0 から +1.0 の範囲に収まることを確認する

### ヒストグラム計算テスト 🔵

**信頼性**: 🔵 *設計より*

- n_bins のビン数が正しく生成されることを確認する
- 全データがいずれかのビンに含まれることを確認する（カウント合計 = データ件数）

**信頼性**: 🔵 *設計より*
