## 実装詳細

### 1. pareto_2d.rs を DownsampleCache 統合対応に更新 🔵

**信頼性**: 🔵 *設計文書より*

既存の `pareto_2d.rs` を更新して DownsampleCache との統合を実装する。

```rust
pub struct Pareto2dChart {
    pub x_objective: usize,
    pub y_objective: usize,
    pub use_downsample: bool,
}

impl Pareto2dChart {
    pub fn show(&self, ui: &mut egui::Ui, app_state: &AppState) {
        let indices = app_state.downsample_cache.scatter.as_deref();
        // indices が Some の場合はサブセットを使用、None の場合は全件
    }
}
```

### 2. scatter インデックスの使用 🔵

**信頼性**: 🔵 *設計文書より*

scatter インデックスが `Some` の場合はそれを使用し、`None` の場合は全件を使用する。

```rust
let display_rows: Vec<&TrialRow> = match indices {
    Some(idx) => idx.iter().map(|&i| &trial_rows[i]).collect(),
    None => trial_rows.iter().collect(),
};
```

### 3. DownsampleDone メッセージ受信時に表示を更新 🔵

**信頼性**: 🔵 *設計文書より*

AppMessage::DownsampleDone を受信したタイミングで scatter インデックスを更新する。

```rust
AppMessage::DownsampleDone { key: DownsampleKey::Scatter, indices } => {
    self.app_state.downsample_cache.scatter = Some(indices);
    ctx.request_repaint();
}
```

### 4. 軸設定: 多目的では2目的関数を X/Y に選択 🔵

**信頼性**: 🔵 *設計文書より*

多目的最適化の場合、2つの ComboBox で X 軸と Y 軸の目的関数を選択できるようにする。

```rust
ui.horizontal(|ui| {
    ui.label("X軸:");
    egui::ComboBox::from_id_source("x_obj")
        .selected_text(&objective_names[self.x_objective])
        .show_ui(ui, |ui| {
            for (i, name) in objective_names.iter().enumerate() {
                ui.selectable_value(&mut self.x_objective, i, name);
            }
        });
    ui.label("Y軸:");
    egui::ComboBox::from_id_source("y_obj")
        .selected_text(&objective_names[self.y_objective])
        .show_ui(ui, |ui| {
            for (i, name) in objective_names.iter().enumerate() {
                ui.selectable_value(&mut self.y_objective, i, name);
            }
        });
});
```

### 5. Paretoランク別カラーリング 🔵

for trial in display_rows {
