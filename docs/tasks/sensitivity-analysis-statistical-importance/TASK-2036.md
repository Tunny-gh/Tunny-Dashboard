## 実装詳細

### 1. compute_diagonal_inverse 🔵

**信頼性**: 🔵 *design-interview.md Q3（対角成分選択）・dataflow.md フロー2より*

**実装ファイル**: `rust_core/src/sensitivity/ridge.rs`

```rust
fn compute_diagonal_inverse(a: &[Vec<f64>]) -> Vec<f64> {
    let p = a.len();
    let mut diag_inv = vec![0.0f64; p];
    for j in 0..p {
        let mut e_j = vec![0.0f64; p];
        e_j[j] = 1.0;
        // 既存の gaussian_elimination を利用 (A × x = e_j)
        let a_clone: Vec<Vec<f64>> = a.to_vec();
        if let Some(x) = gaussian_elimination(a_clone, e_j) {
            diag_inv[j] = x[j];
        }
        // gaussian_elimination が None を返す場合は 0.0 のまま
    }
    diag_inv
}
```

計算コスト: p = 30 で 30 × O(p²) = O(27000)、実用的に高速。

### 2. Ridge 統計計算の統合 🔵

**信頼性**: 🔵 *REQ-STAT-020〜023・dataflow.md フロー2より*

既存の Ridge 計算関数（`compute_ridge_regression()` またはそれに相当するもの）の内部で、β 計算後に以下を追加する:

```rust
// σ² = RSS / (n - p - 1) (REQ-STAT-020)
let df = n as f64 - p as f64 - 1.0;
if df <= 0.0 || n <= p + 2 {
    // 統計情報なし (REQ-STAT-024)
    result.std_errors = None;
    result.p_values = None;
    result.ci_lower = None;
    result.ci_upper = None;
} else {
    let sigma_sq = rss / df;

    // A = X^TX + αI の対角逆行列 (REQ-STAT-021)
    let diag_inv = compute_diagonal_inverse(&a_matrix);

    let mut std_errors = Vec::with_capacity(p);
    let mut p_values = Vec::with_capacity(p);
    let mut ci_lower = Vec::with_capacity(p);
    let mut ci_upper = Vec::with_capacity(p);
    let t_crit = crate::core::math::statistics::t_critical_95(df);

    for j in 0..p {
        let se = (sigma_sq * diag_inv[j]).max(0.0).sqrt();
        std_errors.push(se);
        let t_j = beta[j] / se;
        p_values.push(crate::core::math::statistics::t_two_sided_p(t_j, df));
        ci_lower.push(beta[j] - t_crit * se);
        ci_upper.push(beta[j] + t_crit * se);
    }

    result.std_errors = Some(std_errors);
    result.p_values = Some(p_values);
    result.ci_lower = Some(ci_lower);
    result.ci_upper = Some(ci_upper);
}
result.is_approximate = true;  // α > 0 によるバイアス (REQ-STAT-025)
```

**信頼性**: 🔵 *数学的真値から*

```rust
#[test]
fn test_diagonal_inverse() {
    // 2x2 単位行列の逆行列の対角成分は [1.0, 1.0]
    let a = vec![vec![1.0, 0.0], vec![0.0, 1.0]];
    let diag = compute_diagonal_inverse(&a);
    assert!((diag[0] - 1.0).abs() < 1e-9);
    assert!((diag[1] - 1.0).abs() < 1e-9);

    // 2x2 対角行列 [[2,0],[0,4]] の逆行列の対角成分は [0.5, 0.25]
    let a2 = vec![vec![2.0, 0.0], vec![0.0, 4.0]];
    let diag2 = compute_diagonal_inverse(&a2);
    assert!((diag2[0] - 0.5).abs() < 1e-9);
    assert!((diag2[1] - 0.25).abs() < 1e-9);
}
```
