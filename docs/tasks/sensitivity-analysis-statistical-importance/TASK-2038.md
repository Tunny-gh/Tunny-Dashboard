## 実装詳細

### 1. MDI 正規化前記録の重要性 🔵

**信頼性**: 🔵 *REQ-STAT-034より*

RF-ANOVA との違い: MDI は各木での計算後に正規化（合計=1）するため、正規化後の値を使うと全パラメータの値が独立でない。このため **正規化前** の不純度低下量を記録して SE を計算する。

```rust
// 正規化前の raw 不純度低下量を記録
let mut per_tree_raw: Vec<Vec<f64>> = vec![vec![0.0; n_params]; n_trees];

for t in 0..n_trees {
    for j in 0..n_params {
        per_tree_raw[t][j] = compute_impurity_decrease(tree_t, j);  // 正規化前
    }
}
```

### 2. SE 計算と正規化後スケール変換 🔵

**信頼性**: 🔵 *dataflow.md フロー3の MDI ノートより（RF-ANOVA と同一パターン）*

RF-ANOVA と同じパターンで SE を計算し、正規化後スケールに変換:

```rust
let sum_raw: f64 = raw_means.iter().sum();
for j in 0..n_params {
    let tree_vals: Vec<f64> = (0..n_trees).map(|t| per_tree_raw[t][j]).collect();
    let se_j = std_dev(&tree_vals) / (n_trees as f64).sqrt();
    // 正規化後スケール変換
    let se_norm = if sum_raw > 1e-12 { se_j / sum_raw } else { 0.0 };
    let norm_j = importances[j][obj];  // 正規化済み既存値
    ci_lower = (norm_j - t_crit * se_norm).max(0.0);
    ci_upper = norm_j + t_crit * se_norm;
}
```
