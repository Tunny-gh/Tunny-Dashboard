## 実装詳細

### 1. RF-ANOVA と同一パターン 🔵

**信頼性**: 🔵 *interfaces.rs ShapResult・RF-ANOVAと同パターンより*

SHAP は |SHAP 値| の平均を重要度として使用する実装が多い。木ごとの計算結果を `per_tree_shap: Vec<Vec<f64>>` [tree][param] に記録し、RF-ANOVA（TASK-2037）と同じ SE・CI 計算ロジックを適用する。

**実装ファイル**: `rust_core/src/sensitivity/shap.rs`

### 2. 既存コードの調査 🟡

**信頼性**: 🟡 *shap.rs の実装から妥当な推測*

実装前に `shap.rs` を読んで、SHAP 値の集約方法（|mean|, |sum| など）を確認する。

### 3. SE・p値・CI 計算 🔵

**信頼性**: 🔵 *RF-ANOVA と同一パターンより*

```rust
let sum_raw: f64 = raw_means.iter().sum();
let t_crit = crate::core::math::statistics::t_critical_95(99.0);

for j in 0..n_params {
    let se_j = std_dev(&per_tree_shap.iter().map(|t| t[j]).collect::<Vec<_>>())
        / (n_trees as f64).sqrt();
    let p_val = if se_j < 1e-12 {
        None
    } else {
        let t_j = raw_means[j] / se_j;
        Some(crate::core::math::statistics::t_one_sided_upper_p(t_j, 99.0))
    };
    let norm_j = importances[j][obj];
    let se_norm = if sum_raw > 1e-12 { se_j / sum_raw } else { 0.0 };
    p_values_raw.push(p_val);
    ci_lower_vec.push((norm_j - t_crit * se_norm).max(0.0));
    ci_upper_vec.push(norm_j + t_crit * se_norm);
}
```
