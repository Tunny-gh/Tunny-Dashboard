### 2. regularized_incomplete_beta (内部関数) 🔵

**信頼性**: 🔵 *implementation-guide.md §2 Lentz法コードより*

**実装ファイル**: `rust_core/src/core/math/statistics.rs`

Lentz 継続分数展開で I_x(a, b) を計算する内部関数。
- x <= 0.0 → 0.0, x >= 1.0 → 1.0
- 対称性利用: x > (a+1)/(a+b+2) の場合は 1-I_{1-x}(b,a) へ変換
- 収束判定: |del - 1| < 3e-7、最大200反復
- `t_cdf` の引数 x = df/(df + t²), a = df/2, b = 0.5

### 3. lgamma (内部関数) 🔵

**信頼性**: 🔵 *implementation-guide.md §2 Lanczos近似コードより*

Lanczos近似（g=7, n=9係数）で対数ガンマ関数を計算。

### 4. student_t_cdf 🔵

**信頼性**: 🔵 *NFR-STAT-020・design-interview.md Q4（高精度選択）より*

```rust
pub fn student_t_cdf(t: f64, df: f64) -> f64 {
    let x = df / (df + t * t);
    let ib = regularized_incomplete_beta(x, df / 2.0, 0.5);
    if t >= 0.0 { 1.0 - 0.5 * ib } else { 0.5 * ib }
}
```

df > 30 の場合も同じ式で計算（Lentz法は df に依存しない）。

### 5. t_two_sided_p / t_one_sided_upper_p 🔵

**信頼性**: 🔵 *REQ-STAT-011（両側）・REQ-STAT-032（片側）より*

```rust
pub fn t_two_sided_p(t_stat: f64, df: f64) -> f64 {
    2.0 * (1.0 - student_t_cdf(t_stat.abs(), df))
}

pub fn t_one_sided_upper_p(t_stat: f64, df: f64) -> f64 {
    1.0 - student_t_cdf(t_stat, df)
}
```

### 6. normal_cdf / z_two_sided_p 🔵

**信頼性**: 🔵 *REQ-STAT-043（Sobol z検定）より*

Abramowitz & Stegun 26.2.17 近似（誤差 < 1.5×10^{-7}）:
```rust
pub fn normal_cdf(z: f64) -> f64 {
    if z < 0.0 { return 1.0 - normal_cdf(-z); }
    let t = 1.0 / (1.0 + 0.2316419 * z);
    let poly = t * (0.319381530 + t * (-0.356563782
        + t * (1.781477937 + t * (-1.821255978 + t * 1.330274429))));
    1.0 - ((-0.5 * z * z).exp() / std::f64::consts::TAU.sqrt()) * poly
}
```

### 7. t_critical_95 🟡

**信頼性**: 🟡 *信頼区間計算に必要、既知の近似式から推測*

df >= 100 の場合は 1.96（正規近似）を返す。小さい df には近似テーブルを使用。

### 8. bonferroni_adjust 🔵

**信頼性**: 🔵 *REQ-STAT-050より*

```rust
pub fn bonferroni_adjust(p_values: &[Option<f64>], n_params: usize) -> Vec<Option<f64>> {
    p_values.iter().map(|p| p.map(|v| (v * n_params as f64).min(1.0))).collect()
}
```

### 9. significance_mark 🔵

**信頼性**: 🔵 *REQ-STAT-051より*

```rust
pub fn significance_mark(p_adjusted: Option<f64>) -> &'static str {
    match p_adjusted {
        Some(p) if p < 0.001 => "***",
        Some(p) if p < 0.01  => "**",
        Some(p) if p < 0.05  => "*",
        _ => "",
    }
}
```

### テストケース1: student_t_cdf 基本値確認 🔵

**信頼性**: 🔵 *数学的真値から*

```rust
#[test]
fn test_student_t_cdf() {
    // df=10, t=2.228 → CDF ≈ 0.975 (95% CI 臨界値)
    let p = student_t_cdf(2.228, 10.0);
    assert!((p - 0.975).abs() < 1e-3);
    // df=∞, t=1.96 → CDF ≈ 0.975 (正規分布)
    let p2 = student_t_cdf(1.96, 1000.0);
    assert!((p2 - 0.975).abs() < 1e-3);
}
```
