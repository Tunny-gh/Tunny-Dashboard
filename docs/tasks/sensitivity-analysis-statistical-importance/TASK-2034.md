## 実装詳細

### 1. SensitivityResult への追加 🔵

**信頼性**: 🔵 *REQ-STAT-061より*

**実装ファイル**: `rust_core/src/sensitivity/types.rs`

```rust
pub struct SensitivityResult {
    pub param_names: Vec<String>,
    pub objective_names: Vec<String>,
    // 既存フィールド
    pub spearman: Vec<Vec<f64>>,
    // 追加フィールド
    pub spearman_p_values: Option<Vec<Vec<f64>>>,  // [obj][param] raw（補正前）
    pub spearman_ci_lower: Option<Vec<Vec<f64>>>,  // [obj][param]
    pub spearman_ci_upper: Option<Vec<Vec<f64>>>,
    // 既存フィールド（変更なし）
    pub ridge: Vec<RidgeResult>,
    pub rf_anova: Option<RfAnovaResult>,
    pub mdi: Option<MdiResult>,
    pub shap: Option<ShapResult>,
}
```

### 2. RidgeResult への追加 🔵

**信頼性**: 🔵 *REQ-STAT-062・interfaces.rs より*

```rust
pub struct RidgeResult {
    // 既存フィールド
    pub beta: Vec<f64>,
    pub r_squared: f64,
    // 追加フィールド
    pub std_errors: Option<Vec<f64>>,
    pub p_values: Option<Vec<f64>>,
    pub ci_lower: Option<Vec<f64>>,
    pub ci_upper: Option<Vec<f64>>,
    pub is_approximate: bool,   // α>0による近似バイアスフラグ
}
```

`RidgeResult` の既存の構築箇所に `std_errors: None, p_values: None, ci_lower: None, ci_upper: None, is_approximate: true` を追加する。

## 注意事項

- `#[derive(Default)]` がある場合、`Option` は自動的に `None`、`bool` は `false` になる
- 構造体リテラルで明示的に初期化している箇所はすべて修正する
- `spearman_p_values` のインデックス順は `[obj][param]`（既存の `spearman: Vec<Vec<f64>>` と同じ）
