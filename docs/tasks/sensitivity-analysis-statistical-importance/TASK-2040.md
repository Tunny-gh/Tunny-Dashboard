## 実装詳細

### 1. Jansen 一次指標の分散公式 🔵

**信頼性**: 🔵 *REQ-STAT-041・Jansen (1999) の公式より*

**実装ファイル**: `rust_core/src/sensitivity/sobol.rs`

dataflow.md フロー4 より:
```rust
// d_j = f_B[k][j] * (f_AB_i[k][j] - f_A[k][j]) for each sample j
// var_d = Var(d_j over j=0..N)
// var_s_i = var_d / (N × Var_Y²)
// se_s_i = sqrt(var_s_i)
// ci_lower = max(s_i - 1.96 * se, 0)
// ci_upper = s_i + 1.96 * se

for (param_idx, _) in param_names.iter().enumerate() {
    for obj_idx in 0..n_objectives {
        let var_y = variance(&f_a[obj_idx]);
        if var_y < 1e-12 {
            // EDGE-STAT-003
            first_order_p_values[param_idx][obj_idx] = None;
            continue;
        }

        let d: Vec<f64> = (0..n_samples)
            .map(|j| f_b[obj_idx][j] * (f_ab_i[param_idx][obj_idx][j] - f_a[obj_idx][j]))
            .collect();
        let var_d = variance(&d);
        let var_s_i = var_d / (n_samples as f64 * var_y * var_y);
        let se = var_s_i.sqrt();

        let s_i = first_order[param_idx][obj_idx];
        first_order_ci_lower[param_idx][obj_idx] = (s_i - 1.96 * se).max(0.0);
        first_order_ci_upper[param_idx][obj_idx] = s_i + 1.96 * se;

        // z 統計量（REQ-STAT-043）
        if se < 1e-12 {
            first_order_p_values[param_idx][obj_idx] = None;
        } else {
            let z = s_i / se;
            first_order_p_values[param_idx][obj_idx] =
                Some(crate::core::math::statistics::z_two_sided_p(z));
        }
    }
}
```

### 2. 全効果指標の分散公式 🔵

**信頼性**: 🔵 *REQ-STAT-040〜042・Jansen (1999) の全効果バージョンより*

一次指標と同様のパターンで `f_AB_i` の計算方法だけ変更:
- 全効果: `d_j = (f_A[k][j] - f_AB_i[k][j])²`
- `var_st_i = var_d / (2N × Var_Y²)`
