## 実装詳細

### 1. AppMessage に EntropyDone バリアント追加 🔵

**信頼性**: 🔵 *設計文書 dataflow.md・既存AppMessage定義より*

**実装ファイル**: egui-app の AppMessage enum 定義箇所

既存の McdmDone / Error バリアントと並列に、新規バリアントを追加する。

```rust
pub enum AppMessage {
    // 既存バリアント...
    McdmDone(McdmResult),
    Error(String),
    // 追加:
    EntropyDone(EntropyResult),
}
```

### 2. message_handler.rs にハンドラ追加 🔵

**信頼性**: 🔵 *設計文書 dataflow.md・既存McdmDoneハンドラパターンより*

**実装ファイル**: `egui-app/src/message_handler.rs`

EntropyDone(result) 受信時の処理:

```rust
AppMessage::EntropyDone(result) => {
    widget_states.mcdm_chart.entropy_result = Some(result.clone());
    widget_states.mcdm_chart.weights = result.weights;
    widget_states.mcdm_chart.pending_entropy = false;
}
```

- `entropy_result` に計算結果を保存（UI表示用）
- `weights` にエントロピー重みを反映（後続MCDM計算で使用）
- `pending_entropy` を false に戻す（ローディング状態解除）

### 3. match arm の追加 🔵

**信頼性**: 🔵 *既存message_handler.rsのmatch構造より*

**実装ファイル**: `egui-app/src/message_handler.rs`

既存の McdmDone / Error arm と並列に EntropyDone arm を追加する。
コンパイラの網羅性チェックにより、arm 忘れを防止する。
