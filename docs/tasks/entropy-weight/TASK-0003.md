## 実装詳細

### 1. WeightMode enum の定義 🔵

**信頼性**: 🔵 *設計文書 architecture.md・interfaces.rs・ユーザヒアリングより*

**実装ファイル**: `egui-app/src/state/results.rs`

```rust
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum WeightMode {
    Manual,
    Entropy,
}

impl WeightMode {
    pub fn label(&self) -> &'static str {
        match self {
            WeightMode::Manual => "Manual",
            WeightMode::Entropy => "Entropy",
        }
    }

    pub fn all() -> &'static [WeightMode] {
        &[WeightMode::Manual, WeightMode::Entropy]
    }
}
```

### 2. EntropyResult 構造体の定義 🔵

**信頼性**: 🔵 *設計文書 architecture.md・interfaces.rs・ユーザヒアリングより*

**実装ファイル**: `egui-app/src/state/results.rs`

```rust
#[derive(Debug, Clone)]
pub struct EntropyResult {
    pub weights: Vec<f64>,           // エントロピー重み（目的関数次元）
    pub entropies: Vec<f64>,         // 各基準のエントロピー値
    pub diversities: Vec<f64>,       // 各基準の多様性（1 - エントロピー）
    pub normalized_matrix: Vec<f64>, // 正規化行列（n_trials × n_objectives）
    pub duration_ms: f64,            // 計算時間 (ms)
}
```
