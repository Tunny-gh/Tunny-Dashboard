## 概要

Shannonエントロピーに基づく客観的重み計算アルゴリズムを`rust_core/src/mcdm/entropy.rs`にTDD方式で実装する。比例正規化→エントロピー計算→分散度→重み算出の一連のパイプラインを構築する。

## 実装詳細

### 1. 新規ファイル `rust_core/src/mcdm/entropy.rs` 作成 🔵

- `EntropyResult`構造体: `weights`, `entropies`, `diversities`, `normalized_matrix`, `duration_ms`
- `compute_entropy_weights(values, n_trials, n_objectives) -> Result<EntropyResult, String>`
- 入力検証: `values.len() == n_trials * n_objectives`, `n_trials >= 1`, `n_objectives >= 1`

```rust
#[derive(Debug, Clone, serde::Serialize)]
pub struct EntropyResult {
    pub weights: Vec<f64>,
    pub entropies: Vec<f64>,
    pub diversities: Vec<f64>,
    pub normalized_matrix: Vec<f64>,
    pub duration_ms: u128,
}
```

### 2. NaNフィルタリング 🔵

- `filter_valid_indices()` を使用してNaN試行を除外
- 全試行NaN時は `Err("No valid trials...")` を返却

### 3. 負の値前処理 🔵

- 列ごとに負の値を検出
- 負の値含む場合は min-max正規化で [0,1] に変換
- 非負の場合はスキップ

### 4. 比例正規化 p_ij = x_ij / sum_i(x_ij) 🔵

- `sum_j == 0` の列: `p_ij = 0` for all i

### 5. 情報エントロピー e_j = -(1/ln(m)) * sum(p_ij * ln(p_ij)) 🔵

- `p_ij == 0` の項は `0` として扱う
- `valid_count == 1` (`ln_m == 0`) の場合: `e_j = 0.0`

### 6. 分散度 d_j = 1 - e_j 🔵

### 7. 重み w_j = d_j / sum(d_k)、全d_j==0なら均等重み 🔵
