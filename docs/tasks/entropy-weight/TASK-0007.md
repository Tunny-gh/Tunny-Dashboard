## Task overview

WeightMode::Entropy時にWeights セクション内にエントロピー値テーブルを表示する。各目的のエントロピー値、分散度、重みを4列表形式で表示する。

## Implementation details

### 1. エントロピーテーブルUI追加 🔵

- Weights collapsing セクション内に配置
- WeightMode::Entropy かつ entropy_result.is_some() の場合のみ表示
- 表形式: | 目的名 | Entropy (e_j) | Diversity (d_j) | Weight (w_j) |
- egui::TableBuilder または ui.vertical/table で実装

### 2. 表示フォーマット 🔵

- 目的名: obj0, obj1, ... （または app_state の目的名があれば使用）
- 数値: 小数点以下3桁表示（format!("{:.3}", value)）
- 重みはパーセンテージ併記（例: "0.350 (35.0%)"）

### 3. テーブル非表示制御 🔵

- WeightMode::Manual: テーブル非表示
- entropy_result == None: テーブル非表示（spinner表示）

## Unit tests

- Entropyモード+結果ありでテーブル表示 🔵
- Manualモードでテーブル非表示 🔵
- 表示値がentropy_resultと一致 🔵

## Integration tests

- エントロピー計算完了 → テーブル表示 → Manual切替で非表示のフロー 🔵

## UI/UX

- ローディング: 計算中はテーブル領域にspinner 🔵
- エラー: 計算失敗時はテーブル領域にエラーメッセージ 🔵
- 数値表示: 小数点以下3桁で統一 🔵
