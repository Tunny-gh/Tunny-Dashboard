## Task overview

McdmRankChartにWeightModeセレクタ（Manual/Entropy）を追加し、Entropyモード時にスライダーを読み取り専用にする。Manual→Entropy切替時にpending_entropyをtrueに設定する。

## Implementation details

### 1. WeightModeセレクタUI追加 🔵

- 配置: 手法セレクタ（TOPSIS/VIKOR）の横に横並び
- egui::ComboBox で Manual/Entropy 切替
- ユーザヒアリング回答「手法セレクタの横」に基づく

### 2. WeightMode切替ロジック 🔵

- Manual → Entropy: pending_entropy = true
- Entropy → Manual: スライダー編集可能に変更（entropy_resultはキャッシュ保持）

### 3. スライダー制御 🔵

- WeightMode::Entropy: ui.add_enabled(false, Slider::new(...)) で読み取り専用
- WeightMode::Manual: 通常のSlider（編集可能）
- 値は entropy_result.weights を表示

### 4. Runボタン押下時のweights設定 🔵

- WeightMode::Entropy: weights = entropy_result.weights.clone()
- WeightMode::Manual: weights = self.weights.clone()

## Unit tests

- WeightMode切替でpending_entropyが正しく設定される 🔵
- Entropyモードでスライダー値がentropy_resultと一致 🔵

## Integration tests

- Manual→Entropy切替 → 計算実行 → スライダー更新 → Run押下のフロー 🔵

## UI/UX

- ローディング: pending_entropy=true時にspinner 🔵
- エラー: 計算失敗時のエラー表示 🔵
- レスポンシブ: セレクタ切替は即座に反映（NFR-201） 🔵
