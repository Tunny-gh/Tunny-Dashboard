## 実装詳細

### 1. chart_registry.rs にエントロピーdispatch追加 🔵

**信頼性**: 🔵 *設計文書 dataflow.md・既存VIKOR dispatchパターンより*

**実装ファイル**: `egui-app/src/chart_registry.rs`

```rust
// chart_registry の更新処理内:
if widgets.mcdm_chart.pending_entropy {
    // app_state からデータ収集
    let objectives = /* app_state から目的関数取得 */;
    let n_trials = /* app_state から試行数取得 */;
    let n_objectives = objectives.len();

    // values 行列を構築
    let values: Vec<f64> = /* objectives × trials の値を収集 */;

    spawn_task(move || {
        match tunny_core::entropy::compute_entropy_weights(&values, n_trials, n_objectives) {
            Ok(result) => AppMessage::EntropyDone(result),
            Err(e) => AppMessage::Error(format!("Entropy computation failed: {}", e)),
        }
    });
}
```

処理フロー:
1. `pending_entropy` が true かチェック
2. `app_state` から objectives, n_trials, n_objectives を収集
3. `spawn_task()` で `tunny_core::entropy::compute_entropy_weights()` をバックグラウンド実行
4. Ok -> `AppMessage::EntropyDone(result)` を送信
5. Err -> `AppMessage::Error(format!("Entropy computation failed: {}", e))` を送信

### 2. WeightMode切替ロジック 🔵

**信頼性**: 🔵 *設計文書 dataflow.md・ユーザヒアリングより*

**実装ファイル**: `egui-app/src/chart_registry.rs`

```rust
// WeightMode 切替時の処理:
match new_weight_mode {
    WeightMode::Manual => {
        widgets.mcdm_chart.pending_entropy = false;
        // スライダー編集可能状態に復帰
    }
    WeightMode::Entropy => {
        widgets.mcdm_chart.pending_entropy = true;
        // chart_registry 次回更新時にエントロピー計算がdispatchされる
    }
}
```

- Manual -> Entropy: `pending_entropy = true` を設定（mcdm_chart側で設定、chart_registry側でチェック）
- Entropy -> Manual: `pending_entropy = false`, スライダー編集可能に戻す
