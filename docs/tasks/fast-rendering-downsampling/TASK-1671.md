## タスク概要

`ClusterScatter.tsx` と `DimReductionScatter.tsx` に `useDownsampleStore` を統合する。`getIndices('cluster')` で 10,000 点に制限する。クラスタ別均等サンプリング（フォールバック: Pareto 保持ランダム）が適用済みのインデックスを使用する。

## 実装詳細

### 1. ClusterScatter への統合 🔵

**信頼性**: 🔵 *architecture.md Layer 4 / ユーザヒアリングより*

**実装ファイル**: `frontend/src/components/charts/ClusterScatter.tsx`

```typescript
import { useDownsampleStore } from '../../stores/downsampleStore';

const { getIndices } = useDownsampleStore();
const renderIndices = getIndices('cluster'); // Uint32Array（上限 10,000）

// ECharts / deck.gl のデータを renderIndices でフィルタ
const filteredData = filterDataByIndices(chartData, renderIndices);
```

### 2. DimReductionScatter への統合 🔵

**信頼性**: 🔵 *architecture.md Layer 4 / ユーザヒアリングより*

**実装ファイル**: `frontend/src/components/charts/DimReductionScatter.tsx`

ClusterScatter と同一パターン。PCA / UMAP 次元削減結果の scatter 描画に適用する。

### 3. クラスタラベル考慮 🔵

**信頼性**: 🔵 *architecture.md `downsample_by_cluster` フォールバック設計より*

クラスタ計算（`clusterStore`）が未完了の場合、`downsample_by_cluster` は `downsample_smart` にフォールバックする。チャート側は `getIndices('cluster')` を呼ぶだけでよい（フォールバックは Store・WASM 側で吸収済み）。

## 単体テスト要件

**信頼性**: 🔵 *architecture.md DOWNSAMPLE_CONFIGS より*

**When**: `getIndices('cluster')` を呼び出す
**Then**: `renderIndices.length <= 10,000`

**テストファイル**: `frontend/src/components/charts/ClusterScatter.test.tsx`

### テストケース2: クラスタラベルなし時のフォールバック 🔵

**信頼性**: 🔵 *architecture.md downsample_by_cluster フォールバック設計より*

**Then**: `renderIndices.length <= 10,000`

**テストファイル**: `frontend/src/components/charts/DimReductionScatter.test.tsx`
