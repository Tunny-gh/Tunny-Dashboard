## 実装詳細

### 1. グリッドサンプリングアルゴリズムの実装 🔵

**信頼性**: 🔵 *REQ-063 / architecture.md dataflow.md より*

**実装ファイル**: `rust_core/src/sampling.rs`

アルゴリズム:
1. Pareto Rank1 インデックスを取得
2. Pareto 点を min(pareto_count, max_points / 2) に制限して確保
3. 残り予算 = max_points - confirmed_pareto_count
4. 非 Pareto 点の目的変数空間を sqrt(残り予算) × sqrt(残り予算) セルに分割
5. 各セルから 1 点をランダムに選択
6. Pareto + グリッドサンプル を結合して返す

```rust

```
