## 実装詳細

### 1. ランク別層化サンプリング 🔵

**信頼性**: 🔵 *architecture.md より*

**実装ファイル**: `rust_core/src/sampling.rs`

アルゴリズム:
1. 全試行をランク別にグループ化
2. Rank1 は全量保持（予算オーバーなら Rank1 全量を返す）
3. 残り予算を Rank2, 3, ... に対して 1/rank の割合で配分
4. 各ランクグループからランダムサンプリング

