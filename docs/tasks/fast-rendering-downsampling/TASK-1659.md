## 実装詳細

### 1. クラスタ別均等サンプリング 🔵

**信頼性**: 🔵 *architecture.md より*

**実装ファイル**: `rust_core/src/sampling.rs`

アルゴリズム:
1. DataFrame からクラスタラベルを取得（`None` の場合はフォールバック）
2. クラスタ数 K を取得
3. 予算 = max_points / K（各クラスタへの均等割り当て）
4. 各クラスタから予算分をランダムサンプリング（Pareto 点を優先）
5. 端数は最大クラスタに追加

```rust
pub fn downsample_by_cluster(max_points: usize) -> Option<DownsampleResult>
```

## 単体テスト要件

### テストケース1: クラスタ別均等サンプリング 🔵

- **Given**: クラスタ 4 個、各 2,000 点、合計 8,000 点
- **When**: `downsample_by_cluster(4000)` を呼び出す
- **Then**: 各クラスタから約 1,000 点が含まれる

### テストケース2: クラスタラベルなしフォールバック 🔵

- **Given**: クラスタラベルが未計算の状態
- **When**: `downsample_by_cluster(10000)` を呼び出す
- **Then**: `downsample_smart(10000, true)` と同等の結果
