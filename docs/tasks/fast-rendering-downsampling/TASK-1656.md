### 1. DownsampleResult 構造体の定義 🔵

**信頼性**: 🔵 *interfaces.ts / wasm-api.md より*

**実装ファイル**: `rust_core/src/sampling.rs`

```rust
pub struct DownsampleResult {
    pub indices: Vec<u32>,
    pub pareto_count: usize,
    pub total_count: usize,
    pub duration_ms: f64,
}
```

### 2. downsample_smart 関数の実装 🔵

**信頼性**: 🔵 *architecture.md アルゴリズム設計より*

**実装ファイル**: `rust_core/src/sampling.rs`

アルゴリズム:
1. WASM メモリ上の DataFrame から全 COMPLETE 試行インデックスを取得
2. N ≤ max_points なら全インデックスを返す（ノーオペ）
3. `include_pareto = true` なら Pareto Rank1 インデックスを先行確保（`dataframe::get_pareto_rank1_indices()` を使用）
4. 残り予算 = max_points - pareto_count
5. 非 Pareto 点から残り予算分をランダムサンプリング（シード 42 固定）
6. Pareto + 非 Pareto サンプルを結合して返す

```rust
pub fn downsample_smart(max_points: usize, include_pareto: bool) -> Option<DownsampleResult>
```

## 単体テスト要件

### テストケース1: N ≤ max_points の場合は全点返却 🔵

**信頼性**: 🔵 *architecture.md より*

- **Given**: DataFrame に 100 点
- **When**: `downsample_smart(1000, true)` を呼び出す
- **Then**: indices.len() == 100

### テストケース2: Pareto 点が必ず含まれる 🔵

**信頼性**: 🔵 *ユーザヒアリング（Pareto必須保持）より*

- **Given**: DataFrame に 50,000 点、Pareto Rank1 が 50 点
- **When**: `downsample_smart(1000, true)` を呼び出す
- **Then**: Pareto Rank1 の全インデックスが結果に含まれる

### テストケース3: max_points が Pareto 数より少ない場合 🟡

**信頼性**: 🟡 *エッジケースとして妥当な推測*

- **Given**: DataFrame に 50,000 点、Pareto Rank1 が 200 点
- **When**: `downsample_smart(100, true)` を呼び出す
- **Then**: indices.len() == 100（Pareto 点から 100 点を返す）

### テストケース4: パフォーマンステスト 🔵

**信頼性**: 🔵 *NFR-002 より（filter_by_ranges と同等目標）*

- **Given**: DataFrame に 50,000 点
- **When**: `downsample_smart(10000, true)` を呼び出す
- **Then**: duration_ms < 5.0
