## 実装詳細

### 1. recomputeIfNeeded の実装 🔵

**信頼性**: 🔵 *dataflow.md フロー2より*

```typescript
recomputeIfNeeded: async (filteredIndices: Uint32Array) => {
  const { lastTotalCount, recompute } = get();
  const newCount = filteredIndices.length;
  const changeRatio = Math.abs(newCount - lastTotalCount) / Math.max(lastTotalCount, 1);
  if (changeRatio >= 0.2) {
    set({ lastTotalCount: newCount });
    await recompute();
  }
},
```

### 2. selectionStore サブスクリプション 🔵

**信頼性**: 🔵 *既存 selectionStore パターンより*

```typescript
useSelectionStore.subscribe(
  (state) => state.filteredIndices,
  (filteredIndices) => {
    if (filteredIndices) {
      useDownsampleStore.getState().recomputeIfNeeded(filteredIndices);
    }
  }
);
```
