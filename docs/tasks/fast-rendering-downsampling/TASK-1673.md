## 実装詳細

### 1. Rust ベンチマークの追加 🔵

**信頼性**: 🔵 *wasm-api.md 性能目標（< 5ms per function）/ NFR-002 より*

**実装ファイル**: `rust_core/benches/sampling_bench.rs`

```rust
use criterion::{criterion_group, criterion_main, BenchmarkId, Criterion};

fn bench_downsample_smart(c: &mut Criterion) {
    // 50,000点の DataFrame をセットアップ（事前に populate_dataframe() を呼ぶ）
    c.bench_with_input(
        BenchmarkId::new("downsample_smart", 50_000),
        &50_000usize,
        |b, &n| {
            b.iter(|| sampling::downsample_smart(10_000, true))
        },
    );
}

fn bench_downsample_for_thumbnail(c: &mut Criterion) { ... }
fn bench_downsample_stratified_by_rank(c: &mut Criterion) { ... }
fn bench_downsample_by_cluster(c: &mut Criterion) { ... }

criterion_group!(benches,
    bench_downsample_smart,
    bench_downsample_for_thumbnail,
    bench_downsample_stratified_by_rank,
    bench_downsample_by_cluster,
);
criterion_main!(benches);
```

`Cargo.toml` に `[dev-dependencies]` として `criterion` を追加すること:
```toml
[dev-dependencies]
criterion = { version = "0.5", features = ["html_reports"] }

[[bench]]
name = "sampling_bench"
harness = false
```

### 2. 目標未達成時の最適化候補 🟡

**信頼性**: 🟡 *一般的な Rust パフォーマンス最適化パターンから妥当な推測*

5ms を超える場合の最適化候補（優先順）:
1. **ランダムサンプリングの最適化**: `rand::rngs::SmallRng` の使用（高速な PRNG）
2. **グリッド計算のビット演算化**: セルインデックス計算を整数演算で実装
3. **Pareto インデックスへの直接ポインタアクセス**: DataFrame の Pareto フラグ列を直接参照
4. **シャッフル不要化**: 結合後のシャッフルは省略可能（順序は描画に影響しない）

## 注意事項

- ベンチマーク対象は WASM ではなく **native ターゲット**（`cargo bench`）で計測すること
  - native で 1ms 以内が目標（WASM オーバーヘッドで約 2〜5 倍増）
- ベンチマーク用の DataFrame セットアップは実際のデータ構造に合わせること
- `cargo bench` は `wasm` feature フラグなしでビルドすること: `cargo bench --no-default-features`
