## 実装詳細

### 1. Comparison 専用 worker 追加 🔵

**信頼性**: 🔵 *dataflow.md の Comparison 追加フローより*

既存 `study_worker` パターンを再利用し、比較用途の load 関数を追加する。メイン Study と同名の Study がある場合は優先し、なければ先頭 Study を採用する。

**実装ファイル**: `egui-app/src/io/study_worker.rs`

### 2. 成功/失敗メッセージの整理 🔵

**信頼性**: 🔵 *architecture.md の非同期 worker 層より*

成功時は `ComparisonStudyLoaded`、失敗時は `ComparisonStudyLoadFailed` を返し、UI 側が明確にハンドリングできるようにする。

### 3. 比較セッションのリセット規約 🟡

**信頼性**: 🟡 *REQ-002-G・設計ヒアリング Q4 より*

`comparison_base_study` と現在選択中 Study を比較し、不一致時に `comparison_studies`, `comparison_colors`, `comparison_mode` をリセットする helper を追加する。
