## 実装詳細

### 1. 軸/目的選択 UI と request 生成 🔵

**信頼性**: 🔵 *REQ-005-B, REQ-005-C より*

Surface Plot header に 2 軸 + 1 目的の selector と `Run` ボタンを追加し、選択結果から request を作る。

**実装ファイル**: `egui-app/src/ui/widgets/surface_plot.rs`（新規想定）, `egui-app/src/ui/render_chart.rs`

### 2. 非同期計算と結果受け取り 🟡

**信頼性**: 🟡 *REQ-005-D, REQ-005-E・既存サロゲート計算パターンより*

`poll_chart.rs` から別スレッド計算を起動し、`AppMessage::SurfacePlotDone` で結果を戻す。計算ロジックは既存 PDP/importance の流れを参考にする。

### 3. Heatmap/Contour 描画とエラー表現 🟡

**信頼性**: 🟡 *architecture.md の Phase 1 方針より*

最初の描画形式は Heatmap/Contour とし、3D でなくても比較・探索に使える密度を優先する。試行数不足時は `EDGE-003` のメッセージを表示する。
