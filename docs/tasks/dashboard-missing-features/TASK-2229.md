## 実装詳細

### 1. CSV 文字列生成の純粋関数化 🔵

**信頼性**: 🔵 *REQ-001-D・TC-001-04 より*

`io/export.rs` に `build_csv_string(rows, param_names, objective_names)` のような純粋関数を追加し、文字列生成を UI から分離する。

**実装ファイル**: `egui-app/src/io/export.rs`

### 2. ファイル保存ヘルパーの追加 🔵

**信頼性**: 🔵 *REQ-001-C・NFR-201 より*

`rfd::FileDialog::save_file()` と `std::fs::write()` をまとめた保存ヘルパーを追加し、成功/失敗を `Result` で返す。

### 3. エラー返却契約の整理 🔵

**信頼性**: 🔵 *EDGE-001・dataflow.md より*

UI 側が成功メッセージと失敗メッセージを分けて表示できるよう、エラー型または `String` ベースの返却契約を明確にする。
