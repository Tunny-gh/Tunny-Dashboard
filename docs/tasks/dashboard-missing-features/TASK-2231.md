## タスク概要

`session.rs` に存在する `pinned_trials` を `AppState` と save/load フローに接続し、ピン留め件数制限と round-trip 復元を成立させる。UI トグルは後続タスクで実装するが、状態遷移はこのタスクで完成させる。

## 依存タスク

- **前提タスク**: [TASK-2228](TASK-2228.md)
- **後続タスク**: [TASK-2232](TASK-2232.md), [TASK-2235](TASK-2235.md), [TASK-2246](TASK-2246.md)

## 完了条件

- [x] `AppState` にピン留めトグル helper が実装されている
- [x] 20 件上限を超えるとエラーを返す
- [x] Save Session 時に `pinned_trials` が `SessionSnapshot` へ保存される
- [x] Load Session 時に `pinned_trials` が `AppState` へ戻る

## 実装詳細

### 1. `toggle_pinned_trial()` と上限管理 🔵

**信頼性**: 🔵 *REQ-003-D・EDGE-101 より*

`AppState` にトグル helper を追加し、既存項目なら解除、新規なら 20 件上限を判定して追加する。

**実装ファイル**: `egui-app/src/state/app_state.rs`

### 2. Save/Load への配線 🔵

**信頼性**: 🔵 *session.rs 既存 `pinned_trials` フィールドより*

`app.rs` の `SaveSession` / `LoadSession` 分岐に `pinned_trials` を接続する。`SessionSnapshot::new()` の使用箇所で保存対象を埋める。

### 3. エラー返却と UI 接続準備 🔵

**信頼性**: 🔵 *architecture.md の選択・可視性ポリシー層より*

上限超過時は UI 側が通知に変換できるよう、`Result<(), PinError>` を返す。
