## タスク概要

Toolbar に Comparison Study の追加 UI を実装し、読み込み済み比較 Study を removable chip として表示する。比較 Study 追加時は Comparison レイアウトへ誘導し、base Study 切替時のリセット動作も UI から見える形にする。

## 実装詳細

### 1. `Add Comparison Study` ボタン追加 🔵

**信頼性**: 🔵 *REQ-002-A・toolbar.rs の既存構造より*

Toolbar に新しいボタンを追加し、クリック時に file picker を開いて `ToolbarAction::AddComparisonStudy` を発火させる。

**実装ファイル**: `egui-app/src/ui/toolbar.rs`, `egui-app/src/app.rs`

### 2. 比較 Study chip 表示と削除 🔵

**信頼性**: 🔵 *REQ-002-D より*

現在の `comparison_studies` を chip として表示し、各 chip に remove action を紐付ける。

### 3. base Study 変更時リセットの可視化 🟡

**信頼性**: 🟡 *REQ-002-G・design-interview.md より*

base Study 切替で比較セッションがクリアされたとき、UI 上で比較 chip が消えることと、必要なら短い通知を出す。
