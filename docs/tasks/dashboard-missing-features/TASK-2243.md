## タスク概要

Trial Table、PDP overlay、Pareto Scatter、Parallel Coordinates の選択反映を 1 つの表示ポリシーに揃え、50,000 試行でも体感遅延が出にくいように更新経路を整理する。Brushing & Linking 系の仕上げタスク。

## 完了条件

- [x] 表示対象集合が全チャートで一貫している
- [x] pin 済み試行が Brushing 後も可視性を失わない

## 実装詳細

### 1. 選択反映 helper の統一 🔵

**信頼性**: 🔵 *TASK-2232 の表示ポリシー基盤より*

各ウィジェットが独自に `selected_indices` を解釈しないよう、共通 helper 経由に寄せる。

**実装ファイル**: `egui-app/src/ui/render_chart.rs`, `egui-app/src/ui/widgets/trial_table.rs`, `egui-app/src/ui/widgets/pareto_2d.rs`, `egui-app/src/ui/widgets/parallel_coords.rs`

### 2. 再計算/再描画の過剰実行抑制 🟡

**信頼性**: 🟡 *NFR-002, REQ-006-G より*

selection 更新ごとに不要な heavy compute を走らせないようにし、PDP overlay など再計算不要な経路は描画更新だけで済ませる。

### 3. パフォーマンス計測の補助追加 🟡

**信頼性**: 🟡 *TC-006-P01 は検証で確認が必要なため*

debug log または簡易 timing を追加し、50,000 試行での update latency を観測できるようにする。
