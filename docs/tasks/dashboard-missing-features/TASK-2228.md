## 実装詳細

### 1. `ToolbarAction` と `AppState` の共通拡張 🔵

**信頼性**: 🔵 *architecture.md の「Toolbar コマンド層」「選択・可視性ポリシー層」より*

`egui-app/src/ui/toolbar.rs` と `egui-app/src/state/app_state.rs` を更新し、以下を追加する。

- `ToolbarAction::ExportCsv(ExportTarget)`
- `ToolbarAction::AddComparisonStudy`
- `ToolbarAction::RemoveComparisonStudy(usize)`
- `AppState::pinned_trials: Vec<u32>`
- `AppState::comparison_base_study: Option<u32>`

**実装ファイル**: `egui-app/src/ui/toolbar.rs`, `egui-app/src/state/app_state.rs`

### 2. 新規 `AppMessage` の追加 🔵

**信頼性**: 🔵 *interfaces.rs・dataflow.md より*

`egui-app/src/state/messages.rs` に後続タスクが利用するメッセージを定義する。

- `ComparisonStudyLoadFailed(String)`
- `SurfacePlotDone(SurfacePlotResult)`
- `SurfacePlotFailed(String)`
- `ChartCaptureFailed(String)`

### 3. `WidgetStates` と補助状態の置き場整備 🔵

**信頼性**: 🔵 *architecture.md の変更対象ディレクトリより*

`egui-app/src/ui/widget_states.rs` に Surface Plot と capture の一時状態を追加する。ここでは詳細実装までは行わず、後続タスクが差し込める最小構造まで整える。
