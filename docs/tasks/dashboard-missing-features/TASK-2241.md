## タスク概要

Pareto Scatter 2D にドラッグ矩形による brush selection を実装し、選択範囲内 trial を `selected_indices` に書き戻す。まずは通常ドラッグと空白クリック解除を成立させ、Shift+ドラッグの加算選択は要件に沿って可能なら同タスクで含める。

## 実装詳細

### 1. drag rectangle state の追加 🔵

**信頼性**: 🔵 *pareto_2d.rs の既存 highlight 処理より*

ドラッグ開始点・現在点・確定矩形を state として保持し、UI 上に矩形を描画する。

**実装ファイル**: `egui-app/src/ui/widgets/pareto_2d.rs`

### 2. 点の内包判定と `selected_indices` 更新 🔵

**信頼性**: 🔵 *REQ-006-B より*

plot 座標から trial index を逆引きし、矩形内に入った点だけを選択集合として `AppState` へ反映する。

### 3. 解除操作と空選択処理 🟡

**信頼性**: 🟡 *REQ-006-F は推測要件を含むため*

空白クリックで選択解除、0 件選択時は `selected_indices` を空にするか全件へ戻すかを要件どおり整理する。
