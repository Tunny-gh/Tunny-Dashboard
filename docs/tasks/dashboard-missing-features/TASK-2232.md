## タスク概要

`selected_indices ∪ pinned_trials` を実効可視集合として扱う共通ヘルパーを導入し、Trial Table・PDP・各チャートが同じ基準で表示判定できる導線を作る。Brushing と Pinning の統合ポイントとなる基盤タスク。

## 実装詳細

### 1. 共通 helper の追加 🔵

**信頼性**: 🔵 *design-interview.md Q5 より*

`merge_selected_with_pinned()` と `filter_rows_for_display()` を pure function として実装する。順序は元の `trial_rows` を保つ。

**実装ファイル**: `egui-app/src/state/app_state.rs` または `egui-app/src/ui/widgets/trial_table.rs` の共通化先

### 2. Trial Table / Render への導線整備 🔵

**信頼性**: 🔵 *architecture.md の変更対象一覧より*

後続 UI タスクが使いやすいように、Trial Table と `render_chart.rs` が共通 helper を呼べる形に整える。

### 3. 全件表示の後方互換維持 🔵

**信頼性**: 🔵 *既存 `get_display_rows()` の挙動より*

`selected_indices.is_empty()` のときに突然全件が消えないよう、既存 UX を維持する。
