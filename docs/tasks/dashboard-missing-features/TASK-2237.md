## タスク概要

既存の `Show data` overlay 実装を活かしつつ、PDP に渡す trial 集合を `selected ∪ pinned` ベースへ切り替える。新規 UI は増やさず、既存 toggle が期待どおり「現在見せたい試行だけ」を反映する状態に仕上げる。

## 完了条件

- [x] `render_chart.rs` が PDP に全件ではなく実効可視集合を渡す
- [x] selected が空のときは既存どおり全件 overlay を維持する
- [x] selected があるときは該当 rows と pinned rows だけが overlay 対象になる
- [x] `Show data` toggle の既存 UX を壊さない
- [x] 回帰テストが通る

## 実装詳細

### 1. PDP への入力 rows 差し替え 🔵

**信頼性**: 🔵 *design-interview.md に「greenfield ではない」と明記されているため*

`render_chart.rs` の PDP 分岐で、従来の全 `trial_rows` ではなく共通 helper で絞り込んだ rows を渡す。

**実装ファイル**: `egui-app/src/ui/render_chart.rs`, `egui-app/src/ui/widgets/pdp_chart.rs`

### 2. overlay toggle の後方互換維持 🔵

**信頼性**: 🔵 *既存 `show_observed` 実装より*

toggle の場所・文言・初期値は変えず、対象データだけを切り替える。

### 3. pinning 連動確認 🔵

**信頼性**: 🔵 *REQ-004-D より*

pin された trial が selected から外れても overlay 候補に残ることを確認する。
