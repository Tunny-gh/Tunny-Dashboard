## タスク概要

対象チャートセルの描画結果を PNG として保存する。本タスクでは viewport/image 取得、対象セル矩形の crop、PNG encode、`rfd::FileDialog::save_file()` による保存までを end-to-end で実装する。

## 実装詳細

### 1. viewport capture と矩形 crop 🟡

**信頼性**: 🟡 *REQ-008-D・設計文書の cell-level screenshot 方針より*

利用可能な eframe/egui API を使って viewport 画像を取得し、対象セル矩形で crop する helper を実装する。

**実装ファイル**: `egui-app/src/ui/grid_canvas.rs`, `egui-app/src/io/chart_capture.rs`（新規想定）

### 2. PNG encode とファイル保存 🔵

**信頼性**: 🔵 *REQ-008-C・NFR-201 より*

crop 結果を PNG encode し、保存先は必ず `rfd::FileDialog` 経由で選ばせる。

### 3. 失敗パスのユーザー通知 🟡

**信頼性**: 🟡 *capture backend の可否が実装環境依存のため*

API 非対応、画像取得失敗、書き込み失敗で異なる原因が分かるメッセージを返す。
