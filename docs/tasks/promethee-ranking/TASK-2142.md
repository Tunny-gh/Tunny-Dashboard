## 実装詳細

### 1. McdmRankChart へ cached_promethee フィールド追加 🔵

**信頼性**: 🔵 *REQ-PR-020・architecture.md Layer 4 より*

**実装ファイル**: `egui-app/src/ui/widgets/mcdm_chart.rs`

既存の `cached_vikor: Option<VikorResult>` の後に追加:

```rust
pub cached_promethee: Option<PrometheeResult>,
```

`Default` 実装または `McdmRankChart::new()` がある場合は `cached_promethee: None` を追加する。

### 2. コンボボックスへの PrometheeI / II 追加 🔵

**信頼性**: 🔵 *REQ-PR-021・McdmMethod::all() 自動追加パターンより*

`McdmMethod::all()` を走査してコンボボックスの選択肢を生成している既存コードは変更不要。TASK-2139 で `all()` に追加した時点で自動的にコンボボックスに表示される。

### 3. キャッシュ切替ロジック 🟡

**信頼性**: 🟡 *REQ-PR-021・dataflow.md フロー4・cached_topsis パターンから妥当な推測*

コンボボックス切替時、PrometheeI ↔ PrometheeII は `cached_promethee` から即時復元:

```rust
// 切替時の復元ロジック
if (new_method == McdmMethod::PrometheeI || new_method == McdmMethod::PrometheeII)
    && self.cached_promethee.is_some()
{
    // pending_compute を設定しない（キャッシュから復元）
}
```

### 4. PROMETHEE I バー描画（2本バー） 🔵

**信頼性**: 🔵 *REQ-PR-022・ユーザヒアリング（Φ+青 + Φ-赤の2本横並び）より*

```rust
McdmResult::PrometheeI(r) => {
    for &idx in &r.ranked_indices_i {
        let i = idx as usize;
        // Φ+ バー（青）
        draw_bar(ui, r.phi_plus[i],  Color32::from_rgb(0x0c, 0x6a, 0xc0));
        // Φ- バー（赤）
        draw_bar(ui, r.phi_minus[i], Color32::from_rgb(0xc0, 0x20, 0x20));
    }
}
```

### 5. PROMETHEE II バー描画（Φnet、負値オレンジ） 🔵

**信頼性**: 🔵 *REQ-PR-023・ユーザヒアリング（負値はオレンジ、幅=絶対値）より*

```rust
McdmResult::PrometheeII(r) => {
    for &idx in &r.ranked_indices_ii {
        let i = idx as usize;
        let color = if r.phi_net[i] >= 0.0 {
            Color32::from_rgb(0x0c, 0x6a, 0xc0)  // 青
        } else {
            Color32::from_rgb(0xe0, 0x70, 0x00)  // オレンジ
        };
        draw_bar(ui, r.phi_net[i].abs(), color);
    }
}
```
