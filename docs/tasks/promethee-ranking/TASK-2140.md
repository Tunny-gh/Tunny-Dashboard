## 実装詳細

### 1. McdmDone ハンドラへの Promethee 分岐追加 🔵

**信頼性**: 🔵 *architecture.md Layer 2・dataflow.md フロー2 より*

**実装ファイル**: `egui-app/src/state/message_handler.rs`

既存の match ブロックに以下を追加:

```rust
McdmResult::PrometheeI(r) | McdmResult::PrometheeII(r) => {
    widget_states.mcdm_chart.cached_promethee = Some(r.clone());
}
```

`cached_promethee` フィールドは TASK-2142 で `McdmRankChart` に追加される。このタスク実施時点では先行して `Option<PrometheeResult>` フィールドを追加しておく。

### 2. McdmRankChart への cached_promethee フィールド追加（先行実装） 🟡

**信頼性**: 🟡 *architecture.md Layer 4・dataflow.md フロー4（キャッシュ共有）より*

`egui-app/src/ui/widgets/mcdm_chart.rs` の `McdmRankChart` 構造体に追加:

```rust
pub cached_promethee: Option<PrometheeResult>,
```

`Default` 実装がある場合は `cached_promethee: None` を追加する。
