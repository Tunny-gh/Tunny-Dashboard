### 2. McdmMethod enum 拡張 🔵

**信頼性**: 🔵 *REQ-PR-011・TC-PR-011-01〜03 より*

```rust
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum McdmMethod {
    Topsis,
    Vikor,
    PrometheeI,   // 追加
    PrometheeII,  // 追加
}

impl McdmMethod {
    pub fn label(&self) -> &'static str {
        match self {
            McdmMethod::Topsis      => "TOPSIS",
            McdmMethod::Vikor       => "VIKOR",
            McdmMethod::PrometheeI  => "PROMETHEE I",
            McdmMethod::PrometheeII => "PROMETHEE II",
        }
    }

    pub fn all() -> &'static [McdmMethod] {
        &[McdmMethod::Topsis, McdmMethod::Vikor, McdmMethod::PrometheeI, McdmMethod::PrometheeII]
    }
}
```

### 3. McdmResult enum 拡張 🔵

**信頼性**: 🔵 *REQ-PR-014・ユーザヒアリング（2バリアント分割）より*

```rust
#[derive(Debug, Clone)]
pub enum McdmResult {
    Topsis(TopsisResult),
    Vikor(VikorResult),
    PrometheeI(PrometheeResult),   // 追加: ranked_indices_i / phi_plus を primary として使用
    PrometheeII(PrometheeResult),  // 追加: ranked_indices_ii / phi_net を primary として使用
}
```

### 4. McdmResult メソッドへの match アーム追加 🔵

**信頼性**: 🔵 *REQ-PR-012, REQ-PR-013・interfaces.rs より*

- `primary_scores()`: PrometheeI → &r.phi_plus, PrometheeII → &r.phi_net
- `ranked_indices()`: PrometheeI → &r.ranked_indices_i, PrometheeII → &r.ranked_indices_ii
- `duration_ms()`: PrometheeI(r) | PrometheeII(r) => r.duration_ms
- `method()`: PrometheeI(_) => McdmMethod::PrometheeI, PrometheeII(_) => McdmMethod::PrometheeII
- `method_label()`: self.method().label()（変更不要）
