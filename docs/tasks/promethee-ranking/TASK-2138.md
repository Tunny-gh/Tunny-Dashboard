## タスク概要

`rust_core/src/mcdm/mod.rs` に `pub mod promethee;` を追加し、`rust_core/src/lib.rs` に `pub use mcdm::promethee;` を追加する。これにより `tunny_core::mcdm::promethee::compute_promethee` が `egui-app` から呼び出せるようになる。
