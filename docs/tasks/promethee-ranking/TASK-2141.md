## タスク概要

`egui-app/src/ui/chart_registry.rs` の `pending_compute` ハンドラ内の match 式に `McdmMethod::PrometheeI | McdmMethod::PrometheeII` 分岐を追加する。`crate::app::spawn_task` を使って別スレッドで `tunny_core::mcdm::promethee::compute_promethee` を実行し、結果を `AppMessage::McdmDone(McdmResult::PrometheeI/II(...))` として送信する。

## 実装詳細

### 1. pending_compute ハンドラへの Promethee 分岐追加 🔵

**信頼性**: 🔵 *architecture.md Layer 3・implementation-guide.md Step 6 より*

**実装ファイル**: `egui-app/src/ui/chart_registry.rs`

既存の `McdmMethod::Vikor => { ... }` の後に追加:

```rust
McdmMethod::PrometheeI | McdmMethod::PrometheeII => {
    let method = req.method;
    crate::app::spawn_task(tx, move || {
        match tunny_core::mcdm::promethee::compute_promethee(
            &objectives, n_trials, n_objectives, &weights, &is_minimize,
        ) {
            Ok(r) => {
                let result = crate::state::results::PrometheeResult {
                    phi_plus: r.phi_plus,
                    phi_minus: r.phi_minus,
                    phi_net: r.phi_net,
                    ranked_indices_i: r.ranked_indices_i,
                    ranked_indices_ii: r.ranked_indices_ii,
                    duration_ms: r.duration_ms,
                };
                let mcdm = if method == McdmMethod::PrometheeI {
                    McdmResult::PrometheeI(result)
                } else {
                    McdmResult::PrometheeII(result)
                };
                AppMessage::McdmDone(mcdm)
            }
            Err(e) => AppMessage::Error(format!("PROMETHEE computation failed: {e}")),
        }
    });
}
```

### 2. 既存パターンとの整合性確認 🔵
