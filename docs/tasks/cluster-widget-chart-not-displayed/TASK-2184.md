**実装ファイル**: `egui-app/src/state/message_handler.rs`

### 2. エラー整形ヘルパー追加 🔵

**実装ファイル**: `egui-app/src/state/results.rs` または `egui-app/src/state/messages.rs`

### 3. 不整合ガード追加 🟡

ラベル件数と trial 件数の不整合を検知し、結果反映を拒否する。
