`chart_registry` で `pending_compute` を取得し、`spawn_task` によってクラスタリング計算を非同期起動、完了時に `AppMessage::ClusteringDone` を送信する。

## 実装詳細

### 1. 実行要求の取り出し 🔵

**信頼性**: 🔵 *architecture.md 状態管理レイヤーより*

`ChartId::ClusterScatter` 分岐で pending_compute を `take()` する。

**実装ファイル**: `egui-app/src/ui/chart_registry.rs`

### 2. 非同期計算起動 🔵

**信頼性**: 🔵 *既存 `spawn_task` パターンより*

PCA→kmeans→stats を background task で実行する。

### 3. 完了メッセージ構築と送信 🔵

**信頼性**: 🔵 *REQ-002 より*

成功時に `AppMessage::ClusteringDone`、失敗時に失敗メッセージ経路へ変換する。
