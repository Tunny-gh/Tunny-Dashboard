## タスク概要

D&Dペイロードの統合型 `DragPayload` を定義し、右パネルからの新規配置とセル間移動を区別できるようにする。現在の `PanelItem` ペイロードを `DragPayload` に置き換える準備として、型定義とトレイト実装を行う。

## 実装詳細

### 1. DragPayload enum の定義 🔵

**信頼性**: 🔵 *設計文書 interfaces.rs より*

**実装ファイル**: `egui-app/src/state/layout_state.rs`

```rust
/// D&D ペイロードの統合型（PanelItem を置き換え）
#[derive(Debug, Clone, PartialEq, Eq, Hash)]
pub enum DragPayload {
    /// 右パネルからの新規配置
    NewWidget(PanelItem),
    /// セル間移動（元セル情報付き）
    MoveFromCell {
        item: PanelItem,
        row: usize,
        col: usize,
    },
}

impl DragPayload {
    /// ペイロードから PanelItem を取得する
    pub fn item(&self) -> &PanelItem {
        match self {
            DragPayload::NewWidget(item) => item,
            DragPayload::MoveFromCell { item, .. } => item,
        }
    }
}
```

### 2. 既存コードへの影響確認 🔵

**信頼性**: 🔵 *既存コード分析より*

- `DragPayload` は新規型のため、既存コードには影響しない

- `DragPayload` は `layout_state.rs` の既存 `PanelItem` 定義の直後に配置
