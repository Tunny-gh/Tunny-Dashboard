- [ ] アプリケーションを起動し、手動で以下の操作が可能である:

  - 移動後→ハンドルでリサイズ（移動先で正しくリサイズ可能）

## 実装詳細

### 1. ビルド確認 🔵

**信頼性**: 🔵 *標準的な確認項目*

```bash
cargo build
cargo test
cargo clippy
```

### 2. 統合動作確認シナリオ 🔵

**信頼性**: 🔵 *設計文書・各タスクの完了条件より*

以下のシナリオを手動で確認:

| シナリオ | 操作 | 期待結果 |
|---|---|---|
| S1: 削除 | チャート配置→✕クリック | セルが空になる |
| S2: 移動 | チャート配置→別セルにD&D | 元セル空、先セルに配置 |
| S3: 横長リサイズ | チャート配置→右端ハンドルクリック | 2x1 表示 |
| S4: 縦長リサイズ | チャート配置→下端ハンドルクリック | 1x2 表示 |
| S5: リサイズ後削除 | 2x1→✕クリック | 結合セル解放＋コンテンツ削除 |
| S6: 移動後リサイズ | 移動→ハンドルクリック | 移動先でリサイズ成功 |
| S7: コンテキスト互換 | 右クリック→拡張/縮小/クリア | 従来通り動作 |

### 3. エッジケースの確認 🟡

**信頼性**: 🟡 *設計から妥当な推測*

| ケース | 確認内容 |
|---|---|
| 全セル配置済み時のD&D | ドロップ先なしでドラッグキャンセル |
| 最大グリッドでのハンドル | 境界セルにハンドル非表示 |
| 結合セルへのD&D | ドロップ不可（merged_into チェック） |
