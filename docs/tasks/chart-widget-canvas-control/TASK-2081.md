配置済みチャートのセル内にドラッグソースを設定し、セル間のドラッグ&ドロップ移動を可能にする。ユーザーが配置済みチャートをドラッグし、別のセルにドロップすると移動する。

## 実装詳細

### 1. セル内ドラッグソースの実装 🔵

**信頼性**: 🔵 *設計文書 architecture.md・egui 0.30 D&D API より*

**実装ファイル**: `egui-app/src/ui/grid_canvas.rs`

`render_cell_content` 関数内で、`Some(item)` の場合にチャート描画を `dnd_drag_source` でラップする。

```rust
fn render_cell_content(ui, app_state, widgets, cell, row, col, tx) {
    match &cell.content {
        Some(item) => {
            let payload = DragPayload::MoveFromCell {
                item: item.clone(),
                row,
                col,
            };
            let drag_id = egui::Id::new("cell_drag").with(row).with(col);
            ui.dnd_drag_source(drag_id, payload, |ui| {
                // チャート描画
                chart_registry::show_cell_chart(ui, app_state, widgets, &id, tx);
            });
        }
        None => { ui.label("— No chart selected —"); }
    }
}
```

### 2. dnd_drag_source と dnd_drop_zone のネスト 🔵

**信頼性**: 🔵 *egui 0.30 API でネスト可能*

セル全体が `dnd_drop_zone` でラップされており、その中でチャート描画が `dnd_drag_source` でラップされる。egui 0.30 ではこのネストがサポートされている。

### 3. 同一セルへのドロップ防止 🟡

**信頼性**: 🟡 *設計から妥当な推測*

`GridLayout::place()` は内部で同じアイテムを含む全セルをクリアしてから配置する。同じセルにドロップした場合、クリア後に同じセルに配置されるため実質的に何もしない。追加のチェックは不要だが、動作確認で検証する。

## 単体テスト要件

### テストケース1: セルからドラッグ開始時に DragPayload が設定される 🔵

**信頼性**: 🔵 *設計文書より*

**Given**: セルにチャートが配置されている
**When**: セルのコンテンツをドラッグ開始
**Then**: DragPayload::MoveFromCell がペイロードに設定される

### テストケース2: 別セルへのドロップで移動する 🔵

**信頼性**: 🔵 *GridLayout::place() の動作より*

**Given**: [0][0] に ParetoScatter2D、[1][1] は空
**When**: [0][0] からドラッグして [1][1] にドロップ
**Then**: [0][0] が空、[1][1] に ParetoScatter2D が配置

### テストケース3: 空セルにドラッグソースが設定されない 🔵

**信頼性**: 🔵 *設計文書より*

**Given**: セルが空
**When**: グリッドを描画
**Then**: 空セルには dnd_drag_source が設定されない

### テストケース4: 移動先が結合セルの場合はドロップ不可 🔵

**信頼性**: 🔵 *既存 merged_into チェックより*

**Given**: 移動先セルが他セルに結合されている
**When**: ドロップを試行
**Then**: 配置されない（place が merged_into をチェック）
