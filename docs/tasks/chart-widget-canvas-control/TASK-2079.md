## 実装詳細

### 1. ✕ボタン配置関数の実装 🔵

**信頼性**: 🔵 *設計文書 architecture.md より*

**実装ファイル**: `egui-app/src/ui/grid_canvas.rs`

`register_close_button` 関数を新規追加。グリッド描画ループ内で、`dnd_drop_zone` の外側（親UIレベル）で呼び出す。

```rust
const CLOSE_BUTTON_SIZE: f32 = 16.0;

fn register_close_button(
    ui: &mut egui::Ui,
    cell_rect: egui::Rect,
    row: usize,
    col: usize,
    pending_actions: &mut Vec<CellAction>,
) {
    let close_size = egui::vec2(CLOSE_BUTTON_SIZE, CLOSE_BUTTON_SIZE);
    let close_rect = egui::Rect::from_min_size(
        cell_rect.right_top() - egui::vec2(close_size.x, 0.0),
        close_size,
    );

    let close_resp = ui.put(
        close_rect,
        egui::Button::new(
            egui::RichText::new("✕").small().color(egui::Color32::from_gray(180))
        ).frame(false),
    );

    if close_resp.hovered() {
        ui.painter().rect_filled(
            close_rect,
            2.0,
            egui::Color32::from_rgba_unmultiplied(255, 100, 100, 40),
        );
    }

    if close_resp.clicked() {
        pending_actions.push(CellAction::Clear(row, col));
    }
}
```

### 2. グリッド描画ループへの統合 🔵

**信頼性**: 🔵 *既存 grid_canvas.rs 構造分析より*

`show_grid_canvas` のセル描画ループ内で、`cell.content.is_some()` の場合に `register_close_button` を呼び出す。`dnd_drop_zone` の外側（ループ本体）で実行し、セル内の子UIとの入力競合を避ける。
