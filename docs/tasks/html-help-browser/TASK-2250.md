### 1. theory/ja/ 既存ファイルの数式 LaTeX 記法移行 🔵

**信頼性**: 🔵 *TASK-2249 の実績パターンより*

theory/ja/ 配下の既存Markdownファイルの数式を、英語版（TASK-2249）と同じパターンで LaTeX 記法に移行する。対象ディレクトリ:

- `theory/ja/sensitivity-analysis/*.md`
- `theory/ja/mcdm/*.md`
- `theory/ja/surrogate-models/*.md`
- `theory/ja/clustering/*.md`
- `theory/ja/optimization/*.md`

移行パターンは TASK-2249 の具体例に準拠する:

```
変更前: r_ij = v_ij / sqrt(Σ_i v_ij²)
変更後: $$r_{ij} = \frac{v_{ij}}{\sqrt{\sum_i v_{ij}^2}}$$
```

**実装ファイル**: `theory/ja/**/*.md`（widgets/ 以外）
