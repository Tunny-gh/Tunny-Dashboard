## テスト要件

### ビルド確認 🔵

**信頼性**: 🔵 *基本的なビルド要件より*

```bash
cargo build --release
```

- コンパイルエラーなし
- ビルド時間の増加確認（`+5秒以内`、NFR-002）
- バイナリサイズ確認（KaTeX 埋め込みにより +200KB 程度が許容範囲）

### 全テスト通過確認 🔵

**信頼性**: 🔵 *基本的なテスト要件より*

```bash
cargo test
```

- 全テストが通ること
- 旧テスト（`help_modal_state_default_is_closed` 等）が削除済みであること

### E2E: ヘルプボタンクリック→ブラウザ起動 🔵

**信頼性**: 🔵 *要件定義 REQ-020〜023 より*

手動テスト手順:
1. アプリを起動してスタディを読み込む
2. ウィジェット（例: Trial Table）のヘルプボタンをクリック
3. OS デフォルトブラウザが自動的に開くことを確認
4. HTML が正しく表示されること（ヘッダー、本文、スタイリング）

### E2E: KaTeX 数式レンダリング確認 🔵

**信頼性**: 🔵 *要件定義 REQ-011, REQ-012 より*

手動テスト手順:
1. ImportanceChart のヘルプを開く
2. TOPSIS の正規化式 `$$r_{ij} = \frac{v_{ij}}{\sqrt{\sum_i v_{ij}^2}}$$` が数式表示されることを確認
3. Sobol の一次/全次指標の数式が表示されることを確認
4. コードブロック（Python等）はプレーンテキストのままであることを確認

### E2E: 言語切替 🔵

**信頼性**: 🔵 *要件定義 REQ-030〜032 より*

手動テスト手順:
1. 言語切替メニューで「日本語」を選択
2. ヘルプボタンをクリック
3. 日本語HTMLが開くことを確認
4. 「English」に戻して再度クリックし、英語HTMLが開くことを確認

### E2E: オフライン動作確認 🔵

**信頼性**: 🔵 *要件定義 REQ-013 より*

手動テスト手順:
1. ネットワークを切断した状態でアプリを起動
2. ヘルプを開く
3. KaTeX 数式が正しく表示されること（CDN 参照なし）

### E2E: エラーハンドリング 🟡

**信頼性**: 🟡 *要件定義 EDGE-001, EDGE-002 から妥当な推測*

手動テスト手順（可能な範囲で確認）:
- 一時ディレクトリへの書き込み失敗シナリオ（権限変更等）でエラーが表示されること
- エラー発生後もアプリがクラッシュしないこと
