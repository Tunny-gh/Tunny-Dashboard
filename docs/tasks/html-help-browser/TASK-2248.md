### 2. KaTeX アセットの配置 🔵

**信頼性**: 🔵 *設計文書より*

KaTeX v0.16 の以下ファイルを `egui-app/help-assets/` にダウンロードして配置する。

- `katex.min.css` — KaTeX スタイルシート
- `katex.min.js` — KaTeX コアエンジン
- `auto-render.min.js` — 数式自動検出・レンダリング

```bash
mkdir -p egui-app/help-assets
curl -L https://cdn.jsdelivr.net/npm/katex@0.16/dist/katex.min.css -o egui-app/help-assets/katex.min.css
curl -L https://cdn.jsdelivr.net/npm/katex@0.16/dist/katex.min.js -o egui-app/help-assets/katex.min.js
curl -L https://cdn.jsdelivr.net/npm/katex@0.16/dist/contrib/auto-render.min.js -o egui-app/help-assets/auto-render.min.js
```

**実装ファイル**: `egui-app/help-assets/`

### 3. build.rs に generate_help_html_files() 追加 🔵

**信頼性**: 🔵 *設計文書より*

`egui-app/build.rs` に Markdown→HTML 変換パイプラインを実装する。メインエントリポイントとして `generate_help_html_files()` 関数を追加する。

処理フロー:
1. `theory/en/` と `theory/ja/` ディレクトリを再帰的にスキャンして `.md` ファイルを収集
2. 各 `.md` ファイルを pulldown-cmark でパースしてHTMLボディを生成
3. スタンドアロンHTMLラッパーで包む
4. `OUT_DIR/help/{en,ja}/` に出力

`cargo:rerun-if-changed=theory/` ディレクティブを出力し、theory 配下の変更時に自動リビルドをトリガーする。

```rust
fn generate_help_html_files() {
    println!("cargo:rerun-if-changed=theory/");
    // theory/en/ と theory/ja/ をスキャンしてHTML生成
}
```

**実装ファイル**: `egui-app/build.rs`

### 4. pulldown-cmark Parser による md→html body 生成 🔵

**信頼性**: 🔵 *設計文書より*

pulldown-cmark の `Parser` を使用して Markdown をHTMLに変換する。標準的なMarkdown要素（見出し、太字、コードブロック、リスト、テーブル等）の変換をサポートする。

```rust
use pulldown_cmark::{Parser, Options, html};

fn markdown_to_html_body(md_content: &str) -> String {
    let mut options = Options::empty();
    options.insert(Options::ENABLE_TABLES);
    options.insert(Options::ENABLE_STRIKETHROUGH);
    options.insert(Options::ENABLE_TASKLISTS);
    let parser = Parser::new_ext(md_content, options);
    let mut html_output = String::new();
    html::push_html(&mut html_output, parser);
    html_output
}
```

**実装ファイル**: `egui-app/build.rs`

### 5. HTML ラッパー生成 🔵

**信頼性**: 🔵 *設計文書より*

生成されたHTMLボディを、完全なスタンドアロンHTML5ドキュメントとしてラップする。DOCTYPE宣言、headセクション（メタタグ、CSS）、bodyセクション、スクリプトを含む。

```rust
fn wrap_as_standalone_html(body: &str, katex_css: &str, katex_js: &str, auto_render_js: &str) -> String {
    format!(r#"<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <style>
        /* ライトテーマCSS */
        body {{ font-family: -apple-system, BlinkMacSystemFont, 'Segoe UI', sans-serif; ... }}
        /* KaTeX CSS インライン */
        {katex_css}
    </style>
</head>
<body>
    {body}
    <script>{katex_js}</script>
    <script>{auto_render_js}</script>
    <script>
        renderMathInElement(document.body, {{
            delimiters: [
                {{left: '$$', right: '$$', display: true}},
                {{left: '$', right: '$', display: false}}
            ]
        }});
    </script>
</body>
</html>"#)
}
```

**実装ファイル**: `egui-app/build.rs`

### 6. KaTeX auto-render による数式レンダリング 🔵

**信頼性**: 🔵 *設計文書より*

KaTeX auto-render スクリプトを用いて、`$...$`（インライン数式）と `$$...$$`（ディスプレイ数式）を自動的に検出・レンダリングする。設定はHTMLラッパー内のscriptタグで行う。

```javascript
renderMathInElement(document.body, {
    delimiters: [
        {left: '$$', right: '$$', display: true},
        {left: '$', right: '$', display: false}
    ]
});
```

**実装ファイル**: `egui-app/build.rs`（生成HTML内に埋め込み）
