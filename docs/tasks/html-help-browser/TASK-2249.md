## 具体例

### 変更パターン例

**変更前**（コードブロック内プレーンテキスト）:
```
r_ij = v_ij / sqrt(Σ_i v_ij²)
```

**変更後**（LaTeX ディスプレイ数式）:
```latex
$$r_{ij} = \frac{v_{ij}}{\sqrt{\sum_i v_{ij}^2}}$$
```

**変更前**（インラインプレーンテキスト）:
```
S(x_i) = V_i / V(Y)
```

**変更後**（LaTeX ディスプレイ数式）:
```latex
$$S(x_i) = \frac{V_i}{V(Y)}$$
```
