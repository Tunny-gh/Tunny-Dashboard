## 実装詳細

### 1. HelpLanguage enum 実装 🔵

**信頼性**: 🔵 *設計文書 interfaces.rs より*

`HelpLanguage` enum を実装する。`serde` の Serialize/Deserialize も付与し、将来の設定ファイル保存に対応する。

```rust
#[derive(Debug, Clone, Copy, PartialEq, Eq, Hash, serde::Serialize, serde::Deserialize)]
pub enum HelpLanguage {
    En,
    Ja,
}

impl Default for HelpLanguage {
    fn default() -> Self {
        Self::En
    }
}

impl HelpLanguage {
    pub fn code(&self) -> &'static str {
        match self {
            Self::En => "en",
            Self::Ja => "ja",
        }
    }
}
```

**実装ファイル**: `egui-app/src/ui/help/help_types.rs`

### 2. HelpContent struct 実装 🔵

**信頼性**: 🔵 *設計文書 interfaces.rs・要件定義 REQ-052 より*

旧 `HelpContent`（tabs: &[HelpTabDef]）を廃止し、HTML文字列を直接持つ新構造体に変更する。`html_en` / `html_ja` は `include_str!` で埋め込まれるため `&'static str` とする。

```rust
pub struct HelpContent {
    pub widget_name: &'static str,
    pub html_en: &'static str,
    pub html_ja: &'static str,
}

impl HelpContent {
    pub fn html(&self, lang: HelpLanguage) -> &'static str {
        match lang {
            HelpLanguage::En => self.html_en,
            HelpLanguage::Ja => self.html_ja,
        }
    }
}
```

**実装ファイル**: `egui-app/src/ui/help/help_types.rs`

### 3. 旧型の削除 🔵

**信頼性**: 🔵 *要件定義 REQ-050〜052 より*

以下の旧型を `help_types.rs` から削除する:

削除後、`help_modal.rs` と `help_content.rs` でコンパイルエラーが発生するが、それらは TASK-2256 と TASK-2252 で対処する。
