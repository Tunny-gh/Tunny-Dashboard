## タスク概要

`AppState` に `help_language: HelpLanguage` フィールドを追加し、言語設定をアプリケーション状態として保持できるようにする。また `WidgetStates` から `help_modal: HelpModalState` フィールドを削除する（`help_language` は `AppState` に移動するため）。`clear()` でリセットしない（`selected_colormap` と同じパターン）。

## 実装詳細

### 1. AppState.help_language フィールド追加 🔵

**信頼性**: 🔵 *設計文書 interfaces.rs・要件定義 REQ-031 より*

`AppState` 構造体に `help_language` フィールドを追加する。

```rust
// app_state.rs の AppState 構造体に追加:
pub struct AppState {
    // ... 既存フィールド ...

    // ── HTML Help Browser ──────────────────────────────────────
    /// ヘルプ表示言語（selected_colormap と同じパターンで clear() でリセットしない）
    pub help_language: HelpLanguage,
}
```

`AppState::new()` の初期化:

```rust
help_language: HelpLanguage::default(), // HelpLanguage::En
```

**実装ファイル**: `egui-app/src/state/app_state.rs`

### 2. AppState::clear() の非リセット確認 🔵

**信頼性**: 🔵 *設計文書 interfaces.rs（`selected_colormap` と同じパターン）より*

`clear()` メソッドに `help_language` のリセット行を**追加しない**。`selected_colormap` フィールドと同じ扱いで、ユーザーの言語設定は Study 切り替えを跨いで維持される。

コメントを `clear()` メソッド内に追加:
```rust
// help_language はユーザー設定を維持（selected_colormap と同じパターン）
```

**実装ファイル**: `egui-app/src/state/app_state.rs`

### 3. WidgetStates から help_modal 削除 🔵

**信頼性**: 🔵 *設計文書 architecture.md・要件定義 REQ-050〜051 より*

`widget_states.rs` の `WidgetStates` 構造体から `help_modal: HelpModalState` フィールドを削除する。`HelpModalState` は TASK-2251 で削除済みのため参照エラーが出る場合は削除する。

参照箇所:
- `widget_states.rs`: フィールド定義と `Default` 実装から削除
- `app.rs` や `layout.rs` からの参照: TASK-2255/2256 で対処するため、この時点では `#[allow(unused)]` などを使わず、コンパイルエラーを後続タスクへの作業指示として残す

**実装ファイル**: `egui-app/src/state/widget_states.rs` または対応するファイル
