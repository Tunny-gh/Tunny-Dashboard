## 実装詳細

### 1. CellToolbarAction::Help 処理変更 🔵

**信頼性**: 🔵 *設計文書 interfaces.rs・データフロー dataflow.md より*

`grid_canvas.rs`（または `app.rs`）の `CellToolbarAction::Help` ハンドラを変更する。

```rust
// 変更前:
CellToolbarAction::Help(help_item) => {
    widgets.help_modal.open = true;
    widgets.help_modal.item = Some(help_item.clone());
}

// 変更後:
CellToolbarAction::Help(help_item) => {
    if let Err(e) = crate::ui::help::help_launcher::open_help(
        &help_item,
        app.app_state.help_language,
    ) {
        app.load_error = Some(e);
    }
}
```

**実装ファイル**: `egui-app/src/ui/grid_canvas.rs`（または `CellToolbarAction` を処理しているファイル）

### 2. messages.rs に HelpLaunchFailed 追加 🔵

**信頼性**: 🔵 *設計文書 architecture.md より*

`AppMessage` enum に `HelpLaunchFailed` バリアントを追加する。ヘルプ起動失敗を非同期で通知する場合に使用（同期的にエラー処理する場合は不要）。

```rust
/// HTML Help ブラウザ起動失敗
HelpLaunchFailed(String),
```

実装時、同期的エラー処理（`load_error = Some(e)`）で十分であれば追加不要。設計文書の `messages.rs` への変更指示に基づき追加を検討する。

**実装ファイル**: `egui-app/src/state/messages.rs`

### 3. 旧ファイル削除: md_renderer.rs 🔵

**信頼性**: 🔵 *要件定義 REQ-050 より*

`egui-app/src/ui/help/md_renderer.rs` を削除する。このファイルはカスタム Markdown→egui レンダラーで、HTML ブラウザ表示に移行後は不要になる。

**対象ファイル**: `egui-app/src/ui/help/md_renderer.rs`（削除）

### 4. 旧ファイル削除: help_modal.rs 🔵

**信頼性**: 🔵 *要件定義 REQ-051 より*

`egui-app/src/ui/help/help_modal.rs` を削除する。`show_help_modal()` 関数は HTML ブラウザ表示に移行後は不要になる。

**対象ファイル**: `egui-app/src/ui/help/help_modal.rs`（削除）

### 5. help/mod.rs の整理 🔵

**信頼性**: 🔵 *設計文書 architecture.md より*

`egui-app/src/ui/help/mod.rs` を変更する。

```rust
// 変更前:
pub mod help_content;
pub mod help_modal;    // ← 削除
pub mod help_types;
pub mod md_renderer;   // ← 削除

// 変更後:
pub mod help_content;
pub mod help_launcher; // ← 追加（TASK-2253 で作成済み）
pub mod help_types;
```

**実装ファイル**: `egui-app/src/ui/help/mod.rs`

### 6. layout.rs から show_help_modal 参照削除 🔵

**信頼性**: 🔵 *要件定義 REQ-020・設計文書より*

`layout.rs` から `help_modal::show_help_modal()` の呼び出しを削除する（TASK-2255 で追加した言語切替UIに置き換え済み）。

**実装ファイル**: `egui-app/src/ui/layout.rs`
