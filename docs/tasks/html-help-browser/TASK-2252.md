## 実装詳細

### 1. get_help_html() 関数実装 🔵

**信頼性**: 🔵 *要件定義 REQ-032・設計文書より*

```rust
use crate::state::layout_state::{ChartId, PanelItem};
use crate::ui::help::help_types::HelpLanguage;

pub fn get_help_html(item: &PanelItem, lang: HelpLanguage) -> &'static str {
    let content = get_help_content_inner(item);
    content.html(lang)
}
```

`HelpContent` 構造体のインスタンスを返す内部関数 `get_help_content_inner()` を用意し、`html(lang)` で言語選択する。

**実装ファイル**: `egui-app/src/ui/help/help_content.rs`

### 2. include_str! パスを OUT_DIR HTML に変更 🔵

**信頼性**: 🔵 *要件定義 REQ-004・設計文書より*

`include_str!` の参照先を `theory/en/*.md` から `OUT_DIR/help/en/*.html` に変更する。`env!("OUT_DIR")` マクロを使用して絶対パスを構成する。

```rust
use crate::ui::help::help_types::{HelpContent, HelpLanguage};

fn importance_chart_help() -> HelpContent {
    HelpContent {
        widget_name: "importance-chart",
        html_en: include_str!(concat!(env!("OUT_DIR"), "/help/en/sensitivity-analysis/overview.html")),
        html_ja: include_str!(concat!(env!("OUT_DIR"), "/help/ja/sensitivity-analysis/overview.html")),
    }
}
```

なお、ImportanceChart のように複数タブを持っていたものは、HTML内で複数セクションとして統合された単一ファイルに変換される（TASK-2249/2250 で LaTeX 移行済みの HTML）。

**実装ファイル**: `egui-app/src/ui/help/help_content.rs`
