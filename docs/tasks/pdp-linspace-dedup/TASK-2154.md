### grid.rs の作成 🔵

**信頼性**: 🔵 *設計文書 architecture.md 詳細設計1より*

`rust_core/src/core/math/grid.rs` に以下の関数を作成：

```rust
pub(crate) fn linspace(min: f64, max: f64, n: usize) -> Vec<f64> {
    if n == 0 { return vec![]; }
    if n == 1 { return vec![(min + max) / 2.0]; }
    (0..n).map(|i| min + (max - min) * i as f64 / (n - 1) as f64).collect()
}
```
