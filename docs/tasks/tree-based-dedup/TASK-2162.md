## 主要実装項目

### 1. types.rs の型統合 🔵

**信頼性**: 🔵 *要件 REQ-001〜004・設計文書 §2 より*

`rust_core/src/sensitivity/types.rs` で既存の4つの重複型定義を置換:

```rust
/// Tree-based 感度分析の共通結果型
#[derive(Debug, Clone)]
pub struct TreeImportanceResult {
    pub importances: Vec<Vec<f64>>, // [param][objective]
    pub r_squared: Vec<f64>,        // [objective]
}

pub type MdiResult = TreeImportanceResult;
pub type RfAnovaResult = TreeImportanceResult;
pub type ShapResult = TreeImportanceResult;
pub type PermutationResult = TreeImportanceResult;
```

**注意**:
- `serde` derive は現状不要（既存4型にも付与されていないため）🟡
- 外部クレートから `MdiResult` 等の名前でアクセスしている箇所は型エイリアスにより引き続き動作する 🔵
- `SensitivityResult` のフィールド型 `Option<RfAnovaResult>` 等は型エイリアス経由でそのまま動作するため変更不要 🔵

### 2. mod.rs への pub use 追加 🔵

**信頼性**: 🔵 *要件 REQ-004・設計文書 §3 より*

`rust_core/src/sensitivity/mod.rs` の `pub use types::{ ... }` ブロックに `TreeImportanceResult` を追加する:

```rust
pub use types::{
```
