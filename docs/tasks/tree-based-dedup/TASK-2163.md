### 1. common.rs での transpose_to_tree_result 追加 🔵

**信頼性**: 🔵 *要件 REQ-201〜202・設計文書 §6 より*

`rust_core/src/sensitivity/analysis/common.rs` に以下を追加:

```rust
use super::super::types::TreeImportanceResult;

pub(super) fn transpose_to_tree_result(
    importances_by_objective: &[Vec<f64>],
    r_squared: Vec<f64>,
    param_count: usize,
    objective_count: usize,
) -> TreeImportanceResult {
    TreeImportanceResult {
        importances: transpose_importances_matrix(
            importances_by_objective,
            param_count,
            objective_count,
        ),
        r_squared,
    }
}
```

**信頼性**: 🔵 *要件 REQ-301・設計文書 §7 より*
