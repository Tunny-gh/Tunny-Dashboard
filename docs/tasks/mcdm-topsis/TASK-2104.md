## 実装詳細

### 1. McdmChart構造体の定義 🔵

**ファイル**: `egui-app/src/ui/widgets/mcdm_chart.rs`

```rust
pub struct McdmChart {
    pub method: McdmMethod,
    pub weights: Vec<f64>,
    pub computing: bool,
    pub pending_compute: Option<(McdmMethod, Vec<f64>)>,
    pub top_n: McdmTopN,
    pub view_mode: McdmViewMode,
}
```

- `method`: MCDM手法を選択する列挙型（ComboBoxで選択）
- `weights`: 各目的関数の重み（スライダーで設定、0.0〜1.0）
- `computing`: 計算中フラグ（スピナー表示用）
- `pending_compute`: 計算要求ペイロード（chart_registryが検出してspawn_task実行）
- `top_n`: 上位N件表示切替
- `view_mode`: 表示モード切替（チャート/テーブル/両方）

### 2. McdmTopN列挙型 🔵

```rust
pub enum McdmTopN {
    Top5,
    Top10,
    Top20,
}

impl McdmTopN {
    pub fn value(&self) -> usize {
        match self {
            McdmTopN::Top5 => 5,
            McdmTopN::Top10 => 10,
            McdmTopN::Top20 => 20,
        }
    }
}
```

### 3. McdmViewMode列挙型 🟡

```rust
pub enum McdmViewMode {
    ChartOnly,
    TableOnly,
    ChartAndTable,
}
```

将来的に手法ごとに適した表示モードが異なる可能性があるため、列挙型として定義。

描画要素：

- **Runボタン**: `ui.button("Run")` 押下で `pending_compute` 設定 🔵

### 5. Runボタンの動作 🔵

```rust
if ui.add_enabled(!self.computing, egui::Button::new("Run")).clicked() {
    let normalized = normalize_weights(&self.weights);
    self.pending_compute = Some((self.method, normalized));
    self.computing = true;
}
```

ImportanceChartパターンに従い、`pending_compute` にペイロードを格納し `computing` を true に設定。

### 6. 重み正規化 🔵

```rust
fn normalize_weights(weights: &[f64]) -> Vec<f64> {
    let sum: f64 = weights.iter().sum();
    if sum == 0.0 {
        // ゼロ除算回避: 等しい重みを返す
        let n = weights.len() as f64;
        vec![1.0 / n; weights.len()]
    } else {
        weights.iter().map(|&w| w / sum).collect()
    }
}
```

TOPSIS理論に基づく重み正規化（`w_i / sum(w)`）。全重みがゼロの場合は等重みにフォールバック。

### 7. Default実装 🔵

```rust
impl Default for McdmChart {
    fn default() -> Self {
        Self {
            method: McdmMethod::Topsis,
            weights: Vec::new(),  // 初期化時に目的関数数に応じて1.0で埋める
            computing: false,
            pending_compute: None,
            top_n: McdmTopN::Top10,
            view_mode: McdmViewMode::ChartAndTable,
        }
    }
}
```

## UI/UX仕様

### Computing状態 🔵

```rust
if self.computing {
    ui.spinner();
    ui.label("Computing...");
}
```

計算中はスピナー + テキストを表示。Runボタンは `add_enabled(!self.computing, ...)` で無効化。

### 重み表示 🟡

各スライダーの横に正規化後の値を表示：

```
Objective 0: [========] 0.40  (normalized: 0.40)
Objective 1: [====    ] 0.30  (normalized: 0.30)
Objective 2: [======  ] 0.30  (normalized: 0.30)
Sum: 1.00
```

合計値の表示: `ui.label(format!("Sum: {:.2}", normalized_sum));`

### 空スタディ 🟡

スタディ未選択時のメッセージ表示：

```rust
if obj_count == 0 {
    ui.colored_label(egui::Color32::GRAY, "Select a study first");
    return;
}
```

### 目的関数なし 🟡

```rust
if obj_count == 0 {
    ui.add_enabled(false, egui::Button::new("Run"));
} else {
    // 通常のRunボタン
}
```
