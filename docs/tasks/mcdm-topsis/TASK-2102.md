## タスク概要

AppState, AppMessage, MessageHandler を TASK-2101 で定義した McdmResult 統一型に更新する。既存の `topsis_result: Option<TopsisResult>` を `mcdm_result: Option<McdmResult>` に置き換え、メッセージを TopsisDone から McdmDone に統一することで、将来の VIKOR/PROMETHEE II 追加に耐える基盤を構築する。

## 依存タスク

- **前提タスク**: [TASK-2101: McdmMethod/McdmResult/TopsisResult型定義更新](TASK-2101.md)
- **後続タスク**: [TASK-2103: ChartId + WidgetStates + 右パネル + chart_registry骨組み](TASK-2103.md)

- [ ] AppState::new() で mcdm_result が None で初期化される

### 1. AppState の mcdm_result フィールド変更 🔵

**信頼性**: 🔵 *architecture.md「AppState変更」・interfaces.rs AppState セクションより*

**実装ファイル**: `egui-app/src/state/app_state.rs`

pub struct AppState {

    // ...
    pub mcdm_result: Option<McdmResult>,  // 🔵 統一MCDM結果
    // ...

### 4. AppMessage の McdmDone 統一 🔵

**信頼性**: 🔵 *interfaces.rs「AppMessage変更」・dataflow.md McdmDone フローより*

**実装ファイル**: `egui-app/src/state/messages.rs`

```rust
// 変更前:
pub enum AppMessage {
    // ...
    TopsisDone(TopsisResult),
    // ...
}

// 変更後:
pub enum AppMessage {
    // ...
    McdmDone(McdmResult),  // 🔵 統一MCDMメッセージ
    // ...
}
```

### 5. MessageHandler の更新 🔵

**信頼性**: 🔵 *interfaces.rs「MessageHandler更新」・dataflow.md 非同期タスクフローより*

**実装ファイル**: `egui-app/src/state/message_handler.rs`

```rust
// 変更前:
AppMessage::TopsisDone(result) => {
    app_state.topsis_result = Some(result);
}

// 変更後:
AppMessage::McdmDone(result) => {
    app_state.mcdm_result = Some(result);           // 🔵 McdmResultを保存
    widget_states.mcdm.computing = false;            // 🔵 計算中フラグをリセット
}
```

**注意**: `widget_states.mcdm.computing` へのアクセスは TASK-2103 で WidgetStates に mcdm フィールドが追加されるまでコンパイルエラーとなる。TASK-2103 と並行作業する場合は、一時的に `// TODO: TASK-2103 で widget_states.mcdm 追加後に有効化` コメントを残すか、TASK-2103 完了後に統合確認を行うこと。

### 6. TopsisResult 旧フィールド参照箇所の更新 🔵

**信頼性**: 🔵 *architecture.md「型不一致の解決」・コード分析より*

TopsisResult の旧フィールド `ranking: Vec<usize>` を `ranked_indices: Vec<u32>` に参照置換する。`topsis_result` を `mcdm_result` に参照置換する。

主な変更対象:
- `topsis_result` → `mcdm_result` への参照置換
- `.ranking` → `.ranked_indices` への参照置換（ただし McdmResult 経由では `ranked_indices()` メソッドを使用）
- `TopsisDone` → `McdmDone` への参照置換

## 注意事項

- TASK-2103 で WidgetStates に mcdm フィールドが追加されるまで、`widget_states.mcdm.computing = false` の行はコンパイルエラーとなる。並行作業時は一時的にコメントアウトし、TASK-2103 完了後に有効化すること。
