## 実装詳細

### 1. 統合テスト: ジャーナル読み込み → Study選択 → MCDMチャート表示 → 重み設定 → 実行 → 結果検証 🟡

**信頼性**: 🟡 *統合テストは実装依存*

完全なワークフローを検証する統合テストを実装する。

```rust
#[test]
fn test_full_topsis_workflow() {
    let app = TestApp::new();
    app.load_journal("test_data/multi_objective.db");
    app.select_study(0);
    app.open_mcdm_chart();
    app.set_weights(&[0.3, 0.5, 0.2]);
    app.run_topsis();
    let result = app.get_mcdm_result();
    assert!(result.is_some());
    assert_eq!(result.unwrap().primary_scores().len(), app.trial_count());
}
```

### 2. 統合テスト: TOPSIS実行 → 棒グラフ切替 → Top N表示検証 🟡

**信頼性**: 🟡 *統合テストは実装依存*

TOPSIS実行後に棒グラフへ切り替え、上位N件の表示内容を検証する。

```rust
#[test]
fn test_topsis_bar_chart_display() {
    let app = setup_with_topsis_result();
    app.switch_to_bar_chart();
    let top_n = app.get_bar_chart_top_n();
    assert!(top_n.len() <= 5);
    // 最初の要素が最高スコアであることを確認
```

### 3. 統合テスト: TOPSIS実行 → McdmScoreカラーモード → 散布図色検証 🟡

**信頼性**: 🟡 *統合テストは実装依存*

### 4. 統合テスト: 重み変更 → 再実行 → 結果更新検証 🟡

**信頼性**: 🟡 *統合テストは実装依存*

重みを変更して再度TOPSISを実行し、結果が正しく更新されることを検証する。

```rust
#[test]
fn test_weight_change_rerun() {
    let app = setup_with_topsis_result();
    let first_scores = app.get_mcdm_result().unwrap().primary_scores().to_vec();
    app.set_weights(&[0.7, 0.2, 0.1]);
    app.run_topsis();
    let second_scores = app.get_mcdm_result().unwrap().primary_scores().to_vec();
    assert_ne!(first_scores, second_scores);
}
```

### 5. エッジケース: 単一目的関数StudyでのTOPSIS動作 🔵

**信頼性**: 🔵 *TOPSIS理論より*

目的関数が1つの場合でもTOPSISが正常動作することを確認する。単一目的の場合、全試行のスコアがその目的の相対順位に基づく。

```rust
#[test]
fn test_single_objective_topsis() {
    let app = TestApp::new();
    app.load_journal("test_data/single_objective.db");
    app.select_study(0);
    app.run_topsis();
    let result = app.get_mcdm_result();
    assert!(result.is_some());
}
```

### 6. エッジケース: NaN目的関数値を含むStudyの優雅な処理 🔵

**信頼性**: 🔵 *エッジケース設計より*

目的関数値にNaNが含まれるStudyでパニックが発生せず、NaN値が適切に処理（除外またはゼロ扱い）されることを確認する。

```rust
#[test]
fn test_nan_objective_values() {
    let app = TestApp::new();
    app.load_journal("test_data/with_nan_values.db");
    app.select_study(0);
    app.run_topsis();
    // パニックしないことを確認
    let result = app.get_mcdm_result();
    // NaNを含む試行は除外されるか、デフォルトスコアが割り当てられる
    if let Some(r) = result {
        for score in r.primary_scores() {
            assert!(!score.is_nan());
        }
    }
}
```
