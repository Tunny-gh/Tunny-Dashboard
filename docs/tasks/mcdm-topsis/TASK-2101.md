## 実装詳細

### 1. TopsisResult 型の rust_core 定義への統一 🔵

**信頼性**: 🔵 *architecture.md「型不一致の解決」・interfaces.rs TopsisResult 定義より*

**実装ファイル**: `egui-app/src/state/results.rs`

既存の2フィールド（scores, ranking: Vec<usize>）を rust_core 側の5フィールド定義に一致させる。

```rust
// 変更前:
pub struct TopsisResult {
    pub scores: Vec<f64>,
    pub ranking: Vec<usize>,
}

// 変更後（rust_core定義に統一）:
pub struct TopsisResult {
    pub scores: Vec<f64>,           // 各TrialのTOPSISスコア (0.0〜1.0)
    pub ranked_indices: Vec<u32>,   // スコア降順のTrialインデックス
    pub positive_ideal: Vec<f64>,   // 正理想解（目的関数次元）
    pub negative_ideal: Vec<f64>,   // 負理想解（目的関数次元）
    pub duration_ms: f64,           // 計算時間 (ms)
}
```

**影響範囲**: TopsisResult を参照している箇所（AppState, AppMessage, MessageHandler, mcdm_chartウィジェット等）は後続タスク TASK-2102 で更新する。本タスクでは型定義のみを変更し、コンパイルエラーは TASK-2102 で解消する。

### 3. McdmResult enum の定義 🔵

**信頼性**: 🔵 *interfaces.rs McdmResult 定義・ユーザヒアリングより*

**実装ファイル**: `egui-app/src/state/results.rs`

```rust
#[derive(Debug, Clone)]
pub enum McdmResult {
    Topsis(TopsisResult),
    // 将来追加: Vikor(VikorResult), Promethee2(Promethee2Result)
}

impl McdmResult {
    /// カラーモード用の一次スコア（0.0-1.0）を取得
    pub fn primary_scores(&self) -> &[f64] {
        match self {
            McdmResult::Topsis(r) => &r.scores,
        }
    }

    /// ランキング順のTrialインデックスを取得
    pub fn ranked_indices(&self) -> &[u32] {
        match self {
            McdmResult::Topsis(r) => &r.ranked_indices,
        }
    }

    /// 計算時間を取得 (ms)
    pub fn duration_ms(&self) -> f64 {
        match self {
            McdmResult::Topsis(r) => r.duration_ms,
        }
    }

    /// 現在の手法名
    pub fn method_label(&self) -> &'static str {
        match self {
            McdmResult::Topsis(_) => "TOPSIS",
        }
    }
}
```
