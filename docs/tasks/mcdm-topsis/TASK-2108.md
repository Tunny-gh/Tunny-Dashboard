## 実装詳細

### 1. ColorMode::McdmScore バリアント追加 🔵

**信頼性**: 🔵 *architecture.md より*

`egui-app/src/state/app_state.rs` の `ColorMode` 列挙型に `McdmScore` バリアントを追加する。

```rust
pub enum ColorMode {
    Objective,
    ParetoRank,
    McdmScore,  // 追加
}
```

### 2. update_chart_colors() への match arm 追加 🔵

**信頼性**: 🔵 *dataflow.md より*

`update_chart_colors()` に `McdmScore` の match arm を追加する。`mcdm_result.primary_scores()` からスコア値を読み取り、カラーマップ入力として使用する。

```rust
ColorMode::McdmScore => {
    if let Some(ref mcdm_result) = self.mcdm_result {
        let scores = mcdm_result.primary_scores();
        // スコア値をカラーマップに適用
    }
}
```

### 3. スコア正規化: [0,1] を直接カラーマップ入力に使用 🔵

**信頼性**: 🔵 *theory/topsis.md より*

TOPSIS の Closeness係数は既に [0,1] の範囲に正規化されているため、追加の正規化なしでカラーマップの入力としてそのまま使用可能。

```rust
// スコアは [0,1] の範囲 - colormap に直接入力
let color = colormap.interpolate(score);
```

### 4. mcdm_result が None の場合の無効化処理 🟡

**信頼性**: 🟡 *推定 - UIパターンより*

`mcdm_result` が `None` の場合、McdmScore オプションをセレクターでグレーアウト（無効化）する。

```rust
let has_mcdm = self.mcdm_result.is_some();
ui.add_enabled_ui(has_mcdm, |ui| {
    ui.selectable_value(&mut color_mode, ColorMode::McdmScore, "MCDM Score");
});
```

### 5. 左パネル カラーモードセレクターへのオプション追加 🟡

**信頼性**: 🟡 *推定 - UIパターンより*

左パネルのカラーモードセレクターに "MCDM Score" オプションを追加する。MCDM解析結果がない場合はグレーアウト表示とする。

## テスト要件

### ColorMode::McdmScore + TOPSIS結果あり: スコアから色生成 🔵

**信頼性**: 🔵 *設計より*

- TOPSIS結果が存在する場合、`ColorMode::McdmScore` でスコア値に基づく色が正しく生成されることを確認する
- 生成された色の数が試行数と一致することを確認する

### ColorMode::McdmScore + 結果なし: 色は変更なしまたはデフォルト 🔵

**信頼性**: 🟡 *推定*

- `mcdm_result` が `None` の場合、色が変更されない（前回の状態を維持）またはデフォルト色が使用されることを確認する

### スコア [0.0, 0.5, 1.0] のカラーマップグラデーション検証 🔵

**信頼性**: 🔵 *理論より*

- スコア値 `[0.0, 0.5, 1.0]` に対して、カラーマップが正しいグラデーションを生成することを確認する
- 0.0 が最低色、1.0 が最高色にマッピングされることを確認する

### update_chart_colors: 長さ0のスコア配列処理 🔵

**信頼性**: 🔵 *エッジケース設計より*

- 空のスコア配列が渡された場合、パニックせずに空の色配列を返すことを確認する
