### 2. McdmChart スタブ構造体の作成 🔵

**信頼性**: 🔵 *interfaces.rs McdmChart ウィジェット状態定義・既存ウィジェットパターンより*

**実装ファイル**: `egui-app/src/ui/widgets/mcdm_chart.rs`（新規作成）

```rust
use crate::state::results::{McdmMethod, McdmResult};

/// MCDMウィジェットのUI状態（スタブ実装）
pub struct McdmChart {
    /// 選択中のMCDM手法
    pub method: McdmMethod,
    /// 各目的関数の重み（0.0〜1.0、正規化前の生値）
    pub weights: Vec<f64>,
    /// 計算中フラグ
    pub computing: bool,
    /// 計算要求ペンディング
    pub pending_compute: Option<(McdmMethod, Vec<f64>)>,
}

impl Default for McdmChart {
    fn default() -> Self {
        Self {
            method: McdmMethod::Topsis,
            weights: Vec::new(),
            computing: false,
            pending_compute: None,
        }
    }
}

impl McdmChart {
    /// ウィジェット描画（スタブ: プレースホルダー表示のみ）
    pub fn show(&mut self, ui: &mut egui::Ui, _result: &Option<McdmResult>) {
        ui.vertical_centered(|ui| {
            ui.label("MCDM Analysis");
            ui.add_space(8.0);
            ui.label("(MCDM chart implementation will be added in a subsequent task)");
        });
    }
}
```

**注意**: 上記は最小スタブ。McdmTopN, McdmViewMode フィールドや詳細な show() 実装は後続タスクで追加する。本タスクでは WidgetStates に組み込むために必要な最小限の構造体と Default 実装のみを提供する。
