## 目的

MCDM計算結果を表形式で表示するランキングテーブルを実装する。eguiのTableBuilderを使用してスクロール可能な表を描画し、行クリックによるTrialハイライト連携を実現する。バーチャート（TASK-2105）と並ぶ主要な可視化モード。

### egui TableBuilder API 🟡

eguiのTableBuilderは以下の特徴を持つ：
- スクロール可能なテーブル描画
- ヘッダー行と本体行の分離
- 列幅の動的/固定指定
- 行のレスポンス（クリック検出等）

```rust
use egui_extras::{TableBuilder, Column};

TableBuilder::new(ui)
    .column(Column::exact(40.0))   // Rank列
    .column(Column::exact(80.0))   // Trial ID列
    .column(Column::exact(80.0))   // Score列
    .columns(Column::remainder(), obj_count) // 目的関数列
    .header(20.0, |mut header| {
        // ヘッダー行
    })
    .body(|mut body| {
        // データ行
    });
```

## 実装詳細

### 1. show_table()メソッド 🟡

**ファイル**: `egui-app/src/ui/widgets/mcdm_chart.rs`

```rust
impl McdmChart {
    pub fn show_table(
        &mut self,
        ui: &mut egui::Ui,
        result: &McdmResult,
        trial_rows: &[TrialRow],
        obj_names: &[String],
        set_highlight: &mut dyn FnMut(usize),
    ) {
        // テーブル描画
    }
}
```

引数：
- `result`: MCDM計算結果（スコア、ランキング）
- `trial_rows`: Trial情報（ID、目的関数値）
- `obj_names`: 目的関数名のリスト（列ヘッダー用）
- `set_highlight`: ハイライト更新コールバック

### 2. egui::TableBuilderによるスクロールテーブル 🟡

```rust
use egui_extras::{TableBuilder, Column};

let (scores, ranked_indices, _) = match result {
    McdmResult::Topsis { scores, ranked_indices, compute_duration_ms } => {
        (scores, ranked_indices, compute_duration_ms)
    }
};

let top_count = self.top_n.value().min(ranked_indices.len());
let top_indices = &ranked_indices[..top_count];

TableBuilder::new(ui)
    .striped(true)  // 交互行色
    .column(Column::exact(50.0))    // Rank
    .column(Column::exact(80.0))    // Trial ID
    .column(Column::exact(80.0))    // Score
    .columns(Column::remainder(), obj_names.len()) // 目的関数
    .header(20.0, |mut header| {
        header.col(|ui| { ui.strong("Rank"); });
        header.col(|ui| { ui.strong("Trial ID"); });
        header.col(|ui| { ui.strong("Score"); });
        for name in obj_names {
            header.col(|ui| { ui.strong(name); });
        }
    })
    .body(|mut body| {
        for (rank, &trial_idx) in top_indices.iter().enumerate() {
            let row_response = body.row(20.0, |mut row| {
                row.col(|ui| { ui.label(format!("{}", rank + 1)); });
                row.col(|ui| { ui.label(format!("{}", trial_rows[trial_idx].trial_id)); });
                row.col(|ui| { ui.label(format!("{:.4}", scores[trial_idx])); });
                for &val in &trial_rows[trial_idx].objective_values {
                    row.col(|ui| { ui.label(format!("{:.4}", val)); });
                }
            });
            // 行クリック検出
            if row_response.response().clicked() {
                set_highlight(trial_idx);
            }
        }
    });
```

### 3. カラム構成 🔵

| 列 | 幅 | 内容 | フォーマット |
|----|-----|------|-------------|
| Rank | 50.0px | 順位（1から開始） | 整数 |
| Trial ID | 80.0px | Trial識別子 | 整数 |
| Score | 80.0px | MCDMスコア | `{:.4}`（小数4桁） |
| Obj1...ObjN | remainder | 各目的関数値 | `{:.4}`（小数4桁） |

目的関数列の数は `obj_names.len()` に依存し、動的に生成。

### 4. 行クリック → ハイライト 🟡

```rust
if row_response.response().clicked() {
    set_highlight(trial_idx);
}
```

行のクリックを検出し、`set_highlight` コールバックでハイライト対象のTrial指数を通知。バーチャートやPareto散布図と連携。

### 5. ヘッダー行 🔵

```rust
.header(20.0, |mut header| {
    header.col(|ui| { ui.strong("Rank"); });
    header.col(|ui| { ui.strong("Trial ID"); });
    header.col(|ui| { ui.strong("Score"); });
    for name in obj_names {
        header.col(|ui| { ui.strong(name); });
    }
})
```

目的関数名を `obj_names` から動的に取得してヘッダーに表示。

## UI/UX仕様

### 交互行色 🟡

```rust
TableBuilder::new(ui)
    .striped(true)
```

`.striped(true)` で偶数行と奇数行の背景色を変え、読みやすさを向上。

### ハイライト行の背景色 🟡

現在ハイライトされているTrialに対応する行に、異なる背景色を適用：

```rust
let is_highlighted = /* 現在のハイライト対象か判定 */;
body.row(20.0, |mut row| {
    if is_highlighted {
        row.col(|ui| {
            ui.painter().rect_filled(
                ui.available_rect_before_wrap(),
                0.0,
                egui::Color32::from_rgb(255, 255, 100).linear_multiply(0.3),
            );
            ui.label(/* ... */);
        });
    }
    // ...
});
```

### Score列の右揃え 🟡

```rust
row.col(|ui| {
    ui.with_layout(egui::Layout::right_to_left(egui::Align::Center), |ui| {
        ui.label(format!("{:.4}", scores[trial_idx]));
    });
});
```

数値列は右揃えで表示し、桁の比較を容易にする。

### 空結果時の表示 🟡

```rust
if top_indices.is_empty() {
    ui.colored_label(
        egui::Color32::GRAY,
        "No results to display. Run MCDM computation first.",
    );
    return;
}
```
