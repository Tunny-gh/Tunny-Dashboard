## 前提知識

### 非同期計算フローパターン（ImportanceChart参考） 🔵

```
show() → pending_compute設定
  ↓
chart_registry → pending_compute検出 → spawn_task
  ↓
spawn_task → 同期計算（compute_topsis） → McdmDone送信
  ↓
MessageHandler → mcdm_result格納 + computing=falseリセット
  ↓
次フレーム → show()が結果を描画
```

### 2. pending_compute検出とspawn_task呼び出し 🔵

```rust
// chart_registry内のディスパッチロジック
if let Some((method, weights)) = widgets.mcdm.pending_compute.take() {
    let decision_matrix = app_state.decision_matrix.clone();
    let objectives_metadata = app_state.objectives_metadata.clone();

    let message_tx = message_tx.clone();
    spawn_task(move || {
        match method {
            McdmMethod::Topsis => {
                let start = std::time::Instant::now();
                let result = compute_topsis(&decision_matrix, &weights, &objectives_metadata);
                let duration_ms = start.elapsed().as_secs_f64() * 1000.0;

                match result {
                    Ok((scores, ranked_indices)) => {
                        AppMessage::McdmDone(McdmResult::Topsis {
                            scores,
                            ranked_indices,
                            compute_duration_ms: duration_ms,
                        })
                    }
                    Err(e) => AppMessage::Error(format!("TOPSIS computation failed: {}", e)),
                }
            }
        }
    });
}
```

`pending_compute` を `take()` で消費し、非同期タスクを起動。ImportanceChartと同じパターン。

### 3. spawn_task本体: TOPSIS計算 🔵

```rust
McdmMethod::Topsis => {
    let start = std::time::Instant::now();
    let result = rust_core::mcdm::topsis::compute_topsis(
        &decision_matrix,
        &weights,
        &objectives_metadata,
    );
    let duration_ms = start.elapsed().as_secs_f64() * 1000.0;

    match result {
        Ok((scores, ranked_indices)) => {
            AppMessage::McdmDone(McdmResult::Topsis {
                scores,
                ranked_indices,
                compute_duration_ms: duration_ms,
            })
        }
        Err(e) => {
            AppMessage::Error(format!("TOPSIS computation failed: {}", e))
        }
    }
}
```

- `compute_topsis` は `rust_core` の既存実装を呼び出し 🔵
- 計算時間を `Instant::now()` で計測 🔵
- 成功時: `McdmDone` メッセージ 🔵
- 失敗時: `Error` メッセージ 🔵

### 5. エラーハンドリング 🔵

```rust

    app_state.error_message = Some(msg);
```

## メッセージフロー全体像 🔵

```
[ユーザ操作]
    ↓ Runボタンクリック
[McdmChart::show()]
    ↓ pending_compute = Some((Topsis, weights))
    ↓ computing = true
[chart_registry]
    ↓ pending_compute.take() → Some検出
    ↓ spawn_task(|| { compute_topsis(...) })
[別スレッド]
    ↓ compute_topsis(matrix, weights, metadata)
    ↓ Ok → AppMessage::McdmDone(Topsis{scores, ranked, duration})
    ↓ Err → AppMessage::Error(msg)
[MessageHandler]
    ↓ McdmDone → app_state.mcdm_result = Some(result)
    ↓             computing = false
    ↓ Error → app_state.error_message = Some(msg)
    ↓         computing = false
[次フレーム McdmChart::show()]
    ↓ mcdm_result.as_ref() → Some(result)
    ↓ show_bar_chart() / show_table() を描画
```
