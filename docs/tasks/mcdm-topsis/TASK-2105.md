## 目的

TOPSIS（または他MCDM手法）の計算結果を、上位N件のランキングバーチャートとして可視化する。egui_plotのBarChartを使用し、ホバー/クリックによるTrialハイライト連携を実現する。

pub enum McdmResult {

## 実装詳細

### 1. show_bar_chart()メソッド 🔵

**ファイル**: `egui-app/src/ui/widgets/mcdm_chart.rs`

```rust
impl McdmChart {
    pub fn show_bar_chart(
        &mut self,
        ui: &mut egui::Ui,
        result: &McdmResult,
        trial_rows: &[TrialRow],
        set_highlight: &mut dyn FnMut(usize),
    ) {
        // バーチャート描画
    }
}
```

引数：
- `result`: MCDM計算結果（スコア、ランキング、計算時間）
- `trial_rows`: Trial情報（ID、目的関数値など）
- `set_highlight`: ハイライト更新コールバック

### 2. 上位N件の抽出 🔵

```rust
let (scores, ranked_indices, duration_ms) = match result {
    McdmResult::Topsis { scores, ranked_indices, compute_duration_ms } => {
        (scores, ranked_indices, compute_duration_ms)
    }
};

let top_count = self.top_n.value().min(ranked_indices.len());
let top_indices = &ranked_indices[..top_count];
```

ranked_indicesはすでにスコア降順でソートされているため、先頭からtop_n件を取得。

### 3. egui_plot BarChartの生成 🔵

```rust
use egui_plot::{Bar, BarChart, Plot, PlotUi};

let bars: Vec<Bar> = top_indices
    .iter()
    .enumerate()
    .map(|(rank, &trial_idx)| {
        Bar::new(rank as f64 + 1.0, scores[trial_idx])
            .name(format!("Trial {}", trial_rows[trial_idx].trial_id))
    })
    .collect();

let chart = BarChart::new(bars)
    .horizontal(true)
    .color(bar_color);
```

水平バーでスコアを表現。ランク1位が最上部に表示されるようy軸を反転。

### 4. バーラベル 🟡

```rust
Bar::new(rank as f64 + 1.0, scores[trial_idx])
    .name(format!("Trial {}", trial_rows[trial_idx].trial_id))
    .text_style(egui::TextStyle::Small)
```

"Trial {id}" 形式のラベル。egui_plotのデフォルト名称表示を使用。

### 5. ホバー/クリック検出とハイライト連携 🟡

```rust
let plot_response = Plot::new("mcdm_ranking_chart")
    .show(ui, |plot_ui| {
        plot_ui.bar_chart(&chart);
    });

// ホバー時のツールチップはegui_plotが自動処理
// クリック検出
if let Some(bar_item) = plot_response.response.clicked() {
    // bar_itemからtrial_idxを特定してset_highlightを呼ぶ
}
```

egui_plotの `PlotResponse` を使用してホバー/クリックイベントを検出。クリック時に `set_highlight(trial_idx)` を呼び出し、他のチャート（Pareto散布図など）と連携。

### 6. TopN切替ボタン 🔵

```rust
ui.horizontal(|ui| {
    ui.label("Top N:");
    let top_n_options = [(McdmTopN::Top5, "5"), (McdmTopN::Top10, "10"), (McdmTopN::Top20, "20")];
    for (variant, label) in top_n_options {
        if ui.selectable_label(self.top_n == variant, label).clicked() {
            self.top_n = variant;
        }
    }
});
```

セレクト可能ラベルで5/10/20の切替ボタンを描画。アクティブ状態の表示はeguiの `selectable_label` に委譲。

### 7. 計算時間表示 🔵

```rust
ui.label(format!("Computed in {:.1}ms", duration_ms));
```

バーチャート下部に計算時間を表示。

## UI/UX仕様

### バーチャートタイトル 🔵

```rust
Plot::new("mcdm_ranking_chart")
    .title(format!("{:?} Ranking", self.method))
```

手法名 + "Ranking" をタイトルに表示（例: "Topsis Ranking"）。

### ホバーツールチップ 🟡

egui_plotのデフォルトツールチップを拡張し、以下の情報を表示：
- Trial ID
- TOPSISスコア
- 各目的関数の値

```rust
Bar::new(...)
    .name(format!(
        "Trial {}\nScore: {:.4}\nObj0: {:.4}\nObj1: {:.4}",
        trial_id, score, obj0, obj1
    ))
```

### バークリック → ハイライト 🟡

クリックしたバーに対応するTrialをハイライト：
- 他チャート（ParetoScatter等）で該当Trialが強調表示される
- テーブルビュー（TASK-2106）でも該当行がハイライトされる

### TopN切替ボタンのアクティブ状態 🔵

```rust
ui.selectable_label(matches!(self.top_n, variant), label)
```

選択中のボタンはeguiのテーマに従いハイライト表示。

### バー色 🟡

- 通常: テーマのアクセントカラー
- ホバー: やや明るい色
- ハイライト中のTrial: 別色（例: 黄色）
