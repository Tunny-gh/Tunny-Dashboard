## タスク概要

`compute_pdp_2d_kriging` 内の `train_gp(x_2d, y, 1000, 42)` の subsample_n を 500 に変更する。Cholesky 分解の計算量は O(N³) であるため、N を 1000→500 に削減することで計算量を理論上 8× 削減できる。

ユーザーヒアリングにより精度低下を許容（RF との差別化のため精度はある程度維持）していることが確認済み。

## 実装詳細

### 1. compute_pdp_2d_kriging の subsample_n 変更 🔵

**信頼性**: 🔵 *REQ-004・ユーザヒアリング（許容）より*

**実装ファイル**: `rust_core/src/pdp.rs`

```rust
// Before:
train_gp(&x_2d, y, 1000, 42)

// After:
train_gp(&x_2d, y, 500, 42)
```

`train_gp` の第3引数 `subsample_n` が 500 になる。既存の `train_gp` 実装は N ≤ subsample_n の場合はサブサンプリングしないため、追加の変更は不要。
