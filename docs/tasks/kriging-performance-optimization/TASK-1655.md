### 2. パフォーマンス計測 🔵

**信頼性**: 🔵 *acceptance-criteria.md TC-NFR-001-01, TC-NFR-002-01 より*

**実装ファイル**: `rust_core/src/` (ベンチマークコードまたはテスト内計測)

```rust
// TC-NFR-001-01: Kriging N=1000 パフォーマンス計測
#[test]
fn test_kriging_performance_n1000() {
    let n = 1000;
    let (x_2d, y) = generate_synthetic_data(n, 42);
    
    let start = std::time::Instant::now();
    compute_pdp_2d_kriging_raw(&x_2d, &y, 50);
    let elapsed = start.elapsed().as_millis();
    
    println!("Kriging N=1000: {}ms", elapsed);
    assert!(elapsed < 10_000, "NFR-001 未達: {}ms > 10,000ms", elapsed);
}

// TC-NFR-002-01: Sparse Kriging N=5000 パフォーマンス計測
#[test]  
fn test_sparse_kriging_performance_n5000() {
    let n = 5000;
    let (x_2d, y) = generate_synthetic_data(n, 42);
    
    let start = std::time::Instant::now();
    compute_pdp_2d_sparse_kriging_raw(&x_2d, &y, 50);
    let elapsed = start.elapsed().as_millis();
    
    println!("Sparse Kriging N=5000: {}ms", elapsed);
    assert!(elapsed < 5_000, "NFR-002 未達: {}ms > 5,000ms", elapsed);
}
```

注意: パフォーマンステストは `cargo test --release` で実行すること。

## 注意事項

- パフォーマンス計測は必ず `cargo test --release` で実行すること（`--dev` ビルドでは WASM 最適化が無効）。
- WASM 環境でのパフォーマンスは native Rust より低下する。WASM 上での計測値が NFR を満たすかどうかを確認すること。
- NFR が未達の場合は、Phase 1 の最適化パラメータ（subsample_n、max_iter）を調整する余地がある。
