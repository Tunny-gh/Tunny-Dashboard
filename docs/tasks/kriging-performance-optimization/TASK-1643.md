## タスク概要

現在の `optimize_hyperparams` は `n_iter=100` で固定されており、不必要に多くのイテレーションを実行している。本タスクでは `n_iter=50` への変更と、直近 5 イテレーションの LML 変化が 1e-3 以下になった場合の早期停止を実装する。

早期停止により、収束済みの最適化を不必要に継続することを防ぎ、実質的なイテレーション数を削減する。

### 2. 早期停止ロジックの実装 🔵

**信頼性**: 🔵 *設計文書 dataflow.md L-BFGS 早期停止フロー より*

**実装ファイル**: `rust_core/src/kriging.rs`

dataflow.md に記載の早期停止コードを `optimize_hyperparams` 内のメインループに追加する:

```rust
use std::collections::VecDeque;

let mut lml_history: VecDeque<f64> = VecDeque::with_capacity(5);

for iter in 0..n_iter {
    let (f_x, grad_neg) = log_ml_with_gradient(x, y, &params);
    
    // 早期停止チェック: 直近5イテレーションのLML変化
    let lml = f_x;
    lml_history.push_back(lml);
    if lml_history.len() > 5 { lml_history.pop_front(); }
    
    if lml_history.len() == 5 {
        let span = lml_history.back().unwrap() - lml_history.front().unwrap();
        if span.abs() < 1e-3 { break; }
    }
    
    // 勾配ノルム収束
    let grad_norm: f64 = grad_neg.iter().map(|g| g * g).sum::<f64>().sqrt();
    if grad_norm < 1e-5 { break; }
    
    // L-BFGS 方向計算 + Armijo 線探索 (既存ロジックを維持)
    // ...
}
```
