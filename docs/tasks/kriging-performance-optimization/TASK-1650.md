## タスク概要

Sparse Kriging（FITC 近似）に必要な誘導点（Inducing Points）を K-means クラスタリングで選択する関数を実装する。ユーザーヒアリングにより K-means 選択（Lloyd's アルゴリズム）が確定済み。外部クレートを使用せず純 Rust で実装する。

誘導点はデータ分布を反映した M=50 個の代表点であり、FITC 近似行列 K_ZZ（M×M）および K_XZ（N×M）の構築に使用される。

## 実装詳細

### 1. select_inducing_points_kmeans 関数 🔵

**信頼性**: 🔵 *ユーザヒアリング design-interview.md Q5（K-means・Lloyd's アルゴリズム・外部クレート不使用）より*

**実装ファイル**: `rust_core/src/kriging.rs` または `rust_core/src/sparse_kriging.rs`（新規ファイル）

```rust
/// K-means クラスタリングで誘導点を選択する（Lloyd's アルゴリズム）
///
/// # 引数
/// - `x`: 訓練データ (n_samples × n_dims のフラット配列, 列優先)
/// - `n_samples`: サンプル数
/// - `n_dims`: 次元数（通常 2）
/// - `m`: 誘導点数（通常 50）
/// - `seed`: 乱数シード（再現性のため）
///
/// # 戻り値
/// M×n_dims のフラット配列（列優先）
pub fn select_inducing_points_kmeans(
    x: &[f64],
    n_samples: usize,
    n_dims: usize,
    m: usize,
    seed: u64,
) -> Vec<f64> {
    assert!(m <= n_samples, "誘導点数 M はサンプル数 N 以下でなければならない");
    
    // 1. 初期化: データから M 点をランダムに選択（シードベース）
    let mut centers = initialize_centers(x, n_samples, n_dims, m, seed);
    
    // 2. Lloyd's アルゴリズム（最大 100 イテレーション）
    for _ in 0..100 {
        // 各データ点を最近傍クラスタに割り当て
        let assignments = assign_clusters(&centers, x, n_samples, n_dims, m);
        
        // クラスタ重心を計算
        let new_centers = compute_centroids(&assignments, x, n_samples, n_dims, m);
        
        // 収束チェック（重心の移動量が閾値以下）
        if has_converged(&centers, &new_centers, n_dims) {
            return new_centers;
        }
        centers = new_centers;
    }
    
    centers
}
```

### 2. ヘルパー関数群 🟡

**信頼性**: 🟡 *K-means アルゴリズム標準実装から妥当な推測*

- `initialize_centers`: シードを使ったランダム初期化（線形合同法）
- `assign_clusters`: 各データ点の最近傍クラスタ割り当て（ユークリッド距離）
- `compute_centroids`: 各クラスタの重心計算（空クラスタはランダム点で補完）
- `has_converged`: 重心移動量 < 1e-6 で収束判定
