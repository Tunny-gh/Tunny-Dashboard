## タスク概要

Web Worker はメインスレッドの WASM グローバル状態（`OnceLock<Mutex<GlobalState>>`）にアクセスできないため、データを直接引数で受け取る新しい WASM エクスポート関数 `wasm_compute_kriging_raw` を実装する。

この関数はグローバル状態に依存せず、引数として受け取った `x_flat`, `y`, 各インデックス情報から直接 Kriging 計算を実行し、`JsValue` として結果を返す。

### 1. wasm_compute_kriging_raw 関数の実装 🔵

**信頼性**: 🔵 *ユーザヒアリング design-interview.md Q4・interfaces.ts ComputeKrigingRawFn より*

**実装ファイル**: `rust_core/src/lib.rs`

```rust
/// グローバル状態に依存しない Kriging/Sparse Kriging 計算関数
/// Web Worker から呼び出すために設計
///
/// # 引数
/// - `x_flat`: パラメータデータのフラット配列 [param1_0..param1_n, param2_0..param2_n]
/// - `y`: 目的関数値配列 (n_samples,)
/// - `n_samples`: 試行数
/// - `param1_idx`: x_flat 内の param1 列インデックス (0)
/// - `param2_idx`: x_flat 内の param2 列インデックス (1)
/// - `n_grid`: グリッド解像度（通常 50）
/// - `model_type`: "kriging" または "sparse_kriging"
#[wasm_bindgen(js_name = "computeKrigingRaw")]
pub fn wasm_compute_kriging_raw(
    x_flat: &[f64],
    y: &[f64],
    n_samples: u32,
    param1_idx: u32,
    param2_idx: u32,
    n_grid: u32,
    model_type: &str,
) -> Result<JsValue, JsValue> {
    let n = n_samples as usize;
    
    // x_flat から 2D 配列を再構築
    // x_flat = [param1_0, ..., param1_n, param2_0, ..., param2_n] (列優先)
    let x_2d = reconstruct_x2d(x_flat, n, param1_idx as usize, param2_idx as usize);
    
    // モデルタイプに応じて計算
    let result = match model_type {
        "kriging" => pdp::compute_pdp_2d_kriging_raw(&x_2d, y, n_grid as usize),
        "sparse_kriging" => pdp::compute_pdp_2d_sparse_kriging_raw(&x_2d, y, n_grid as usize),
        _ => return Err(JsValue::from_str(&format!("Unknown model_type: {}", model_type))),
    };
    
    match result {
        Some(r) => serde_wasm_bindgen::to_value(&r).map_err(|e| JsValue::from_str(&e.to_string())),
        None => Err(JsValue::from_str("Kriging computation failed")),
    }
}
```

注意: `compute_pdp_2d_kriging_raw` は既存の `compute_pdp_2d_kriging` をラップし、グローバル状態から x_2d/y を読み取る代わりに引数として受け取るバージョン。pdp.rs に追加実装が必要。
