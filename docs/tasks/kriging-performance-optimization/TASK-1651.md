## タスク概要

FITC 近似に必要な行列を構築する関数群を実装する:
- `K_ZZ`: 誘導点間のカーネル行列（M×M）
- `K_XZ`: 訓練データと誘導点間のカーネル行列（N×M）
- `Q`: 低ランク近似行列 `K_XZ · K_ZZ^{-1} · K_XZ^T`（N×N）
- `Λ`: 対角補正行列 `diag(K_exact_diag - Q_diag) + σ_n² I`

これらの行列が FITC 近似カーネル `K_FITC = Q + Λ` を構成する。

## 実装詳細

### 1. build_kzz: 誘導点間カーネル行列 🟡

**信頼性**: 🟡 *FITC 理論・dataflow.md Sparse Kriging フローより*

**実装ファイル**: `rust_core/src/sparse_kriging.rs`（または `kriging.rs`）

```rust
/// 誘導点間カーネル行列 K_ZZ を構築する (M×M)
/// 既存の `matern52_ard` カーネル関数を使用
pub fn build_kzz(z: &[f64], m: usize, params: &[f64]) -> Vec<f64> {
    let mut kzz = vec![0.0f64; m * m];
    for i in 0..m {
        for j in i..m {
            let k = matern52_ard(z, z, i, j, m, params);
            kzz[i * m + j] = k;
            kzz[j * m + i] = k;  // 対称行列
        }
        // 数値安定性のためジッター追加
        kzz[i * m + i] += 1e-6;
    }
    kzz
}
```

### 2. build_kxz: 訓練-誘導点間カーネル行列 🟡

**信頼性**: 🟡 *FITC 理論・dataflow.md より*

**実装ファイル**: `rust_core/src/sparse_kriging.rs`

```rust
/// 訓練データ - 誘導点間カーネル行列 K_XZ を構築する (N×M)
pub fn build_kxz(x: &[f64], z: &[f64], n: usize, m: usize, params: &[f64]) -> Vec<f64> {
    let mut kxz = vec![0.0f64; n * m];
    for i in 0..n {
        for j in 0..m {
            kxz[i * m + j] = matern52_ard(x, z, i, j, n, params);  // x[i] と z[j] 間
        }
    }
    kxz
}
```

### 3. FITC 行列の構築（Q と Λ の対角成分） 🟡

**信頼性**: 🟡 *dataflow.md FITC_CALC サブグラフより*

FITC 近似のアルゴリズム:
1. `L_ZZ = cholesky(K_ZZ)` — M×M
2. `V = L_ZZ^{-1} K_XZ^T` — M×N （前進代入で解く）
3. `Q_diag[i] = ||V[:,i]||^2` — N 次元ベクトル（Q の対角成分）
4. `K_exact_diag[i] = k(x_i, x_i)` — N 次元（各点の自己カーネル値）
5. `Lambda_diag[i] = max(K_exact_diag[i] - Q_diag[i], 1e-6) + exp(2*log_sn)` — ノイズ込み対角

## 注意事項

- `matern52_ard` の引数は既存の `build_kernel_matrix` での使用パターンを踏襲すること。
- K_ZZ のジッターは 1e-6 から開始し、Cholesky が失敗した場合は 10 倍ずつ増やすロジックを検討する（TC-005-E01 対応）。
- Q_diag は `K_XZ · K_ZZ^{-1} · K_XZ^T` の対角成分のみが必要。完全な N×N 行列は作らず、V = L_ZZ^{-1} K_XZ^T の列ノルムとして計算する（メモリ効率化）。
