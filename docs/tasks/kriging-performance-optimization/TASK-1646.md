## タスク概要

viteSingleFile 制約下で Web Worker を動作させるため、Worker スクリプトを文字列として保持し、実行時に Blob URL を生成して `new Worker(blobUrl)` で起動する `createKrigingWorker` 関数を実装する。

本タスクでは Worker の起動部分（Blob URL 生成）のみを担当する。WASM 初期化とメッセージハンドリングは TASK-1647 で実装する。

## 実装詳細

### 1. createKrigingWorker ファクトリー関数の実装 🟡

**信頼性**: 🟡 *Blob URL + viteSingleFile 設計から妥当な推測*

**実装ファイル**: `frontend/src/workers/createKrigingWorker.ts`

```typescript
/**
 * viteSingleFile 対応 Worker 生成ファクトリー
 * Worker スクリプトを Blob URL で起動することで、
 * vite-plugin-singlefile の単一 HTML バンドルに対応する
 */
export function createKrigingWorker(workerSrc: string): Worker {
  const blob = new Blob([workerSrc], { type: 'application/javascript' });
  const blobUrl = URL.createObjectURL(blob);
  const worker = new Worker(blobUrl);
  
  // Worker 終了後に URL を解放してメモリリークを防ぐ
  worker.addEventListener('error', () => URL.revokeObjectURL(blobUrl));
  
  return worker;
}

/**
 * Worker スクリプトのソース文字列（vite build 時にバンドルされる）
 * TASK-1647 で完全な実装に置き換える
 */
export const KRIGING_WORKER_SRC = `
  self.onmessage = function(e) {
    if (e.data.type === 'init') {
      self.postMessage({ type: 'ready' });
    }
  };
`;
```
