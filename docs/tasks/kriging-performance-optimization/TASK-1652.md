### 1. compute_pdp_2d_sparse_kriging_raw の実装 🟡

**信頼性**: 🟡 *設計文書 architecture.md Sparse GP 設計・dataflow.md FITC フローより*

**実装ファイル**: `rust_core/src/pdp.rs` または `rust_core/src/sparse_kriging.rs`

```rust
pub fn compute_pdp_2d_sparse_kriging_raw(
    x_2d: &[f64],
    y: &[f64],
    n_grid: usize,
) -> Option<PdpResult2d> {
    let n = y.len();
    let m = 50;  // 誘導点数
    
    // フォールバック: N < M の場合は標準 Kriging を使用
    if n < m {
        return compute_pdp_2d_kriging_raw(x_2d, y, n_grid);
    }
    
    // 1. K-means で誘導点選択
    let z = select_inducing_points_kmeans(x_2d, n, 2, m, 42);
    
    // 2. ハイパーパラメータ初期化
    let mut params = vec![0.0f64; 4];  // [log_ls0, log_ls1, log_sf, log_sn=-2]
    params[3] = -2.0;
    
    // 3. FITC LML に対して L-BFGS 最適化 (max_iter=50 + 早期停止)
    optimize_fitc_hyperparams(x_2d, &z, y, &mut params, 50);
    
    // 4. FITC 予測分布でグリッド予測
    let grid_result = fitc_grid_predict(x_2d, &z, y, &params, n_grid);
    
    Some(grid_result)
}
```

### 2. FITC LML の最適化 🟡

**信頼性**: 🟡 *FITC 理論 + Phase 1 の L-BFGS 実装パターンから妥当な推測*

FITC の LML は以下の近似式で計算:
- `log p(y|X,θ) ≈ -0.5 * [y^T (K_FITC + Λ)^{-1} y + log|K_FITC + Λ| + N*log(2π)]`

Woodbury 恒等式で `(K_FITC + Λ)^{-1}` を効率的に計算:
- `(Q + Λ)^{-1} = Λ^{-1} - Λ^{-1} K_XZ (K_ZZ + K_XZ^T Λ^{-1} K_XZ)^{-1} K_XZ^T Λ^{-1}`

Phase 1 の `log_ml_with_gradient` パターンを踏襲し、値と勾配を同時計算する。

## 注意事項

- Woodbury 恒等式の実装は数値的に不安定になりやすい。`K_ZZ + K_XZ^T Λ^{-1} K_XZ` の Cholesky 分解時にジッターが必要な場合がある。
- FITC の勾配計算は複雑なため、数値勾配（有限差分）と比較してテストすることを推奨。
- グリッド予測は標準 Kriging の `predict_mean` と同様のパターンで実装する。
