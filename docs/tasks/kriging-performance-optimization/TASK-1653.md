## 実装詳細

### 1. pdp.rs dispatch への sparse_kriging 追加 🔵

**信頼性**: 🔵 *既存 pdp.rs の model_type dispatch パターンより*

**実装ファイル**: `rust_core/src/pdp.rs`

```rust
// 既存の dispatch 関数に追加
pub fn compute_pdp_2d(
    param1: &str,
    param2: &str,
    objective: &str,
    n_grid: usize,
    model_type: &str,
) -> Option<PdpResult2d> {
    match model_type {
        "kriging" => compute_pdp_2d_kriging(param1, param2, objective, n_grid),
        "sparse_kriging" => {
            // グローバル状態からデータを取得して sparse kriging を実行
            let state = GLOBAL_STATE.get()?.lock().ok()?;
            let x_2d = state.extract_x_2d(param1, param2)?;
            let y = state.get_objective(objective)?;
            compute_pdp_2d_sparse_kriging_raw(&x_2d, &y, n_grid)
        }
        "ridge" => compute_pdp_2d_ridge(param1, param2, objective, n_grid),
        "random_forest" => compute_pdp_2d_rf(param1, param2, objective, n_grid),
        _ => None,
    }
}
```
