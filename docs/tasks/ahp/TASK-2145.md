## 実装詳細

### 1. `egui-app/src/state/results.rs` — AhpResult 追加 🔵

**信頼性**: 🔵 *REQ-AHP-010 / 既存 TopsisResult / VikorResult / PrometheeResult パターンより*

**実装ファイル**: `egui-app/src/state/results.rs`

rust_core 側 `AhpResult` と同一フィールド構成。`serde` は不要（永続化しない）。

```rust
#[derive(Debug, Clone)]
pub struct AhpResult {
    pub priority_vector: Vec<f64>,
    pub scores: Vec<f64>,
    pub ranked_indices: Vec<u32>,
    pub lambda_max: f64,
    pub ci: f64,
    pub ri: f64,
    pub cr: f64,
    pub is_consistent: bool,
    pub duration_ms: f64,
}
```

### 2. `egui-app/src/state/messages.rs` — AppMessage::AhpDone 追加 🔵

**信頼性**: 🔵 *REQ-AHP-011 / 既存 AppMessage::McdmDone パターンより*

**実装ファイル**: `egui-app/src/state/messages.rs`

`McdmDone` とは完全に独立した別バリアントとして追加する。

```rust
pub enum AppMessage {
    // ... 既存 ...
    McdmDone(McdmResult),
    AhpDone(AhpResult),  // ← 新規追加
    // ...
}
```

### 3. `egui-app/src/state/app_state.rs` — ahp_result フィールド追加 🔵

**信頼性**: 🔵 *REQ-AHP-013 / 既存 mcdm_result パターンより*

**実装ファイル**: `egui-app/src/state/app_state.rs`

```rust
pub struct AppState {
    // ... 既存 ...
    pub mcdm_result: Option<McdmResult>,
    pub ahp_result: Option<AhpResult>,  // ← 新規追加
}
```

`AppState::clear()` 時に `ahp_result = None` を追加する（REQ-AHP-013-B）。

### 4. `egui-app/src/state/message_handler.rs` — AhpDone 分岐追加 🔵

**信頼性**: 🔵 *REQ-AHP-012 / 既存 McdmDone ハンドラパターンより*

**実装ファイル**: `egui-app/src/state/message_handler.rs`

```rust
AppMessage::AhpDone(result) => {
    widget_states.ahp_chart.computing = false;
    app_state.ahp_result = Some(result);
}
```

また `AppMessage::StudySelected` ハンドラに以下を追加する（REQ-AHP-027）:

```rust
AppMessage::StudySelected(_) => {
    // ... 既存 ...
    app_state.ahp_result = None;
    widget_states.ahp_chart = AhpChart::default();
    // ※ AhpChart::reset_for_objectives(n_objectives) も検討
}
```

### 5. `egui-app/src/state/layout_state.rs` — ChartId 追加 🔵

**信頼性**: 🔵 *REQ-AHP-014 より*

**実装ファイル**: `egui-app/src/state/layout_state.rs`

pub enum ChartId {
    // ... 既存 ...

## 注意事項

- `AhpResult` のフィールドは rust_core 側と**完全に同一**にする（chart_registry.rs でフィールドコピーして生成するため）
- `AppMessage::AhpDone` は `McdmDone` の追加バリアントではなく、完全に独立した新規バリアント
- `StudySelected` リセット時は `widget_states.ahp_chart = AhpChart::default()` を使用（TASK-2146 実装後に `reset_for_objectives` への変更も検討）
- `ChartId::all()` への追加を忘れると UI のタブに表示されないため注意
