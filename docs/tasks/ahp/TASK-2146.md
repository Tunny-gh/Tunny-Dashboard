### 3. `AhpChart` 構造体 🔵

**信頼性**: 🔵 *REQ-AHP-020 / interfaces.rs より*

**実装ファイル**: `egui-app/src/ui/widgets/ahp_chart.rs`

```rust
#[derive(Debug, Default)]
pub struct AhpChart {
    pub pairwise: Vec<f64>,                      // 上三角 len=n*(n-1)/2
    pub computing: bool,
    pub pending_compute: Option<AhpComputeRequest>,
    pub top_n: AhpTopN,
}

impl AhpChart {
    pub fn reset_for_objectives(n_objectives: usize) -> Self { ... }
    pub fn upper_tri_index(n: usize, i: usize, j: usize) -> usize {
        i * (2 * n - i - 1) / 2 + (j - i - 1)
    }
}
```

### 4. `show_rank_chart()` — 一対比較行列グリッド 🔵

**信頼性**: 🔵 *REQ-AHP-021 / 実装ガイド Step 9 より*

**実装ファイル**: `egui-app/src/ui/widgets/ahp_chart.rs`

`egui::Grid` を使用してヘッダー行 + n 行分の一対比較行列を表示する。

- 対角 (i == j): `ui.label("1.0")` — 読み取り専用（REQ-AHP-021-B）
- 上三角 (i < j): `egui::DragValue::new(&mut self.pairwise[idx]).range(1.0..=9.0).speed(0.5)` — Saaty スケール（REQ-AHP-021-C）
- 下三角 (i > j): `ui.label(format!("{:.3}", 1.0 / self.pairwise[upper_idx]))` — 読み取り専用（REQ-AHP-021-D）
- 行・列ヘッダー: 目的関数名を表示（REQ-AHP-021-E）

n=1 の場合は一対比較グリッドを省略してよい（EDGE-AHP-011 🟡）。

## 注意事項

- egui-app はインラインスタイルのみを使用する（Tailwind CSS 禁止, NFR-AHP-011）
- `pairwise` の長さは `n_objectives * n_objectives.saturating_sub(1) / 2`
- n=1 の場合は `pairwise.len() == 0` のため、行列グリッド描画をスキップする（EDGE-AHP-011）
- `show_rank_chart()` と `show_table()` は同一構造体 `AhpChart` のメソッドとして実装し、chart_registry.rs から ChartId に応じて呼び分ける
