## 実装詳細

### 1. `ChartId::AhpRankChart` 分岐 🔵

**信頼性**: 🔵 *REQ-AHP-026 / 既存 McdmRankChart 分岐パターンより*

**実装ファイル**: `egui-app/src/ui/chart_registry.rs`

```rust
ChartId::AhpRankChart => {
    // pending_compute の取り出し + spawn_task
    if let Some(req) = widget_states.ahp_chart.pending_compute.take() {
        let tx = tx.clone();
        widget_states.ahp_chart.computing = true;
        crate::app::spawn_task(tx, move || {
            match tunny_core::mcdm::ahp::compute_ahp(
                &req.objectives,
                req.n_trials,
                req.n_objectives,
                &req.pairwise_matrix,
                &req.is_minimize,
            ) {
                Ok(r) => AppMessage::AhpDone(AhpResult {
                    priority_vector: r.priority_vector,
                    scores: r.scores,
                    ranked_indices: r.ranked_indices,
                    lambda_max: r.lambda_max,
                    ci: r.ci,
                    ri: r.ri,
                    cr: r.cr,
                    is_consistent: r.is_consistent,
                    duration_ms: r.duration_ms,
                }),
                Err(e) => AppMessage::Error(format!("AHP computation failed: {e}")),
            }
        });
    }

    // ウィジェット描画
    let obj_names = /* app_state から目的関数名を取得 */;
    let n_objectives = obj_names.len();
    widget_states.ahp_chart.show_rank_chart(
        ui,
        &obj_names,
        &app_state.ahp_result,
        n_objectives,
        // 必要な追加引数
    );
}
```

## 注意事項

- `AhpResult` 型コピー時は全フィールドを明示的にコピーする（rust_core 側の `AhpResult` と egui-app 側の `AhpResult` は別型）
- `spawn_task` 内は `move ||` クロージャのため、キャプチャする変数は clone またはムーブする
- `widget_states.ahp_chart.computing = true` は `spawn_task` 呼び出し**前**に設定する
- Run ボタンを押しても `computing = true` の場合は `pending_compute` をセットしないよう `show_rank_chart` 側で制御されていることを確認
