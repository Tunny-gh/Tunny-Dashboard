## 実装詳細

### 1. ドキュメント構成 🟡

**信頼性**: 🟡 *REQ-AHP-030 / 既存 topsis.md / vikor.md パターンから妥当な推測*

**実装ファイル**: `theory/mcdm/ahp.md`

既存の理論ドキュメントのフォーマットを確認して同一構成で作成する。以下の章立てを含む:

1. **AHP の概要**
   - 一対比較行列の説明（Saaty スケール 1-9）
   - A[i][j] = a_ij（i が j より a_ij 倍重要）
   - A[j][i] = 1 / a_ij（逆数の法則）
   - A[i][i] = 1.0（対角）

2. **優先度ベクトル導出（固有ベクトル近似法）**
   - Step 1: 各列を列合計で除算 → 正規化行列 B
   - Step 2: 各行の平均 → 優先度ベクトル w
   - 数式: w[i] = Σ_j B[i][j] / n

3. **整合性チェック**
   - λmax = Σ_j (A のj列合計 × w[j])
   - CI = (λmax - n) / (n - 1)
   - RI テーブル（Saaty 標準値）: n=1→0.00, n=2→0.00, n=3→0.58, n=4→0.90, n=5→1.12, n≥6→1.24
   - CR = CI / RI
   - CR ≤ 0.10: 整合性あり

4. **スコア計算（加重和法）**
   - Min-Max 正規化（最小化/最大化方向考慮）
   - AHP スコア = Σ_j w[j] × normalized_j

5. **参考文献**（任意: Saaty の論文等）
