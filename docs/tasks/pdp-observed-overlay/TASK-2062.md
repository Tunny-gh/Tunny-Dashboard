### 2. `extract_observed` 純粋関数 🔵

**信頼性**: 🔵 *dataflow.md + `TrialRow.params: HashMap<String, f64>` 構造より*

```rust
/// 観測データを trial_rows から抽出する（テスト可能な純粋関数）
pub fn extract_observed(
    trial_rows: &[crate::state::app_state::TrialRow],
    param_name: &str,
    obj_idx: usize,
) -> Vec<[f64; 2]> {
    trial_rows
        .iter()
        .filter_map(|row| {
            let x = row.params.get(param_name).copied()?;
            let y = row.objectives.get(obj_idx).copied()?;
            Some([x, y])
        })
        .collect()
}
```
