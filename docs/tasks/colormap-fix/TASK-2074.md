## 実装詳細

### 1. per-point 色の適用 🔵

**信頼性**: 🔵 *設計文書 dataflow.md の pareto_2d フローより*

**実装ファイル**: `egui-app/src/ui/widgets/pareto_2d.rs`

現在のハードコード実装:

```rust
// 現在: 3つの固定色グループ
plot_ui.points(egui_plot::Points::new(unselected_pts)
    .color(egui::Color32::from_rgba_unmultiplied(100, 100, 200, 50)));
plot_ui.points(egui_plot::Points::new(selected_pts)
    .color(egui::Color32::from_rgb(50, 100, 255)));
plot_ui.points(egui_plot::Points::new(vec![pt])
    .color(egui::Color32::RED));
```

変更後:
- 各ポイントの色を `app_state.chart_colors[trial_index]` から取得
- 選択状態に応じてalpha値を調整
- egui_plot::Points は単一色のみ対応のため、グループ化して描画する戦略を取る

### 2. 描画戦略 🔵

**信頼性**: 🔵 *コード調査（egui_plot API制約）より*

egui_plot::Points の .color() は全点同一色のため、以下の戦略を取る:
- **選択済み**: chart_colors[i] をそのまま使用（グループごとに1つのPointsオブジェクトで色は変わる→個別Points化）
- **未選択**: chart_colors[i] を低alpha（50/255）で描画
- **ハイライト**: 既存の赤色大ポイントを維持

パフォーマンス考慮:
- 同じ色のポイントをバッチ化するか、per-pointごとにPointsを作成する
- 5万点の場合、per-point Points は重いため、色を量子化してグループ化する戦略を検討
