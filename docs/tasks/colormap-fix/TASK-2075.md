## 実装詳細

### 1. scatter_matrix 色対応 🔵

**信頼性**: 🔵 *コード調査（scatter_matrix.rs line 89-90）より*

**実装ファイル**: `egui-app/src/ui/widgets/scatter_matrix.rs`

現在:
```rust
let dot_color = egui::Color32::from_rgb(70, 130, 220);
let point_colors: Vec<egui::Color32> = vec![dot_color; trial_rows.len()];
```

変更後:
```rust
let point_colors: Vec<egui::Color32> = if app_state.chart_colors.is_empty() {
    vec![egui::Color32::from_rgb(70, 130, 220); trial_rows.len()]
} else {
    app_state.chart_colors.clone()
};
```

### 2. cluster_scatter 色対応 🔵

**信頼性**: 🔵 *コード調査（cluster_scatter.rs line 96-103）より*

**実装ファイル**: `egui-app/src/ui/widgets/cluster_scatter.rs`

現在: 5色ハードコードテーブル
```rust
let cluster_colors = [
    egui::Color32::from_rgb(230, 80, 80),
    // ... 5色
];
```

変更後:
- show() メソッドに app_state パラメータを追加
- chart_colors から各点の色を取得
- クラスタグループごとに代表色を決定（グループ内の最初の点の色を使用）
