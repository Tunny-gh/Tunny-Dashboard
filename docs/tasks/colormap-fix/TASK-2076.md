pdp_2dウィジェットのヒートマップカラーマップをAppState.selected_colormapに連動させる。現在のviridis/plasma固定呼び出しを、selected_colormap.to_colormap()に置換する。

## 実装詳細

### 1. PDP ヒートマップのカラーマップ取得変更 🔵

**信頼性**: 🔵 *コード調査（pdp_2d.rs line 149-193）・ユーザヒアリング（連動させる）より*

**実装ファイル**: `egui-app/src/ui/widgets/pdp_2d.rs`

現在:
```rust
let cmap = ColorMap::viridis();  // or ColorMap::plasma()
```

変更後:
```rust
let cmap = app_state.selected_colormap.to_colormap();
```

**信頼性**: 🔵 *設計文書 dataflow.md より*
