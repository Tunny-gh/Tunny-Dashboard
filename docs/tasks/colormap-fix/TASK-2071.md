### 2. normalize_trial 関数 🔵

**信頼性**: 🔵 *設計文書 architecture.md の正規化ロジック表より*

**実装ファイル**: `egui-app/src/render/colormap.rs`

```rust
/// ColorMode に基づいて TrialRow の値を [0.0, 1.0] に正規化する
/// ClusterId の場合は離散パレットのインデックス計算（f32::NAN を返し、呼び出し元で tab10_palette を使用）
pub fn normalize_trial(
    trial: &TrialRow,
    color_mode: &ColorMode,
    max_rank: u32,
    objective_min_max: &[(f64, f64)],
    total_trials: u32,
) -> f32 {
    match color_mode {
        ColorMode::ParetoRank => {
            1.0 - (trial.pareto_rank as f32 / (max_rank.max(1) as f32 + 1.0))
        }
        ColorMode::ObjectiveValue(name) => {
            // objective_names からインデックスを見つけて min-max正規化
            // 実装では objective_min_max にインデックスでアクセス
            // ...
        }
        ColorMode::TrialNumber => {
            trial.trial_id as f32 / (total_trials.max(1) as f32 - 1.0).max(1.0)
        }
        ColorMode::ClusterId => {
            f32::NAN // 離散パレットで直接処理
        }
    }
}
```

**注意**: ObjectiveValueの実装では、呼び出し側でobjective_namesからインデックスを解決してからmin/maxを渡す設計とする。関数シグネチャは実装時に最適化してよい。

### 3. compute_chart_colors 関数 🔵

**信頼性**: 🔵 *設計文書 architecture.md・dataflow.md より*

**実装ファイル**: `egui-app/src/render/colormap.rs`

```rust
/// 全TrialRowの色を計算する
pub fn compute_chart_colors(
    color_mode: &ColorMode,
    colormap_name: &ColormapName,
    trial_rows: &[TrialRow],
    objective_names: &[String],
) -> Vec<egui::Color32> {
    let cmap = colormap_name.to_colormap();
    let palette = tab10_palette();
    let max_rank = trial_rows.iter().map(|r| r.pareto_rank).max().unwrap_or(1);
    let total = trial_rows.len() as u32;

    // ObjectiveValue の min/max を事前計算
    // ...

    trial_rows.iter().map(|trial| {
        match color_mode {
            ColorMode::ClusterId => {
                let id = trial.cluster_id.unwrap_or(0);
                palette[(id.abs() as usize) % palette.len()]
            }
            _ => {
                let t = normalize_trial(trial, color_mode, max_rank, &obj_min_max, total);
                cmap.interpolate(t)
            }
        }
    }).collect()
}
```

**信頼性**: 🔵 *設計文書 architecture.md の正規化ロジック表より*

- rank 0 → 最も高い t 値
