### 3. left_panel.rs の定義削除と呼び出し切り替え 🔵

**信頼性**: 🔵 *requirements.md REQ-002・dataflow.md REQ-002 より*

**実装ファイル**: `egui-app/src/ui/left_panel.rs`

以下の 3 関数の定義を削除する：
- `fn normalize_weights(weights: &mut [f64])` またはその `pub` 版
- `fn compute_improvement_rate(history: &[(u32, f64)], last_n: usize) -> f64`
- `fn build_best_trial_history(...)` （`TrialRow` を受け取るシグネチャ）

呼び出し側コードを以下のように変更する：

```rust
// normalize_weights の呼び出し
tunny_core::multi_objective::weights::normalize_weights(&mut app_state.tradeoff_weights);

// build_best_trial_history の呼び出し（型変換を追加）
let trial_ids: Vec<u32> = trials.iter().map(|t| t.trial_id).collect();
let obj_values: Vec<f64> = trials
    .iter()
    .filter_map(|t| t.objectives.get(objective_idx).copied())
    .collect();
let history = tunny_core::convergence::build_best_trial_history(
    &trial_ids, &obj_values, is_minimize,
);
let rate = tunny_core::convergence::compute_improvement_rate(&history, 100);
```
