## 実装詳細

### 1. `app.rs` の GenerateHtmlReport ブロック変更 🔵

**信頼性**: 🔵 *requirements.md REQ-003 より*

**実装ファイル**: `egui-app/src/app.rs`

変更前（~30行の inline 構築）:
```rust
ToolbarAction::GenerateHtmlReport => {
    // HtmlReportSnapshot { ... } の構築が ~30行
    let snap = HtmlReportSnapshot { ... };
    generate_html_report_async(snap, self.sender());
}
```

変更後（~5行）:
```rust
ToolbarAction::GenerateHtmlReport => {
    if let Some(ctx) = &self.app_state.current_study {
        crate::io::html_report::build_and_send_report(
            ctx, &self.app_state.selected_indices, self.sender(),
        );
    }
}
```

### 2. 不要な use 宣言の削除 🔵

**信頼性**: 🔵 *acceptance-criteria.md TC-003-01 より*

`app.rs` から以下の use 宣言を削除する：
- `use crate::io::html_report::HtmlReportSnapshot;`（または类似のパス）
- `use crate::io::html_report::HtmlTrialRow;`
- `use crate::io::html_report::TrialStatistics;`
- `use crate::io::html_report::generate_html_report_async;`（build_and_send_report 経由で不要になる場合）
