## タスク概要

Pareto系・MCDM系の5ウィジェットファイルに存在するインライン色定数定義・インラインリテラルを `crate::theme::chart_colors` の定数に置換する。

対象ファイル:
- `egui-app/src/ui/widgets/pareto_2d.rs`
- `egui-app/src/ui/widgets/pareto_3d.rs`
- `egui-app/src/ui/widgets/slice_chart.rs`
- `egui-app/src/ui/widgets/mcdm_scatter_chart.rs`
- `egui-app/src/ui/widgets/mcdm_chart.rs`

- [ ] `mcdm_chart.rs` のインラインバー色が `theme::chart_colors` 定数に置換されている

## 実装詳細

### 1. pareto_2d.rs の更新 🔵

**信頼性**: 🔵 *REQ-031・データフロー図の置換マップより*

**実装ファイル**: `egui-app/src/ui/widgets/pareto_2d.rs`

削除する行:
```rust
const COLOR_PARETO: egui::Color32 = egui::Color32::from_rgb(220, 50, 50);
const COLOR_NON_PARETO: egui::Color32 = egui::Color32::from_rgb(50, 150, 250);
const COLOR_NON_PARETO_DIM: egui::Color32 = egui::Color32::from_rgba_premultiplied(50, 150, 250, 60);
const COLOR_PARETO_DIM: egui::Color32 = egui::Color32::from_rgba_premultiplied(220, 50, 50, 60);
```

追加するインポート:
```rust
use crate::theme::colormap::compute_point_alpha;  // 既存を更新
use crate::theme::chart_colors::{COLOR_PARETO, COLOR_NON_PARETO, COLOR_PARETO_DIM, COLOR_NON_PARETO_DIM};
```

### 2. pareto_3d.rs の更新 🔵

**信頼性**: 🔵 *データフロー図の置換マップより*

**実装ファイル**: `egui-app/src/ui/widgets/pareto_3d.rs`

インライン色をすべて定数に置換:
- `from_rgb(220, 80, 80)` → `crate::theme::chart_colors::COLOR_AXIS_X`
- `from_rgb(80, 220, 80)` → `crate::theme::chart_colors::COLOR_AXIS_Y`
- `from_rgb(80, 80, 220)` → `crate::theme::chart_colors::COLOR_AXIS_Z`
- `from_rgb(220, 50, 50)` (Pareto点) → `crate::theme::chart_colors::COLOR_PARETO`
- `from_rgb(50, 150, 250)` (非Pareto点) → `crate::theme::chart_colors::COLOR_NON_PARETO`

追加するインポート:
```rust
use crate::theme::chart_colors::{
    COLOR_AXIS_X, COLOR_AXIS_Y, COLOR_AXIS_Z,
    COLOR_PARETO, COLOR_NON_PARETO
};
```

### 3. slice_chart.rs の更新 🔵

**信頼性**: 🔵 *REQ-032・データフロー図の置換マップより*

**実装ファイル**: `egui-app/src/ui/widgets/slice_chart.rs`

削除する行:
```rust
const COLOR_PARETO: egui::Color32 = egui::Color32::from_rgb(220, 50, 50);
const COLOR_NON_PARETO: egui::Color32 = egui::Color32::from_rgb(100, 149, 237);
```

注意: `slice_chart.rs` の `COLOR_NON_PARETO` は `(100, 149, 237)` で `pareto_2d.rs` の `(50, 150, 250)` と値が異なる。`theme::chart_colors::COLOR_NON_PARETO = (50, 150, 250)` で統一する（EDGE-011の解決）。

### 4. mcdm_scatter_chart.rs の更新 🔵

**信頼性**: 🔵 *REQ-033・ユーザヒアリングより*

**実装ファイル**: `egui-app/src/ui/widgets/mcdm_scatter_chart.rs`

削除するローカル定数:
```rust
pub(crate) const COLOR_RED: Color32 = Color32::from_rgb(255, 0, 0);
pub(crate) const COLOR_ORANGE: Color32 = Color32::from_rgb(255, 165, 0);
pub(crate) const COLOR_YELLOW: Color32 = Color32::from_rgb(255, 255, 0);
pub(crate) const COLOR_GRAY: Color32 = Color32::from_rgb(200, 200, 200);
```

追加するインポートと置換:
```rust
use crate::theme::chart_colors::{COLOR_MCDM_HIGH, COLOR_MCDM_MID, COLOR_MCDM_LOW, COLOR_MCDM_NONE};
```

使用箇所の置換:
- `COLOR_RED` → `COLOR_MCDM_HIGH`
- `COLOR_ORANGE` → `COLOR_MCDM_MID`
- `COLOR_YELLOW` → `COLOR_MCDM_LOW`
- `COLOR_GRAY` → `COLOR_MCDM_NONE`

### 5. mcdm_chart.rs の更新 🔵

**信頼性**: 🔵 *データフロー図の置換マップより*

**実装ファイル**: `egui-app/src/ui/widgets/mcdm_chart.rs`

インライン色を定数に置換:
- `from_rgb(0x0c, 0x6a, 0xc0)` → `crate::theme::chart_colors::COLOR_BAR_PRIMARY`
- `from_rgb(0xc0, 0x20, 0x20)` → `crate::theme::chart_colors::COLOR_BAR_NEGATIVE`
- `from_rgb(0xe0, 0x70, 0x00)` → `crate::theme::chart_colors::COLOR_BAR_ACCENT`

## 注意事項

- `slice_chart.rs` の `COLOR_NON_PARETO` の値 `(100, 149, 237)` は `pareto_2d.rs` の `(50, 150, 250)` と微妙に異なる。`theme::chart_colors::COLOR_NON_PARETO = (50, 150, 250)` で統一するが、視覚的な変化が生じる可能性があることを認識する（REQ-051の「外観変更なし」の例外ケース）
