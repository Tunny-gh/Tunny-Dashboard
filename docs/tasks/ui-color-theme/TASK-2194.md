## 実装詳細

### 1. importance_chart.rs の更新 🔵

**信頼性**: 🔵 *データフロー図の置換マップより*

**実装ファイル**: `egui-app/src/ui/widgets/importance_chart.rs`

置換内容:
- `from_rgb(220, 80, 80)` → `COLOR_FIT_LOW`
- `from_rgb(200, 160, 0)` → `COLOR_FIT_MID`
- `from_rgb(60, 180, 60)` → `COLOR_FIT_HIGH`
- `from_rgb(0x0c, 0x0c, 0x6a)` → `COLOR_IMPORTANCE_BAR`

```rust
use crate::theme::chart_colors::{COLOR_FIT_LOW, COLOR_FIT_MID, COLOR_FIT_HIGH, COLOR_IMPORTANCE_BAR};
```

### 2. sensitivity_heatmap.rs の更新 🟡

**信頼性**: 🟡 *データフロー図の置換マップから妥当な推測*

**実装ファイル**: `egui-app/src/ui/widgets/sensitivity_heatmap.rs`

置換内容:
- ヒートマップの赤/青グラデーション生成関数内のインライン色はダイナミック計算なので置換対象外
- `egui::Color32::GRAY` のグリッド色 → `egui::Color32::GRAY`（組み込み定数のため任意）
- `egui::Color32::BLACK` のテキスト色 → そのまま（組み込み定数）

### 3. scatter_matrix.rs の更新 🔵

**信頼性**: 🔵 *データフロー図の置換マップより*

**実装ファイル**: `egui-app/src/ui/widgets/scatter_matrix.rs`

置換内容:
- `from_rgb(70, 130, 220)` (ドット色) → `COLOR_SCATTER_DOT`

```rust
use crate::theme::chart_colors::COLOR_SCATTER_DOT;
```

注意: `scatter_matrix.rs` のヒートマップグラデーション計算（`from_rgb((255.0 * f) as u8, ...)` 等）はダイナミック計算なので置換対象外。

### 4. parallel_coords.rs の更新 🟡

**信頼性**: 🟡 *データフロー図の置換マップから妥当な推測*

**実装ファイル**: `egui-app/src/ui/widgets/parallel_coords.rs`

置換内容:
- `egui::Color32::WHITE` 背景 → そのまま（組み込み定数、任意）
- `egui::Color32::BLACK` テキスト → そのまま
- `from_gray(60)` ティック色 → そのまま（動的生成）
- `from_rgb(100, 150, 220)` デフォルトライン色 → `COLOR_NON_PARETO` に近いが異なる値。新定数 `COLOR_PARALLEL_LINE` を chart_colors.rs に追加するか、そのまま残すかは実装者の判断

### 5. pdp_chart.rs の更新 🔵

**信頼性**: 🔵 *データフロー図の置換マップより*

**実装ファイル**: `egui-app/src/ui/widgets/pdp_chart.rs`

置換内容:
- `from_rgb(50, 100, 255)` → `COLOR_PDP_LINE`
- `from_rgba_unmultiplied(50, 100, 255, 50)` → `COLOR_PDP_CI`
- `from_rgba_unmultiplied(150, 150, 150, 60)` → `COLOR_ICE_LINE`
- `from_rgb(220, 50, 50)` (Pareto線) → `COLOR_PARETO`

```rust
use crate::theme::chart_colors::{COLOR_PDP_LINE, COLOR_PDP_CI, COLOR_ICE_LINE, COLOR_PARETO};
```

### 6. pdp_2d.rs の更新 🔵

**信頼性**: 🔵 *データフロー図の置換マップより*

**実装ファイル**: `egui-app/src/ui/widgets/pdp_2d.rs`

置換内容:
- `egui::Color32::YELLOW` (等高線) → `crate::theme::chart_colors::COLOR_CONTOUR`

## 注意事項

- `sensitivity_heatmap.rs` のヒートマップ赤/青グラデーションは `f` パラメータに依存した計算式なので置換対象外
- `scatter_matrix.rs` の相関係数ヒートマップ色も同様に動的計算のため対象外
- `parallel_coords.rs` の `from_gray(60)` は輝度値からの計算なので対象外
- `pdp_chart.rs` の `from_rgba_unmultiplied` は `chart_colors.rs` の `from_rgba_premultiplied` 変換済み定数を使用する
