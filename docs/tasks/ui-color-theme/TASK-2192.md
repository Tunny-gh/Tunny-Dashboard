## 注意事項

- `from_rgba_premultiplied` の値は `from_rgba_unmultiplied(r, g, b, a)` から変換: `r_pre = r * a / 255`
  - `(37, 99, 235, 40)` → `(6, 16, 37, 40)`
  - `(37, 99, 235, 80)` → `(12, 31, 74, 80)`
  - `(50, 100, 255, 50)` → `(10, 20, 50, 50)`
  - `(150, 150, 150, 60)` → `(35, 35, 35, 60)`
- `COLOR_IMPORTANCE_BAR` (12,12,106) は暗いネイビー、`COLOR_BAR_PRIMARY` (12,106,192) は明るいブルーであることを確認
