## タスク概要

残りのウィジェットファイル（最適化履歴・HV・クラスタ・AHP・トライアルテーブル）のインライン色リテラルを `crate::theme::chart_colors` の定数に置換する。

対象ファイル:
- `egui-app/src/ui/widgets/optimization_history.rs`
- `egui-app/src/ui/widgets/hv_history.rs`
- `egui-app/src/ui/widgets/cluster_scatter.rs`
- `egui-app/src/ui/widgets/ahp_chart.rs`
- `egui-app/src/ui/widgets/trial_table.rs`
