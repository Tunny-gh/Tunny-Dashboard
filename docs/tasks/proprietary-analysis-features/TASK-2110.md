## タスク概要

`egui-app/src/state/app_state.rs` の `AppState` 構造体に、Trade-off Navigator（REQ-001）・多 Study 比較（REQ-006）・アーティファクト連携（REQ-007）・単目的 Best 履歴（REQ-008）に必要な 8 フィールドを追加する。

- `comparison_mode: bool`
- `comparison_studies: Vec<StudyContext>`
- `comparison_colors: Vec<egui::Color32>`
- `artifacts_dir: Option<PathBuf>`
- `artifact_map: HashMap<u32, Vec<PathBuf>>`
- `best_trial_history: Option<Vec<(u32, f64)>>`

## 単体テスト要件

### テストケース 1: デフォルト値の確認 🔵

**信頼性**: 🔵 *既存 AppState テストパターンより*

**Given**: `AppState::new()` または `AppState::default()` を呼び出す
**When**: 追加フィールドにアクセスする
**Then**: 各フィールドが初期値である

**テストファイル**: `egui-app/src/state/app_state.rs` (`#[cfg(test)]` ブロック内)

```rust
#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn test_app_state_new_defaults() {
        let state = AppState::new();
        assert!(state.tradeoff_weights.is_empty());
        assert!(state.tradeoff_sorted_indices.is_none());
        assert!(!state.comparison_mode);
        assert!(state.comparison_studies.is_empty());
        assert_eq!(state.comparison_colors.len(), 4);
        assert!(state.artifacts_dir.is_none());
        assert!(state.artifact_map.is_empty());
        assert!(state.best_trial_history.is_none());
    }
}
```
