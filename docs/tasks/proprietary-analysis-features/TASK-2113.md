## 単体テスト要件

### テストケース 1: `axis_visibility` のデフォルト値 🔵

**信頼性**: 🔵 *REQ-009-A の軸表示仕様より*

**Given**: `ParallelCoordsChart::default()` を呼び出す
**When**: `axis_visibility` にアクセスする
**Then**: 空の HashMap（すべて表示状態）

**テストファイル**: `egui-app/src/ui/widgets/parallel_coords.rs`

```rust
#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn test_axis_visibility_default_empty() {
        let chart = ParallelCoordsChart::default();
        assert!(chart.axis_visibility.is_empty());
        // 空 HashMap = 軸はすべて表示（UI 側で未登録 → true と解釈）
    }

    #[test]
    fn test_axis_visibility_toggle() {
        let mut chart = ParallelCoordsChart::default();
        chart.axis_visibility.insert("x1".to_string(), false);
        assert_eq!(chart.axis_visibility.get("x1"), Some(&false));
        // 非表示設定が保持されることを確認
        chart.axis_visibility.insert("x1".to_string(), true);
        assert_eq!(chart.axis_visibility.get("x1"), Some(&true));
    }
}
```
