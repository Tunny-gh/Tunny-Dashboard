| `ArtifactsDirScanned` | `trial_artifacts: HashMap<u32, Vec<PathBuf>>`, `artifacts_dir: PathBuf` | Artifacts スキャン完了 | REQ-007 |
| `HtmlReportDone` | `html: String`, `suggested_filename: String` | HTML レポート生成完了 | REQ-005 |

### テストケース 1: `TradeoffDone` バリアントの構築 🔵

**信頼性**: 🔵 *既存 AppMessage テストパターンより*

**Given**: `sorted_indices: vec![2, 0, 1]` を持つ `TradeoffDone` を構築する
**When**: フィールドにアクセスする
**Then**: `sorted_indices` が `[2, 0, 1]` である

**テストファイル**: `egui-app/src/state/messages.rs` (`#[cfg(test)]`)

```rust
#[test]
fn test_tradeoff_done_construction() {
    let msg = AppMessage::TradeoffDone { sorted_indices: vec![2, 0, 1] };
    if let AppMessage::TradeoffDone { sorted_indices } = msg {
        assert_eq!(sorted_indices, vec![2, 0, 1]);
    } else {
        panic!("Expected TradeoffDone");
    }
}
```

### テストケース 2: `ArtifactsDirScanned` のフィールド確認 🔵

**信頼性**: 🔵 *REQ-007-A・dataflow.md REQ-007 シーケンス図より*

**Given**: `ArtifactsDirScanned { trial_artifacts, artifacts_dir }` を構築する
**When**: `trial_artifacts` に trial_id=42 のエントリを持つ map を設定する
**Then**: `trial_artifacts.contains_key(&42)` が true

```rust
#[test]
fn test_artifacts_dir_scanned_construction() {
    use std::collections::HashMap;
    use std::path::PathBuf;
    let mut map = HashMap::new();
    map.insert(42u32, vec![PathBuf::from("artifacts/42/result.png")]);
    let msg = AppMessage::ArtifactsDirScanned {
        trial_artifacts: map,
        artifacts_dir: PathBuf::from("artifacts"),
    };
    if let AppMessage::ArtifactsDirScanned { trial_artifacts, .. } = msg {
        assert!(trial_artifacts.contains_key(&42));
    }
}
```
