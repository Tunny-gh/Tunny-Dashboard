## テスト実装

### テスト 1: ArtifactsScanner — 一時ディレクトリのスキャン（REQ-007） 🔵

**信頼性**: 🔵 *REQ-007-B・NFR-201・ArtifactsScanner API より*

```rust
#[test]
fn test_scan_artifacts_dir_finds_files() {
    use tempfile::TempDir;
    use crate::io::artifacts::scan_artifacts_dir;

    let tmp = TempDir::new().unwrap();
    let artifacts_base = tmp.path();

    // 模擬 artifacts ディレクトリ構造を作成
    // trial_0/ → result.png
    // trial_1/ → data.csv
    // trial_2/ → output.txt
    let trial_dirs = ["trial_0", "trial_1", "trial_2"];
    let files = ["result.png", "data.csv", "output.txt"];

    for (dir_name, file_name) in trial_dirs.iter().zip(files.iter()) {
        let dir = artifacts_base.join(dir_name);
        std::fs::create_dir_all(&dir).unwrap();
        std::fs::write(dir.join(file_name), b"dummy content").unwrap();
    }

    // スキャン実行
    let artifact_map = scan_artifacts_dir(artifacts_base).unwrap();

    // 各 trial のファイルが検出される
    assert_eq!(artifact_map.len(), 3);
    // trial_0 (trial_id=0) の PNG が含まれる
    assert!(artifact_map.values().any(|files| {
        files.iter().any(|p| p.extension().and_then(|e| e.to_str()) == Some("png"))
    }));
}
```

### テスト 4: HtmlReportBuilder — HTML 出力の基本確認（REQ-005） 🔵

**信頼性**: 🔵 *REQ-005・build_html_report() API より*

```rust
#[test]
fn test_build_html_report_returns_valid_html() {
    use crate::io::html_report::{build_html_report, HtmlReportSnapshot};

    let snapshot = HtmlReportSnapshot {
        study_name: "test_study".to_string(),
        trials: vec![
            HtmlTrialRow { trial_id: 0, objective_value: 0.5, params: vec![] },
            HtmlTrialRow { trial_id: 1, objective_value: 0.3, params: vec![] },
        ],
        statistics: TrialStatistics {
            n_trials: 2,
            best_value: 0.3,
            median: 0.4,
            std_dev: 0.1,
        },
    };

    let html = build_html_report(&snapshot);

    // 基本的な HTML 構造を確認
    assert!(html.contains("<!DOCTYPE html>") || html.contains("<html"));
    assert!(html.contains("test_study"));
    assert!(html.contains("0.3"));  // Best 値が含まれる
    // スクリプトインジェクション対策：study_name が適切にエスケープされている
    assert!(!html.contains("<script>") || html.contains("&lt;script&gt;"));
}
```

### テスト 5: HtmlReportBuilder — HTML インジェクション対策（REQ-005/セキュリティ） 🔵

**信頼性**: 🔵 *OWASP XSS・TASK-2117 のエスケープ要件より*

```rust
#[test]
fn test_build_html_report_escapes_user_data() {
    use crate::io::html_report::{build_html_report, HtmlReportSnapshot};

    let snapshot = HtmlReportSnapshot {
        study_name: "<script>alert('xss')</script>".to_string(),
        trials: vec![],
        statistics: TrialStatistics::default(),
    };

    let html = build_html_report(&snapshot);

    // study_name の <script> タグがエスケープされている
    assert!(!html.contains("<script>alert('xss')</script>"),
        "HTML インジェクションを許容してはならない");
    assert!(html.contains("&lt;script&gt;") || html.contains("&lt;"),
        "< は &lt; にエスケープされること");
}
```

### テスト 6: AppMessage チャネル — ArtifactsDirScanned 往復（REQ-007） 🟡

**信頼性**: 🟡 *mpsc チャネルのテストパターンは spawn_task の実装に依存するため推測*

```rust
#[test]
fn test_artifacts_dir_scanned_message_round_trip() {
    use std::sync::mpsc;
    use std::collections::HashMap;
    use std::path::PathBuf;
    use crate::app_message::AppMessage;

    let (tx, rx) = mpsc::channel::<AppMessage>();

    // 模擬スキャン結果を送信
    let mut trial_artifacts: HashMap<u32, Vec<PathBuf>> = HashMap::new();
    trial_artifacts.insert(0, vec![PathBuf::from("/tmp/trial_0/result.png")]);

    tx.send(AppMessage::ArtifactsDirScanned {
        trial_artifacts: trial_artifacts.clone(),
        artifacts_dir: PathBuf::from("/tmp"),
    }).unwrap();

    // 受信確認
    match rx.recv().unwrap() {
        AppMessage::ArtifactsDirScanned { trial_artifacts: received, artifacts_dir } => {
            assert_eq!(received.len(), 1);
            assert!(received.contains_key(&0));
            assert_eq!(artifacts_dir, PathBuf::from("/tmp"));
        }
        _ => panic!("予期しないメッセージタイプ"),
    }
}
```
