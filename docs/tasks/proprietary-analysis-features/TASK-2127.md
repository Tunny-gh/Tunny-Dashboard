## テスト実装

### テスト 1: フィルタ JSON 往復（REQ-002） 🔵

**信頼性**: 🔵 *REQ-002・save_filter_json / load_filter_json API より*

```rust
#[test]
fn test_filter_json_roundtrip() {
    use tempfile::NamedTempFile;
    use crate::io::session::{save_filter_json, load_filter_json, FilterConfig};

    let original = FilterConfig {
        min_values: vec![0.1, 0.2],
        max_values: vec![0.9, 0.8],
        selected_params: vec!["x1".to_string(), "x2".to_string()],
    };

    let tmp = NamedTempFile::new().unwrap();
    save_filter_json(&original, tmp.path()).unwrap();

    let loaded = load_filter_json(tmp.path()).unwrap();
    assert_eq!(loaded.min_values, original.min_values);
    assert_eq!(loaded.max_values, original.max_values);
    assert_eq!(loaded.selected_params, original.selected_params);
}
```

### テスト 3: `.tdash` SessionSnapshot 全フィールド往復（REQ-004） 🔵

**信頼性**: 🔵 *REQ-004・SessionSnapshot 11 フィールドの serde(default) 設計より*

```rust
#[test]
fn test_tdash_session_roundtrip() {
    use tempfile::NamedTempFile;
    use crate::io::session::SessionSnapshot;

    let original = SessionSnapshot {
        version: 1,
        study_file_path: Some("/path/to/study.db".to_string()),
        filter_config: Some(FilterConfig { /* ... */ }),
        layout_config: Some(LayoutConfig { /* ... */ }),
        tradeoff_weights: vec![0.5, 0.5],
        comparison_study_paths: vec!["/path/a.db".to_string()],
        artifacts_dir: Some("/path/to/artifacts".to_string()),
        // 残りのフィールド（serde(default) 対象）はデフォルトで OK
        ..Default::default()
    };

    let tmp = NamedTempFile::new().unwrap();
    // .tdash 形式（JSON）で保存
    let json = serde_json::to_string(&original).unwrap();
    std::fs::write(tmp.path(), &json).unwrap();

    // 読み込み
    let content = std::fs::read_to_string(tmp.path()).unwrap();
    let loaded: SessionSnapshot = serde_json::from_str(&content).unwrap();

    assert_eq!(loaded.version, original.version);
    assert_eq!(loaded.study_file_path, original.study_file_path);
    assert_eq!(loaded.tradeoff_weights, original.tradeoff_weights);
    assert_eq!(loaded.comparison_study_paths, original.comparison_study_paths);
}
```

### テスト 5: 旧バージョン互換性（欠落フィールドのデフォルト値） 🔵

**信頼性**: 🔵 *REQ-004・serde(default) 設計より（前方互換保証）*

```rust
#[test]
fn test_tdash_missing_fields_use_defaults() {
    use crate::io::session::SessionSnapshot;

    // 新フィールドが含まれていない旧バージョンの JSON
    let old_json = r#"{"version": 1, "study_file_path": null}"#;
    let loaded: SessionSnapshot = serde_json::from_str(old_json).unwrap();

    // serde(default) により新フィールドはデフォルト値になる
    assert!(loaded.tradeoff_weights.is_empty());
    assert!(loaded.comparison_study_paths.is_empty());
    assert_eq!(loaded.artifacts_dir, None);
}
```
