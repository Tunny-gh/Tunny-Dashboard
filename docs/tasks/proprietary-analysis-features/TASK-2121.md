### 1. Trial Table に Artifacts 列を追加 🔵

**信頼性**: 🔵 *REQ-007-C・architecture.md Bottom Panel 拡張より*

**実装ファイル**: `egui-app/src/ui/bottom_panel.rs`

```rust
// show_trial_table() 内、テーブルヘッダーに追加
// REQ-007-H: artifact_map が空でない場合のみ列を追加
let show_artifacts_col = !app_state.artifact_map.is_empty();

// ヘッダー行
if show_artifacts_col {
    row.col(|ui| { ui.strong("Artifacts"); });
}

// データ行（各 trial）
if show_artifacts_col {
    row.col(|ui| {
        let trial_id = trial.trial_id;
        if let Some(files) = app_state.artifact_map.get(&trial_id) {
            let icon = artifact_icon(files);
            let btn = ui.button(icon);
            if btn.clicked() {
                // REQ-007-D: モーダル開口フラグ
                widget_states.artifact_modal_trial_id = Some(trial_id);
                widget_states.artifact_modal_open = true;
            }
        }
    });
}
```

### 2. `artifact_icon` — ファイルタイプアイコン選択 🔵

**信頼性**: 🔵 *REQ-007-C（ファイルタイプアイコン）・REQ-007-E/F/G より*

```rust
/// trial の artifacts ファイルリストから最初のファイルのタイプに基づくアイコンを返す
fn artifact_icon(files: &[std::path::PathBuf]) -> &'static str {
    if files.is_empty() {
        return "";
    }
    use crate::io::artifacts::ArtifactFileType;
    match ArtifactFileType::from_path(&files[0]) {
        ArtifactFileType::Image => "🖼",  // 画像
        ArtifactFileType::Csv   => "📊",  // CSV
        ArtifactFileType::Other => "📎",  // その他
    }
}
```

（egui フォントで絵文字が表示されない場合は `[IMG]`・`[CSV]`・`[FILE]` などの ASCII テキストに変更する）

**Then**: 画像アイコン文字列が返る

fn test_artifact_icon_image() {
    use std::path::PathBuf;
    let files = vec![PathBuf::from("result.png")];
    let icon = artifact_icon(&files);
