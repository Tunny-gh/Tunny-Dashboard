## 実装詳細

### 1. `show_convergence_card()` 関数 🔵

**信頼性**: 🔵 *REQ-008-A/B・architecture.md Layer 4: UI 既存拡張テーブルより*

**実装ファイル**: `egui-app/src/ui/left_panel.rs`

```rust
/// 収束診断カード（単目的 Study 時のみ表示）
pub fn show_convergence_card(
    ui: &mut egui::Ui,
    app_state: &AppState,
) {
    ui.separator();
    ui.collapsing("📈 収束診断", |ui| {
        match &app_state.best_trial_history {
            None => {
                ui.label("データなし");
                return;
            }
            Some(history) if history.is_empty() => {
                ui.label("試行データがありません");
                return;
            }
            Some(history) => {
                // REQ-008-B: Best 値と Best 達成 Trial ID
                let (best_trial_id, best_value) = history
                    .iter()
                    .min_by(|a, b| a.1.partial_cmp(&b.1).unwrap_or(std::cmp::Ordering::Equal))
                    .copied()
                    .unwrap();
                ui.label(format!("Best 値: {:.6}", best_value));
                ui.label(format!("Best Trial: #{}", best_trial_id));

                // REQ-008-B: 直近 100 試行の改善率
                let improvement_rate = compute_improvement_rate(history, 100);
                ui.label(format!("直近 100 試行の改善率: {:.1}%", improvement_rate * 100.0));
            }
        }
    });
}
```

### 2. `compute_improvement_rate` — 改善率計算 🔵

**信頼性**: 🔵 *REQ-008-B「直近 100 試行の改善率」より*

```rust
/// 直近 last_n 試行で Best 値が改善された割合を計算する
/// (0.0 = 一度も改善なし, 1.0 = すべての試行で改善)
fn compute_improvement_rate(history: &[(u32, f64)], last_n: usize) -> f64 {
    let window: Vec<_> = history.iter().rev().take(last_n).collect();
    if window.len() < 2 {
        return 0.0;
    }
    let mut best_so_far = f64::INFINITY;
    let mut improved_count = 0usize;
    for &(_, val) in window.iter().rev() {
        if val < best_so_far {
            best_so_far = val;
            improved_count += 1;
        }
    }
    (improved_count as f64) / (window.len() as f64)
}
```

### 3. `build_best_trial_history` — Study 読み込み時のデータ構築 🔵

**信頼性**: 🔵 *REQ-008-B・AppState.best_trial_history 設計より*

**実装ファイル**: `egui-app/src/state/app_state.rs` または `egui-app/src/app.rs`

Study が読み込まれたとき（`StudyLoaded` メッセージ処理時）に以下を実行:

```rust
/// 単目的 Study の Best 値推移を計算して AppState に格納する
pub fn build_best_trial_history(
    trials: &[TrialRow],
    objective_idx: usize,
    is_minimize: bool,
) -> Vec<(u32, f64)> {
    let mut history = Vec::with_capacity(trials.len());
    let mut best = if is_minimize { f64::INFINITY } else { f64::NEG_INFINITY };

    for trial in trials {
        if let Some(&obj_val) = trial.objectives.get(objective_idx) {
            let improved = if is_minimize { obj_val < best } else { obj_val > best };
            if improved {
                best = obj_val;
            }
            history.push((trial.trial_id, best));
        }
    }
    history
}
```

## 注意事項

- `best_trial_history` は `Option<Vec<(u32, f64)>>` で `u32` が trial_id、`f64` が Best 値の推移（毎 trial の累積 Best 値）
