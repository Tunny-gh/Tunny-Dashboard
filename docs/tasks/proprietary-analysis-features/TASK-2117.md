### 2. `build_html_report` — HTML 文字列生成 🔵

**信頼性**: 🔵 *REQ-005-B/C（セクション要件・スタンドアロン要件）より*

```rust
/// スタンドアロン HTML レポートを生成する（外部リソース参照なし）
pub fn build_html_report(snapshot: &HtmlReportSnapshot) -> String {
    let mut html = String::with_capacity(64 * 1024);

    html.push_str(r#"<!DOCTYPE html>
<html lang="ja">
<head>
<meta charset="UTF-8">
<title>Tunny Dashboard Report</title>
<style>
body { font-family: sans-serif; margin: 20px; }
table { border-collapse: collapse; width: 100%; }
th, td { border: 1px solid #ccc; padding: 6px 8px; text-align: right; }
th { background: #f0f0f0; }
h1, h2 { color: #333; }
.summary { display: flex; gap: 20px; margin-bottom: 20px; }
.card { border: 1px solid #ddd; border-radius: 4px; padding: 12px; min-width: 120px; }
</style>
</head>
<body>"#);

    // --- Section 1: スタディ情報サマリー ---
    write_study_summary(&mut html, snapshot);

    // --- Section 2: SVG チャート（散布図）---
    write_scatter_svg_section(&mut html, snapshot);

    // --- Section 3: 選択試行テーブル ---
    write_trial_table(&mut html, snapshot);

    // --- Section 4: 統計情報 ---
    write_statistics(&mut html, snapshot);

    html.push_str("</body></html>");
    html
}
```

各セクション関数は `write!(html, "...")` マクロで文字列追記する（clone なし）。

### 4. `generate_html_report_async` — 非同期生成 🔵

**信頼性**: 🔵 *NFR-003（10秒以内）・architecture.md spawn_task パターンより*

```rust
use std::sync::mpsc::SyncSender;
use crate::state::messages::AppMessage;

pub fn generate_html_report_async(
    snapshot: HtmlReportSnapshot,
    tx: SyncSender<AppMessage>,
) {
    crate::spawn_task(move || {
        let html = build_html_report(&snapshot);
        let filename = format!(
            "{}_report_{}.html",
            sanitize_filename(&snapshot.study_name),
            chrono_timestamp(),
        );
        let _ = tx.send(AppMessage::HtmlReportDone {
            html,
            suggested_filename: filename,
        });
    });
}

fn sanitize_filename(name: &str) -> String {
    name.chars()
        .map(|c| if c.is_alphanumeric() || c == '_' || c == '-' { c } else { '_' })
        .collect()
}
```

## 注意事項

- `chrono_timestamp()` は `chrono` クレートを使う場合は `Cargo.toml` への追加が必要。代替として `std::time::SystemTime` を使い Unix timestamp を文字列化する方法も可
- HTML インジェクション防止: `write_study_summary` 等でユーザーデータ（スタディ名・変数名）を HTML に埋め込む際は `<>&"` をエスケープすること
- `write!(html, ...)` は `std::fmt::Write` トレイトが必要（`use std::fmt::Write;` を追加）
- SVG の点描画は座標変換（min-max スケーリング）のみで OK。データ点数が多い場合（10000 件超）はサンプリングする
