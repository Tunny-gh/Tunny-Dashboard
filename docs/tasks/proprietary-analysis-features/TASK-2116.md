## 実装詳細

### 1. `detect_artifacts_dir` — 自動検出 🔵

**信頼性**: 🔵 *REQ-007-A より*

**実装ファイル**: `egui-app/src/io/artifacts.rs`（新規）

```rust
use std::path::{Path, PathBuf};

/// Journal ファイルの親ディレクトリに `artifacts/` フォルダが存在するか検出する
/// 存在する場合は Some(artifacts_dir)、存在しない場合は None を返す
pub fn detect_artifacts_dir(journal_path: &Path) -> Option<PathBuf> {
    let parent = journal_path.parent()?;
    let artifacts_dir = parent.join("artifacts");
    if artifacts_dir.is_dir() {
        Some(artifacts_dir)
    } else {
        None
    }
}
```

### 2. `ArtifactFileType` enum — ファイルタイプ判別 🔵

**信頼性**: 🔵 *REQ-007-E/F/G より*

```rust
#[derive(Debug, Clone, PartialEq)]
pub enum ArtifactFileType {
    Image,   // PNG / JPG / JPEG / GIF / WEBP
    Csv,     // CSV
    Other,   // その他
}

impl ArtifactFileType {
    pub fn from_path(path: &Path) -> Self {
        match path.extension().and_then(|e| e.to_str()).map(str::to_lowercase).as_deref() {
            Some("png") | Some("jpg") | Some("jpeg") | Some("gif") | Some("webp") => Self::Image,
            Some("csv") => Self::Csv,
            _ => Self::Other,
        }
    }
}
```

### 3. `validate_path` — パストラバーサル防止（NFR-201） 🔵

**信頼性**: 🔵 *architecture.md NFR-201 実現方法・OWASP パストラバーサル対策より*

```rust
#[derive(Debug)]
pub enum ArtifactsError {
    PathTraversal,
    Io(std::io::Error),
}

/// base_dir 外へのアクセスを防ぐ安全なパス検証
/// パストラバーサル（`../` 等）を検出した場合は Err(PathTraversal) を返す
pub fn validate_path(base_dir: &Path, file_path: &Path) -> Result<PathBuf, ArtifactsError> {
    let canonical_base = base_dir.canonicalize().map_err(ArtifactsError::Io)?;
    let canonical_file = file_path.canonicalize().map_err(ArtifactsError::Io)?;
    if canonical_file.starts_with(&canonical_base) {
        Ok(canonical_file)
    } else {
        Err(ArtifactsError::PathTraversal)
    }
}
```

### 4. `scan_artifacts_dir` — フォルダスキャン + `ArtifactsDirScanned` 送信 🔵

**信頼性**: 🔵 *REQ-007-A/C・dataflow.md REQ-007 シーケンス図より*

```rust
use std::collections::HashMap;
use std::sync::mpsc::SyncSender;
use crate::state::messages::AppMessage;

/// artifacts/ フォルダをスキャンし、trial_id 別にファイルをグループ化する
/// ディレクトリ構造: artifacts/{trial_id}/file.ext または artifacts/{trial_id}_file.ext
pub fn scan_artifacts_dir(base_dir: PathBuf, tx: SyncSender<AppMessage>) {
    crate::spawn_task(move || {
        let mut trial_artifacts: HashMap<u32, Vec<PathBuf>> = HashMap::new();

        if let Ok(entries) = std::fs::read_dir(&base_dir) {
            for entry in entries.flatten() {
                let path = entry.path();
                // trial_id をパス名から解析（先頭数値部分）
                if let Some(trial_id) = extract_trial_id(&path) {
                    // NFR-201: validate_path でセキュリティ検証
                    if validate_path(&base_dir, &path).is_ok() {
                        trial_artifacts.entry(trial_id).or_default().push(path);
                    }
                }
            }
        }

        let _ = tx.send(AppMessage::ArtifactsDirScanned {
            trial_artifacts,
            artifacts_dir: base_dir,
        });
    });
}

/// ファイル/ディレクトリ名の先頭数値を trial_id として抽出する
fn extract_trial_id(path: &Path) -> Option<u32> {
    let name = path.file_name()?.to_str()?;
    // 例: "42" (ディレクトリ名) または "42_result.png" (ファイル名)
    name.split(|c: char| !c.is_ascii_digit())
        .next()
        .and_then(|s| s.parse::<u32>().ok())
}
```

```rust
fn test_detect_artifacts_dir_exists() {
    let tmp = tempfile::tempdir().unwrap();
```

```rust
#[test]
fn test_validate_path_traversal_blocked() {
    let tmp = tempfile::tempdir().unwrap();
    let base = tmp.path();
    // base_dir 外のパスを参照しようとする
    let outside = base.join("../outside_file.txt");
    // ファイルが存在しないと canonicalize() が失敗するので Io エラーも許容
    let result = validate_path(base, &outside);
    assert!(matches!(result, Err(ArtifactsError::PathTraversal) | Err(ArtifactsError::Io(_))));
}
```
