## タスク概要

`egui-app/src/` の `MessageHandler`（`app.rs` または専用ファイル）の `handle()` メソッドに、TASK-2112 で追加した 4 バリアント (`TradeoffDone`, `ComparisonStudyLoaded`, `ArtifactsDirScanned`, `HtmlReportDone`) の処理アームを実装する。各バリアントは対応する `AppState` フィールド（TASK-2110）を更新する。

```rust
        // comparison_studies を必要に応じてリサイズ
        if app_state.comparison_studies.len() <= study_idx {

}
```

```rust
AppMessage::HtmlReportDone { html, suggested_filename } => {
    // rfd::FileDialog で保存先を選択させてファイルに書き込む
    if let Some(path) = rfd::FileDialog::new()
        .set_file_name(&suggested_filename)
        .add_filter("HTML", &["html"])
        .save_file()
    {
        let _ = std::fs::write(&path, html.as_bytes());
    }
}
```

### 5. Trade-off Navigator の `spawn_task` ワイヤリング 🔵

**信頼性**: 🔵 *dataflow.md REQ-001 シーケンス図・tradeoff.rs 実装調査より*

Trade-off Navigator スライダー変更時（UI 側 TASK-2119 で呼ばれる）に以下を実行:

```rust
// UI 側からの呼び出しエントリーポイント例（app.rs 内の helper 関数）
fn trigger_tradeoff_computation(
    weights: Vec<f64>,
    is_minimize: Vec<bool>,
    sorted_pareto_indices: Vec<u32>,
    tx: mpsc::SyncSender<AppMessage>,
) {
    spawn_task(move || {
        let sorted = rust_core::multi_objective::pareto::tradeoff::score_tradeoff_navigator(
            &weights,
            &is_minimize,
        );
        let _ = tx.send(AppMessage::TradeoffDone { sorted_indices: sorted });
    });
}
```

## 注意事項

- 既存の `MessageHandler::handle()` が `match` で実装されている場合、新バリアントのアームを追加するだけでよい
- `StudyContext::default()` が実装されていない場合、`comparison_studies.resize_with` の代替として `push` パターンを使用すること
- `HtmlReportDone` の処理で `rfd::FileDialog` を MessageHandler 内で呼ぶのが適切か、または UI スレッドに委ねるかを確認する（egui のスレッドモデルによっては UI スレッドでのみ呼べる制約がある）
