## 実装詳細

### 1. `show_tradeoff_navigator()` 関数の追加 🔵

**信頼性**: 🔵 *architecture.md Layer 4: UI 既存拡張テーブル・REQ-001-A より*

**実装ファイル**: `egui-app/src/ui/left_panel.rs`

```rust
/// Trade-off Navigator セクション（多目的 Study 時のみ表示）
pub fn show_tradeoff_navigator(
    ui: &mut egui::Ui,
    app_state: &mut AppState,
    objective_names: &[String],
    is_minimize: &[bool],
    tx: &mpsc::SyncSender<AppMessage>,
) {
    // REQ-001-A/F: 目的数 ≥ 2 の場合のみ表示
    if objective_names.len() < 2 {
        return;
    }

    ui.separator();
    ui.collapsing("★ Trade-off Navigator", |ui| {
        // 重みスライダーのリサイズ（目的数に合わせる）
        if app_state.tradeoff_weights.len() != objective_names.len() {
            let n = objective_names.len();
            app_state.tradeoff_weights = vec![1.0 / n as f64; n];
        }

        let mut changed = false;

        // REQ-001-B: 各目的のスライダー
        for (i, name) in objective_names.iter().enumerate() {
            let old_val = app_state.tradeoff_weights[i];
            let mut val = old_val as f32;
            if ui.add(egui::Slider::new(&mut val, 0.0_f32..=1.0_f32)
                .text(name)).changed()
            {
                app_state.tradeoff_weights[i] = val as f64;
                changed = true;
            }
        }

        // REQ-001-C: 重みの正規化
        if changed {
            normalize_weights(&mut app_state.tradeoff_weights);
            // REQ-001-D: 非同期スコアリング
            trigger_tradeoff_computation(
                app_state.tradeoff_weights.clone(),
                is_minimize.to_vec(),
                tx.clone(),
            );
        }

        // REQ-001-E: 最良解の表示
        if let Some(indices) = &app_state.tradeoff_sorted_indices {
            if let Some(&best_idx) = indices.first() {
                ui.label(format!("★ 最良解: Trial #{}", best_idx));
            }
        }
    });
}
```

### 2. `normalize_weights` — 重み正規化 🔵

**信頼性**: 🔵 *REQ-001-C より*

```rust
/// 重みベクタの合計が 1.0 になるよう正規化する
/// 合計が 0 の場合は均等分割にフォールバック
fn normalize_weights(weights: &mut Vec<f64>) {
    let sum: f64 = weights.iter().sum();
    if sum > f64::EPSILON {
        for w in weights.iter_mut() {
            *w /= sum;
        }
    } else {
        // フォールバック: 均等分割
        let n = weights.len();
        if n > 0 {
            let uniform = 1.0 / n as f64;
            for w in weights.iter_mut() {
                *w = uniform;
            }
        }
    }
}
```

### 3. `trigger_tradeoff_computation` への委譲 🔵

**信頼性**: 🔵 *dataflow.md REQ-001 シーケンス図・TASK-2114 より*

```rust
/// バックグラウンドで score_tradeoff_navigator を実行し TradeoffDone を送信する
fn trigger_tradeoff_computation(
    weights: Vec<f64>,
    is_minimize: Vec<bool>,
    tx: mpsc::SyncSender<AppMessage>,
) {
    spawn_task(move || {
        let sorted = rust_core::multi_objective::pareto::tradeoff::score_tradeoff_navigator(
            &weights,
            &is_minimize,
        );
        let _ = tx.send(AppMessage::TradeoffDone { sorted_indices: sorted });
    });
}
```

### テストケース 1: `normalize_weights` — 通常ケース 🔵

**信頼性**: 🔵 *REQ-001-C より*

**Given**: `weights = [0.3, 0.6, 0.1]`（合計 1.0）
**When**: `normalize_weights(&mut weights)` を呼ぶ
**Then**: 合計が `1.0`（± ε）になる

```rust
#[test]
fn test_normalize_weights_normal() {
    let mut weights = vec![0.3, 0.6, 0.1];
    normalize_weights(&mut weights);
    let sum: f64 = weights.iter().sum();
    assert!((sum - 1.0).abs() < 1e-10);
}
```

### テストケース 2: `normalize_weights` — 合計 0 のフォールバック 🔵

**Given**: `weights = [0.0, 0.0, 0.0]`
**When**: `normalize_weights(&mut weights)` を呼ぶ
**Then**: 各要素が `1/3`（均等分割）になる

```rust
#[test]
fn test_normalize_weights_zero_sum_fallback() {
    let mut weights = vec![0.0, 0.0, 0.0];
    normalize_weights(&mut weights);
    for w in &weights {
        assert!((w - 1.0 / 3.0).abs() < 1e-10);
    }
}
```
