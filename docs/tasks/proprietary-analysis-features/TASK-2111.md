### 3. `egui::Color32` の serde 非対応問題への対処 🟡

**信頼性**: 🟡 *architecture.md 技術的制約（Rust/egui 制約）から妥当な推測*

`LayoutState` や関連型に `egui::Color32` フィールドが含まれる場合、以下いずれかで対処する:

**Option A（推奨）**: `[r, g, b, a]: [u8; 4]` 形式で保存するカスタムシリアライズを追加

```rust
// Color32 を [u8;4] に変換するヘルパー
fn serialize_color32<S: Serializer>(c: &egui::Color32, s: S) -> Result<S::Ok, S::Error> {
    let rgba = [c.r(), c.g(), c.b(), c.a()];
    rgba.serialize(s)
}

fn deserialize_color32<'de, D: Deserializer<'de>>(d: D) -> Result<egui::Color32, D::Error> {
    let [r, g, b, a] = <[u8; 4]>::deserialize(d)?;
    Ok(egui::Color32::from_rgba_unmultiplied(r, g, b, a))
}
```

**Option B**: `LayoutState` が `Color32` を含まない場合は対処不要（調査上は含まない可能性あり）

### テストケース 2: `LayoutMode` の JSON シリアライズ 🔵

**信頼性**: 🔵 *REQ-003-B の JSON 保存要件より*

**Given**: `LayoutMode::Comparison` を `serde_json::to_string` でシリアライズする
**When**: 結果文字列を `serde_json::from_str` でデシリアライズする
**Then**: `LayoutMode::Comparison` が復元される（ラウンドトリップ成功）

```rust
#[test]
fn test_layout_mode_serde_roundtrip() {
    let mode = LayoutMode::Comparison;
    let json = serde_json::to_string(&mode).unwrap();
    let restored: LayoutMode = serde_json::from_str(&json).unwrap();
    assert_eq!(mode, restored);
}
```
