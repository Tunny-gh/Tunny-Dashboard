## 実装詳細

### 1. stats.rs の新規作成 🔵

**信頼性**: 🔵 *REQ-001-1, REQ-001-2, EDGE-001 より*

**実装ファイル**: `rust_core/src/core/math/stats.rs`

実装する関数:
```rust
/// 列データの平均と標準偏差を返す。
/// - 空スライス: (0.0, 1.0) を返す（ゼロ除算防止）
/// - std < f64::EPSILON: std を 1.0 に固定
pub(crate) fn column_mean_std(vals: &[f64]) -> (f64, f64) {
    let n = vals.len();
    if n == 0 {
        return (0.0, 1.0);
    }
    let nf = n as f64;
    let mean = vals.iter().sum::<f64>() / nf;
    let var = vals.iter().map(|&v| (v - mean).powi(2)).sum::<f64>() / nf;
    let std_dev = var.sqrt();
    let std_dev = if std_dev < f64::EPSILON { 1.0 } else { std_dev };
    (mean, std_dev)
}
```
