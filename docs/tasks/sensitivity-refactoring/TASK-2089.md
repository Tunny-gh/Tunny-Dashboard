## 実装詳細

### 1. sensitivity/ridge.rs の変更 🔵

**信頼性**: 🔵 *REQ-002-1 より*

**実装ファイル**: `rust_core/src/sensitivity/ridge.rs`

`transpose_and_standardize` 関数の変更:

変更前（行14〜18のインライン計算）:
```rust
let nf = n as f64;
for j in 0..p {
    let col = &mut x_cols[j * n..(j + 1) * n];
    let mean: f64 = col.iter().sum::<f64>() / nf;
    let std_dev = (col.iter().map(|&v| (v - mean).powi(2)).sum::<f64>() / nf).sqrt();
    let std_dev = if std_dev < f64::EPSILON { 1.0 } else { std_dev };
    for v in col.iter_mut() { *v = (*v - mean) / std_dev; }
}
```

変更後:
```rust
use crate::core::math::stats::column_mean_std;

// ...
for j in 0..p {
    let col = &mut x_cols[j * n..(j + 1) * n];
    let vals: Vec<f64> = col.to_vec();
    let (mean, std_dev) = column_mean_std(&vals);
    for v in col.iter_mut() { *v = (*v - mean) / std_dev; }
}
```

**注意**: `column_mean_std` は不変スライスを受け取るため、`col` を一旦 `to_vec()` でコピーしてから統計を計算し、再度 `col` を更新する。

## 注意事項

- `col.to_vec()` を経由することで不変スライスの問題を回避する（計算後に元のスライスを更新する2ステップ方式）
- 空スライスの挙動が変わる可能性があるが、`column_mean_std` は `(0.0, 1.0)` を返すためゼロ除算は起きない
- `nf = n as f64` のローカル変数も不要になるので削除する
