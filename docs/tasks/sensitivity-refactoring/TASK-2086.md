## 実装詳細

### 1. types.rs の変更 🔵

**信頼性**: 🔵 *REQ-003-1 より*

**実装ファイル**: `rust_core/src/sensitivity/types.rs`

変更前:
```rust
pub type RfAnovaResult = TreeImportanceResult;
pub type MdiResult = TreeImportanceResult;
pub type ShapResult = TreeImportanceResult;
pub type PermutationResult = TreeImportanceResult;
```

変更後:
```rust
#[derive(Debug, Clone)]
pub struct RfAnovaResult(pub TreeImportanceResult);
#[derive(Debug, Clone)]
pub struct MdiResult(pub TreeImportanceResult);
#[derive(Debug, Clone)]
pub struct ShapResult(pub TreeImportanceResult);
#[derive(Debug, Clone)]
pub struct PermutationResult(pub TreeImportanceResult);
```

### 2. 影響箇所の修正 🔵

**信頼性**: 🔵 *EDGE-002 より*

`cargo build` のエラーを確認しながら以下のパターンを修正する:

**analysis/common.rs の `transpose_to_tree_result`**:
- 戻り値が `TreeImportanceResult` のままで問題ない（Newtype でラップするのは呼び出し側）

**analysis/full.rs の呼び出し箇所** (合計4箇所):
- `rf_anova:` フィールドへの代入時: `Some(TreeImportanceResult { ... })` → `Some(RfAnovaResult(TreeImportanceResult { ... }))` 相当
- 実際は `transpose_to_tree_result(...)` の結果を `RfAnovaResult(...)` でラップする

**analysis/selected.rs の呼び出し箇所**:
- 同様に各メトリクス結果を Newtype でラップする

**アクセスパターンの変更**（`.importances` / `.r_squared` を使っている箇所）:
- `result.rf_anova.as_ref().map(|r| &r.importances)` → `result.rf_anova.as_ref().map(|r| &r.0.importances)`

## 注意事項

- `pub struct` の `pub` フィールド（`pub TreeImportanceResult`）により、外部から `.0` でアクセス可能
- `#[derive(Debug, Clone)]` を忘れずに追加する（既存の型エイリアスは Debug/Clone を TreeImportanceResult から継承していたが、Newtype では明示が必要）
- `SensitivityResult` 構造体のフィールド型は自動的に対応する（`rf_anova: Option<RfAnovaResult>` は変更不要）
