## 実装詳細

### 1. TreeMetric トレイトの定義 🔵

**信頼性**: 🔵 *REQ-004-1 より*

**実装ファイル**: `rust_core/src/sensitivity/metrics.rs`

```rust
use super::tree_common::PreparedData;

/// ツリーベースの感度分析メトリクス共通トレイト。
pub(crate) trait TreeMetric {
    /// 前処理済みデータから (importances, r_squared) を計算する。
    /// 失敗時は None を返す。importances の合計は 1.0 または 0.0。
    fn compute_importances(
        &self,
        data: &PreparedData,
    ) -> Option<(Vec<f64>, f64)>;

    /// ダウンサンプリング上限行数
    fn max_rows(&self) -> usize;

    /// データサンプリング用シード（ダウンサンプリング時に使用）
    fn data_seed(&self) -> u64;

    /// ホールドアウト分割シャッフル用シード
    fn split_seed(&self) -> u64;
}
```

### 2. 各メトリクス構造体の実装 🔵

**信頼性**: 🔵 *REQ-004-2 より*

**実装ファイル**: `rust_core/src/sensitivity/metrics.rs`

各メトリクスの実装:

```rust
use super::constants::*;
use super::rf_anova::compute_rf_anova_core;  // または rf_anova.rs の内部ロジック
use super::mdi::compute_mdi_core;
use super::shap::compute_shap_core;
use super::permutation::compute_permutation_core;

pub(crate) struct RfAnovaMetric;
pub(crate) struct MdiMetric;
pub(crate) struct ShapMetric;
pub(crate) struct PermutationMetric;

impl TreeMetric for RfAnovaMetric {
    fn compute_importances(&self, data: &PreparedData) -> Option<(Vec<f64>, f64)> {
        // rf_anova.rs の計算ロジックをここから呼び出す
        compute_rf_anova_core(data)
    }
    fn max_rows(&self) -> usize { RF_ANOVA_MAX_ROWS }
    fn data_seed(&self) -> u64 { RF_SEED }
    fn split_seed(&self) -> u64 { RF_SEED.wrapping_add(1) }
}

// MdiMetric, ShapMetric, PermutationMetric も同様
```

**設計の注意**: `metrics.rs` から各メトリクスファイルの内部ロジックを呼ぶ方法として、各ファイルに `pub(super) fn compute_xxx_core(data: &PreparedData) -> Option<(Vec<f64>, f64)>` を追加する。
