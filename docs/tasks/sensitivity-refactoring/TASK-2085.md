## 実装詳細

### 1. constants.rs の新規作成 🔵

**信頼性**: 🔵 *REQ-005-1, REQ-005-2, NFR-005 より*

**実装ファイル**: `rust_core/src/sensitivity/constants.rs`

```rust
// ============================================================
// sensitivity モジュール共通定数
// ============================================================

// --- ツリーモデル共通 LightGBM 設定 ---
// rf_anova.rs, mdi.rs, shap.rs が共有
pub(crate) const RF_TREES: usize = 64;
pub(crate) const RF_MAX_DEPTH: usize = 64;
pub(crate) const RF_MIN_SAMPLES_LEAF: usize = 2;

// --- ダウンサンプリング上限行数 ---
// MDI: LightGBM のゲイン計算（全ノードのゲイン合計）は
//      木が深くなるほど計算コストが大きいため 1000 に抑制
pub(crate) const MDI_MAX_ROWS: usize = 1_000;
// SHAP: TreeSHAP はノードを再帰的に走査するため
//       データ数・深さに比例してコストが増加。1000 に抑制
pub(crate) const SHAP_MAX_ROWS: usize = 1_000;
// RF-ANOVA: 分散分析は各ノードの統計量のみを参照するため
//            MDI/SHAP よりも軽量。2000 まで許容
pub(crate) const RF_ANOVA_MAX_ROWS: usize = 2_000;
// PFI: 列を並べ替えて予測するだけでありコストは低いが
//      5回リピートするため、2000 までを許容
pub(crate) const PFI_MAX_ROWS: usize = 2_000;

// --- 再現性のための固定シード ---
// テスト再現性のために固定値を使用
pub(crate) const RF_SEED: u64 = 42;
// PFI は特徴量×リピート数分のシードを生成するため基底値を定義
pub(crate) const PFI_SEED_BASE: u64 = 1_000;
// PFI の反復回数（複数回繰り返しでばらつきを安定化）
pub(crate) const N_REPEATS: usize = 5;
```
