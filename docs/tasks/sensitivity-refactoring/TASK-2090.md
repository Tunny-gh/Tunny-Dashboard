## 実装詳細

### 1. pdp/utils.rs の col_mean_std 委譲 🔵

**信頼性**: 🔵 *REQ-002-4・dataflow.md セクション6 より*

**実装ファイル**: `rust_core/src/pdp/utils.rs`

変更前（ローカル実装）:
```rust
pub(super) fn col_mean_std(data: &[f64]) -> (f64, f64) {
    if data.is_empty() {
        return (0.0, 1.0);
    }
    let n = data.len() as f64;
    let mean = data.iter().sum::<f64>() / n;
    let std_dev = (data.iter().map(|&v| (v - mean).powi(2)).sum::<f64>() / n).sqrt();
    (mean, if std_dev < f64::EPSILON { 1.0 } else { std_dev })
}
```

変更後（委譲）:
```rust
use crate::core::math::stats::column_mean_std;

pub(super) fn col_mean_std(data: &[f64]) -> (f64, f64) {
    column_mean_std(data)
}
```

**シグネチャ変更なし**: `pub(super) fn col_mean_std(data: &[f64]) -> (f64, f64)` のシグネチャは維持する。内部を委譲に変更するのみ。
