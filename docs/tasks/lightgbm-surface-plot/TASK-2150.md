## 実装詳細

### 1. "random_forest" アームの追加 🔵

**信頼性**: 🔵 *REQ-002 / 既存 "kriging" ディスパッチパターン / 実装ガイド Step 2 より*

**実装ファイル**: `rust_core/src/pdp/api.rs`

`compute_pdp_from_data()` の `match model_type` ブロックを以下のように更新する（`"kriging"` アームの直前に追加）:

```rust
"random_forest" => {
    let param_name = param_names
        .get(target_param_idx)
        .cloned()
        .unwrap_or_default();
    match crate::core::lgbm::compute_pdp_1d_lgbm(
        &x_matrix,
        &y,
        target_param_idx,
        n_grid,
    ) {
        Some((grid, values, r_squared)) => PdpResult1d {
            param_name,
            objective_name: objective_name.to_string(),
            grid,
            values,
            r_squared,
            y_upper: None,
            y_lower: None,
        },
        None => compute_pdp_from_matrix(
            &x_matrix,
            &y,
            &param_names,
            objective_name,
            target_param_idx,
            n_grid,
        ),
    }
}
```

**設計上の注意点**:
- `y_upper: None, y_lower: None` — LightGBM 1D は ICE・信頼区間を返さない（REQ-003 確認済み）
- `None` の場合は Ridge フォールバック（EDGE-002 対応）。UI クラッシュを防ぐ重要な安全装置
