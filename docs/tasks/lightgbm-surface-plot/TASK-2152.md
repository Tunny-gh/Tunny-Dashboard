### 2. 2D PDP n_grid に RandomForest 分岐を追加 🔵

**信頼性**: 🔵 *REQ-022（RandomForest は n_grid=30）/ 実装ガイド 4-2 より*

**実装ファイル**: `egui-app/src/ui/widgets/pdp_2d.rs`

"Run 2D PDP" ボタンクリック時のハンドラを更新する:

```rust
// 変更前（"Run 2D PDP" クリック時）
self.pending_compute = Some(Pdp2dComputeRequest {
    param1: self.selected_param1.clone(),
    param2: self.selected_param2.clone(),
    objective: obj_name.clone(),
    n_grid: 20,   // ← ハードコード
    model_type: self.selected_model.to_str().to_string(),
});

// 変更後
let n_grid = match self.selected_model {
    ModelType::RandomForest => 30,  // REQ-022
    _ => 20,
};
self.pending_compute = Some(Pdp2dComputeRequest {
    param1: self.selected_param1.clone(),
    param2: self.selected_param2.clone(),
    objective: obj_name.clone(),
    n_grid,
    model_type: self.selected_model.to_str().to_string(),
});
```

**設計上の注意点**:
- 2D LightGBM のバックエンド計算（`compute_pdp_2d_lgbm()`）は既実装済み。UI と n_grid の変更のみ
- Ridge/Kriging/SparseKriging の n_grid=20 は変更しない（NFR-011 後方互換性）
