## タスク概要

`egui-app/src/ui/grid_canvas.rs` の `show_cell_toolbar()` に `csv_available: bool` 引数を追加し、
データが利用できない場合に「Save as CSV」ボタンをグレーアウトして「No data available」ツールチップを表示する。

`render_cell_content()` で `has_csv_data()` を呼び出し、その結果を `show_cell_toolbar()` に渡す。

### 2. グレーアウト・ツールチップ実装 🔵

**信頼性**: 🔵 *REQ-201/202・architecture.md より*

```rust
// ⋯ポップアップメニュー内の「Save as CSV」ボタン
let csv_button = ui.add_enabled(csv_available, egui::Button::new("Save as CSV"));
if csv_button.clicked() {
    menu_action = Some(CellToolbarAction::SaveAsCsv(item.clone()));
    ui.close_menu();
}
if !csv_available {
    csv_button.on_hover_text("No data available");
}
```

### 3. render_cell_content() で has_csv_data() を呼び出す 🔵

**信頼性**: 🔵 *architecture.md・dataflow.md グレーアウトフローより*

```rust
// render_cell_content() 内で chart_id を取得した後
let csv_available = if let PanelItem::Chart(chart_id) = &item {
    crate::io::csv_export::has_csv_data(chart_id, app_state, widgets)
} else {
    false
};
let toolbar_action = show_cell_toolbar(ui, row, col, item, title, csv_available);
```
