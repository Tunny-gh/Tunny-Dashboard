## 実装詳細

### 1. build_mcdm_rank_csv() 🔵

**信頼性**: 🔵 *REQ-031・McdmResult 型定義より*

**データソース**: `app_state.mcdm_result: Option<McdmResult>`

```rust
fn build_mcdm_rank_csv(app_state: &AppState) -> Option<String> {
    let result = app_state.mcdm_result.as_ref()?;
    let method_name = result.method_label();
    let scores = result.primary_scores();
    let ranked = result.ranked_indices();
    
    let mut csv = String::from("trial_id,rank,score,method\n");
    for (rank, &idx) in ranked.iter().enumerate() {
        let trial_id = idx; // trial_id はインデックスから取得
        let score = scores.get(idx).copied().unwrap_or(f64::NAN);
        csv.push_str(&format!("{},{},{},{}\n", trial_id, rank + 1, score, method_name));
    }
    Some(csv)
}
```

### 3. build_mcdm_table_csv() 🔵

**信頼性**: 🔵 *REQ-032・McdmResult バリアント定義より*

バリアント別に列構成が異なる:

```rust
fn build_mcdm_table_csv(app_state: &AppState) -> Option<String> {
    let result = app_state.mcdm_result.as_ref()?;
    match result {
        McdmResult::Topsis(r) => {
            let mut csv = String::from("trial_id,rank,topsis_score\n");
            for (rank, &idx) in r.ranked_indices().iter().enumerate() {
                csv.push_str(&format!("{},{},{}\n", idx, rank+1, r.scores[idx]));
            }
            Some(csv)
        },
        McdmResult::Vikor(r) => {
            let mut csv = String::from("trial_id,rank,s_value,r_value,q_value\n");
            for (rank, &idx) in r.ranked_indices().iter().enumerate() {
                csv.push_str(&format!("{},{},{},{},{}\n", idx, rank+1, r.s[idx], r.r[idx], r.q[idx]));
            }
            Some(csv)
        },
        McdmResult::PrometheeI(r) => {
            let mut csv = String::from("trial_id,rank,phi_plus,phi_minus\n");
            for (rank, &idx) in r.ranked_indices().iter().enumerate() {
                csv.push_str(&format!("{},{},{},{}\n", idx, rank+1, r.phi_plus[idx], r.phi_minus[idx]));
            }
            Some(csv)
        },
        McdmResult::PrometheeII(r) => {
            let mut csv = String::from("trial_id,rank,phi_net\n");
            for (rank, &idx) in r.ranked_indices().iter().enumerate() {
                csv.push_str(&format!("{},{},{}\n", idx, rank+1, r.phi_net[idx]));
            }
            Some(csv)
        },
    }
}
```

### 5. build_ahp_table_csv() 🔵

**信頼性**: 🔵 *REQ-035・AhpResult 型定義より*

```rust
fn build_ahp_table_csv(app_state: &AppState) -> Option<String> {
    let result = app_state.ahp_result.as_ref()?;
    let mut csv = String::from("trial_id,rank,ahp_score,priority_weight_contribution\n");
    for (rank, (trial_id, score)) in result.ranked_scores().iter().enumerate() {
        let contribution = result.priority_weight_contribution(*trial_id);
        csv.push_str(&format!("{},{},{},{}\n", trial_id, rank + 1, score, contribution));
    }
    Some(csv)
}
```
