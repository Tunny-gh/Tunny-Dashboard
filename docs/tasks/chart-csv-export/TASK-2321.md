## 実装詳細

### 1. build_optimization_history_csv() 🔵

**信頼性**: 🔵 *REQ-020・dataflow.md より*

**データソース**: `app_state.current_study.trial_rows` + `widgets.opt_history.selected_obj_idx`

```rust
fn build_optimization_history_csv(app_state: &AppState, widgets: &WidgetStates) -> Option<String> {
    let study = app_state.current_study.as_ref()?;
    let obj_idx = widgets.opt_history.selected_obj_idx;
    let is_minimize = study.objectives_directions.get(obj_idx).copied().unwrap_or(true);
    
    let mut csv = String::from("trial_index,objective_value,best_value\n");
    let mut best = if is_minimize { f64::INFINITY } else { f64::NEG_INFINITY };
    
    for (i, row) in study.trial_rows.iter().enumerate() {
        let val = row.objectives.get(obj_idx).copied().unwrap_or(f64::NAN);
        best = if is_minimize { best.min(val) } else { best.max(val) };
        csv.push_str(&format!("{},{},{}\n", i, val, best));
    }
    Some(csv)
}
```

### 2. build_hv_history_csv() 🔵

**信頼性**: 🔵 *REQ-021・HvHistory 型定義より*

**データソース**: `app_state.hv_history: Option<HvHistory>`

```rust
fn build_hv_history_csv(app_state: &AppState) -> Option<String> {
    let hv = app_state.hv_history.as_ref()?;
    let mut csv = String::from("trial_index,hypervolume\n");
    for (i, &hv_val) in hv.hv_values.iter().enumerate() {
        let trial_idx = i * hv.sample_step;
        csv.push_str(&format!("{},{}\n", trial_idx, hv_val));
    }
    Some(csv)
}
```

### 3. build_slice_csv() 🟡

**信頼性**: 🟡 *REQ-036・SliceChart 型定義から妥当な推測*

**データソース**: `app_state.current_study.trial_rows` + `widgets.slice_chart`

```rust
fn build_slice_csv(app_state: &AppState, widgets: &WidgetStates) -> Option<String> {
    let study = app_state.current_study.as_ref()?;
    let param_idx = widgets.slice_chart.selected_param_idx;
    let obj_idx = widgets.slice_chart.selected_obj_idx;
    let param_name = study.param_names.get(param_idx)?;
    let obj_name = study.objective_names.get(obj_idx)?;
    
    let mut csv = format!("trial_id,{},{},is_pareto\n", param_name, obj_name);
    for row in &study.trial_rows {
        let param_val = row.params.get(param_idx).copied().unwrap_or(f64::NAN);
        let obj_val = row.objectives.get(obj_idx).copied().unwrap_or(f64::NAN);
        let is_pareto = study.pareto_front_indices.contains(&row.trial_id);
        csv.push_str(&format!("{},{},{},{}\n", row.trial_id, param_val, obj_val, is_pareto));
    }
    Some(csv)
}
```
