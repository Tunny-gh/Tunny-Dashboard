## 実装詳細

### 1. build_importance_csv() 🔵

**信頼性**: 🔵 *REQ-022・SensitivityResult / SobolResult 型定義より*

**データソース**: `app_state.importance_cache / sobol_cache` + `widgets.importance`

計算中（`widgets.importance.computing == true`）の場合は `None` を返す。

```rust
fn build_importance_csv(app_state: &AppState, widgets: &WidgetStates) -> Option<String> {
    if widgets.importance.computing {
        return None;
    }
    let metric = &widgets.importance.metric;
    let method_name = metric.label();
    
    // メトリクスに応じてデータソースを選択
    let importances: Vec<(String, f64)> = if metric.is_sobol() {
        let sobol = app_state.sobol_cache.as_ref()?;
        sobol.get_importances(metric)
    } else {
        let sensitivity = app_state.importance_cache.as_ref()?;
        sensitivity.get_importances(metric)
    };
    
    let mut csv = String::from("variable,importance_score,method\n");
    for (name, score) in &importances {
        csv.push_str(&format!("{},{},{}\n", name, score, method_name));
    }
    Some(csv)
}
```

### 2. build_sensitivity_csv() 🔵

**信頼性**: 🔵 *REQ-027・SensitivityResult 型定義より*

**データソース**: `widgets.sensitivity_heatmap.result: Option<SensitivityResult>`

```rust
fn build_sensitivity_csv(app_state: &AppState, widgets: &WidgetStates) -> Option<String> {
    let result = widgets.sensitivity_heatmap.result.as_ref()?;
    let study = app_state.current_study.as_ref()?;
    
    let mut csv = String::from("variable");
    for name in &study.objective_names { csv.push_str(&format!(",{}", name)); }
    csv.push('\n');
    
    for (param_name, scores) in result.param_scores() {
        csv.push_str(&param_name);
        for score in scores { csv.push_str(&format!(",{}", score)); }
        csv.push('\n');
    }
    Some(csv)
}
```
