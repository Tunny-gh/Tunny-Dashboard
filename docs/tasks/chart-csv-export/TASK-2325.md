## 実装詳細

### 1. build_pdp_csv() 🟡

**信頼性**: 🟡 *REQ-023・PdpResult 型定義は実装前に egui-app/src/state/messages.rs で確認が必要*

**データソース**: `widgets.pdp_chart.cache: HashMap<String, PdpResult>`

```rust
fn build_pdp_csv(app_state: &AppState, widgets: &WidgetStates) -> Option<String> {
    let pdp = &widgets.pdp_chart;
    let cache = &pdp.cache;
    if cache.is_empty() {
        return None;
    }
    let param_name = &pdp.selected_param;
    let result = cache.get(param_name)?;
    
    let mut csv = format!("variable,variable_value,predicted_objective,lower_ci,upper_ci\n");
    for point in &result.points {
        csv.push_str(&format!(
            "{},{},{},{},{}\n",
            param_name,
            point.x,
            point.mean,
            point.lower,
            point.upper,
        ));
    }
    Some(csv)
}
```

**実装時確認事項**: `PdpResult` の構造（`points` フィールド名、`x`, `mean`, `lower`, `upper` 等）は `egui-app/src/state/messages.rs` を確認してから実際のフィールド名を使用すること。

### 2. build_pdp_2d_csv() 🟡

**信頼性**: 🟡 *REQ-024・PdpChart2D 型定義は実装前に確認が必要*

**データソース**: `widgets.pdp_2d` の計算結果

```rust
fn build_pdp_2d_csv(app_state: &AppState, widgets: &WidgetStates) -> Option<String> {
    let pdp_2d = &widgets.pdp_2d;
    let result = pdp_2d.result.as_ref()?;
    let param1 = &pdp_2d.selected_param1;
    let param2 = &pdp_2d.selected_param2;
    
    let mut csv = format!("param1_name,param1_value,param2_name,param2_value,predicted_objective\n");
    for point in &result.points {
        csv.push_str(&format!(
            "{},{},{},{},{}\n",
            param1, point.x1, param2, point.x2, point.value
        ));
    }
    Some(csv)
}
```
