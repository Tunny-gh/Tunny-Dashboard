### 2. build_cluster_csv() 🔵

**信頼性**: 🔵 *REQ-028・ClusterResult 型定義より*

**データソース**: `app_state.current_study` + `app_state.cluster_result`

cluster_result が None の場合は cluster_id 列を "-" で埋める。

```rust
fn build_cluster_csv(app_state: &AppState) -> Option<String> {
    let study = app_state.current_study.as_ref()?;
    let cluster_result = app_state.cluster_result.as_ref();
    
    let mut csv = format!("trial_id,trial_number");
    for name in &study.param_names { csv.push_str(&format!(",{}", name)); }
    for name in &study.objective_names { csv.push_str(&format!(",{}", name)); }
    csv.push_str(",cluster_id\n");
    
    for row in &study.trial_rows {
        csv.push_str(&format!("{},{}", row.trial_id, row.trial_number));
        for val in &row.params { csv.push_str(&format!(",{}", val)); }
        for val in &row.objectives { csv.push_str(&format!(",{}", val)); }
        let cluster_id = cluster_result
            .and_then(|cr| cr.get_cluster(row.trial_id))
            .map(|id| id.to_string())
            .unwrap_or_else(|| "-".to_string());
        csv.push_str(&format!(",{}\n", cluster_id));
    }
    Some(csv)
}
```

### 3. build_pareto_csv() 🔵

**信頼性**: 🔵 *REQ-029/030・pareto_front_indices より*

**データソース**: `app_state.current_study`（`pareto_front_indices` でフィルタ）

```rust
fn build_pareto_csv(app_state: &AppState) -> Option<String> {
    let study = app_state.current_study.as_ref()?;
    let pareto_set: std::collections::HashSet<u32> = study.pareto_front_indices.iter().copied().collect();
    
    let mut csv = format!("trial_id,trial_number");
    for name in &study.objective_names { csv.push_str(&format!(",{}", name)); }
    csv.push_str(",pareto_rank\n");
    
    let mut rank = 1;
    for row in study.trial_rows.iter().filter(|r| pareto_set.contains(&r.trial_id)) {
        csv.push_str(&format!("{},{}", row.trial_id, row.trial_number));
        for val in &row.objectives { csv.push_str(&format!(",{}", val)); }
        csv.push_str(&format!(",{}\n", rank));
        rank += 1;
    }
    Some(csv)
}
```
