# SOM (自己組織化マップ) — 数値突き合わせ対象外・実装読解による性質検証

- **実施日**: 2026-07-05
- **対象実装**: `rust_core/src/clustering/som.rs`(`train_som`)
- **リファレンス**: なし(下記の理由により対象外)
- **結果**: 🚫 **対象外**(確立された決定的リファレンス実装が存在しないため数値突き合わせは行わない)。実装読解により、標準的な batch SOM の定式に沿っていることを確認。

## 対象外とする理由

SOM は k-means や PCA と異なり、`scipy` / `scikit-learn` に標準実装が存在しない。
代表的な Python 実装(`MiniSom`, `SOMPY` など)はいずれもオンライン学習・乱数初期化
ベースで、`rust_core` の実装(バッチ学習・PCA 決定論的初期化)とアルゴリズムの
種類自体が異なるため、同一入力に対する数値一致を求める意味がない
(初期化方式・更新方式が違えば収束先のマップが異なるのは当然であり、
「不一致」を検出しても実装の正しさとは無関係)。そのため本レポートでは
数値クロスチェックを行わず、**実装がバッチ SOM の標準的な定式に沿っているか**を
コードリーディングのみで確認する方針とした(理論的背景: `theory/{en,ja}/clustering/som.md`)。

## 実装読解での確認点

### 1. BMU (Best Matching Unit) 計算は最近傍か

`rust_core/src/clustering/som.rs:142-153` の `find_bmu` は、標準化空間で全ノードとの
二乗ユークリッド距離 `d2(w, row)` を総当たりで計算し、最小のノードを返す
単純な最近傍探索である。近似や早期打ち切りはなく、教科書通りの BMU 定義
(`BMU = argmin_i ||x - w_i||`)と一致する。

### 2. 近傍関数は標準形か

`rust_core/src/clustering/som.rs:170-180` の近傍カーネルは

```
h(node, bmu) = exp(-‖grid_pos(node) - grid_pos(bmu)‖² / (2σ²))
```

というガウス関数で、グリッド座標(`node_xy`)上のユークリッド距離を使う。
これは Kohonen の SOM で最も一般的に使われる近傍関数の標準形そのもの
(トーラス状ではなく矩形グリッドの通常のユークリッド距離)。`h < 1e-6` の
ノードは更新をスキップする早期打ち切り最適化があるが、これは数値上無視できる
範囲のみを省略しており定式自体は変えていない。

### 3. 学習率・近傍半径の減衰式は標準形か

本実装は**バッチ SOM**(`rust_core/src/clustering/som.rs:1-6` の doc comment 参照)
であり、各エポックで全データ点の BMU を先に確定してから

```
w_node ← Σ_i h(node, bmu_i) x_i / Σ_i h(node, bmu_i)
```

という重み付き平均で重みを更新する(`rust_core/src/clustering/som.rs:163-189`)。
これは Kohonen のオリジナル逐次更新(`w ← w + α・h・(x - w)`)とは異なり、
**バッチ版 SOM の標準的な更新式**(学習率 α が不要な加重平均形式)であり、
文献(Kohonen "Self-Organizing Maps" のバッチアルゴリズム章)や MATLAB SOM
Toolbox のバッチ学習と同じ定式。したがって学習率パラメータ自体が存在しない
ことは実装漏れではなく、アルゴリズム選択(バッチ版)による正しい設計。

近傍半径 σ は `rust_core/src/clustering/som.rs:156-161` でエポック `t`(0..1 に正規化)
に対し

```
σ(t) = σ0 · (σ_end / σ0)^t,   σ0 = max(grid_w, grid_h) / 2,   σ_end = 0.5
```

という指数減衰スケジュールを使う。これは SOM 学習で一般的に使われる
「粗い大域的整列 → 局所的な微調整」という指数減衰の標準的な設計であり、
最終半径 0.5 は「ほぼ自分自身のノードのみ」に相当し収束の妥当性がある。

### 4. 初期化は決定論的か

`rust_core/src/clustering/som.rs:96-136` は標準化データの上位 2 主成分平面に沿って
格子状にノードを線形配置する初期化(PCA 初期化)。乱数を一切使わないため、
同じ入力に対し常に同じ初期配置・同じ学習結果になる(既存ユニットテスト
`deterministic_without_seed` で確認済み)。ランダム初期化を使う一般的な SOM 実装
とは異なり再現性を優先した設計であり、これも文献で知られた代替初期化手法
(linear initialization)の一種である。

## 既存ユニットテストで確認されている性質

`rust_core/src/clustering/som.rs` の `#[cfg(test)]` モジュールには、本検証と
重複しない範囲で以下がすでに検証されている(今回はコードを変更していないため
再実行のみで再確認):

- 出力配列の形状の整合性(`weights` / `u_matrix` / `hits` / `bmu` の長さ)
- 決定論性(同じ入力に対し `bmu` と `u_matrix` が完全一致)
- 明確に分離した 2 ブロブが異なるノード集合に写像される(BMU の分離)
- 成分プレーン(`component_plane`)が正しく元単位に逆標準化されている

```bash
cargo test -p tunny-core clustering::som
```

## まとめ

数値突き合わせは対象外だが、BMU 計算・近傍関数・バッチ更新式・半径減衰・
決定論的初期化のいずれも SOM の標準的な定式(文献に基づく batch SOM)に
沿っていることをコードリーディングで確認した。設計上の既知の特性
(学習率パラメータが存在しないのはバッチ版であるため、乱数を使わないのは
PCA 決定論的初期化を採用しているため)であり、実装上の疑義は見つからなかった。
