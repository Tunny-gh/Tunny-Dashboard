## REQ-001: 手動実行でクラスタリング計算を開始できる 🔵

**信頼性**: 🔵 *ヒアリング（手動実行・UI配置） + 実装調査より*

### Given（前提条件）
- Study が選択済みである。
- クラスタリング図ウィジェットが配置済みである。

### When（実行条件）
- ユーザーがウィジェットヘッダーの実行UIを押下する。

### Then（期待結果）
- クラスタリング計算処理が開始される。
- 完了後メッセージが送信される。

### テストケース

#### 正常系

- [ ] **TC-001-01**: 実行操作で計算開始される 🔵
  - **入力**: 実行ボタン押下
  - **期待結果**: 計算タスクが開始される
  - **信頼性**: 🔵 *ヒアリングより*

- [ ] **TC-001-02**: 完了メッセージ送信後に表示更新される 🔵
  - **入力**: 計算完了イベント
  - **期待結果**: クラスタリング図が再描画される
  - **信頼性**: 🔵 *実装調査より*

#### 異常系

- [ ] **TC-001-E01**: 実行中の重複押下は抑止される 🟡
  - **入力**: 実行中に再度実行押下
  - **期待結果**: 二重起動されない
  - **信頼性**: 🟡 *UIメモから推測*

## REQ-101: 未実行時に案内メッセージを表示する 🔵

**信頼性**: 🔵 *ヒアリング（未実行表示）より*

### Given（前提条件）
- クラスタリング結果が存在しない。

### When（実行条件）
- ユーザーがクラスタリング図を表示する。

### Then（期待結果）
- 「クラスタリングを実行してください」等の案内メッセージが表示される。

### テストケース

#### 正常系

- [ ] **TC-101-01**: 初回表示で案内メッセージが表示される 🔵
  - **入力**: ウィジェット配置のみ
  - **期待結果**: 案内メッセージ表示
  - **信頼性**: 🔵 *ヒアリングより*

#### 境界値

- [ ] **TC-101-B01**: trial 0件でもクラッシュせず案内/データ不足表示となる 🔵
  - **入力**: empty trial dataset
  - **期待結果**: 散布図は描画せず状態メッセージ表示
  - **信頼性**: 🔵 *既存ガード実装より*

## REQ-201: Study切替時にクラスタリング状態をリセットする 🔵

**信頼性**: 🔵 *ヒアリング（影響許容） + 実装調査より*

### Given（前提条件）
- Study A でクラスタリング済み結果が表示されている。

### When（実行条件）
- ユーザーが Study B へ切り替える。

### Then（期待結果）
- Study A由来のクラスタリング結果/キャッシュがクリアされる。
- 未実行案内状態へ遷移する。

### テストケース

#### 正常系

- [ ] **TC-201-01**: Study切替で結果状態がクリアされる 🔵
  - **入力**: Study切替操作
  - **期待結果**: cluster_result が空になる
  - **信頼性**: 🔵 *ヒアリング + 実装調査*

- [ ] **TC-201-02**: Study切替後は再実行まで案内表示となる 🔵
  - **入力**: Study切替直後の画面表示
  - **期待結果**: 未実行案内表示
  - **信頼性**: 🔵 *要件整合より*

#### 異常系

- [ ] **TC-201-E01**: 旧Studyのキャッシュが残っていても新Study表示に混入しない 🟡
  - **入力**: キャッシュあり状態で切替
  - **期待結果**: 旧表示は利用されない
  - **信頼性**: 🟡 *調査推測*
