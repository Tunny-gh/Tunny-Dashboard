## REQ-001 ~ REQ-006: UI背景色の刷新 🔵

**信頼性**: 🔵 *参考画像分析より*

### Given（前提条件）
- アプリケーションがライトテーマで起動している
- `tunny_light_visuals()` が適用されている

### When（実行条件）
- ユーザーがアプリケーションを開く

### Then（期待結果）
- 左右パネル背景がニュートラルグレー（青みなし）で表示される
- メインキャンバスが純白で表示される
- セルツールバーがパネルよりわずかに明るいグレーで表示される
- ウィジェット背景が薄いグレーで表示される

### テストケース

#### 正常系

- [ ] **TC-BG-01**: パネル背景色の青み排除 🔵
  - **入力**: PANEL_BG のRGB値を確認
  - **期待結果**: B値がR値・G値に対して極端に高くない（差が±10以内）
  - **信頼性**: 🔵 *参考画像の背景色はニュートラルグレー*

- [ ] **TC-BG-02**: 中央キャンバスの白色維持 🔵
  - **入力**: CENTRAL_BG の値を確認
  - **期待結果**: `Color32::WHITE` または rgb(255,255,255)
  - **信頼性**: 🔵 *参考画像のパネルは純白*

- [ ] **TC-BG-03**: ウィジェット背景のグレー階調 🔵
  - **入力**: WIDGET_BG, WIDGET_BG_HOVER のRGB値を確認
  - **期待結果**: WIDGET_BG が PANEL_BG より明るく、WIDGET_BG_HOVER が WIDGET_BG より暗い
  - **信頼性**: 🔵 *参考画像の視覚階層分析*

#### 境界値

- [ ] **TC-BG-B01**: 全背景色の明度一貫性 🔵
  - **入力**: PANEL_BG, CELL_TOOLBAR_BG, WIDGET_BG, WIDGET_BG_HOVER の明度を確認
  - **期待結果**: 階層順序が PANEL_BG < CELL_TOOLBAR_BG < WIDGET_BG < CENTRAL_BG を満たす
  - **信頼性**: 🔵 *視覚階層の一貫性要件*

  - **信頼性**: 🔵 *参考画像の #4285f4 分析*

- [ ] **TC-ACC-02**: テキスト色のコントラスト 🔵
  - **入力**: TEXT_PRIMARY と PANEL_BG のRGB値
  - **期待結果**: コントラスト比 ≥ 4.5:1（WCAG AA）
  - **信頼性**: 🔵 *アクセシビリティ基準*

- [ ] **TC-ACC-03**: セカンダリテキストの視認性 🔵
  - **入力**: TEXT_SECONDARY と PANEL_BG のRGB値

  - **信頼性**: 🔵 *アクセシビリティ基準*

- [ ] **TC-ACC-04**: ボーダー色の控えめさ 🟡

  - **入力**: COLOR_NON_PARETO のRGB値を確認
  - **期待結果**: ACCENT_BLUE と同系統の青
  - **信頼性**: 🔵 *参考画像の散布図ドット分析*

  - **入力**: COLOR_PARETO_DIM, COLOR_NON_PARETO_DIM の値を確認

- [ ] **TC-CHART-04**: バーチャート色の統一 🟡
  - **入力**: COLOR_BAR_PRIMARY のRGB値を確認
  - **期待結果**: ACCENT_BLUE と同系統の青

- [ ] **TC-CHART-05**: 散布図ドット色 🔵
  - **入力**: COLOR_SCATTER_DOT のRGB値を確認
  - **期待結果**: ACCENT_BLUE と同系統の青
  - **信頼性**: 🔵 *参考画像の散布図分析*

#### 異常系

  - **期待結果**: 両者が視覚的に区別可能（色相差 ≥ 30度、または明度差 ≥ 50）
  - **信頼性**: 🟡 *セマンティック色の区別要件から推測*

## テスト実施計画

### Phase 1: 定数値検証
- 定数のRGB値が期待範囲内にあることを確認
- premultiplied alpha 計算の正しさを確認
- 方法: コードレビュー + 単体テスト

### Phase 2: ビルド・テスト確認
- `cargo build` / `cargo test` / `cargo clippy` が通過
- 変更ファイル範囲が期待通り
- 方法: CI実行

### Phase 3: 視覚確認
- アプリケーションを起動し、各画面の視覚的整合性を確認
- 2D/3Dビューの表示確認
- 方法: 手動テスト
