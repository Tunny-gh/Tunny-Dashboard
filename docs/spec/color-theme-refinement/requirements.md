# カラーテーマ洗練 要件定義書

## 概要

添付画像（Optuna Dashboard風モダンUI）を参考に、Tunny Dashboard の全UI・チャート色を
統一感のあるプロフェッショナルなパレットに刷新する。
既存の色定義ファイル構成（`theme/ui_colors.rs`, `theme/chart_colors.rs`, `theme/colormap.rs`）は維持し、
色の数値のみを変更する。

## 非機能要件

### 外観一貫性

- NFR-001: 全UI要素は参考画像の「クリーンでミニマルなデータファースト」の美学を再現しなければならない 🔵 *ユーザヒアリング「忠実に再現」より*
- NFR-002: 背景は青みを排除し、ニュートラルなグレー系で統一しなければならない 🔵 *参考画像分析より*
- NFR-003: インタラクティブ要素（ボタン、タブ、スライダー）は統一されたアクセントブルー（#4285f4系）を使用しなければならない 🔵 *参考画像分析より*

### コンパイル・テスト

- NFR-011: `cargo build` が警告ゼロで成功しなければならない 🔵 *Rustプロジェクト標準より*
- NFR-012: `cargo test` が既存テストをすべて通過しなければならない 🔵 *既存テスト保護のため*
- NFR-013: `cargo clippy` がエラーを出力してはならない 🟡 *プロジェクト慣習より*

### 保守性

- NFR-021: 色の変更は `theme/ui_colors.rs` と `theme/chart_colors.rs` のみの編集で完結しなければならない 🔵 *前回要件（ui-color-theme）で確立されたアーキテクチャより*
- NFR-022: `theme/colormap.rs` は一切編集してはならない 🔵 *ユーザヒアリング「カラーマップは維持」より*
- NFR-023: `tunny_light_visuals()` の構造（Stroke設定等）は維持し、色の数値のみを変更しなければならない 🔵 *要件のスコープ制限より*

### アクセシビリティ

- NFR-031: テキストと背景のコントラスト比は WCAG AA（4.5:1）を満たさなければならない 🟡 *アクセシビリティ標準から推測*

## Edgeケース

### 3Dビューの可視性

- EDGE-001: 3Dビューをライト背景に変更した際、3D軸色（X:赤, Y:緑, Z:青）がライト背景でも十分なコントラストを保つよう確認が必要 🟡 *3D背景変更に伴う影響から推測*
- EDGE-002: 3DビューのPareto点・Non-Pareto点がライト背景でも視認可能であることを確認しなければならない 🟡 *3D背景変更に伴う影響から推測*

### チャートの視認性

- EDGE-011: コンターマップ（CONTOUR色: 現在YELLOW）がライト背景でも判読可能であることを確認しなければならない 🟡 *背景変更による影響から推測*
- EDGE-012: ハイライト点（COLOR_HIGHLIGHT_PT: 現在YELLOW）がライト背景でも判読可能であることを確認しなければならない 🟡 *背景変更による影響から推測*
- EDGE-013: PDP信頼区間（COLOR_PDP_CI）がライト背景でも適切に表示されることを確認しなければならない 🟡 *背景変更による影響から推測*

### セマンティック色の区別

- EDGE-021: エラー色（赤）とPareto点色（赤）が意味的に区別でき、ユーザーが混同しないことを確認しなければならない 🟡 *両者が同系統の赤になるため推測*
- EDGE-022: 最適化履歴の状態色（Trial/Pruned/Running/Best）が互いに明確に区別できることを確認しなければならない 🟡 *色変更による識別性への影響から推測*

### premultiplied alpha値

- EDGE-031: `COLOR_PARETO_DIM`, `COLOR_NON_PARETO_DIM`, `COLOR_SELECTION_HIGHLIGHT`, `COLOR_CELL_HIGHLIGHT`, `COLOR_PDP_CI`, `COLOR_ICE_LINE`, `COLOR_PDP_CI_LEGEND`, `COLOR_3D_GRID` の premultiplied alpha 色は、RGB値変更に合わせて再計算しなければならない 🔵 *premultiplied alpha の仕様より*
