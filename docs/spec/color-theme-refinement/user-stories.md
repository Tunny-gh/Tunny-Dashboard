## エピック1: UI背景の刷新

### ストーリー 1.1: ニュートラルグレー背景への統一 🔵

**信頼性**: 🔵 *参考画像分析・ユーザヒアリング「忠実に再現」より*

**私は** Tunny Dashboard 利用者 **として**
**青みのないクリーンなグレー背景で分析画面を見たい**
**そうすることで** データ可視化に集中でき、目の疲れを軽減できる

**関連要件**: REQ-001 ~ REQ-006

**詳細シナリオ**:
1. アプリケーションを起動する
2. 左右パネルがニュートラルなライトグレー（~#f0f2f5）で表示される
3. メインキャンバスが純白（#ffffff）で表示される
4. 現在の青みがかった背景（rgb(225,233,248)）は表示されない

**前提条件**:
- `theme/ui_colors.rs` が既に色の一元化を完了している
- `tunny_light_visuals()` が PANEL_BG を参照している

**優先度**: Must Have

---

### ストーリー 1.2: ウィジェット・セルツールバーの背景統一 🔵

**信頼性**: 🔵 *参考画像のパネル境界分析より*

**私は** Tunny Dashboard 利用者 **として**
**ウィジェットの背景もパネルと統一感のあるグレーで表示されてほしい**
**そうすることで** UI全体の視覚的な一貫性が保たれる

**関連要件**: REQ-004, REQ-005, REQ-071 ~ REQ-073

**詳細シナリオ**:
1. チャートセルのツールバーが薄いグレーで表示される
2. ウィジェットの背景がパネル背景と調和する
3. ホバー時にウィジェット背景がわずかに暗くなる

**前提条件**:
- PANEL_BG がニュートラルグレーに変更済み

**優先度**: Must Have

## エピック2: アクセント・テキスト色の刷新

### ストーリー 2.1: Google Blue系アクセントカラーへの統一 🔵

**信頼性**: 🔵 *参考画像のアクセント色分析・ヒアリングより*

**私は** Tunny Dashboard 利用者 **として**
**ボタン・選択状態・インタラクティブ要素が統一された青（#4285f4系）で表示されてほしい**
**そうすることで** インタラクティブ要素が一目で分かり、操作の迷いが減る

**関連要件**: REQ-012, REQ-021 ~ REQ-023

**詳細シナリオ**:
1. ツールバーのアクティブボタンが Google Blue（~#4285f4）で表示される
2. ウィジェットのホバー枠線がアクセントブルーで表示される
3. 選択中のテキストが薄いブルー背景（~#e8f0fe）でハイライトされる

**前提条件**:
- ACCENT_BLUE 定数が ui_colors.rs で定義されている

**優先度**: Must Have

---

### ストーリー 2.2: テキスト色の最適化 🔵

**信頼性**: 🔵 *参考画像のテキスト色分析より*

**私は** Tunny Dashboard 利用者 **として**
**メインテキストがダークグレー、サブテキストがミディアムグレーで表示されてほしい**
**そうすることで** 情報の重要度が視覚的に区別でき、読みやすさが向上する

**関連要件**: REQ-024 ~ REQ-026

**詳細シナリオ**:
1. パネルタイトル・チャートタイトルがダークグレー（~#202124）で表示される
2. メタデータ・ラベルがミディアムグレー（~#5f6368）で表示される
3. パネル境界がライトグレー（~#dadce0）で表示される

**前提条件**:
- TEXT_PRIMARY, TEXT_SECONDARY が ui_colors.rs で定義されている

**優先度**: Must Have

## エピック3: チャート描画色の調整

### ストーリー 3.1: Pareto分析色の刷新 🔵

**信頼性**: 🔵 *参考画像の散布図色分析より*

**私は** 最適化結果の分析者 **として**
**Pareto点とNon-Pareto点が参考画像と同じ鮮やかな赤と青で表示されてほしい**
**そうすることで** Paretoフロントの判別が直感的になる

**関連要件**: REQ-031 ~ REQ-033, REQ-037

**詳細シナリオ**:
1. Pareto Front チャートでPareto点が鮮やかな赤（~#ea4335）で表示される
2. Non-Pareto点がアクセントブルー系で表示される
3. 選択されていない点の半透明バージョンが自然に表示される

**前提条件**:
- ACCENT_BLUE が Google Blue 系に変更済み
- premultiplied alpha 値の再計算が必要

**優先度**: Must Have

---

### ストーリー 3.2: 最適化履歴・バーチャート色の統一 🟡

**信頼性**: 🟡 *参考画像のバーチャート・履歴チャートから推測*

**私は** 最適化結果の分析者 **として**
**履歴チャートやバーチャートの色も統一されたパレットで表示されてほしい**
**そうすることで** 複数チャート間でデータの対応関係が視覚的に追える

**関連要件**: REQ-034 ~ REQ-036, REQ-038 ~ REQ-040

**詳細シナリオ**:
1. 最適化履歴のTrial線がアクセントブルー系で表示される
2. バーチャートのプライマリ色がアクセントブルー系で表示される
3. パラレルコーディネートのデフォルト線色がアクセントブルー系で表示される

**前提条件**:
- アクセントブルーが確定済み
- ネガティブ（赤）・警告（オレンジ）色のバランス調整

**優先度**: Should Have

---

### ストーリー 3.3: セマンティック状態色の調整 🟡

**信頼性**: 🟡 *参考画像の状態表示から推測*

**私は** 最適化結果の分析者 **として**
**エラー・Pruned・Running等の状態色が統一されたセマンティックパレットで表示されてほしい**
**そうすることで** 試行状態の判別が一貫する

**関連要件**: REQ-051 ~ REQ-053

**詳細シナリオ**:
1. エラー表示が落ち着いた赤（~#ea4335）で表示される
2. Pruned試行が同じ赤系で表示される
3. Running試行が鮮やかなグリーンで表示される

**前提条件**:
- エラー色とPareto色が同系統の赤になることを許容

**優先度**: Should Have

## エピック4: 3Dビューのライト化

### ストーリー 4.1: 3Dビューのライト背景化 🔵

**信頼性**: 🔵 *ユーザヒアリング「ライト背景に変更」より*

**私は** 3D Pareto Front の分析者 **として**
**3Dビューの背景もライトテーマに統一されてほしい**
**そうすることで** 2D/3Dビュー間の視覚的な違和感がなくなる

**関連要件**: REQ-061, REQ-062, EDGE-001, EDGE-002

**詳細シナリオ**:
1. 3Dビューの背景がライトグレーで表示される
2. 3Dグリッド線がライト背景に映える半透明グレーで表示される
3. 3D軸（X:赤, Y:緑, Z:青）がライト背景でも視認可能

**前提条件**:
- COLOR_3D_BG がライトグレーに変更
- COLOR_3D_GRID がライト背景向けに再計算

**優先度**: Must Have
