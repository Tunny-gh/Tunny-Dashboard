## ヒアリング結果サマリー

### 確認できた事項

- 全 8 機能が「高優先（今すぐ必要）」と確認
- フィルタースライダー連動は現状問題なし（要件対象外）
- チャートコンテキストメニューはHelp + PNG保存の2項目（SVGは今回スコープ外）
- Click Highlight は実装済みのため Brushing 要件から除外
- ピン留め機能の上限は最大20件（REQ-156と整合）

### 追加/変更要件

- F-007 (Comparison Diff モード) を一括比較UI質問の回答から追加
- F-008 (チャートPNG保存) をコンテキストメニュー質問の回答から追加
- ピン留め機能：ピン済み試行はフィルター除外時も描画維持（REQ-003-E）を追加

### 残課題

- PDP Observed Overlay の実装方式（`PdpResult1d` 構造体に `observed_x/y` を追加するか、描画時 `trial_rows` から直接取得するか）は実装時に決定が必要
- Surface Plot の 3D 描画方式（egui_plot 非対応のため wgpu カスタムレンダラーが必要な可能性）は設計段階で確認が必要
- チャート PNG 保存の技術実装（egui のテクスチャキャプチャ API）は実装調査が必要
