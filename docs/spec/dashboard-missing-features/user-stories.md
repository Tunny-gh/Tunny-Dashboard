## エピック1: データエクスポート

### ストーリー 1.1: 選択試行の CSV エクスポート 🔵

**信頼性**: 🔵 *tunny-dashboard-requirements.md REQ-150・REQ-151・ユーザヒアリング2026-05-12より*

**私は** 最適化結果を外部ツールで活用したい設計エンジニア **として**
**ダッシュボードから直接 CSV をエクスポートしたい**
**そうすることで** 選択した有望な試行のパラメータを他の解析ツールやスプレッドシートに渡せる

**関連要件**: REQ-001-A, REQ-001-B, REQ-001-C, REQ-001-D

**詳細シナリオ**:
1. ツールバーの「Export CSV」ボタンをクリックする
2. エクスポート対象を選択するダイアログが開く（全データ / 選択データのみ / Pareto解のみ）
3. 「選択データのみ」を選択する
4. OS 標準のファイル保存ダイアログが開く
5. 保存先を指定して確定する
6. trial_id・パラメータ値・目的関数値・pareto_rank・cluster_id を含む CSV が保存される

**前提条件**:
- Studyが読み込まれている
- Brushing または Pareto フィルターで一部試行が選択されている

**制約事項**:
- Studyが未選択の場合はボタンが無効状態

**優先度**: Must Have

### ストーリー 1.2: 各チャートの PNG 保存 🔵

**信頼性**: 🔵 *REQ-152・ユーザヒアリング2026-05-12より*

**私は** 分析結果を報告書に貼り付けたいデータアナリスト **として**
**各チャートウィジェットを PNG として保存したい**
**そうすることで** スクリーンショットなしに高品質な画像を得られる

**関連要件**: REQ-008-A, REQ-008-B, REQ-008-C

**詳細シナリオ**:
1. 任意のチャートウィジェットのヘッダー右端の「⋯」ボタンをクリックする
2. コンテキストメニューに「Save as PNG」が表示される
3. クリックするとファイル保存ダイアログが開く
4. 保存先を指定して確定する
5. チャートが PNG として保存される

**前提条件**:
- Studyが読み込まれてチャートが描画済み

**優先度**: Must Have

## エピック2: 複数 Study 比較

### ストーリー 2.1: 別 Journal の Study を比較に追加 🔵

**信頼性**: 🔵 *comparison_panel.rs "Add comparison studies via toolbar"・REQ-120・ユーザヒアリング2026-05-12より*

**私は** 異なるサンプラー設定の Study を比較したい最適化研究者 **として**
**別の Journal ファイルの Study をダッシュボードに追加して比較したい**
**そうすることで** サンプラーごとの Pareto フロントと収束性を並べて評価できる

**関連要件**: REQ-002-A, REQ-002-B, REQ-002-C, REQ-002-D

**詳細シナリオ**:
1. ツールバーの「Add Comparison Study」ボタンをクリックする
2. Journal ファイル選択ダイアログが開く
3. 比較したい Journal を選択する
4. バックグラウンドで Journal がパースされ、Study が追加される
5. レイアウトモードが自動的に「Comparison」に切り替わる
6. Comparison パネルに Stats・HV History・Pareto・KDE タブが表示され、比較分析が開始できる

**前提条件**:
- メインの Study が既に読み込まれている

**優先度**: Must Have

---

### ストーリー 2.2: Study 間の Diff（差分）分析 🔵

**信頼性**: 🔵 *REQ-123・REQ-124・ユーザヒアリング2026-05-12（Diff比較モード選択）より*

**私は** Study 間のパフォーマンス差を数値で把握したい研究者 **として**
**Diff タブで Study 間の差分を定量的に確認したい**
**そうすることで** どの Study が優位かを客観的な指標で判断できる**

**関連要件**: REQ-007-A, REQ-007-B, REQ-007-C, REQ-007-D

**詳細シナリオ**:
1. 複数の Study が比較に追加された状態で Comparison パネルを開く
2. 「Diff」タブをクリックする
3. メイン Study と各比較 Study の HV 差分・最良値差分・試行数差分が表形式で表示される
4. Pareto 支配率（支配/非支配/無関係の比率）も確認できる

**前提条件**:
- 比較 Study が少なくとも1件追加されている
- 目的数・方向がメイン Study と一致している

**優先度**: Must Have

## エピック3: 試行ブックマーク

### ストーリー 3.1: 注目試行のピン留め 🔵

**信頼性**: 🔵 *REQ-156・session.rs pinned_trials・ユーザヒアリング2026-05-12より*

**私は** 有望な試行を後から参照したい設計エンジニア **として**
**重要な試行をピン留めしてセッションをまたいでも追跡したい**
**そうすることで** 複数セッションにわたる分析で注目解を見失わない

**関連要件**: REQ-003-A, REQ-003-B, REQ-003-C, REQ-003-D, REQ-003-F

**詳細シナリオ**:
1. Trial Table の任意の行の📌ボタンをクリックする
2. その trial がピン留めされ、行が視覚的にハイライトされる
3. フィルターで他の試行を絞り込んでもピン留め試行は常に表示される
4. セッションを保存し、次回起動・復元後もピン留め状態が維持される

**前提条件**:
- Studyが読み込まれている
- ピン留め件数が20件未満

**制約事項**:
- 最大20件まで

**優先度**: Must Have

## エピック4: 分析精度向上

### ストーリー 4.1: PDP に実測データ点をオーバーレイ 🔵

**信頼性**: 🔵 *docs/design/pdp-observed-overlay/・ユーザヒアリング2026-05-12より*

**私は** サロゲートモデルの精度を視覚的に確認したい解析担当者 **として**
**PDP 曲線に実際の試行データ点を重ねて表示したい**
**そうすることで** サロゲートモデルが実測値をどの程度再現しているかを直感的に判断できる

**関連要件**: REQ-004-A, REQ-004-B, REQ-004-C, REQ-004-D

**詳細シナリオ**:
1. PDP Chart ウィジェットを開き、パラメータと目的関数を選択する
2. チャートヘッダーの「Show Observed」トグルをONにする
3. PDP 曲線に加えて、実際の試行点（x: パラメータ値, y: 目的関数値）が散布図として重ねて表示される
4. Brushing でフィルターをかけると、表示される観測点もリアルタイムに更新される

**前提条件**:
- PDP Chart が描画済み（サロゲートモデル計算完了）

**優先度**: Must Have

---

### ストーリー 4.2: 2変数 Surface Plot で応答曲面を確認 🔵

**信頼性**: 🔵 *docs/design/lightgbm-surface-plot/・ユーザヒアリング2026-05-12より*

**私は** パラメータ間の交互作用を立体的に把握したい設計エンジニア **として**
**2変数と1目的関数の組み合わせを3D サーフェスで可視化したい**
**そうすることで** 応答曲面の形状（谷・山・鞍点）を直感的に理解し、設計指針を得られる

**関連要件**: REQ-005-A, REQ-005-B, REQ-005-C, REQ-005-D, REQ-005-E, REQ-005-F

**詳細シナリオ**:
1. 右パネルから「Surface Plot」ウィジェットをキャンバスにドラッグして追加する
2. チャートヘッダーで x軸パラメータ・y軸パラメータ・目的関数を選択する
3. 「Run」ボタンをクリックすると別スレッドでサロゲートモデルが計算される
4. 計算完了後、3D サーフェスが描画される（z = 目的関数値の予測）

**前提条件**:
- Studyが読み込まれている（2変数以上）

**優先度**: Must Have

## エピック5: インタラクティブ探索

### ストーリー 5.1: チャート上で試行を矩形選択 🔵

**信頼性**: 🔵 *tunny-dashboard-requirements.md REQ-041・ユーザヒアリング2026-05-12より*

**私は** 特定の目的関数値範囲の試行を絞り込みたいデータアナリスト **として**
**Pareto Scatter 2D チャート上でドラッグして矩形選択したい**
**そうすることで** 左パネルのスライダーを操作せずに直感的に試行を絞り込める

**関連要件**: REQ-006-A, REQ-006-B, REQ-006-E, REQ-006-F, REQ-006-G

**詳細シナリオ**:
1. Pareto Scatter 2D チャートの任意の位置でマウスをドラッグ開始する
2. 矩形の選択領域がビジュアルでリアルタイム表示される
3. ドラッグを離すと、矩形内の試行が `selected_indices` に設定される
4. 全チャートが即座に選択された試行のみを強調表示する

**前提条件**:
- Studyが読み込まれてチャートが描画済み

**優先度**: Must Have

---

### ストーリー 5.2: Parallel Coordinates の軸で値範囲を絞り込み 🔵

**信頼性**: 🔵 *REQ-041・ユーザヒアリング2026-05-12より*

**私は** 複数のパラメータ条件を同時に設定して試行を絞り込みたいエンジニア **として**
**Parallel Coordinates の各軸をドラッグして値範囲を設定したい**
**そうすることで** 複数条件の AND フィルターを視覚的に設定できる

**関連要件**: REQ-006-C, REQ-006-D, REQ-006-G

**詳細シナリオ**:
1. Parallel Coordinates チャートを開く
2. 任意の軸上でマウスをドラッグして値範囲を設定する
3. 設定した範囲外の試行線が薄く表示される（除外）
4. 複数軸に範囲を設定すると AND 条件で絞り込まれる
5. 全チャートが連動して絞り込み後の試行のみを強調表示する

**前提条件**:
- Studyが読み込まれている（1変数以上）

**優先度**: Must Have
