## REQ-001: Trade-off Navigator 🔵

**信頼性**: 🔵 *ユーザヒアリング Q3・Q4・tradeoff.rs 実装確認より*

### Given（前提条件）
- 多目的 Study（目的数 ≥ 2）が選択されている
- `rust_core::multi_objective::pareto::tradeoff::score_tradeoff_navigator()` が実装済み

### When（実行条件）
- ユーザーが Left Panel の Trade-off Navigator スライダーを操作する

### Then（期待結果）
- 重みの合計が 1.0 に自動正規化される
- WASM `score_tradeoff_navigator(weights)` が呼ばれ最良解インデックスが更新される
- 全グラフ上で最良解試行がゴールドスターハイライトで表示される

### テストケース

#### 正常系

- [ ] **TC-001-01**: 多目的 Study 選択時に Trade-off Navigator が表示される 🔵
  - **入力**: 2 目的の Study を選択
  - **期待結果**: Left Panel 下部に重みスライダーが 2 本表示される
  - **信頼性**: 🔵 *ユーザヒアリング Q4 より*

- [ ] **TC-001-02**: スライダー操作でハイライトがリアルタイム更新される 🔵
  - **入力**: obj1 重みを 0.8 に設定
  - **期待結果**: 50,000 試行での `score_tradeoff_navigator` 呼び出しが 100ms 以内に完了し、全グラフのハイライトが更新される
  - **信頼性**: 🔵 *NFR-001 パフォーマンス要件より*

- [ ] **TC-001-03**: 重みの自動正規化が動作する 🔵
  - **入力**: obj1 を 0.8 → 0.9 に変更
  - **期待結果**: obj2 が (1.0 - 0.9) / (n-1) に自動調整される
  - **信頼性**: 🔵 *REQ-001-C より*

#### 異常系

- [ ] **TC-001-E01**: 単目的 Study 選択時に非表示 🔵
  - **入力**: 1 目的の Study を選択
  - **期待結果**: Trade-off Navigator セクションが Left Panel に表示されない
  - **信頼性**: 🔵 *REQ-001-F より*

- [ ] **TC-001-E02**: 全スライダーを 0 にしようとした場合 🟡
  - **入力**: 最後の非ゼロスライダーを 0 に操作
  - **期待結果**: 操作が取り消され直前の値に戻る
  - **信頼性**: 🟡 *EDGE-002 から妥当な推測*
