### Q3: Must Have（必須）機能の選択

**質問日時**: 2026-04-26  
**カテゴリ**: 優先順位  
**背景**: first_spec.md の差別化ポイント 10 種を整理し、優先度を確認

**回答**: 以下 8 機能をすべて Must Have として選択

2. フィルタ条件の保存・復元（JSON永続化）
3. レイアウト設定の保存・読み込み
4. HTMLレポート生成・エクスポート
5. 分析セッション永続化（再現・共有）
6. 複数Study比較UI（統計サマリー・HV重畳）
7. アーティファクト連携（画像・CSVプレビュー）
8. 単目的最適化専用UI（収束診断パネル）

**信頼性への影響**:
- REQ-001〜REQ-008 の信頼性レベルが 🔴（推測）→ 🔵（確認済み）に向上

## ヒアリング結果サマリー

### 確認できた事項

- WASM 分析コア（tradeoff.rs / hypervolume.rs / live_update.rs）は実装済みで UI 接続のみ必要
- HTML レポートは静的 SVG+テーブル形式（インタラクティブ不要）
- アーティファクトは自動検出＋手動選択の併用
- 複数 Study 比較は 4 要素すべて必要
- 単目的専用 UI は 3 要素

### 追加/変更要件

- REQ-009（Parallel Coordinates 軸制御）を Should Have として追加
- REQ-005（HTML レポート）のスコープを静的レポートに絞り込み

### 残課題

- ライブ更新完成は本スコープ外（既存 live_update.rs の UI 統合は別タスク）
- Hypervolume 世代別寄与度分解は本スコープ外
