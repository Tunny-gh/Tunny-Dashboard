## REQ-001〜004: ビルド時HTML生成 🔵

**信頼性**: 🔵 *ユーザヒアリング: ビルド時生成選択より*

### Given（前提条件）
- theory/en/ と theory/ja/ にMarkdownファイルが存在する
- Cargo.toml の build-dependencies に pulldown-cmark が追加されている

### When（実行条件）
- `cargo build` を実行する

### Then（期待結果）
- theory/en/ と theory/ja/ の全 .md ファイルがHTMLに変換される
- 生成されたHTMLが OUT_DIR に配置される
- include_str! でHTMLがバイナリに埋め込まれる
- ビルド時間の増加が +5秒以内である

### テストケース

#### 正常系

- [ ] **TC-001-01**: 全mdファイルがHTMLに変換される 🔵
  - **入力**: theory/en/ の30個以上のmdファイル + theory/ja/ の同数ファイル
  - **期待結果**: すべて対応するHTMLファイルが生成される
  - **信頼性**: 🔵 *既存ファイル構成より*

- [ ] **TC-001-02**: 生成HTMLが有効なHTML5である 🔵
  - **入力**: 任意の生成HTML
  - **期待結果**: `<!DOCTYPE html>` で始まり、`</html>` で終わる
  - **信頼性**: 🔵 *HTML生成要件より*

- [ ] **TC-001-03**: ビルド時間増加が許容範囲内 🔵
  - **入力**: cargo build --release
  - **期待結果**: 従来ビルドと比較して +5秒以内の増加
  - **信頼性**: 🔵 *NFR-002より*

#### 異常系

- [ ] **TC-001-E01**: 不正なMarkdownファイルがあってもビルドが継続する 🟡
  - **入力**: パースエラーを含むmdファイル
  - **期待結果**: エラーログを出力しつつビルドは継続（または安全に失敗）
  - **信頼性**: 🟡 *堅牢性要件から推測*

## REQ-010〜013: KaTeX数式レンダリング 🔵

**信頼性**: 🔵 *ユーザヒアリング: KaTeX埋め込み選択より*

### Given（前提条件）
- Markdown内に `$...$` または `$$...$$` 記法の数式が含まれている
- KaTeX CSS/JSがHTMLにインライン埋め込みされている

### When（実行条件）
- ブラウザで生成されたHTMLを開く

### Then（期待結果）
- インライン数式が行内に正しくレンダリングされる
- ブロック数式が中央揃えでレンダリングされる
- オフライン環境でも表示される

### テストケース

#### 正常系

- [ ] **TC-010-01**: インライン数式が正しくレンダリングされる 🔵
  - **入力**: `$r_{ij}$` を含むMarkdown
  - **期待結果**: ブラウザで添字付きの r_ij が表示される
  - **信頼性**: 🔵 *KaTeX仕様より*

- [ ] **TC-010-02**: ブロック数式が正しくレンダリングされる 🔵
  - **入力**: `$$r_{ij} = \frac{v_{ij}}{\sqrt{\sum_i v_{ij}^2}}$$` を含むMarkdown
  - **期待結果**: ブラウザで分数付きの数式が中央揃えで表示される
  - **信頼性**: 🔵 *KaTeX仕様より*

- [ ] **TC-010-03**: オフライン環境で数式が表示される 🔵
  - **入力**: ネットワーク切断状態でHTMLを開く
  - **期待結果**: KaTeXがインライン埋め込みのため数式が正しく表示される
  - **信頼性**: 🔵 *ユーザヒアリング: KaTeX埋め込み選択より*

- [ ] **TC-010-04**: TOPSISの全数式が正しく表示される 🔵
  - **入力**: theory/en/mcdm/topsis.md の変換結果
  - **期待結果**: Step1〜Step6の全数式が正しくフォーマットされる
  - **信頼性**: 🔵 *既存コンテンツの確認より*

#### 異常系

- [ ] **TC-010-E01**: 不正なLaTeX記法でもページが崩れない 🟡
  - **入力**: `$\frac{` のような未閉じLaTeX
  - **期待結果**: KaTeXエラー表示が出るがページ全体は表示される
  - **信頼性**: 🟡 *KaTeXのエラーハンドリングから推測*
