## エピック1: ビルド時HTML生成

### ストーリー 1.1: Markdown→HTML変換パイプライン 🔵

**信頼性**: 🔵 *ユーザヒアリング: ビルド時生成選択より*

**私は** Tunny Dashboard 開発者 **として**
**theory/ 配下のMarkdownファイルをビルド時に自動的にHTMLに変換したい**
**そうすることで** 実行時のオーバーヘッドなしにリッチなヘルプドキュメントを提供できる

**関連要件**: REQ-001, REQ-002, REQ-003, REQ-004

**詳細シナリオ**:
1. `cargo build` 実行時に build.rs が起動する
2. build.rs が theory/en/ と theory/ja/ の全 .md ファイルを検出する
3. pulldown-cmark で Markdown→HTML 変換を実行する
4. KaTeX のCSS/JSをインライン埋め込みした完全なHTMLを生成する
5. 生成されたHTMLは OUT_DIR に配置され、include_str! でバイナリに埋め込まれる

**前提条件**:
- pulldown-cmark が Cargo.toml の build-dependencies に追加されている
- theory/ 配下のMarkdownがLaTeX記法に移行済み

**制約事項**:
- ビルド時間への影響は +5秒以内
- 生成HTMLは完全にスタンドアロン（外部リソース参照なし）

**優先度**: Must Have

### ストーリー 1.2: LaTeX記法の数式移行 🔵

**信頼性**: 🔵 *ユーザヒアリング: LaTeX記法書き換え選択より*

**私は** Tunny Dashboard ユーザー **として**
**ヘルプドキュメント内の数式を正しくフォーマットされた形で見たい**
**そうすることで** TOPSIS のスコア計算式やSobol指数の数式を正確に理解できる

**関連要件**: REQ-040, REQ-041, REQ-010, REQ-011, REQ-012

**詳細シナリオ**:
1. TOPSIS のヘルプを開く
2. 「Step 1: Vector Normalization」の数式が KaTeX で美しくレンダリングされる
3. インライン数式 `$r_{ij}$` が文中に正しく表示される
4. ブロック数式 `$$r_{ij} = \frac{v_{ij}}{\sqrt{\sum_i v_{ij}^2}}$$` が中央揃えで表示される
4. オフライン環境でも数式が正しく表示される

**前提条件**:
- KaTeX CSS/JSがHTMLにインライン埋め込みされている
- Markdown内の数式が `$...$` / `$$...$$` 記法に書き換えられている

**優先度**: Must Have

## エピック2: ブラウザ表示

### ストーリー 2.1: ヘルプボタンでブラウザ起動 🔵

**信頼性**: 🔵 *ユーザヒアリング: ブラウザのみ選択より*

**私は** Tunny Dashboard ユーザー **として**
**ウィジェットのヘルプボタンをクリックしてブラウザでヘルプを読みたい**
**そうすることで** 数式やテーブルが正しくフォーマットされた状態でドキュメントを閲覧できる

**関連要件**: REQ-020, REQ-021, REQ-022

**詳細シナリオ**:
1. ウィジェットのツールバー「⋯」メニューから「Help」をクリックする
2. デフォルトブラウザが起動し、該当ウィジェットのヘルプHTMLが表示される
3. HTMLはKaTeX数式、スタイル付きテーブル、コードブロックを含む
4. ブラウザのタブ/戻るボタンで通常通り操作可能

**前提条件**:
- ブラウザがインストールされている
- 一時ディレクトリへの書き込み権限がある

**優先度**: Must Have

### ストーリー 2.2: ブラウザ起動失敗時のエラー表示 🟡

**信頼性**: 🟡 *既存 artifact_modal のパターンから妥当な推測*

**信頼性**: 🔵 *ユーザヒアリング: モーダル廃止承認より*

5. layout.rs の show_help_modal 呼び出しをヘルプボタンアクションに変更する
6. widget_states.rs の HelpModalState を HelpLanguageState 等に変更する
7. 全テストが通ることを確認する

**前提条件**:
- ブラウザ表示機能が完全に動作している

**優先度**: Must Have
