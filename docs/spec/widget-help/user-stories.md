## エピック1: ヘルプボタンとモーダル基本機能

### ストーリー 1.1: ヘルプボタンをクリックしてモーダルを開く 🔵

**信頼性**: 🔵 *ユーザヒアリング: モーダルウィンドウ・セルツールバー配置より*

**私は** Tunny Dashboard ユーザー **として**
**ウィジェットの「?」ボタンをクリックしてヘルプを表示したい**
**そうすることで** ウィジェットの理論背景や使い方をその場で確認できる**

**関連要件**: REQ-001, REQ-002, REQ-003, REQ-004, REQ-005

**詳細シナリオ**:
1. ユーザーがグリッドセルのツールバーにある「?」ボタンを確認する
2. 「?」ボタンをクリックする
3. ヘルプモーダルがウィンドウ中央に表示される
4. モーダルのヘッダーにウィジェット名が表示される
5. 閉じるボタンまたは Esc キーでモーダルを閉じる

**前提条件**:
- ダッシュボードに少なくとも1つのウィジェットが配置されている

**優先度**: Must Have

## エピック2: Theory 情報ありウィジェットのヘルプ

### ストーリー 2.1: 感度分析の概要と選び方を確認する 🔵

**信頼性**: 🔵 *Theory/sensitivity-analysis/README.md・ユーザヒアリング: 概要＋選び方ガイドより*

**私は** Tunny Dashboard ユーザー **として**
**ImportanceChart のヘルプで感度分析手法の比較と選び方を確認したい**
**そうすることで** 目的に合った手法を適切に選択できる**

**関連要件**: REQ-010, REQ-011, REQ-012, REQ-030

**詳細シナリオ**:
1. ImportanceChart の「?」ボタンをクリックする
2. モーダルが開き、「Overview」タブが表示される
3. 手法一覧表（Spearman, Ridge, MDI, RF-ANOVA, Permutation, SHAP, Sobol）が表示される
4. 各手法の特徴・値域・目安コストが表形式で確認できる
5. 選び方フローチャートがテキスト形式で表示される

**前提条件**:
- ImportanceChart が配置されている

**優先度**: Must Have
