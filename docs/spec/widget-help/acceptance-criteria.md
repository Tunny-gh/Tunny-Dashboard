## REQ-001: セルツールバーにヘルプボタン表示 🔵

**信頼性**: 🔵 *ユーザヒアリング: セルツールバー配置より*

### Given（前提条件）
- ダッシュボードに少なくとも1つのウィジェットが配置されている

### When（実行条件）
- グリッドセルのツールバーが描画される

### Then（期待結果）
- ツールバーに「?」ボタンが表示される
- 「?」ボタンはタイトルの右隣、閉じるボタンの左に配置される
- 「?」ボタンは移動ボタンや閉じるボタンと視覚的に調和する

### テストケース

#### 正常系

- [ ] **TC-001-01**: ウィジェット配置時の「?」ボタン表示 🔵
  - **入力**: ウィジェットがグリッドセルに配置されている状態
  - **期待結果**: ツールバーに移動・タイトル・?・閉じるの順で要素が表示される
  - **信頼性**: 🔵 *ユーザヒアリングより*

- [ ] **TC-001-02**: 全18種のウィジェットで「?」ボタン表示 🔵
  - **入力**: PanelItem::all() の各ウィジェットを配置
  - **期待結果**: 全てのウィジェットで「?」ボタンが表示される
  - **信頼性**: 🔵 *全ウィジェットにヘルプより*
