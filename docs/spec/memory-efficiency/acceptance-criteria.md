**【信頼性レベル凡例】**:
- 🔵 **青信号**: PRD・コード調査・ユーザヒアリングを参考にした確実な基準
- 🟡 **黄信号**: それらから妥当に推測した基準
- 🔴 **赤信号**: 根拠資料にない推測による基準

> **共通の測定前提（NFR-004）**: メモリ計測は **100k trials × 約22列** の代表 Optuna Journal データセットで、改修前（ベースライン）と改修後の **定常メモリ** および **ピークメモリ** を測定する。測定手段は [prep.md](prep.md) の確認事項で確定する。
> **共通の等価性前提（REQ-404）**: すべての項目で `cargo test --workspace` がグリーンであること。

## REQ-001 / REQ-101: 行指向データの永続複製を排除 🔵

**信頼性**: 🔵 *PRD MEM-001 受け入れ基準・`io/study.rs:46-94` より*

### Given（前提条件）
- 100k × 22 の代表データセットを読み込んでいる。

### When（実行条件）
- study を選択する。

### Then（期待結果）
- 通常運用で永続的な `Vec<TrialRow>` コピーが生成されない。
- 単一 study の定常メモリがベースライン比 **50% 以上削減**。

### テストケース

#### 正常系
- [ ] **TC-001-01**: study 選択後、永続 `Vec<TrialRow>` が生成されないことをコード・型レベルで確認（`StudyContext` から行指向永続フィールドが除去/未使用）🔵 *PRD MEM-001*
- [ ] **TC-001-02**: 100k×22 で定常メモリを計測し、ベースライン比 -50% 以上を数値確認 🔵 *NFR-001 / ヒアリングQ4*

#### 異常系
- [ ] **TC-001-E01**: 0 試行の空 study を選択してもパニックせず空表現を返す（EDGE-001）🟡 *`model.rs:27` から推測*

#### 境界値
- [ ] **TC-001-B01**: カテゴリ／文字列パラメータを含む study で数値変換挙動が現行と一致（EDGE-002）🟡 *`model.rs:76-99` から推測*

## REQ-004 / REQ-005: Pareto ウィジェットの行クローン撤廃 🔵

**信頼性**: 🔵 *PRD MEM-002・`pareto_2d.rs:38`, `pareto_3d.rs:99` より*

- ダウンサンプル時・非ダウンサンプル時とも描画挙動が不変。

### テストケース

#### 正常系
- [ ] **TC-004-01**: `display_rows_cache: Option<Vec<TrialRow>>` が両ウィジェットから削除されている 🔵 *PRD MEM-002 受け入れ基準*

#### 境界値
- [ ] **TC-004-B01**: ダウンサンプル ON/OFF の両モードで描画点・色が現行と一致 🔵 *PRD MEM-002「Rendering behavior remains unchanged」*

#### 境界値
- [ ] **TC-006-B01**: 100k×22 規模で各ウィジェットの描画結果が現行と一致 🔵 *PRD MEM-003（~17.6MB/widget 基準）*

## REQ-008 / REQ-009 / REQ-102: 分析一時行列の削減 🔵

**信頼性**: 🔵 *PRD MEM-004・`poll_chart.rs:16-22` より*

### Given
- PDP / Surface Plot / Sensitivity が実行ごとに `Vec<Vec<f64>>` を `r.params` 参照から再構築。

#### 境界値
- [ ] **TC-008-B01**: PDP/Surface/Sensitivity の数値出力が現行と等価 🔵 *REQ-401*
