## エピック1: チャートデータの手元への持ち出し

### ストーリー 1.1: 最適化結果を後処理のためにCSVで取得する 🔵

**信頼性**: 🔵 *ユーザヒアリング（要件の発端: 手元で図の値を処理したい）より*

**私は** Optuna最適化ユーザー **として**
**各チャートの⋯メニューから「Save as CSV」をクリックしたい**
**そうすることで** チャートが表示しているデータを手元のツール（Excel, Python, R等）で後処理・再プロットできる

**関連要件**: REQ-001, REQ-002, REQ-010, REQ-011

**詳細シナリオ**:
1. チャートセルのツールバー右側にある ⋯ ボタンをクリックする
2. ポップアップメニューに「Save as PNG」「Save as CSV」「Help」が表示される
3. 「Save as CSV」をクリックする
4. ファイル保存ダイアログが開く（デフォルトファイル名: そのチャートに応じた名前）
5. 保存先を選択してOKをクリックすると、CSVファイルが保存される
6. ダイアログをキャンセルした場合、何も保存されずに戻る

**前提条件**:
- Journalファイルが読み込まれスタディが存在している
- チャートにデータが存在している（計算完了済み）

**制約事項**:
- Surface Plot はCSV出力対象外
- データ未準備時はボタンがグレーアウト

**優先度**: Must Have

### ストーリー 1.2: 重要度スコアをCSVで取得する 🔵

**信頼性**: 🔵 *ユーザヒアリング Q2 + ImportanceChart の実装より*

**私は** Optuna最適化ユーザー **として**
**ImportanceChartの⋯メニューから「Save as CSV」をクリックしたい**
**そうすることで** 各パラメータの重要度スコアをCSVで取得して論文・レポートに活用できる

**関連要件**: REQ-022

**詳細シナリオ**:
1. ImportanceChartセルの⋯メニューから「Save as CSV」をクリック
2. ファイル保存ダイアログが開く（デフォルト名: `importance_chart.csv`）
3. CSV保存後、以下の形式のファイルが生成される:

```
variable,importance_score,method
x0,0.8234,permutation
x1,0.1523,permutation
x2,0.0243,permutation
```

**前提条件**:
- 重要度計算が完了している

**優先度**: Must Have

### ストーリー 1.3: パレートフロントデータをCSVで取得する 🔵

**信頼性**: 🔵 *ParetoScatter2D の実装・pareto_indices より*

**私は** 多目的最適化ユーザー **として**
**ParetoScatter2Dチャートの⋯メニューから「Save as CSV」をクリックしたい**
**そうすることで** パレートフロントの点のみを絞り込んだCSVを取得して意思決定に活用できる

**関連要件**: REQ-029

**詳細シナリオ**:
1. ParetoScatter2D セルの⋯メニューから「Save as CSV」をクリック
2. パレートフロントの試行のみが含まれるCSVが保存される（全試行ではない）

**前提条件**:
- 多目的スタディが読み込まれパレート計算が完了している

**優先度**: Must Have

## エピック2: データ未準備時の安全な操作

### ストーリー 2.1: 計算中のチャートでCSVボタンが誤動作しない 🔵

**信頼性**: 🔵 *ユーザヒアリング Q4 より*

**私は** Optuna最適化ユーザー **として**
**計算中のチャートの⋯メニューを開いたとき「Save as CSV」がグレーアウトされていることを確認したい**
**そうすることで** 不完全なデータがCSVとして保存されることを防げる

**関連要件**: REQ-201, REQ-202

**詳細シナリオ**:
1. ImportanceChart 等の計算が完了していないチャートの⋯メニューを開く
2. 「Save as CSV」ボタンがグレーアウトされている
3. グレーアウトされたボタンにホバーすると「No data available」ツールチップが表示される
4. ボタンをクリックしても何も起こらない

**前提条件**:
- スタディが読み込まれているが、特定チャートの計算が未完了

**優先度**: Must Have
