## REQ-001〜003: ボタン配置 🔵

**信頼性**: 🔵 *ユーザヒアリング Q1 + 既存 `grid_canvas.rs` より*

### Given
- Journalファイルが読み込まれ、いずれかのチャートがセルに配置されている

### When
- ユーザーがチャートセルのツールバー右側の ⋯ ボタンをクリックする

### Then
- ポップアップメニューに「Save as PNG」「Save as CSV」「Help」の3つが表示される
- 「Save as CSV」は「Save as PNG」の直下に配置される

### テストケース

- [ ] **TC-001-01**: ⋯メニューに「Save as CSV」が存在する 🔵
  - **検証**: `chart_cell_menu_items()` の戻り値に "Save as CSV" が含まれる
  - **信頼性**: 🔵 *既存テスト `menu_contains_save_as_png_and_help` のパターンより*

- [ ] **TC-001-02**: `CellToolbarAction::SaveAsCsv` バリアントが存在する 🔵
  - **検証**: `CellToolbarAction::SaveAsCsv(item)` がコンパイルできる

- [ ] **TC-001-03**: Surface Plot セルの⋯メニューには「Save as CSV」が存在しない、またはグレーアウトされる 🔵
  - **信頼性**: 🔵 *ユーザヒアリング Q3 より*

## REQ-010〜013: CSV内容の基本仕様 🔵

**信頼性**: 🔵 *ユーザヒアリング Q2 + 既存 `build_csv_string()` より*

### Given
- チャートにデータが存在している
- ユーザーが「Save as CSV」をクリックした

### When
- ファイル保存ダイアログで保存先を選択してOKをクリックする

### Then
- CSVファイルが指定パスに保存される
- 先頭行はヘッダー行（英語スネークケース）
- ファイルはUTF-8エンコード

### テストケース

- [ ] **TC-010-01**: 保存ダイアログのデフォルトファイル名がチャート名に対応している 🟡
  - **入力**: ChartId::OptimizationHistory
  - **期待結果**: デフォルトファイル名が "optimization_history.csv"

- [ ] **TC-010-02**: ダイアログキャンセル時はファイルが生成されない 🔵
  - **期待結果**: `Ok(())` が返され、副作用なし

- [ ] **TC-010-03**: CSVの先頭行がヘッダーである 🔵
  - **期待結果**: `csv.lines().next()` がヘッダー文字列を返す

## REQ-201〜204: データ未準備時の挙動 🔵

**信頼性**: 🔵 *ユーザヒアリング Q4 より*
