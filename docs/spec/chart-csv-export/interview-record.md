# chart-csv-export ヒアリング記録

**作成日**: 2026-05-28
**ヒアリング実施**: step4 既存情報ベースの差分ヒアリング

## ヒアリング目的

既存のCSVエクスポートインフラ・チャートウィジェット構造を確認し、各チャートへのCSVダウンロードボタン追加の詳細仕様を明確化するためのヒアリングを実施しました。

## 質問と回答

### Q1: CSVダウンロードボタンはどこに配置しますか？

**カテゴリ**: 未定義部分詳細化
**背景**: `grid_canvas.rs` のセルツールバーに「⋯」メニューがあり、既存の「Save as PNG」「Help」と同様のパターンで追加できる。別の場所（ウィジェット内）も選択肢としてあった。

**回答**: セルツールバーの⋯メニュー内（推奨）- 既存の「Save as PNG」「Help」と同じ⋯ポップアップメニューに「Save as CSV」を追加する。

**信頼性への影響**:
- REQ-001（ボタン配置）の信頼性レベルが 🔴 → 🔵 に向上
- 既存パターン（CellToolbarAction enum）との整合性が確認できた

---

### Q2: チャートによって出力するCSVの内容が異なります。どのアプローチを取りますか？

**カテゴリ**: 未定義部分詳細化
**背景**: チャートごとに表示データが異なる（試行全データ vs 重要度スコア vs 感度行列 vs MCDM結果など）。全チャートで同じ「全試行データ」を出力するか、チャート固有データを出力するかの判断が必要。

**回答**: チャートが表示しているデータを出力（推奨）- 後処理に便利なのはチャートが見せているデータそのものであるため、チャート固有のCSVを出力する。

**信頼性への影響**:
- REQ-002（CSV内容）の信頼性レベルが 🟡 → 🔵 に向上
- 各チャートの出力仕様が明確になった

---

### Q3: Surface Plot・3D Paretoなど、CSVに落とし込みにくいデータ形式のチャートも対応必須ですか？

**カテゴリ**: スコープ確認
**背景**: Surface Plot は X×Y グリッドの Z 値行列であり、CSV化はできるが行列形式になる。ParetoScatter3D は通常の点データ（3目的値）なのでCSV化は容易。

**回答**: 対応不要、少ないチャートはスキップ - Surface Plotのような3Dグリッドデータは実装をスキップし、対応できるチャートのみ実装する。

**信頼性への影響**:
- REQ-103（Surface Plot スキップ）の信頼性レベル 🔵 を確認

---

### Q4: チャートにCSV出力がそもそも適切でないケース（計算中やデータなし）ではどうしますか？

**カテゴリ**: エラーハンドリング
**背景**: ImportanceChart・SensitivityHeatmap・MCDM等は非同期計算が完了するまでデータが存在しない。この状態でボタンをクリックされた場合の処理が必要。

**回答**: ボタンをグレーアウトして業務中ることを示す - データが存在しない・計算中の場合はボタンを無効化し、ホバー時に「No data available」ツールチップを表示する。

**信頼性への影響**:
- REQ-201（エラー処理）の信頼性レベルが 🔴 → 🔵 に向上

---

## ヒアリング結果サマリー

### 確認できた事項
- ボタン配置は既存⋯メニュー内（CellToolbarAction パターンを踏襲）
- CSV内容はチャート固有データを出力（後処理利便性を優先）
- Surface Plot のみスキップ（3Dグリッド形式は不適）
- データ未準備時はボタングレーアウト + ツールチップで対応

### 追加/変更要件
- `CellToolbarAction` enum に `SaveAsCsv` バリアントを追加
- `chart_cell_menu_items()` に "Save as CSV" を追加
- 各チャートウィジェットに `to_csv_rows()` メソッドまたは同等の CSV生成関数を追加
- `WidgetStates` に CSV 出力ができるか判定するメソッドを追加

### 残課題
- チャートごとのCSV列定義の詳細（特にPDP2D, SensitivityHeatmap）
- ParetoScatter3D は「点データ」なのでCSV化可能（ユーザーに確認せず実装で判断）
- AhpTable / McdmTable は result の型によって列数が変わるため、実装時に確認が必要
