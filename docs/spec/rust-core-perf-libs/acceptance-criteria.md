## REQ-101: PCA 固有値分解の faer 化 🔵

**信頼性**: 🔵 *コードベース調査・ユーザヒアリングより*

### Given（前提条件）
- PCA 入力データ（NxP 行列）が用意されている
- faer が既に依存関係に含まれている

### When（実行条件）
- `PcaResult::compute()` を呼び出す

### Then（期待結果）
- 射影結果が従来と同一（相対誤差 < 1e-10）
- 固有値が降順でソートされている
- 指定した n_components 次元に射影される

### テストケース

  - **信頼性**: 🔵 *既存テストケースより*

- [ ] **TC-101-02**: p=20 次元データの PCA が正しく動作する 🔵
  - **入力**: 20 次元のランダムデータ（N=1000）
  - **期待結果**: 固有値降順・射影次元正しい
  - **信頼性**: 🔵 *PCA 仕様より*

#### 境界値

- [ ] **TC-101-B01**: N=2, P=2 の最小構成で動作する 🔵
  - **入力**: 2x2 データ
  - **期待結果**: 1 次元に射影される
  - **信頼性**: 🔵 *PCA 最小構成より*
