## REQ-STAT-010〜013: Spearman の統計指標 🔵

**信頼性**: 🔵 *ユーザヒアリング・Spearman理論より*

### Given
- `x` と `y` がそれぞれ n 個のデータを持つ
- Spearman相関係数 ρ が計算済み

### When
- `compute_spearman_with_stats(x, y)` を呼び出す

### Then
- t統計量 `t = ρ√(n-2) / √(1-ρ²)` が返される
- 自由度 df = n-2 の t 分布から両側p値が計算される
- 95%信頼区間が Fisher z 変換から計算される

### テストケース

#### 正常系

- [ ] **TC-STAT-001**: ρ=0（無相関）では p ≈ 1.0 🔵
  - 入力: x=[1,2,3,4,5], y=[3,1,4,1,5]（計算でρ≈0のデータ）
  - 期待結果: p値 > 0.5

- [ ] **TC-STAT-002**: ρ=1.0（完全相関）では p ≈ 0.0 🔵
  - 入力: x=[1,2,3,4,5], y=[1,2,3,4,5]
  - 期待結果: p値 < 0.001（信頼区間は CI=[1.0, 1.0]近傍）

- [ ] **TC-STAT-003**: 既知のρで t統計量の数値確認 🔵
  - 入力: n=100, ρ=0.3
  - 期待結果: t ≈ 0.3×√98/√(1-0.09) ≈ 3.082, p ≈ 0.0026

#### 異常系

- [ ] **TC-STAT-004**: n < 4 では `None` を返す 🔵
  - 入力: x=[1,2,3], y=[1,2,3]
  - 期待結果: p_value=None, ci_lower=None, ci_upper=None

- [ ] **TC-STAT-005**: ρ=±1.0（退化ケース）で NaN/Inf が発生しない 🔵
  - 入力: x=[1,2,3,4,5], y=[1,2,3,4,5]
  - 期待結果: p値は 0.0（NaNでない）、エラーなし

## REQ-STAT-020〜025: Ridge の統計指標 🔵

**信頼性**: 🔵 *ユーザヒアリング・Ridge理論より*

### Given
- X: n×p の設計行列（標準化済み）、y: n次元ターゲット
- Ridge α=1.0

### When
- `compute_ridge_with_stats(x_matrix, y, alpha)` を呼び出す

### Then
- `RidgeResult.p_values` に各係数の t 検定p値が格納される
- `RidgeResult.std_errors` に各係数の標準誤差が格納される
- `RidgeResult.ci_lower` / `ci_upper` に95%信頼区間が格納される

### テストケース

#### 正常系

- [ ] **TC-STAT-010**: 完全線形関係でβ_1が有意 🔵
  - 入力: y = 2×x_1 + noise（noise小）、n=50, p=2
  - 期待結果: x_1 の p値 < 0.05

- [ ] **TC-STAT-011**: 無関係パラメータが非有意 🔵
  - 入力: y = x_1 + noise、x_2 は y と無関係、n=50
  - 期待結果: x_2 の p値 > 0.05

- [ ] **TC-STAT-012**: 近似バイアス警告フラグが付与される 🟡
  - 入力: α=1.0（標準）
  - 期待結果: `RidgeResult.is_approximate = true`

#### 異常系

- [ ] **TC-STAT-013**: n ≤ p + 2 では統計情報が `None` 🟡
  - 入力: n=5, p=4
  - 期待結果: p_values=None, std_errors=None

## REQ-STAT-030〜034: RF-ANOVA のツリー間統計指標 🔵

**信頼性**: 🔵 *ユーザヒアリング・RF-ANOVA理論より*

### Given
- x_matrix: n×p のパラメータ行列
- y: n次元目的関数値
- ランダムフォレスト 100 本

### When
- `compute_rf_anova_importances(x_matrix, y)` を呼び出す（拡張版）

### Then
- 各パラメータについて 100 本の木の重要度から標準誤差が計算される
- t 統計量（df=99）から片側p値が計算される
- 95%信頼区間（mean ± t_{0.025,99} × SE）が計算される

### テストケース

#### 正常系

- [ ] **TC-STAT-020**: 重要パラメータが有意（p < 0.05） 🔵
  - 入力: y = x_1² + noise（noise小）、n=200
  - 期待結果: x_1 の p値 < 0.05

- [ ] **TC-STAT-021**: 無関係パラメータが非有意 🔵
  - 入力: y = x_1、x_2 は無関係、n=100
  - 期待結果: x_2 の p値 > 0.1（多くの場合）

- [ ] **TC-STAT-022**: 全木で同じ重要度（SE=0）の場合 🟡
  - 入力: 全木で重要度が 0.0 のパラメータ
  - 期待結果: p_value=None または 1.0

## REQ-STAT-040〜044: Sobol の Jansen 統計指標 🔵

**信頼性**: 🔵 *ユーザヒアリング・Jansen (1999) より*

### Given
- Sobol 計算が完了済み（f_A, f_B, f_AB_i の評価値あり）
- N=1024 サンプル

### When
- Jansen 分散公式を適用する

### Then
- 一次指標 S_i の分散から95%信頼区間が計算される
- p値（帰無仮説 S_i=0）が正規近似から計算される

### テストケース

#### 正常系

- [ ] **TC-STAT-030**: 線形関係で S_i が有意 🔵
  - 入力: サロゲートがほぼ完全に近似できるデータ（R²≥0.9）
  - 期待結果: 主要パラメータの S_i の CI 下限 > 0

- [ ] **TC-STAT-031**: Var_Y ≈ 0 で統計情報 `None` 🔵
  - 入力: y が定数
  - 期待結果: 全パラメータの統計情報 = None

#### 警告系

- [ ] **TC-STAT-032**: R² < 0.5 で警告フラグが付与される 🟡
  - 入力: ランダムデータ（サロゲート品質低）
  - 期待結果: `SobolResult.surrogate_quality_warning = true`

## REQ-STAT-050〜052: Bonferroni 補正 🔵

**信頼性**: 🔵 *ユーザヒアリングより*

### Given
- P 個のパラメータの raw p値リスト

### When
- `bonferroni_correction(p_values, n_params)` を呼び出す

### Then
- 各 p_adjusted_j = min(p_raw_j × P, 1.0) が計算される

### テストケース

- [ ] **TC-STAT-040**: 基本的な補正計算 🔵
  - 入力: p_raw=[0.01, 0.03, 0.1], P=3
  - 期待結果: p_adj=[0.03, 0.09, 0.3]

- [ ] **TC-STAT-041**: 補正後が 1.0 を超える場合はクリップ 🔵
  - 入力: p_raw=[0.5], P=3
  - 期待結果: p_adj=[1.0]（min(1.5, 1.0)=1.0）

- [ ] **TC-STAT-042**: P=1 の場合は補正なし 🟡
  - 入力: p_raw=[0.03], P=1
  - 期待結果: p_adj=[0.03]

## REQ-STAT-004, REQ-STAT-005: UI の有意性マーク表示 🔵

**信頼性**: 🔵 *ユーザヒアリングより*

### Given
- 感度分析チャートに重要度と統計情報が揃っている

### When
- ユーザーが感度分析タブを開く

### Then
- 各パラメータのバー右側に「0.032 *」形式で表示される
- 有意性マーク: p_adj < 0.001 → ***、< 0.01 → **、< 0.05 → *、≥ 0.05 → 省略
- Ridge の場合「～0.032 *」で近似を示す

### テストケース

- [ ] **TC-STAT-050**: p_adj=0.003 の表示 🔵
  - 期待: 「0.003 **」形式のテキスト

- [ ] **TC-STAT-051**: p_adj=0.1（非有意）の表示 🔵
  - 期待: マークなし（「0.1」または省略）

- [ ] **TC-STAT-052**: 統計情報 None のケース 🟡
  - 期待: 「n/a」または空白表示
