## エピック1: egui デスクトップ UI カラー統一

### ストーリー 1.1: ツールバーのブランドカラー適用 🔵

**信頼性**: 🔵 *TONMANUAL §4 ナビゲーションバー・ユーザヒアリングより*

**私は** Tunny Dashboard ユーザー **として**
**ツールバーが Tunny ブランドの blue-200 (#BFDBFE) で表示されているのを見たい**
**そうすることで** Tunny の web ドキュメントサイトと一貫したブランド体験を得られる

**関連要件**: REQ-008, REQ-009, REQ-010, REQ-011, REQ-012

**詳細シナリオ**:
1. ユーザーが Tunny Dashboard を起動する
2. 上部ツールバーが TONMANUAL のナビゲーションバーと同じ blue-200 (#BFDBFE) 背景で表示される
3. ツールバー内のテキスト・ラベルが gray-700 (#374151) で読みやすく表示される
4. アクティブなボタンが blue-500 (#3B82F6) で強調表示される
5. 入力欄が gray-100 (#F3F4F6) 背景・gray-200 (#E5E7EB) ボーダーで表示される

**前提条件**:
- egui アプリが light モードで動作している

**制約事項**:
- ツールバー内のすべての要素が WCAG AA 基準（コントラスト比 4.5:1 以上）を満たす

**優先度**: Must Have

### ストーリー 1.2: アクセントカラーのブランド統一 🔵

**信頼性**: 🔵 *TONMANUAL §2 プライマリカラー・ユーザヒアリングより*

**私は** Tunny Dashboard ユーザー **として**
**インタラクティブ要素（ボタン・選択状態）が Tunny ブランドの blue (#3B82F6) で統一されているのを見たい**
**そうすることで** どの操作ポイントが重要かを直感的に理解できる

**関連要件**: REQ-001, REQ-002, REQ-018

**詳細シナリオ**:
1. ユーザーがウィジェットを操作する
2. アクティブ（クリック中）状態のボタンが blue-500 (#3B82F6) で表示される
3. ホバー時のハイライトが blue-600 (#2563EB) で表示される
4. 選択ハイライト（テキスト選択等）が blue-200 (#BFDBFE) 背景で表示される

**優先度**: Must Have

### ストーリー 1.3: パネル・テキスト色のブランド統一 🔵

**信頼性**: 🔵 *TONMANUAL §2 セカンダリカラー・§3 タイポグラフィより*

**私は** Tunny Dashboard ユーザー **として**
**左右パネルが gray-100 (#F3F4F6)、本文テキストが gray-600 (#4B5563)、見出しが gray-900 (#111827) で表示されているのを見たい**
**そうすることで** Tunny ブランドの清潔感あるカラーリングでデータを読みやすく確認できる

**関連要件**: REQ-003, REQ-005, REQ-006, REQ-007

**詳細シナリオ**:
1. ユーザーがダッシュボードを開く
2. 左右パネル背景が gray-100 (#F3F4F6) で表示される
3. 見出しテキストが gray-900 (#111827) で濃く表示される
4. 補助テキスト・ラベルが gray-600 (#4B5563) で適度な濃さで表示される
5. ボーダーが gray-200 (#E5E7EB) で清潔に区切られる

**優先度**: Must Have

## エピック2: ヘルプ HTML ブラウザ スタイル統一

### ストーリー 2.1: ヘルプ記事のブランドスタイル適用 🔵

**信頼性**: 🔵 *TONMANUAL §6 コンテンツスタイル・§3 タイポグラフィより*

**私は** Tunny Dashboard ユーザー **として**
**ヘルプブラウザ内の説明記事が Tunny ブランドのタイポグラフィ・カラーで表示されているのを見たい**
**そうすることで** Tunny ドキュメントサイトと一貫した読みやすい体験でヘルプを確認できる

**関連要件**: REQ-101, REQ-102, REQ-103, REQ-104, REQ-105, REQ-106

**詳細シナリオ**:
1. ユーザーがウィジェットのヘルプを開く
2. 本文テキストが gray-600 (#4B5563) で表示される
3. H1/H2/H3 が gray-900 (#111827) ・font-weight 800 で表示される
4. テーブルの `th` 背景が gray-100 (#F3F4F6) で表示される
5. コードブロック背景が gray-100 (#F3F4F6) で表示される
6. リンクが blue-600 (#2563EB) で表示され、ホバー時にアンダーラインが出る

**前提条件**:
- `cargo build` によってヘルプ HTML が再生成されている

**優先度**: Must Have

## エピック3: HTML エクスポートレポート スタイル統一

### ストーリー 3.1: ブランドカラーを反映したレポート出力 🔵

**信頼性**: 🔵 *TONMANUAL §2 §3・ユーザヒアリングより*

**私は** Tunny Dashboard ユーザー **として**
**エクスポートした HTML レポートが Tunny ブランドのカラーパレット・タイポグラフィで表示されているのを見たい**
**そうすることで** レポートを第三者に共有する際に Tunny ブランドへの信頼感を伝えられる

**関連要件**: REQ-201, REQ-202, REQ-203, REQ-204, REQ-205, REQ-207

**詳細シナリオ**:
1. ユーザーが CSV/HTML エクスポートを実行する
2. ブラウザで開いた HTML レポートの見出しが gray-900 (#111827) で表示される
3. 本文テキストが gray-600 (#4B5563) で表示される
4. テーブル `th` が gray-100 (#F3F4F6) 背景・gray-200 (#E5E7EB) ボーダーで表示される
5. `.card` が border-radius 8px（rounded-lg）・gray-200 ボーダーで表示される
6. 散布図の Pareto 外の点が blue-500 (#3B82F6) で表示される

**前提条件**:
- スタンドアロン HTML（外部リソースなし）の制約を維持する

**優先度**: Must Have

### ストーリー 3.2: レポートへのブランドヘッダー追加 🟡

**信頼性**: 🟡 *TONMANUAL §4 ドキュメントヘッダーから妥当な推測*

**私は** Tunny Dashboard ユーザー **として**
**HTML レポートの先頭に Tunny ブランドの blue-300 (#93C5FD) ヘッダーバーが表示されているのを見たい**
**そうすることで** レポートが Tunny ツールから生成されたことを視覚的に示せる

**関連要件**: REQ-206

**詳細シナリオ**:
1. ユーザーが HTML レポートをブラウザで開く
2. ページ最上部に blue-300 (#93C5FD) 背景の Tunny ブランドバーが表示される
3. バー内に "Tunny Dashboard Report" のタイトルが gray-900 テキストで表示される

**優先度**: Should Have

**備考**: TONMANUAL §4 のドキュメントヘッダー構成から推測。レポートの第三者共有を考慮すると価値がある。
