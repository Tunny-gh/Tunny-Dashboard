### Q2: 適用スコープ

**質問日時**: 2026-05-25
**カテゴリ**: 未定義部分詳細化
**背景**: TONMANUAL.md は Twind CSS ベースの web UI を前提としており、Rust egui デスクトップ app への適用方法が自明でなかった。また HTML 出力が複数あるため（ヘルプ・エクスポートレポート）スコープを明確化する必要があった。

**回答**: 以下の 3 面すべてに適用する
1. egui テーマカラー（`ui_colors.rs`）
2. ヘルプ HTML スタイル（`build.rs` の `wrap_as_standalone_html`）
3. HTML エクスポートレポート（`html_report.rs`）

**信頼性への影響**:
- REQ-001〜REQ-019（egui テーマ）が 🔵 に確定
- REQ-101〜REQ-107（ヘルプ HTML）が 🔵 に確定
- REQ-201〜REQ-207（エクスポートレポート）が 🔵 に確定

### Q3: egui テーマへの適用方針

**質問日時**: 2026-05-25
**カテゴリ**: 既存設計確認
**背景**: TONMANUAL の Twind カラーを egui Color32 に変換する際、忠実変換（HEX 値そのまま）か、視認性を優先した微調整かで実装が変わる。特に `TOOLBAR_BG` が dark (#202124) から light blue (#BFDBFE) に変わる大きな変更について確認が必要だった。

**回答**: ブランドカラーに忠実に変換する

**信頼性への影響**:
- REQ-008（TOOLBAR_BG の dark→light 変更）が 🔵 に確定
- EDGE-001・EDGE-002（ツールバー文字色の追従）は 🟡 のまま（実装時に検証が必要）

## ヒアリング結果サマリー

### 確認できた事項

- 適用スコープ: egui テーマ・ヘルプ HTML・エクスポートレポートの全 3 面
- egui テーマは TONMANUAL の HEX 値に忠実にマッピングする
- ツールバーの dark → light 変更は意図的な仕様変更として受け入れる
- 詳細コード分析は不要（既存ファイルの確認情報で充足）

### 追加/変更要件

- TONMANUAL に存在しない egui 固有の色定数（`TOOLBAR_BTN_HOVER`・`TOOLBAR_BTN_FG`・`CELL_TOOLBAR_BG` 等）は TONMANUAL の精神に則った推測値を 🟡 として記載

### 残課題

- TOOLBAR_BTN_HOVER の具体的な調整値（実装時に視認性を確認しながら決定）
- `ACCENT_BLUE_MUTED` の最適な blue-200 への変更が選択ハイライトとして適切かどうかは実装後の視認性確認が必要
