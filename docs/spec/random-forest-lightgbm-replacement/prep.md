## 必須（実装開始前に完了が必要）

- [ ] **`lib_lightgbm.dll` の配置** 🔵 *ユーザヒアリング（DLL配置方針）より*
  - `lib_lightgbm.dll` を所定のフォルダに配置する（例: `libs/` またはシステムパス）
  - Windows の場合、対応するインポートライブラリ `lib_lightgbm.lib` も同フォルダに配置する
  - 配置したフォルダパスを実装担当者に伝える（`build.rs` に設定するため）
  - 関連要件: REQ-401

- [ ] **配置フォルダのパスを実装者に連絡** 🔵 *ユーザヒアリングより*
  - `lib_lightgbm.dll` を配置したフォルダの絶対パス（または相対パス）を伝える
  - `build.rs` または `.cargo/config.toml` に `cargo:rustc-link-search` を設定するために必要
  - 関連要件: REQ-401

## 推奨（実装中に用意できればOK）

- [ ] **LightGBM ライブラリのバージョン確認** 🟡 *lightgbm-rs バージョン互換性から推測*
  - 配置する `lib_lightgbm.dll` の LightGBM バージョン（v3.x / v4.x）を確認する
  - `lightgbm` クレートのバージョンと対応する LightGBM バージョンが一致している必要がある
  - 必要になるフェーズ: エピック1（依存関係追加）
  - 関連要件: REQ-001

## 確認事項（判断が必要）

- [ ] **`lib_lightgbm.dll` の配置場所の方針** 🟡 *DLL配置とビルド設定の関係から推測*
  - リポジトリに `libs/` ディレクトリを作って DLL を含めるか、システム PATH に追加するか、環境変数（`LIGHTGBM_LIB_DIR` 等）で指定するかを決定する
  - 選択によって `build.rs` の実装が異なる
  - 関連要件: REQ-401, NFR-201
