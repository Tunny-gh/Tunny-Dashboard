## REQ-101: 2D PDP — LightGBM RF モード 🔵

**信頼性**: 🔵 *ユーザヒアリング（スコープ①）より*

### Given
- 50行以上の学習データ（x_matrix, y）
- `n_grid = 20`

### When
- `compute_pdp_2d` を `model_type = "random_forest"` で呼び出す

### Then
- `n_grid × n_grid` の z_values グリッドが返る
- R² が `0.0` 以上の値で返る
- `uncertainties` は `None`（RF は不確実性を持たない）

### テストケース

#### 正常系

- [ ] **TC-101-01**: 2D PDP グリッド形状 🔵
  - **入力**: n=50 サンプル、n_grid=5
  - **期待結果**: `grid1.len() == 5`, `grid2.len() == 5`, `values.len() == 5`, `values[0].len() == 5`
  - **信頼性**: 🔵 *既存テスト `tc_1632_01_pdp_2d_rf_grid_shape` より*

- [ ] **TC-101-02**: R² が非負 🟡
  - **入力**: 線形な学習データ（y = x1 + x2）
  - **期待結果**: R² > 0.0
  - **信頼性**: 🟡 *RF の性質から妥当な推測*

#### 異常系

- [ ] **TC-101-E01**: 空データで None を返す 🔵
  - **入力**: x_matrix = [], y = []
  - **期待結果**: `None`
  - **信頼性**: 🔵 *既存テスト `tc_1632_02_pdp_2d_rf_empty` より*

## REQ-103: MDI — LightGBM feature_importance(Gain) 🔵

**信頼性**: 🔵 *ユーザヒアリング（スコープ③・MDI互換性許容）より*

### Given
- 有効な学習データ
- 複数の特徴量（パラメータ）

### When
- MDI 感度分析を実行する

### Then
- 各特徴量の重要度スコアが返る（Vec\<f64>、要素数 = 特徴量数）
- スコアの合計が > 0.0（何らかの重要度が検出される）
- `MdiNode` を使った旧実装に依存しない

### テストケース

#### 正常系

- [ ] **TC-103-01**: MDI スコアが正しい件数で返る 🔵
  - **入力**: 50サンプル、4特徴量
  - **期待結果**: 長さ4の Vec\<f64> が返る
  - **信頼性**: 🔵 *ヒアリングと MDI 出力形式より*

- [ ] **TC-103-02**: 重要な特徴量のスコアが高い 🟡
  - **入力**: y = x0 * 10 + noise（x0 が支配的）
  - **期待結果**: x0 のスコアが最大
  - **信頼性**: 🟡 *feature_importance の性質から妥当な推測*

#### 異常系

- [ ] **TC-103-E01**: 全スコアがゼロのときパニックしない 🟡
  - **入力**: y が定数（変動なし）
  - **期待結果**: ゼロ初期化されたスコアを返す（パニックなし）
  - **信頼性**: 🟡 *EDGE-002 から妥当な推測*
