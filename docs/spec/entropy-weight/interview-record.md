# Entropy Weight Method ヒアリング記録

**作成日**: 2026-04-24
**ヒアリング実施**: step4 既存情報ベースの差分ヒアリング

## ヒアリング目的

既存の MCDM 実装（TOPSIS/VIKOR）における重み管理の仕組みを確認し、エントロピー法による自動重み付けの要件を明確化するためのヒアリングを実施しました。

## 質問と回答

### Q1: エントロピー重みの適用範囲

**質問日時**: 2026-04-24
**カテゴリ**: 未定義部分詳細化
**背景**: エントロピー重みが手法ごとに独立か共通かで、UI設計とステート管理が大きく変わるため

**回答**: 全手法共通

**信頼性への影響**:
- この回答により、重み管理の UI は手法セレクタとは独立した Weight Mode として設計できることが確定（信頼性レベル: 🔵）
- ステート管理が単純化される（手法切替時に重みを再計算する必要がない）

---

### Q2: 計算結果の表示方法

**質問日時**: 2026-04-24
**カテゴリ**: 未定義部分詳細化
**背景**: エントロピー計算結果をどのようにUIに反映するかで、実装規模が変わるため

**回答**: 重みスライダーに自動反映 + エントロピー値のテーブル表示

**信頼性への影響**:
- この回答により、UI変更範囲が明確化: (1) Weight Mode トグル追加 (2) スライダー値の自動設定 (3) テーブルウィジェット追加（信頼性レベル: 🔵）
- REQ-003, REQ-004 の信頼性レベルが 🔵 に向上

---

### Q3: 正規化方式

**質問日時**: 2026-04-24
**カテゴリ**: 技術選択
**背景**: エントロピー法では複数の正規化方式が存在し、負の値の扱いが異なるため

**回答**: 比例正規化（推奨）

**信頼性への影響**:
- 比例正規化は非負データが前提のため、負の値を含む場合の前処理要件（REQ-104）を特定（信頼性レベル: 🟡）
- アルゴリズムの数学的定義が確定（信頼性レベル: 🔵）

---

### Q4: 既存コードベースの詳細分析

**質問日時**: 2026-04-24
**カテゴリ**: 既存設計確認
**背景**: 詳細なコード調査が要件定義の品質に影響するかを確認

**回答**: 不要

**信頼性への影響**:
- Explore agent による事前調査で十分なコンテキストを収集済みであることを確認
- 既存パターン（TOPSIS/VIKOR）からの類推で要件定義可能と判断

---

## ヒアリング結果サマリー

### 確認できた事項
- エントロピー重みは全MCDM手法で共通利用
- 計算結果はスライダーに自動反映 + テーブル表示
- 正規化方式は比例正規化（非負前提）
- 負の値を含む場合は前処理（min-max正規化）が必要

### 追加/変更要件
- REQ-104: 負の値に対する非負変換（比例正規化の制約により必要）

### 残課題
- なし（全主要項目が確認済み）
