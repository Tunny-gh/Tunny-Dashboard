## REQ-AHP-001〜008: アルゴリズム層

### REQ-AHP-005: 優先度ベクトル導出 🔵

**信頼性**: 🔵 _ユーザヒアリング・AHP アルゴリズム標準定義より_

#### Given（前提条件）

- n_objectives = 3、pairwise_matrix = [1, 3, 5, 1/3, 1, 3, 1/5, 1/3, 1]（行優先）
- is_minimize = [true, true, true]

#### When（実行条件）

- `compute_ahp` を呼び出す

#### Then（期待結果）

- `priority_vector` の長さが 3 である
- `priority_vector` の合計が 1.0 に近い（±0.001）
- 各要素が正の値である

#### テストケース

##### 正常系

- [ ] **TC-AHP-005-01**: 3×3 一対比較行列の優先度ベクトル導出 🔵
  - **入力**: A = [[1,3,5],[1/3,1,3],[1/5,1/3,1]]
  - **期待結果**: priority_vector ≈ [0.637, 0.258, 0.105]（列正規化→行平均）
  - **信頼性**: 🔵 _AHP 固有ベクトル近似法の標準計算_

- [ ] **TC-AHP-005-02**: 単位行列（全要素=1）の優先度ベクトル 🔵
  - **入力**: A = [[1,1,1],[1,1,1],[1,1,1]]（n=3）
  - **期待結果**: priority_vector = [1/3, 1/3, 1/3]（均等）
  - **信頼性**: 🔵 _全て同等の比較は均等重みになる_

- [ ] **TC-AHP-005-03**: n_objectives=1 の優先度ベクトル 🔵
  - **入力**: A = [1.0]、n_objectives=1
  - **期待結果**: priority_vector = [1.0]
  - **信頼性**: 🔵 _EDGE-AHP-001 より確定_

- [ ] **TC-AHP-005-04**: n_objectives=2 の優先度ベクトル 🔵
  - **入力**: A = [[1,3],[1/3,1]]
  - **期待結果**: priority_vector ≈ [0.75, 0.25]
  - **信頼性**: 🔵 _標準計算_

### REQ-AHP-007: スコア計算（加重和法） 🔵

**信頼性**: 🔵 _ユーザヒアリング（加重和法・Min-Max正規化）より_

#### テストケース

##### 正常系

- [ ] **TC-AHP-007-01**: 2 試行 2 目的（is_minimize=[true,true]）の正常計算 🔵
  - **入力**: values=[1.0, 3.0, 5.0, 2.0]（trial0=[1,3], trial1=[5,2]）、w=[0.75, 0.25]
  - **期待結果**: trial0 の正規化値≈[1.0, 0.0]、スコア≈0.75。trial1 の正規化値≈[0.0, 1.0]、スコア≈0.25
  - **信頼性**: 🔵 _Min-Max正規化 + 加重和法の直接計算_

- [ ] **TC-AHP-007-02**: is_minimize=[false,false]（最大化）の正規化方向 🔵
  - **入力**: values=[1.0, 3.0, 5.0, 2.0]（trial0=[1,3], trial1=[5,2]）、w=[0.5, 0.5]、is_minimize=[false,false]
  - **期待結果**: trial1 がより高いスコアを持つ（f1=5 > f1=1、f2=2 < f2=3 で差し引き）
  - **信頼性**: 🔵 _最大化方向の正規化ロジックより_

##### 境界値

- [ ] **TC-AHP-007-B01**: 全試行が同一目的関数値（max_j == min_j）🔵
  - **入力**: values=[3.0, 3.0, 3.0, 3.0]（全目的値が同じ）
  - **期待結果**: 全 normalized = 0.0、全スコア = 0.0、正常終了
  - **信頼性**: 🔵 _REQ-AHP-007-C 除算回避より確定_

- [ ] **TC-AHP-007-B02**: NaN 試行を含む場合 🔵
  - **入力**: trial0=[1.0, NaN]、trial1=[3.0, 2.0]
  - **期待結果**: trial0 の scores = 0.0、trial1 は正常計算、trial0 は ranked_indices 末尾
  - **信頼性**: 🔵 _REQ-AHP-007-E, REQ-AHP-008-B より確定_
