## エピック1: 実行不可能解のグレーアウト表示

### ストーリー 1.1: 制約付き最適化結果の可視化 🔵

**信頼性**: 🔵 *ユーザヒアリング 2026-06-03 より*

**私は** 制約付き最適化を実施した研究者 **として**
**制約条件を満たさない trial をプロット上で視覚的に区別したい**
**そうすることで** 実行可能解のみに注目して最適解の評価ができる

**関連要件**: REQ-CAV-001, REQ-CAV-010, REQ-CAV-011, REQ-CAV-012, REQ-CAV-013

**詳細シナリオ**:
1. ユーザーが制約付き最適化の journal ファイルを読み込む
2. Study 選択後、Pareto 散布図が表示される
3. 実行不可能解（constraints に > 0 の値を持つ trial）がグレー半透明で表示される
4. 実行可能解は通常の色分け（Pareto ランクなど）で表示される

**前提条件**:
- journal ファイルに `system_attrs.constraints` が記録されている trial が存在する
- `StudyMeta.has_constraints == true` である

**制約事項**:
- `has_constraints = false` の Study では全 trial を通常表示し、グレーアウトは適用しない

**優先度**: Must Have

---

### ストーリー 1.2: 制約なし Study での変化なし 🔵

**信頼性**: 🔵 *REQ-CAV-012 / 既存実装より*

**私は** 制約なし最適化の研究者 **として**
**制約機能を有効化した後も既存の表示が変わらないことを確認したい**
**そうすることで** 制約機能追加による既存ユーザーへの影響がないことを保証できる

**関連要件**: REQ-CAV-012, EDGE-CAV-021

**詳細シナリオ**:
1. 制約なしの journal ファイルを読み込む
2. Study 選択後、全 trial が従来通りの色分けで表示される
3. "Show Infeasible" トグルは表示されない

**優先度**: Must Have

## エピック2: Show Infeasible トグル

### ストーリー 2.1: チャートごとに実行不可能解を非表示にする 🔵

**信頼性**: 🔵 *ユーザヒアリング「各チャートのツールバーで個別対応」より*

**私は** 制約付き最適化の研究者 **として**
**実行不可能解を非表示にして実行可能解のみのプロットを確認したい**
**そうすることで** 実行可能解の分布・Pareto フロントをクリアに把握できる

**関連要件**: REQ-CAV-020, REQ-CAV-021, REQ-CAV-022, REQ-CAV-023

**詳細シナリオ**:
1. 制約付き Study のチャートが表示されている
2. チャートのツールバーに "Show Infeasible" チェックボックスが表示される
3. チェックボックスを外すと、実行不可能解の点が即座に非表示になる
4. 再度チェックすると即座に表示される

**前提条件**:
- `StudyMeta.has_constraints == true`

**優先度**: Must Have

---

### ストーリー 2.2: 各チャートが独立したトグル状態を持つ 🔵

**信頼性**: 🔵 *ユーザヒアリング「各チャートのツールバーで個別対応」より*

**私は** 複数チャートを同時に表示している研究者 **として**
**一方のチャートで実行不可能解を非表示にしても他方のチャートに影響しないことを求める**
**そうすることで** チャートを目的に応じて柔軟に使い分けられる

**関連要件**: REQ-CAV-040, REQ-CAV-060, REQ-CAV-070, REQ-CAV-080, REQ-CAV-090

**詳細シナリオ**:
1. Pareto 散布図と並行座標を同時に表示
2. Pareto 散布図の "Show Infeasible" をオフにする
3. 並行座標には影響がなく、実行不可能解が引き続き表示される

**優先度**: Must Have

## エピック3: Pareto ランク計算からの除外

### ストーリー 3.1: 実行不可能解を除いた Pareto フロントの確認 🔵

**信頼性**: 🔵 *ユーザヒアリング「Pareto 計算から除外」より*

**私は** 制約付き多目的最適化の研究者 **として**
**実行可能解のみで構成された Pareto フロントを確認したい**
**そうすることで** 実際に運用可能な解の中で最も優れた組み合わせを特定できる

**関連要件**: REQ-CAV-030, REQ-CAV-031, REQ-CAV-032, REQ-CAV-033

**詳細シナリオ**:
1. 制約付き最適化 journal を読み込む
2. Pareto ランク計算時、実行不可能解は除外される
3. Pareto 散布図では実行可能解のみが Pareto フロントとしてハイライトされる
4. 実行不可能解はグレーアウトで表示され、Pareto ランクが割り当てられない

**前提条件**:
- `StudyMeta.has_constraints == true`
- 実行可能解が1件以上存在する

**優先度**: Must Have
